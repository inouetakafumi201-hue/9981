## 需求陈述

### R001: 碰撞箱注册系统
**When** 实体 spawn 时  
**the system shall** 自动注册圆形碰撞箱  
**so that** 寻路算法可以检测碰撞

**验收标准**:
- 碰撞箱圆心 = 贴图最下方几何中心
- 碰撞箱半径 = 组件宽度的一半的 80%
- 可动性分类正确（movable-actor / movable-entity / immovable-actor / immovable-entity）
- 车辆可动性随驾驶状态动态变化

### R002: 可通行域预运算
**When** 对局启动时  
**the system shall** 在 Web Worker 中预运算可通行域  
**so that** 移动命令可以判定是否可通行

**验收标准**:
- 可通行域栅格化（cellSize = 16px）
- 标记物理遮挡为不可通行
- 标记静止碰撞箱为不可通行
- 预运算不阻塞主线程

### R003: 段1 可通行判定
**When** 玩家选择移动目标  
**the system shall** 判定该目标是否可通行  
**so that** 不可通行的动作变灰并提示

**验收标准**:
- 不可通行时动作变灰 + 提示"因阻塞无法执行"
- 使用 Bresenham 直线算法检查路径
- 判定时间 < 5ms

### R004: A* 点对点寻路
**When** 玩家提交移动意图且段1 判定可通行  
**the system shall** 用 A* 算法计算路径点数组  
**so that** 活体可以绕开静态障碍物

**验收标准**:
- 使用 `pathfinding` 库的 A* 实现
- 标记动态碰撞箱为不可通行
- 允许对角线移动，但不允许跨角
- 寻路时间 < 10ms
- 失败时返回 null 并提示"路径被阻挡"

### R005: ORCA 实时避障
**When** A* 给出粗略路径点  
**the system shall** 用 ORCA 算法平滑避开动态活体  
**so that** 活体移动时不穿模、不怪异

**验收标准**:
- 优先使用 `rvo2-js` 库实现
- 每帧计算时间 < 5ms
- 超时时降级为直线位移
- 传染式连锁：挤到可动碰撞箱 → 纳入 ORCA

### R006: 恢复对峙算法
**When** 任何行为扰动微型场景  
**the system shall** 触发该场景的恢复对峙  
**so that** 活体向中心收敛、不重叠

**验收标准**:
- 原位就可站 → 不移动（no-op 出口）
- 向心移位：沿"当前位置 → 中心"方向试探前行
- 被卡兜底：向多个方向微位移找合法可站位
- 收敛时间 < 16ms
- 超时时回滚到上一稳定态

### R007: 传染式连锁
**When** 恢复对峙过程中挤到其他微型场景的可动碰撞箱  
**the system shall** 触发该场景的恢复对峙  
**so that** 连锁调整、最终收敛

**验收标准**:
- 单向传染（防止回路）
- 最多 10 层传染（超过强制终止）
- 连锁动画串行播放

### R008: 泛光圈动态
**When** 微型场景实体数变化  
**the system shall** 调整泛光圈半径  
**so that** 泛光圈视觉反映实体数

**验收标准**:
- 半径 = baseRadius + entityCount * radiusPerEntity
- 半径变化平滑过渡（CSS transition 0.3s）
- 泛光圈重叠时触发传染式 ORCA
- 可交互时高亮（brightness 1.2）

### R009: 移动动画
**When** `after:entity.place` 事件触发  
**the system shall** 播放跳跃式位移动画  
**so that** 移动看起来自然

**验收标准**:
- 跳跃曲线（Y 先上升 20px 再下降）
- 落地压缩（scaleY 0.9 → 1）+ 尘土扬起（3-5 个灰色粒子）
- 重物移动：低矮跳跃（高度降低 60%）
- 迟缓移动：拖曳感（slower ease）
- 快步跳移动：更高更快（高度 +100%、时长 -30%）

### R010: 三动画攻击模型
**When** `after:attack` 事件触发  
**the system shall** 播放三段动画  
**so that** 攻击看起来有冲击感

**验收标准**:
- ① 快步跳移动到目标面前（停在前方 20px）
- ② 攻击 + 受击（前倾 + 红色闪烁 + 后退）
- ③ 恢复对峙（向中心收敛）
- 三段动画串行执行

### R011: 朝向系统
**When** 特定事件触发（攻击、被攻击、新玩家进入）  
**the system shall** 改变活体朝向  
**so that** 朝向符合视觉常识

**验收标准**:
- 单一左右朝向维度（CSS scaleX -1 / 1）
- 攻击后目标转向攻击者
- 新玩家进入时随机 1-3 人转向
- 恢复对峙不改朝向
- 翻面动画 0.1 秒

### R012: 不可动实体归位
**When** 行动轮结束且检测到不可动实体漂移  
**the system shall** 归位到最近同天然场景微型场景点  
**so that** 无人车不会离它的点太远

**验收标准**:
- 漂移阈值 100px
- 归位到最近同天然场景点
- 平滑归位动画 0.5 秒
- 只在行动轮结束时触发

### R013: 性能监控与降级
**When** 算法执行时间超过阈值  
**the system shall** 降级为简化实现  
**so that** 不阻塞渲染帧

**验收标准**:
- ORCA 超时（> 5ms）→ 直线位移
- 恢复对峙超时（> 16ms）→ 回滚到上一稳定态
- A* 寻路超时（> 10ms）→ 返回"路径被阻挡"
- 同屏活体 > 20 → 渲染剔除远处

### R014: 可访问性支持
**When** 用户开启 reduced motion  
**the system shall** 简化动画  
**so that** 不引起眩晕

**验收标准**:
- 动画时长缩短 70%
- 移除跳跃曲线（改为直线位移）
- 移除粒子效果
- 移除余辉拖尾
- 保留颜色变化、不透明度变化
