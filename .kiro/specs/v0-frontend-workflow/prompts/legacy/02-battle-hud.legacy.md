# V0.dev 投喂 Prompt · batch-2：battle HUD

## 1. Project Positioning

本项目是一个「WakeUp前端」UI 壳层：用一套声明式 React 界面，把整个游戏的 UI 表面全部做出来（对局 HUD、驻地、叙事对话框、过渡屏、系统通知、控制面板、次面板），供开发期演示、抽取与后续接线。**本壳层只表达视觉与交互手感，不实现任何玩法规则。**

本批次交付对局 HUD 主屏（`hud-main`）：以既有草图为布局基线，把轮次栏、动作面板、投点面板与全部固定组件按文字描述呈现出来，并挂载到 batch-1 的壳层路由上。

## 2. Scope List

**In scope（本批次）：**
- `hud-main` 全部要素：轮次栏、回合指示器、动作面板（付费 + 零费）、投点面板（骰子 + 强力骰滑块 + 逆转滑块 + 结算行）、固定组件（buff 区/状态区/弱点图标/AP 徽标/物品栏槽位/负重提示/退出+设置入口）、三个 HUD 变体（standard / solo / minimal）。
- 投点面板的爆发档位选择特效与触发特效（档位冻结为 0/1/2）。

**Out of scope（本批次及全项目）：**
- 画布层游戏内容（地图、节点、实体、ORCA、寻路、路径成本）——本批次只做 HUD 壳层，地图区域用纯占位底板。
- `editor` / `research-bench` / `material-library` / `computer` 内部界面。
- 玩法规则结算（AP 扣除、伤害、目标选择、投点结果）。

## 4. Technical Constraints

- 技术栈：React + TypeScript；动效 Framer Motion；图标 lucide-react；可访问 Radix；跨组件状态 Zustand；音效 Howler（本批次可留音频槽）。
- 基准 1920×1080，最小 1280×720。
- 语义色 token：红=生命/伤害/致命；蓝=清醒/体力/科技；黄=感官/警戒；橙=AP/行动；绿=安全/免费；紫=关系约束/远程/条件；珊瑚=近战/格斗；青=社交/UGC；灰=冷却/不可点击；灰白=可交互但受状态限制；纯白/奶白=梦境边界/过载；金/银=品级高光。
- 交互语法：可交互=边缘发光+高光+材质；不可交互=扁平无高光。
- 像素前景 + 全息投影背景叠层观感；HUD 面板半透明。
- 离散柱状资源：生命 5 格红、清醒 5 格蓝、AP 几格橙，分段小方块，不是细长连续条。

- 页面 id：`hud-main`；变体 id：`standard` / `solo` / `minimal`；状态 id：`投点阶段` / `行动阶段` / `目标选择` / `结算` / `AP耗尽倒计时` / `空手进场`。

- 组件名与上述 id 保持一致。

## 6. Interaction Rules

### 6.1 轮次栏（左侧常驻）

- 每个轮次 = 独立轮次框：排名 + 头像 + 名字 + 生命红 5 格 + 清醒蓝 5 格。
- 当前行动者反光高亮；玩家自己的框更宽更粗约一个骰子宽度；已行动者整行降饱和。
- 骰子图标是悬空图标：只在统一投点/某行动投点时于轮次栏右侧出现，平时不出现。
- 投完从骰子右侧伸出横条，多人并排成横向条状对比；按行动轮排名实时重排（列表重排动效）。

### 6.2 回合指示器（顶部细条）

- `回合 N｜阶段｜当前行动方`；轮到时 `⚡ 你的回合！ 剩余 AP: n`；NPC 阶段 `NPC 行动阶段｜僵尸移动中…`。

### 6.3 动作面板（右下）

- 付费面板：`可用动作（剩余AP: 2）` 纵向列表，动作行 = 图标 + 文字；**行右侧不显示 AP 成本数字**；不足 AP 项扁平灰。
- 右上「切到零费」按钮；零费面板与付费面板互斥显示，0 AP 卡标绿色免费语义。
- AP 耗尽态：自动切零费菜单 + 3s 倒计时条 + 「结束回合」键（结束回合按钮点击=占位视觉，不提交规则）。
- 空手进场：无付费动作，直接零费 + 结束回合。

### 6.4 投点面板（就地，非独立弹窗）

- 骰子 🎲 + [投掷] 按钮 + 强力骰滑块（橙）+ 逆转滑块（紫）+ 结算结果行（投点→AP→排名），在轮次栏状态条旁就地播放。
- 滑块是**离散推挡**：MVP 只开放 `0 / 1 / 2` 三档。
- **爆发档位冻结条款**：
  1. `+3极限爆发` 不作为可选档位出现；如有预留视觉位，必须标为不可选（置灰/扁平）。
  2. 选择特效（selection effect）必须实现：档位推动时充能感递增——0=静置灰白；1=轻微充能光晕；2=粒子残影+色浓度升。
  3. 触发特效（trigger effect）必须实现：确认投掷时爆闪 + 一次性粒子爆发，随后进入横条生长演出。
  4. 档位越高，特效越重，让玩家一眼看出激进程度。
- 横条三段式生长：①灰白伸出 ②强力骰玩家快速伸长 + 右侧 +1/+2 角标 ③统一从左侧刷色（0灰/1绿/2橙/3红），强力骰多出段泛红。
- 横条带格状刻度、无上限框；结算行「玩家 A：🎲4(+2)=6→2AP」。

### 6.5 固定组件（只作展示，不写玩法逻辑）

- `fixed-buff-zone`：玩家框资源柱下方/状态栏右侧；图标 + 剩余回合角标；正面绿/负面红边；多层横向堆叠。
- `fixed-status-zone`：头像旁；状态图标；正面=绿、冷却=灰、约束=紫、损害=红；招架无任何标识。
- `fixed-weakness-icon`：实体头顶常驻小图标（本批次用占位像素块），悬停显示克制说明 tooltip。
- `fixed-ap-badge`：橙色 ◆ 徽标 + 计数；耗尽时降饱和。
- `fixed-inventory-slots`：2 手 + 2 格，出生空手全空；图标位像素小件占位。
- `fixed-encumbrance-tag`：`⚠️ [重装] 大场景移动+1AP` + 来源名；黄/橙告警语义。
- `fixed-leave-entry`：左上角退出 + 设置入口。

### 6.6 通用规则

- 五态：hover / focus / active / disabled / return 全部实现。
- placeholder-only：所有交互只改变呈现，不结算规则。
- mock 数据：假玩家、假 AP、假状态一律标 `mock`。
- 变体：standard（完整轮次栏）/ solo（顶部单行，只显自己）/ minimal（轮次栏折叠为角落小图标）。

## 7. Explicit Exclusions

- ❌ 不做地图画布、节点、拓扑、实体移动、ORCA、寻路、路径成本。
- ❌ 不结算投点、不扣除 AP/HP/SP、不选择目标、不提交动作。
- ❌ 不做编辑器/研究台/素材库/电脑界面。
- ❌ 不做 `+3极限爆发` 可选档位。
- ❌ 不引入第 4 节之外的新依赖。
