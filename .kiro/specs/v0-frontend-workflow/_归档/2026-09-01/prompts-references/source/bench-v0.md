# WakeUp 研究台 · v0.dev 完整需求文档

> **目标**：为 v0.dev 提供完整的功能需求、交互逻辑、布局设计、视觉规范，生成研究台（素材级工作台）前端壳层。
> **技术栈**：React 18 + TypeScript + Tailwind CSS，桌面端 1920×1080 优先。可根据审美和质感任意发挥，不要有限制。

## 一、项目定位

### 什么是这个研究台

这是一个**内嵌在独立游戏里的素材级工作台**，玩家从出租屋驻地的「研究台」进入。它是「把你攒的材料变成你的作品」的地方，面向**绝大多数玩家**（不只是硬核创作者）：

- **词条库（材料收集库）**：收集词条、看收集进度、星标、拖拽取用
- **锻造工作台**：改枪式 5 槽（属性/技能/状态/防御/机动），把词条盖到基体素材上
- **合成仪式**：投料 → 全屏仪式演出 → 收下成品（或软裁决失败）
- **塑形备选栏**：把要带进对局的素材拖入 5 格

**最终角色**：创作工作流的「加工厂」——素材库找到材料 → 研究台变成作品 → 塑形栏带进对局。

### 不是什么

- ❌ 不是网页应用、SaaS 后台、工程软件、属性编辑器
- ❌ 不是地图编辑器（造梦舱才是，本界面不做地图）
- ❌ 不是电脑（账号级元状态：套餐/活动/证据提交在电脑）
- ❌ 不是 LLM 对话工具（玩家零输入，LLM 是后台守门人）

### 核心设计理念

1. **游戏化、仪式感**：质感是「改枪工作台 + 材料收集册」，不是工具感三栏（那是地图编辑器）。合成有仪式演出（郑重交付，不是抽卡开箱）。
2. **底图感**：锻造槽位可能预先印有默认词条（素材自带），拖新词条是「盖上去」。只替换、不删除——把词条拖回词条库/快捷栏 = 默认值自动恢复（像底图弹回来）。
3. **每类槽位 1 个词条**：五大类固定 5 槽，不能双重强化。玩家不用学「这个素材有什么槽」，永远是「5 大类，每类 1 个词条」。
4. **软裁决不惩罚**：合成失败 = 成品变灰 + 解释面板 + 材料返还（驳回），或降级保底（输出不合法）。失败不是爆炸/惩罚感。
5. **同屏一个主动作焦点**：锻造、合成、塑形不堆叠（低心智约束）。
6. **音效生成风格统一**：交互的音效具有全息科技游戏感，同时具有一定像素游戏风味。和其他两个UI界面风格统一。。

### 参考风格

- 像素 + 全息投影的独立游戏 UI 质感，游戏化的材料工作台（改枪工作台 + 收集册的实体感），暖灯出租屋氛围。
- 明确**不参考**：现代 SaaS / 工程软件属性面板 / 暗黑科技终端。
- 与素材库（书架，检索清爽）**气质必须拉开**：本界面是仪式感、材料感。

## 二、视觉风格与色彩规范

### 2.1 画风基线

**像素 + 全息投影叠加**（对齐地图编辑器全息游戏风）：
- 交互组件/词条卡/素材图标 = 高饱和像素艺术（32×32 或 64×64）
- 背景 = 工作台意象以全息投影方式浮现——台面、木纹、工具剪影、暖灯做成半透明暖光光层，微微泛光、轻微闪烁，不是手绘简笔画
- UI 面板 = 半透明深色浮层，让底下的台面氛围透出来一点

**平面 2D**：
- UI 平面布局，无 3D 透视、无 isometric
- 素材/词条图标沿用正面俯视视图的剪影语言（平面轮廓 + 落地阴影）

**游戏化、仪式感**：
- 合成仪式全屏演出（发光的锻造门 → 3 个台子 → 高光爆发）
- 克制暗调略冷 + 暖灯，主功能色 ≤3-4
- 不是黑色科技终端（不要霓虹扫描线、金属栅格）

### 2.2 颜色语义（必须遵守）

| 颜色 | 色值 | 用途 |
|---|---|---|
| **青 social** | `#06b6d4` | 唯一高饱和主操作：W 徽标、分区切换、回素材库、可拖拽素材悬停发光、合成门/能量流 |
| **金/银** | `#d4af37` / `#a8b2bd` | 品级高光（词条卡品质 4-5 描边、合成物） |
| **橙 action** | `#dd6b20` | 进行中/消耗：锻造槽位有词条、合成进度、塑形栏状态 |
| **黄 alert** | `#d69e2e` | 星标 |
| **红 damage** | `#e53e3e` | 合成失败解释边界色、非法拖拽红闪（不做惩罚感） |
| **绿 safe** | `#38a169` | 收集完成/解锁格亮起 |
| **灰白** | `#f3f4f6` | 可交互但受制于状态：UGC 灰显、未解锁塑形格 |
| **墨 ink** | `#0d1824` | 最深背景 |
| **灰 muted** | `#627383` | 次要文字（简介小字、收集时间） |
| **暗边** | `#2a3a44` | 分隔线 |

**品质色**（词条卡/素材描边）：灰白 1 / 绿 2 / 蓝 3 / 银 4 / 金 5——只作高光描边，不构成严格评级阶梯。

**五大类标签色**（词条库）：属性 / 技能 / 状态 / 防御 / 机动——每类一个小语义色系标签（可用品质色的近似区分，或用图标区分；与全局颜色语义不冲突即可）。

**边缘发光规则**：
- 可交互 = 边缘发光（悬停白/青，激活青）
- 不可交互 = 扁平灰色、无高光（UGC 灰显、未解锁塑形格 = 扁平灰 + 锁图标）
- 拖拽拒绝 = 落点红闪

## 四、逐区功能需求

### 4.1 顶栏（工作台头）

**左段**：40×40 青色方块徽标，内白色字母 W，边缘发光；两行标题（粗「WakeUp 研究台」+ 小字暗「素材级工作台 · 材料工作台」）。

**中段**：分区切换 **词条库 / 锻造台**（当前项青色底发光；切换时对应视图淡入淡出）。

**右段**：**回素材库**小按钮（青色描边，与素材详情页「去研究台锻造」对偶）。

### 4.2 词条库（材料收集册 · 左栏面板）

- **五大类标签页**：`属性` / `技能` / `状态` / `防御` / `机动`，每类一个小语义色系标签，当前类亮起。词条是「从素材里抽出来的材料」，收集本身是玩法。
- 每类顶部：**收集进度**（如「5 / 22 已收集」）。
- **卡牌网格**：
  - **已收集**（owned:true）：词条卡亮起——像素图标 + 名称 + **品质色描边**（灰白/绿/蓝/银/金）+ 简介小字（机制话术）+ 收集时间。
  - **未收集**：灰暗剪影 + 中央「？」占位——能看到「这格是什么」的轮廓（名称可读或半隐），但拿不到。像收集册里没集齐的格子。
- 词条卡交互：
  - **点击** → 词条详情（来源 / 可贴宿主 / 可提取素材 / 品质）。
  - **星标**（黄）→ 词条库排序/快速取用标记（研究台无词条快捷栏，2026-08-19 定案）。
  - **拖拽源** → 直接拖进中央锻造槽位（盖上去）。

### 4.3 锻造工作台（改枪式 5 槽 · 中央）

**基体**：当前锻造素材（来自拥有库），大像素图标 + 名称。可以从素材库自动装载（全屏切换带过来）。

**槽位（五大类，固定 5 个）**：`[属性] [技能] [状态] [防御] [机动]`，每槽 1 个词条，不能双重强化。

- **底图感**：槽位可能预先印有默认词条（素材自带），像一张底图上印好的字；拖新词条进来 = 盖上去。
- **只替换、不删除**：没有「清空槽位」操作。拖新词条进已占用槽 = 替换；把词条**拖回词条库/快捷栏** = 默认值自动恢复（像底图弹回来）。
- **空槽**（素材本来就没这个词条）：灰「+」占位，可拖入一个词条填充；一旦填充，之后只能替换、不能变回空（除非拖回恢复默认）。
- **拖拽非法落点**（限免素材等）：落点红闪 + 拒绝提示。
- **UGC 素材**（青角标）：在快捷栏中灰显不可拖，悬停提示「UGC 素材请到研究台处理」——但在研究台内部可以正常拖入锻造（这就是处理它的地方）。

**右侧组合预览**：当前槽位组合的**词条语义清单**——每个已挂载词条一行「名称 + 机制话术简介」（如「烈焰：造成火焰伤害，对易燃目标额外效果」），空槽显示「未挂载」。强调「你正在设计的是什么样的机制」。**不设火力/射程/机动强度条**——不模仿普通改枪界面的数值强度（那会削弱对自主设计机制的强调，2026-08-19 定案）。

**底部动作按钮排**（从左到右）：
- **提取**（暗钮，点击进入提取流程）：玩家选一个拥有素材 → 聚焦某个可提取属性（打词条标签的属性）→ 确认提取 → **烧掉该素材（不可逆）** → 得词条（纯语义文本 + 品质 1-5）→ 词条进入对应大类下亮起。**提取演出**：素材溶解（像素崩解）→ 词条浮现（品质色光效）。
- **保存** / **派生**（锻造结果处理，07 §6.4.7）：改动过的素材（`modified:true` 角标）可**保存**（覆盖自身）或**派生**（新 ID + 溯源），二选一确认。
- **合成**（青色主按钮）：点击 → 全屏覆盖层合成仪式（§4.4）。

### 4.4 合成仪式（全屏覆盖层）

**合成 ≠ 抽卡**：合成是「你的改进智慧组合出来的作品，品质是未知数」，不是开箱赌博。仪式感承担「郑重交付」的体验。

**流程**：

```
1. 玩家在锻造工作台确认槽位组合（基体 + 词条，最多 5）
2. 投料：基体 + 词条全部消耗（不可逆）
3. 点击「合成」→ 全屏跳进「高科技锻造入口」（贴图场景，不是弹窗）
   ├─ 入口 = 一扇发光的锻造门/闸口（梦境科技质感）
   └─ 点击入口组件 → 进入「3 个台子」的合成 UI
4. 合成进行（覆盖 LLM 真实消耗时长 60-120秒，是特效的集中爆发地，需要有很强的特效功力，把组件做出立体重量感和“正在科研加工”。绝不能让人感觉是轻飘飘的特效。）：
   ├─ 组件悬浮上下摆动
   ├─ 时而突然高速旋转（带运动模糊）
   ├─ 时而粒子效果缓缓划过（电焊火花/能量流，可多设计几种，随机交替播放。）
   └─ 3 个台子各司其职（左侧材料熔炼 / 中央主锻造 / 右侧铭刻）
5. 完成：高光爆发 + 成品浮现 → 点击成品弹面板 → 下方「收下」+ **「绘制贴图」**（品级色描边小按钮）
   ├─ 「收下」→ 成品入拥有库，合成完成
   ├─ 「绘制贴图」→ 自动**收下**（成品入拥有库）并**切到素材库**、选中该成品、**自动调出像素绘制器**（`docs/v0-dev-pixel-painter-spec.md`），让玩家立刻在成品上追加绘制（底图 = 刚合成的成品贴图）
   └─ 绘制器保存后回到素材库该成品详情（或按绘制器 onSave 关闭回原界面，二选一由接线定，但必须已选中该成品）
6. 失败/驳回（LLM 判定语义不相容/输出不合法）：
   ├─ 成品变灰（不是爆炸/惩罚感）
   ├─ 点开面板 → 填充解释逻辑（「这个组合差点意思」「材料之间不太合」）
   ├─ 点击「确定」→ 所有素材和词条返还（驳回）；或降级到品级 1 保底模板（输出不合法）
```


**演出纪律**：
- 动画是规则结果的视觉重演，不改变结算、不提交状态、不泄露 LLM 细节。
- 粒子/全屏只承担仪式感，关键结果（品质/成败）必须靠图标/文字/面板承载。
- 合成结果（成品/失败）由动作通道返回，前端**不得**本地随机生成。

### 4.5 塑形备选栏（底部）

- 科技感**独立长条框**，横贯锻造界面最下方，**固定 5 格**。
- **解锁状态**：部分格子随主线/套餐解锁。解锁格 = 亮，可拖入素材；未解锁格 = 扁平灰 + 锁图标，不可交互。
- **用途**：把要带进对局的素材拖入备选栏。局内「塑形」从备选栏取用（第三环消耗，塑形成功失去成品——机制后端管，本界面只负责配置）。
- **拖入替换**：拖新素材到已占用的格子 = 替换，无删除操作（与锻造槽位同哲学）。
- 限免素材不可拖入（数据层拒绝 + 交互层红闪）。

### 4.6 素材快捷栏（右栏 · 与素材库/编辑器共享同一份）

- **数据共享**：与地图编辑器、素材库是**同一份** `quickBar.materialSlots`——在素材库/研究台配置的 7 格，切回编辑器立即生效（07 §10.1）。
- **7 格**（未展开，只有图标，悬停浮出名称/类别/角标）+ **展开 7×10** 全素材库矩阵（类别筛选 + 搜索，与素材库共用同一套筛选语义）。
- **研究台用途**：拖素材到塑形备选栏配置、换锻造基体、把常用素材置顶待用。
- **研究台没有词条快捷栏**（2026-08-19 定案）：词条从左侧词条库直接拖入锻造槽位（拖拽距离近，不设第二套词条容器）。

## 五、组件层级与状态管理

### 5.1 组件树（预期结构，命名规范见 5.3）

```
<BenchApp>（全屏根容器；挂载三界面切换回调）
  ├─ <BenchTopBar>
  │    ├─ <WBadge>（青发光方块徽标 W + 两行标题）
  │    ├─ <SectionTabs>（词条库 / 锻造台 分区切换）
  │    └─ <SwitchToLibraryButton>（回素材库）
  ├─ <TokenLibraryPanel>（左栏 · 材料收集册）
  │    ├─ <CategoryTabs>（属性/技能/状态/防御/机动 五类标签）
  │    ├─ <CollectProgress>（每类顶部收集进度，如 5/22 已收集）
```

## 九、风险与兜底

### 9.1 已知冲突

- **冲突 1**：V0 可能把合成结果做成前端随机/动画假结果。
  - 处置：合成结果由动作通道返回（LLM 裁决 + 品级公式），前端只做演出与展示；演出阶段机不产生任何数据。
- **冲突 2**：V0 可能发明「清空槽位」按钮（违背底图感 = 只替换）。
  - 处置：明确不做（§十）；「恢复默认」的唯一动作是把词条拖回词条库/快捷栏。
- **冲突 3**：V0 可能把词条库当成仓库（展示拥有量管理主界面）。
  - 处置：词条库是「材料收集册」（收集进度 + 未收集剪影 + 拖拽源），不做批量整理/删除。
- **冲突 4**：V0 可能加入玩家文本输入（描述想要什么）。
  - 处置：合成台 LLM 零输入（防提示词攻击），本界面没有任何给玩家描述需求的文本框。
- **冲突 5**：V0 可能按旧认知加「词条快捷栏」或改枪式强度数值栏。
  - 处置：明确不做（§十）：研究台没有词条快捷栏（词条从词条库直拖），没有火力/射程强度条（用组合预览展示词条语义）。
- **冲突 6**：V0 可能把「绘制贴图」做成研究台内部实现、或不在收下后自动跳素材库打开。
  - 处置：绘制贴图 = 独立解耦的像素绘制器（`docs/v0-dev-pixel-painter-spec.md`）；合成完成点「绘制贴图」→ 自动收下 → 切到素材库选中该成品 → 自动打开绘制器（D-085 流程，§4.4）。

### 9.2 技术债登记

- **债务 1**：提取聚焦属性需要白名单数据（后端/运营增量），未提供时提取按钮禁用并标注「待白名单」。
- **债务 2**：合成「加急」消耗数值后端未定，界面先做按钮 + 置顶动画，消耗提示用占位。
- **债务 3**：词条卡/素材图标用 lucide 占位；真实素材待 sprite-forge 组件管线产出后替换（记入占位素材清单）。
- **债务 4**：V0 若用原生 `<select>` 做类别筛选，需替换为 Radix 组件。
