# V0.dev 投喂 Prompt · batch-4：模态与悬浮面板（暂停菜单 / 叙事对话框 / 系统通知 / 次面板）

## 1. Project Positioning

本项目是一个「WakeUp前端」UI 壳层：用一套声明式 React 界面，把整个游戏的 UI 表面全部做出来（标题画面、对局 HUD、驻地、叙事对话框、过渡屏、系统通知、控制面板、次面板），供开发期演示、抽取与后续接线。**本壳层只表达视觉与交互手感，不实现任何玩法规则。**

本批次交付模态与悬浮面板家族：暂停菜单（`menu-pause`）、叙事对话框（`dialog-line` / `dialog-options`）、系统通知（`notice-broadcast` / `notice-toast`）、四个次面板（`utility-settings` / `utility-inventory` / `utility-safe` / `utility-match`）。它们都是覆盖在游戏之上的浮层，共享同一层级与动效约束。

## 2. Scope List

**In scope（本批次）：**
- `menu-pause`：暂停菜单（继续 / 设置 / 重新开始 / 返回标题；设置复用五脏俱全面板）。
- `dialog-line`：P5 风格单句对话框（立绘区 + 名字栏 + 文本区 + 打字机 + 点击继续 + 降级无立绘变体）。
- `dialog-options`：选项对话框（最多 4 个垂直选项 + 快捷键 + 悬停/选中动效）。
- `notice-broadcast`：公告/活动横幅（电视呈现，被动显示）。
- `notice-toast`：系统提示/错误反馈 toast（info / error 语义）。
- `utility-settings`：设置悬浮面板（五脏俱全，与 batch-3 共用）。
- `utility-inventory`：背包/物品栏（4/6 格槽位 + 拖拽交换 + 右键快捷菜单）。
- `utility-safe`：保险箱收藏室（高价值/纪念对象陈列）。
- `utility-match`：匹配状态/影子大厅（匹配中 / 已就绪 / 影子在场）。

**Out of scope（本批次及全项目）：**
- 对话框背后的规则触发（选项结算、任务给予）——只做呈现与占位。
- 保险箱/背包的真实物品数据与效果。
- `editor` / `research-bench` / `material-library` / `computer` 内部界面。
- 地图节点/拓扑/ORCA/寻路/路径成本/玩法规则。

## 4. Technical Constraints

- 技术栈：React + TypeScript；动效 Framer Motion；图标 lucide-react；可访问 Radix（对话框/下拉/tooltip/context-menu）；状态 Zustand；音效 Howler（留音频槽）。
- 基准 1920×1080，最小 1280×720。
- 语义色 token：红/蓝/黄/橙/绿/紫/珊瑚/青/灰/灰白/纯白/金/银（同全局语义）。
- P5 风格约束：强烈的偏移变换（skewX 斜切 + 滑入/滑出 + 弹性），对话框浮在立绘之上（立绘可被遮挡，属正常层次）。
- 面板视觉：半透明暗调，边缘发光表达可交互。

### 4.1 反网页感硬门禁（不可妥协）

- 这些组件是叠在正在运行的游戏世界上的表现层，不是网页 modal、设置页、消息中心或卡片式后台。不得生成浏览器 chrome、SaaS 侧栏、白底表单、标准 dashboard 卡片墙或网页滚动条。
- 暂停菜单必须冻结/降饱和当前世界后从空间中浮现；继续时恢复同一画面。不要把暂停做成一张居中的普通对话框盖住一个空背景。
- 对话框必须像一段正在发生的舞台演出：立绘、名字栏、斜切主体、文本和焦点有前后层级；选项从对话框附近生长，不是四个等宽网页按钮。
- toast、公告、保险箱、背包和匹配状态必须依附于触发位置或世界层级；只显示必要信息，不把所有次面板同时铺成应用窗口。
- 面板使用半透明、多层高光、断边/斜切/局部阴影和语义色边缘光；禁止所有面板统一圆角、统一边框、统一内边距的默认组件模板。
- 动效必须表达对象的来源、方向和落点：立绘滑入、对话框斜切、选项重排、toast 堆叠、背包拖拽和匹配影子出现都要保持空间连续性。使用 Framer Motion 的 `AnimatePresence`、`layout`、spring 和声明式序列，不用 CSS 线性淡入淡出充数。
- 先保留游戏世界的环境/实体/事件层，再叠加模态层。隐藏全部文字后，画面仍应像游戏演出，不像一组网页组件。

### 4.2 交付前视觉验收

- [ ] 暂停菜单是“世界被冻结后浮现”，不是普通居中弹窗。
- [ ] 对话框、选项、toast 和次面板没有重复的 SaaS 卡片模板或表单感。
- [ ] 每个浮层都能看出触发来源、空间层级和退出落点；打开/关闭不造成整页重载感。
- [ ] 立绘/像素前景、全息背景和浮层材质仍然分层可见；网页 chrome、滚动条和工程属性面板不存在。

## 6. Interaction Rules

### 6.0 暂停菜单（menu-pause）

- 对局中暂停触发；入口：`继续`（resume）/ `设置`（settings）/ `重新开始`（restart）/ `返回标题`（quit-to-title）。
- 打开 = 当前画面降饱和冻结 + 暂停菜单浮层浮现（轮廓显影 + 半透明暗调）。
- `继续`：浮层淡出，画面恢复。
- `设置`：展开五脏俱全设置面板（六个选项卡 mock 可调）。
- `重新开始`：确认态（确认 = 占位，重新开始当前对局视觉）。
- `返回标题`：确认态（确认 = 淡出回 `menu-title`）。
- 快捷键：Esc 暂停/继续；↑/↓ 切换项；Enter 确认。
- 五态、placeholder-only、mock 标注照常。

### 6.1 单句对话框（dialog-line）

- 布局：左侧立绘区（320×480 固定视觉遮挡空间）+ 右侧对话框主体（名字栏黑底白字红斜条装饰 + 文本区半透明黑底白字）。
- 出现动画（0.6s）：立绘从左滑入（ease-out-back）；对话框主体右下斜切滑入（translateX 50%→0 + skewX -5deg→0 + opacity 0→1）；名字栏红斜条扫过；文本打字机逐字显示。
- 消失动画（0.4s）：主体向右上斜切滑出；立绘向左滑出。
- 切换说话人：立绘淡出左移 50px → 新立绘淡入；名字栏红斜条重扫；文本切换。
- 打字机：20 字符/秒（可配置），点击跳过打字机直接显示全文。
- 定时 vs 不定时：不定时 = 右下「点击继续」提示，点击进下句；定时 = 文本完成后右下 3s 倒计时条，倒计时结束自动推进，点击可跳过倒计时（定时本体不可整段跳过）。
- 整段跳过：不定时对话框按住 Ctrl/Space 可整段淡出跳过（0.2s）。
- 无立绘变体（no-portrait）：仅对话框 + 名字栏，无左侧图像（降级检索第 4 步）。
- 快捷键：↑/↓ 切换、Enter 确认、1-4 数字键选选项、Esc 关闭。

### 6.2 选项对话框（dialog-options）

- 选项在对话框下方悬浮按钮，最多 4 个，垂直排列；样式 = 黑底白字 + 红色左边框（4px）+ 序号。
- 悬停：按钮右移 10px + 红左边框加粗（→8px）+ 背景微亮。
- 点击：按钮白色高光闪烁 0.1s → 右滑淡出（0.3s）→ 其他选项同时淡出 → 对话框主体淡出。
- 选项选择结果 = 占位（不接任务/不结算）。

### 6.3 公告/活动横幅（notice-broadcast）

- 被动显示横幅：标题 + 摘要 + 展开/关闭；announcement（公告）与 event（活动）两态语义色区分。
- 不承载玩法推进；展开为可读详情（mock 文本）。

### 6.4 系统提示/错误反馈（notice-toast）

- info：中性/青色语义；error：红语义；出现 → 自动消失（可堆叠）。
- 空状态提示与错误提示都可演示。

### 6.5 设置（utility-settings）

- 悬浮面板：选项卡切换（显示/声音/输入/无障碍/语言/图形，全部 mock 可调）；关闭回到触发位置（Radix 焦点归还）。

### 6.6 背包/物品栏（utility-inventory）

- 4/6 格槽位；出生空手全空（mock 一两件示例物品可切换）。
- 拖拽交换（非法落点回原位 + 提示）；右键快捷菜单（使用/丢弃/检查，占位）。

### 6.7 保险箱收藏室（utility-safe）

- 高价值/纪念对象陈列（mock 图标 + 名称）；选中显示详情占位；关闭回到驻地。

### 6.8 匹配状态/影子大厅（utility-match）

- 匹配中（异步，可继续活动提示）→ 已就绪 → 影子在场（半透明影子占位，mock）。
- 不重载场景，仅悬浮状态呈现。

### 6.9 通用规则

- 五态：hover / focus / active / disabled / return 全部实现。
- placeholder-only：选项、按钮、开关只改变呈现。
- mock 标注：全部内容数据标 `mock`。

## 7. Explicit Exclusions

- ❌ 选项不接任务/声望/结算；对话框不触发规则。
- ❌ 不做编辑器/素材库/研究台/电脑内部界面。
- ❌ 不做地图节点/拓扑/ORCA/寻路/路径成本。
- ❌ 不引入第 4 节之外的新依赖。

## 8. Batch Objective
