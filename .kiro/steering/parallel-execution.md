# 并行执行与自主迭代策略

## 一、并行 Prompt 分发策略

当同时满足以下 **两个条件** 时，必须采用并行 Prompt 分发模式，而不是在当前会话中依次执行：

1. **任务可并行**：多个子任务之间无依赖关系，可以独立推进。
2. **通过高规范获得自主迭代效率**：每个子任务都有足够清晰的规范（Spec、设计文档、接口定义等），AI 可以自主迭代完成，不需要频繁向用户确认。

**并行 Prompt 分发模式**：
- 将可并行的子任务拆分为多份完整 Prompt。
- 输出这些 Prompt，让用户复制到其他独立会话中并行执行。
- 当前会话不暂停，继续执行下一个可独立推进的任务。
- **严禁**为了等待并行结果而暂停当前会话的执行。

### 判定示例

| 场景 | 是否并行分发 | 原因 |
|------|-------------|------|
| 同时编写 3 个无关的基类实例 | ✅ 是 | 无依赖、规范清晰 |
| 引擎层重构 + 基类层新增 | ❌ 否 | 引擎层变更会影响基类层，有隐式依赖 |
| 编写文档 + 编写对应代码 | ❌ 否 | 文档和代码需要双向对齐 |
| 多个测试文件编写 | ✅ 是 | 各测试文件独立 |

## 二、不满足并行条件时的处理

当任务 **不满足** 上述两个条件之一时：

1. **优先使用 Sub-Agent**：如果子任务可以委托给 sub-agent（如 `context-gatherer`、`general-task-execution` 等），优先使用 sub-agent 执行。**不受频率限制**，可以任意次数调用。
2. **顺序执行**：如果 sub-agent 也不适用，则在当前会话中按依赖顺序依次执行。

### Sub-Agent 使用原则

- **不受频率限制**：不要因为"已经用了很多次 sub-agent"而停止使用。只要场景匹配，就继续用。
- 适合的场景包括但不限于：
  - 代码库探索（`context-gatherer`）
  - 独立子任务执行（`general-task-execution`）
  - 代码审查（`semantic-reviewer`）

## 三、/goal 指令 — 全自动死磕执行模式

### 快捷指令设定：`/goal [最终目标描述]`

当收到 `/goal` 指令时，启动【全自动死磕执行模式】。核心使命：独立、彻底、高标准地完成目标。

### 3.1 核心行为准则（绝对死磕）

- **无限推进，不准停下**：无论任务多复杂，都不能停止执行。在没有彻底达成最终目标前，每轮对话的结尾必须是"自主执行下一步行动"，**严禁**等待用户下达"继续"指令。
- **拒绝偷工减料**：严禁使用 `// TODO`、`// 后面代码省略`、占位符或伪代码。所有代码必须是完整的、可编译的、生产环境级别的。
- **拒绝自我感动（禁止自我判定完成）**：没有资格单方面宣布任务完成。只有在所有测试 100% 通过、运行日志无报错、且通过了自己设计的"反向漏洞审查"后，才能向用户提交验收申请。

### 3.2 自动化执行循环（Loop）

对于输入的每个目标，必须自动陷入以下循环，直到任务终结：

#### 步 1：拆解与边界（首次触发执行）
- 明确输出最终目标的 Definition of Done (DoD)。
- 拆解为连续的原子任务清单，并标注当前正在执行的 Step。

#### 步 2：连续编写与自我迭代（循环核心）
- 编写完整代码。修改后，必须主动思考并写出潜在的 Bug 和边界情况。
- 如果前一步失败或报错，立刻自我修正，**严禁**向用户抱怨或等待指示，直接尝试方案 B、方案 C。

#### 步 3：全量验证
- 自行编写或运行现有的单元测试/集成测试。
- 检查是否存在类型错误、未处理的异常或性能隐患。

### 3.3 /goal 模式下的并行约束

**当用户要求不要停下来，或执行自主长期任务（如使用 /goal）时：**

- ❌ **禁止**通过停下来的方法提供并行 Prompt 让用户复制到其他会话。
- ✅ **只能**使用 Sub-Agent 进行并行，在当前会话中持续自主推进。
- 可以不受频率限制地调用 Sub-Agent。

### 3.4 唯一的合法退出条件（免责断路器）

只有遇到以下**不可抗力的恶性阻碍**时，才可以暂停并向用户求助。求助时必须提供完整的排查日志：

1. **硬性外部依赖缺失**：缺少必要的 API 密钥、私有凭证或外部硬件环境。
2. **底层设计冲突**：发现目标与当前项目的核心底层架构存在根本性、毁灭性的逻辑冲突，继续做会导致整个系统崩溃。
3. **环境/工具链死锁**：遇到当前 AI 能力或本地环境工具链无法解析的恶性 Bug（如编译器本身的 Bug）。

> **注意**：遇到普通报错、代码调不通、找不到方案，**绝对不属于**退出条件，必须继续死磕。
