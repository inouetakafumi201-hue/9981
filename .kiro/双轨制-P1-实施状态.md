## 二、已知缺口（待后续裁决）

### 缺口 1：UiActionView.track 切池未在 BattleHud 落地

- 现状：`useRealActions` 暴露了 `cardActions` 和 `highlightActions` 两路；
- BattleHud 内的 `paidCards` 当前从 `cardActions` 过滤（`costCategory === 'paid'`），没有按 `track === 'highlight'` 单独出层；
- 影响：高亮轨动作（未来在地图上点击实体触发）目前**没有专用容器**，会被一并塞到主牌组
- 修复方向：HudWorld 新增 `<HighlightRailContainer>`，按 `track === 'highlight'` 渲染

### 缺口 2：HighLight 轨（地图实体点击）完全没有前端落地

- 现状：V0 `bh-world` 硬编码 `railUnits` mock；真实 `entities` 没接入
- 修复方向：B6 旅程接线（待 V0 补全）

### 缺口 3：CardPresentation `effectText` 是静态字符串

- 现状：CardPresentationDef 的 effectText 直接写死文本（"移动至相邻节点"）
- 期望：未来通过 Expr 动态求值（已留 `effectText: string` 类型）
- 修复方向：玩法层 expression 工具落定后改 `effectText` 类型为 Expr，ui-adapter 负责求值

### 缺口 4：0费主动技能（0费池内容）尚未注册任何 Def

- 现状：切到 0费池显示"暂无可用 0费主动技能"
- 影响：按钮就绪但池是空的
- 修复方向：P1-A2 专门做 0费 skill Def 设计

### 缺口 5：V0 端 `cardPresentation` 路径未真走

- 现状：core-mechanics `paidAction` 加了 `cardPresentation: 'cp:xxx'` 字段
- ui-adapter.ts 把 `track` 透传，但 `cardPresentation`（L2 ResolvedCardPresentation）字段是 `undefined`（注册表里没有 CardPresentationDef 的 L2 family contract）
- 修复方向：L2 ActionFamilyContract 增加 `cardPresentation` 字段（双轨制 P2 阶段）

### 缺口 6：双轨制 L1/L2 ↔ L3 路由缺

- 现状：`track: 'highlight'` 的 action 在 L3 没有专门的"地图点击 → 触发"路径
- L3 现在把 highlight 轨当作普通 action（用 1 AP 发起），但高亮轨的语义是"鼠标移到地图实体 → 自动浮现，不消耗 AP"
- 修复方向：双轨制 P3 阶段

## 三、未变动的设计（备查）

- **L0 1-5 宪法**：所有数值字段守 1-5，CardPresentation 字段不在此约束（Presentation 字段是 Internal_Metric 或 enum）
- **L0 第十三条 表现系统正交域**：表现层不改写规则事实——双轨制所有新增（track / cardPresentation / ResolvedCardPresentation）都是 UI 投影字段，不进 Op 写入通道
- **L0 第十四条 装载等价**：官方 TS 包与 UGC JSON 包共享同一装载入口；CardPresentationDef 通过 playpack.defs 注册到 DefRegistry，跨装载等价
