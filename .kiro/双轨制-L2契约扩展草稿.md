## 1. ActionDef 层（基类层 + 玩法层）

```ts
// src/core/kernel/actions/types.ts
export type ActionTrack = 'highlight' | 'card';
export interface ActionDef extends Def {
  // ...现有字段...
  readonly track: ActionTrack;          // 必填，新增
  readonly cardPresentation?: Id;        // 可选，指向 CardPresentationDef
}
```

- `track` 是权威判定，**不靠 require 推断**。
- `track: 'highlight'`：不进入卡片列表，只作为"地图上可直接点实体"的轨道。
- `track: 'card'`：进入 `CardData[]` 投影。
- `cardPresentation` 可缺省——缺省 = 用默认模板（图标=action.assetRefs[0]，颜色=costCategory 派生）。

## 2. 卡片元数据（基类层新概念）

```ts
// 新文件 src/core/kernel/actions/card-presentation.ts
export interface CardPresentationDef extends Def {
  readonly kind: 'card-presentation';
  readonly icon: AssetRef;             // 必填，注册过的图标
  readonly colorTheme: ColorTheme;     // 必填，闭合枚举
  readonly effectText: Expr;           // 必填，运行时求值
  readonly interactionMode: 'instant' | 'toggle' | 'target';
}
```

- `CardPresentationDef` 是**新 Def 类型**，与 ActionDef 并列，存于同一 DefRegistry。
- 它的字段**纯为前端渲染服务**——不进入引擎层逻辑，不影响 L0 1-5 数值铁律。
- `effectText` 是 Expr，求值后得到一段人类可读的效果说明。

## 3. L2 ActionDescriptor 层（投影）

```ts
// src/l2/model/projection.ts
export interface ActionDescriptor {
  // ...现有字段...
  readonly track: ActionTrack;                         // 从 ActionDef 透传
  readonly cardPresentation?: ResolvedCardPresentation; // 已求值的卡片元数据
}

export interface ResolvedCardPresentation {
  readonly icon: AssetRef;
  readonly colorTheme: ColorTheme;
  readonly effectText: string;   // Expr 已求值
  readonly interactionMode: 'instant' | 'toggle' | 'target';
}
```

- `ResolvedCardPresentation` 在投影阶段（`l2/adapters/ui-adapter.ts`）从 `CardPresentationDef.effectText` 求值得到。
- `descriptor-validator.ts` 需要白名单加这两个字段。
- `InteractionIntent`（4 值）与 `interactionMode` 协同：

| interactionMode | 对应 interactionIntent |
|---|---|
| `instant` | `traversal` / `precise-interaction` |
| `toggle` | `precise-interaction` |
| `target` | `hostile-interaction` / `executable-target` |

## 4. UiActionView 层（前端）

```ts
// src/ui/model/view.ts
export interface UiActionView {
  // ...现有字段...
  readonly track: ActionTrack;                          // 透传
  readonly cardPresentation?: UiCardPresentation;       // 已安全化的卡片元数据
}

export interface UiCardPresentation {
  readonly iconRef: string;          // 已注册路径
  readonly colorTheme: ColorTheme;
  readonly effectText: string;       // 不可用时降级为 unavailabilityText
  readonly interactionMode: 'instant' | 'toggle' | 'target';
}
```

- 前端拿到 `UiActionView` 后，按 `track` 切两个池：`highlightPool` / `cardPool`。
- 卡片池交给发牌器渲染（动画/位置/选择）。
- 高亮池交给地图高亮组件。

## 5. 发牌时机（纯前端）

- **玩法层不设计触发时机**——`UiView.actions` 永远是当前状态的全量合法动作投影。
- "重发"是纯前端渲染概念：前端订阅 `UiView` 变更 → 计算差集 → 执行"新卡插入/旧卡退出"动画。
- 已记录为成熟问题，归 V0 前端工作（用户原话）。
