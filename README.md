# 《起床》(WakeUp) - 离散策略游戏引擎

> 将童年的石头剪刀布叙事游戏，转化为零门槛UGC的数字策略游戏

## 🎯 项目概述

《起床》是一个基于极简离散系统的策略游戏引擎，核心特点：

- **数值≤5约束**：所有玩家可见数值严格限制在1-5
- **五并列原则**：任何选择不超过5个选项
- **自然语言UGC**：通过LLM将创意转化为游戏规则
- **完全信息对称**：无隐藏属性，纯策略博弈

## 💡 核心创新

### 1. 数值≤5约束
防止数值膨胀，逼迫创作者用机制组合而非堆数字来实现创意

```
❌ 错误："造成999伤害的核弹"
✅ 正确："造成3伤害 + 辐射状态(每回合1伤害，持续5回合) + 影响相邻节点"
```

### 2. 五并列原则
严格限制每个节点的连接数和选项数量，保持可推演性

```
微型场景：最多3个连接
中型场景：最多4个连接
大型场景：最多5个连接
```

### 3. 自然语言UGC
通过LLM降低创作门槛到零

```
玩家："我想做一个香蕉皮，踩到会摔倒"
  ↓
LLM理解并追问边界
  ↓
生成JSON规则
  ↓
自动验证和测试
  ↓
注入游戏，AI自动适配
```

## 📊 关键数据

### 投点概率（3人局）
| 获得AP | 概率 | 说明 |
|--------|------|------|
| 3 AP | ~14% | 大胜爆发 |
| 2 AP | ~28% | 中等优势 |
| 1 AP | ~32% | 最常见 |
| 0 AP | ~26% | 掉队（体力退回）|

### 数值约束表
| 项目 | 范围 | 违规后果 |
|------|------|----------|
| 生命值 | 1-5 | 静态验证失败 |
| 伤害 | 1-5 | 静态验证失败 |
| AP成本 | 1-5 | 静态验证失败 |
| 状态持续 | 1-5 | 静态验证失败 |
| 节点连接 | 1-5 | 拓扑Linter报错 |

## 🎮 游戏特色

- ✨ **完全信息对称**：无隐藏数值，无手牌，无迷雾
- ✨ **回合制策略**：像下棋一样推演和计算
- ✨ **零费动作智能**：不产生搜索分支的0 AP操作
- ✨ **通用AI**：自动适配所有UGC内容
- ✨ **极简美术**：2D扁平风格，UGC友好

## 🛠️ 技术栈（推荐）

- **前端**：TypeScript + React + Canvas 2D
- **后端**：Node.js + WebSocket + PostgreSQL
- **AI/LLM**：OpenAI API / Claude API
- **部署**：云服务 + CDN

详见[开发路线图](docs/09_开发路线图.md)
