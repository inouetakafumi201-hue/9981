## 目标
补上开发板编辑器缺失的三块核心图元交互，让地图真正可以「改图闭环」——不是修 UI 审美，而是补上编辑内核能力。全部落在 `src/devboard/`，不碰 `src/play/map/**` 契约（障碍/锚点等字段已存在于 MapEdge/ObstructionSpec，devboard 只消费；过渡窗口/高地/洼地走 devboard 编辑态 + 导出投射）。

## 三个缺口对应的工作

### 1. 拉边能拖拽（§九 拉边流程）
现在是「点 A → 点 B 建一条 2 点直线」。改成真正的拖拽描线：
- `edge` 模式下指针在**节点上按下** → 开始描线（记录起点节点 + 捕获指针），拖动时实时采集采样点、预览折线。
- 拖动中在另一节点吸附半径（`SNAP_TOLERANCE` / `findSnapTarget`）内 → 该节点亮蓝（合法终点）。
- 在节点上**松手** → 采样点经 `simplifyPath`（RDP）压成折点 → `addEdge` 建带 `path` 的边（首尾精确吸附节点中心）。
- 在空白处松手 → 整条丢弃 + 红色一闪（§九 设计过的行为）。
- 状态机：`edge` 模式内用 `edgeDraft: { from, points[] }` 存草稿，Esc/换工具清空。松手决策用 `findSnapTarget`，其余时刻采样点永不吸附（§九：只有松手吸附）。

### 2. 拉出曲线 / 样条塑形（§九 拉线后的塑形）
在选中边上做「按住线段外拖 → 追加隐藏样条点 → 松手定型」：
- 画布渲染边缘时，若选中，把 `path`（折点数组）用 Catmull-Rom 样条画出平滑曲线（工程实现在 `curve.ts` 已有的 `insertControlPoint` + 新加一个折线→样条采样辅助）。
- 选中边，按住线段主体外拖 → 在落点 `insertControlPoint` 追加一个隐藏样条点（松手定型；拖多少次塞多少，无上限）。
- 双击线段 → 清空该线段内隐藏样条点、拍直回直线（唯一重塑入口）。
- 不加控制柄状态机（§九 三态合一最小动作集）；不新增 moveOf（路径折点不可逐点拖）。

### 3. 「框」补齐（§八 图元穷举 D-074）
当前只有圆点 + 直线 + 素材方块，把缺失的图元渲染 + 可编辑补上，颜色严格映射视觉语义：
- **场景框**：把节点从「圆点」改为「带虚线描边的场景框」（矩形，随 scale 变化：大/中/小不同尺寸），并支持框内放置其他图元（叠加语义）。这是「框 vs 点」的核心（框才可吸附）。
- **视觉遮挡框**（黄半透明）与 **物理遮挡框**（红半透明，醒目+不可通行）：在选中边上通过检查器/工具栏绘制，落进 `MapEdge.visualObstruction` / `MapEdge.physicalObstruction`（ObstructionSpec，shape box）。画布按框渲染；支持阴影选中、Delete 删除、滚轮旋转（框 translate + 框内 path 显示）。
- **高地框（深绿）/ 洼地框（浅绿）**：`MapEdge.semanticAnchor: 'high' | 'low'` 的框可视化；勾选即可标为高地/洼地，端点边显示。
- **过渡窗口**：在选中边上加「过渡窗口」开关，落进 `MapEdge.transitionWindow`（TransitionWindowPoints.control）；画布在过渡点画一个非节点悬浮组件。

## 工具 / 边界
- 全部用既有依赖（React/SVG/`curve.ts`），不新增库。
- 不碰 `src/play/map/**`（障碍/锚点字段已存在，devboard 只消费）。
- 校验由既有 `validateMapStructure` 即时驱动，错误不阻止保存只提示（§九 校验反馈）。
- 为新的编辑纯函数补 PBT + 模拟用例（沿用前述 37 测模式），跑 devboard build / vitest / eslint 回归。

## 交付判断
浏览器里能：进 `edge` 模式按住一个场景框拖到另一个框建边（松手吸附、空白丢弃红闪）、选中边按住外拖拉出曲线、双击拉直线、选中边画/删视觉或物理遮挡框、打高地/洼地框、开关过渡窗口——全部即时结构校验。实现按「拉边拖拽 → 曲线塑形 → 框图元」顺序推进，每步回归门禁。
