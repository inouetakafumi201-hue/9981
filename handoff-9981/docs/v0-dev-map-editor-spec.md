> **目标**：为 v0.dev 提供完整的功能需求、交互逻辑、布局设计、视觉规范，生成地图编辑器前端。

## 一、项目定位

### 什么是这个编辑器

这是一个**内嵌在独立游戏里的梦境地图编辑器**。玩家从出租屋驻地的「筑梦工作台」进入，用**涂鸦式交互**构建回合制战术游戏的地图：
- 拖框画场景（大教室/中走廊/小卧铺）
- 拉线连通道（样条曲线，可拉弯）
- 标注遮挡（视觉遮挡黄色、物理遮挡红色）
- 标注地形（高地深绿、洼地浅绿）
- 放置过渡窗口（橙色菱形）
- 拖入素材（储物柜/灯/椅子等）

**最终产出**：`MapData` JSON 文件，供游戏引擎读取。

### 不是什么

- ❌ 不是网页应用、SaaS 后台、浏览器工具
- ❌ 不是 Photoshop 式专业工具（4 角控制点拖拽、复杂图层系统）
- ❌ 不是素材管理 App 或资产库

### 核心设计理念

1. **涂鸦式交互**：所有矩形/线用同一种方式——拖拽创建、整体选中（阴影提起）、整体删除/旋转，不逐控制点微调。
2. **指哪打哪**：连线用 Catmull-Rom 样条，绝对穿过手绘的每个必经点，不是贝塞尔控制点在外拉。
3. **极简模式**：只有 5 个模式（选择/放置场景/拉边/取样/测试），Esc 永远回到选择模式。
4. **双击空白不创建节点**：误创建是第一号烦人事，创建必须按 N 或右键菜单。
5. **错误不阻止保存**：只阻止发布，避免半成品丢失。
6. **必须有撤销/重做**：让所有破坏性操作变安全。

## 二、视觉风格与色彩规范

### 2.1 画风基线

**像素风 + 简笔画叠加**：
- 交互组件（按钮/工具/素材图标）= 高饱和像素艺术（32×32 或 64×64）
- 地图背景 = 低饱和简笔画（粗笔触、手绘感）
- UI 面板 = 半透明深色浮层，让底下的梦境剪影透出来一点

**正面俯视 2D**：
- 所有地图元素从正上方查看
- 用平面轮廓、落地阴影表达，无 3D 透视
- 禁止：isometric、oblique、three-quarter 等斜视角

**克制暗调略冷**：
- 主功能色 ≤3–4 个（青/黄/红为主），其余灰阶
- 整体暗色调，不是鲜艳卡通
- 不是黑色科技终端（不要霓虹扫描线、金属栅格）

### 4.3.1 场景框 vs 高光点（核心图元区分）

**这是 v0 上次漏掉的最关键图元，必须明确：**

#### 场景框（Scene Box）

- **是什么**：玩家涂鸦拖出的矩形框，代表地图上的一个「天然场景」或「微型场景」边界
- **数量**：一个场景可以由**多个重叠的场景框**聚合而成（涂鸦式合并）
- **视觉**：淡青色虚线矩形，半透明淡底，圆角，内部显示场景名 + 尺度字母（L/M/S）
- **交互**：
  - **左键单击** = 选中整个场景（所有成员框一起高亮）
  - **左键拖拽空白** = 框选（不是拖拽单个框）
  - **左键拖拽选中框** = 移动整个场景（聚合的所有框一起移动）
  - **滚轮** = 整体旋转 10°/格
  - **Delete** = 删除整个场景
  - **双击** = 聚焦该场景（镜头飞过去）
  - **悬停** = 白色边缘发光
- **为什么不能直接拖出连线**：因为场景框只是「边界」，不是「锚点」。连线起点/终点是**高光点**。

#### 高光点（Highlight Point）

- **是什么**：一个场景（多个场景框聚合）的**最大距离矩形中心点**，作为连线拖出的锚点
- **数量**：**一个场景 = 一个高光点**（自动计算，不允许手动创建）
- **位置**：所有成员场景框的外接矩形中心点（自动跟随场景移动/聚合）
- **视觉**：青色发光小圆点（半径 4-6px），带柔和光晕，比场景框小很多但视觉权重高
- **交互**：
  - **左键单击** = 选中整个场景（同点击场景框效果）
  - **左键拖拽** = **进入「拉边」流程**（即使不在 DrawEdge 模式）：从此高光点开始描线，到目标高光点松手建边
  - **左键按住不动**（悬停 1 秒）= 显示该场景的详细属性浮层（名称/尺度/楼层/包含素材等）
  - **悬停** = 强青色发光（比场景框更亮），提示「这是拖线起点」
- **为什么必须区分**：
  - 场景框 = 「边界涂鸦」，人画什么就是什么
  - 高光点 = 「逻辑锚点」，AI 读图时只看这个点连线
  - 一个场景框集群太大，玩家自己都不知道中心在哪——系统自动算出「最大距离矩形中心」避免人为误差
  - 大场景（L）的高光点与场景的连接上限 5 是同一个数（小 3/中 4）

#### 涂鸦式合并规则（v0 上次完全漏掉）

**多个同类型矩形涂鸦重叠 = 自动合并为一个图形**，边界消失：

| 规则 | 行为 |
|---|---|
| **场景框重叠** | 同类型重叠 → 合并为一个场景，高光点自动重算到新外接矩形中心 |
| **视觉遮挡重叠** | 多个黄框重叠 → 合并为一个黄框，边界消失 |
| **物理遮挡重叠** | 多个红框重叠 → 合并为一个红框，边界消失 |
| **地形框重叠** | 同类型重叠 → 合并（高地+高地 / 洼地+洼地） |
| **不同类型** | 不合并（如场景框+遮挡框重叠，各自保持） |
| **选中聚合图形** | 点击任一成员框 = 选中整个聚合（阴影高亮覆盖所有成员） |
| **删除聚合** | Delete = 删除全部成员框 |

#### 空洞全填（仅场景框）

- **触发**：场景框围成一个封闭区域（如 4 个矩形围出矩形空洞）
- **视觉**：空洞区域被半透明青色「油漆桶」填充（看起来像一个连续的场景）
- **逻辑**：空洞区域视为场景的一部分，**不可在其中放置新场景节点**
- **存储**：仍是多个独立矩形，**不用虚假矩形填补空洞**
- **为什么必须**：跨场景寻路依赖场景外框的连续闭合边缘，空洞会破坏寻路交点定位

#### 粘连判定（拒绝跨场景连接）

- **触发**：一次场景框拖拽/创建**同时碰到两个已有不同场景**
- **行为**：**整个拖拽操作被拒绝**，蓝框拖出后松手 = 消失 + 淡出提示「不能跨场景连接」
- **为什么**：如果允许，会出现两个不同场景被同一个新框「粘」在一起，破坏场景边界

#### 同类图元旋转

- 所有矩形图元（场景框/遮挡框/地形框）选中后，**滚轮 = 10°/格旋转**
- 旋转围绕**聚合外接矩形中心**，不是单个框中心
- 旋转角度显示在检查器中

## 五、核心交互逻辑

### 5.1 模式系统

5 个互斥模式，按快捷键切换，Esc 永远回到 Select：

| 模式 | 快捷键 | 功能 |
|---|---|---|
| Select | V / Esc | 默认模式：选择/移动/框选 |
| PlaceNode | N | 放置场景框 |
| DrawEdge | E | 拉边连线 |
| Sample | I 或 Alt | 取样（复制已有元素配置） |
| Playtest | P | 试玩模式（游戏运行预览） |

### 5.2 Select 模式交互

| 鼠标操作 | 目标 | 行为 |
|---|---|---|
| 单击空白 | — | 清空选择 |
| 单击元素 | 场景框/连线/遮挡/素材 | 选中（黄光） |
| 拖拽空白 | — | 框选（青色虚线框） |
| 拖拽元素 | 已选中的元素 | 移动 |
| 双击空白 | — | **不创建**（避免误操作） |
| 双击场景框 | — | 聚焦（镜头飞到该元素） |
| 双击连线 | 选中的连线 | 插入新折点 |
| 双击拉弯的线段 | — | 拍直（清空该段隐藏样条点） |
| 右键空白 | — | 画布右键菜单 |
| 右键元素 | — | 元素右键菜单（删除/复制/属性） |
| 悬停 | 可交互元素 | 白色边缘发光 |
| Delete | 选中的元素 | 删除 |

### 5.3 PlaceNode 模式（放置场景框）

1. 按 N 进入模式
2. 鼠标变为十字光标 + 小场景框预览
3. 在画布拖拽：
   - 按下：记录起点
   - 拖动：实时预览矩形（青色虚线）
   - 松手：创建场景框
4. 创建后自动切回 Select 模式（或保持 PlaceNode 连续创建）
5. 按 Esc 退出模式

### 5.4 DrawEdge 模式（拉边）

**拉边流程**：
1. 按 E 进入模式
2. 悬停场景框：高亮蓝光（合法起点）
3. 在场景框上按下：开始描线
4. 拖动鼠标：实时预览折线（蓝色虚线），记录所有原始轨迹点
5. 进入其他场景框吸附半径：目标场景框亮蓝光
6. 在目标场景框上松手：
   - 端点精确吸附到两个场景框中心
   - RDP 简化轨迹点为折点
   - 创建连线
7. 在空白松手：整条丢弃 + 红闪提示
8. 保持 E 模式可连续拉边，Esc 退出

**拉线后的塑形（样条编辑）**：
- 选中一条连线后，显示所有折点（白圆点 + 橙描边）
- **拉伸建线**：拖拽末端折点延伸新线段
- **折点调整**：拖拽中间折点改变位置
- **拉弯塑形**：按住线段主体往外拖 → 在落点追加隐藏样条点 → 样条穿过它（Fire-and-Forget，不可二次编辑隐藏点）
- **双击线段**：拍直（清空该段全部隐藏样条点）
- **删除折点**：选中折点按 Delete，或拖至邻近折点触发融合删除
- **吸附删除**：拖某折点距邻折点 <10px → 高亮提示 → 松手删除

**关键规则**：
- 只有松手点吸附，中间点永不吸附（避免绕过节点时被抢走）
- 删除折点后，两侧线段直接拍直成直线（安全降级，避免幽灵曲线）
- 隐藏样条点不可见、不可选中，只能整段清空重拉

### 5.5 Sample 模式（取样）

1. 按 I 或按住 Alt 进入
2. 鼠标变为吸管图标
3. 点击任意已存在的元素：
   - 复制其配置到"样本槽"
   - 提示「已取样：储物柜#7f3a」
4. 点击其他场景框：套用样本槽配置
5. 松开 Alt 或按 Esc 退出模式

**用途**：零注册表、零搜索，直接指着地图上的东西说"再来一个这样的"。

### 5.6 Playtest 模式（试玩）

1. 按 P 进入
2. 画布切换为游戏运行预览：
   - 加载当前地图
   - 显示可通行域、场景连接
   - 可测试移动/寻路
3. 编辑状态保留（不重置）
4. 按 Esc 退出回到编辑模式

### 5.7 全局快捷键

| 快捷键 | 功能 |
|---|---|
| 空格 + 拖拽 / 中键拖拽 | 平移画布（操作 SVG viewBox） |
| 滚轮 | 以光标为中心缩放 |
| Ctrl+Z | 撤销 |
| Ctrl+Shift+Z | 重做 |
| Delete | 删除选中元素 |
| Esc | 退出当前模式回到 Select / 清空选择 |

| Tab | 开合右侧面板 |
| 1 / 2 / 3 | 切换楼层 |

### 5.8 拖拽交互细节

**素材拖拽**：
- 从右栏素材库拖出素材卡
- 拖到画布上时：
  - 进入场景框吸附半径：场景框亮蓝光（合法落点）
  - 松手在场景框内：放置素材
  - 松手在空白：丢弃 + 淡出动画

**元素移动**：

## 六、数据结构（JSON 产出）

最终产出 `MapData` JSON，包含：

```typescript
interface MapData {
  id: string;
  name: string;
  
  // 场景节点
  scenes: Array<{
    id: string;
    name: string;
    x: number;          // 归一化坐标 0-1
    y: number;
    width: number;
    height: number;
    scale: 'large' | 'medium' | 'small';
    layer: number;      // 楼层高度
    def?: string;       // 场景类型定义引用
  }>;
  
  // 连接
  edges: Array<{
    id: string;
    from: string;       // 场景 id
    to: string;
    bidirectional: boolean;
    points: Array<{x: number, y: number}>;  // Catmull-Rom 样条点
    transitionWindow?: {x: number, y: number};
    def?: string;
  }>;
  
  // 遮挡
  obstructions: Array<{
    id: string;
    type: 'visual' | 'physical';
    x: number;
    y: number;
    width: number;
    height: number;
    rotation: number;   // 角度
    affectsEdges: string[];  // 覆盖的连线 id
  }>;
  
  // 地形
  terrains: Array<{
    id: string;
    type: 'highland' | 'lowland';
    x: number;
    y: number;
    width: number;
    height: number;
    rotation: number;
  }>;
  
  // 放置的素材
  placements: Array<{
    id: string;
    materialId: string;  // 素材库中的 id
    sceneId: string;     // 所属场景
    x: number;
    y: number;
  }>;

  // 原生组件占位框 (Crop-to-Sprite / 06 & 07 规范)
  placeholderBoxes?: Array<{
    id: string;          // 语义标识符，如 door_subway_45
    type: 'transition' | 'asset'; // 过渡通道框或独立组件框
    bounds: { x: number; y: number; width: number; height: number }; // 归一化坐标 [0, 1]
    connectedEdgeId?: string;     // 若为 transition，关联边 id
    hostNodeId?: string;          // 若为 asset，绑定节点 id
    sourceCrop?: string;          // 导出的切片相对路径，如 crops/door_subway_45.png
    spriteRef?: string;           // 替换素材 id（如 d:item/door_subway_45）
  }>;
  
  // 元数据
  metadata: {
    created: string;
    modified: string;
    author: string;
  };
}
```

### 6.1 占位框切片与导出工作流 (Crop-to-Sprite)

1. **标定与切片**：策划在底图上框选原生门/变电箱等组件，编辑器导出时自动将每个占位框按实际像素坐标裁切保存为 `crops/<id>.png`。
2. **图生图闭环**：AI 以切片为母图通过 `asset-pipeline-v2.py` 生成 1:1 像素组件与状态序列，回填 `spriteRef`。
3. **无缝过门**：运行时在底图原坐标 1:1 覆盖该组件，过门瞬间播放序列帧并瞬移角色，彻底杜绝割裂。

## 七、校验与诊断

### 7.1 实时校验（编辑时）

底部诊断条实时显示：

**结构校验规则**：
- ✅ 所有场景至少有一条连接
- ✅ 所有场景可从出生点到达
- ✅ 连接端点吸附到场景框中心（不能悬空）
- ✅ 场景框不能完全重叠（同类型框可部分重叠合并）
- ❌ 场景名不能为空
- ❌ 连接数不能超过场景尺度上限（大5/中4/小3）
- ⚠️ 出生点建议 ≥2 个
- ⚠️ 遮挡框未覆盖任何连线（无效）

### 7.2 诊断列表交互

点击某条诊断：
1. 画布摄像机平滑飞到出问题的元素
2. 元素红色脉冲闪烁 3 次
3. 自动选中该元素
4. 检查器显示该元素属性

**诊断分级**：
- 🔴 错误（error）：阻止发布，不阻止保存
- 🟡 警告（warning）：不阻止发布，建议修复
- 🔵 提示（info）：优化建议

## 九、技术建议

### 9.1 建议使用的库。

- **React 18** + TypeScript
- **Tailwind CSS** + 自定义配置（颜色令牌已定义）
- **SVG** 画布
- **Catmull-Rom 样条**：纯函数计算路径，不用第三方库（可自己实现或用简单工具函数）
- **状态管理**：可用 Zustand 或 React Context
- **图标**：Lucide React（已安装）

### 9.2 禁止使用

- ❌ 浏览器滚动条（用 SVG viewBox 平移缩放）
- ❌ 贝塞尔曲线控制点（必须用 Catmull-Rom）
- ❌ Photoshop 式 4 角拖拽框（用涂鸦式阴影选中）
- ❌ 复杂图层系统（只有楼层高度）
- ❌ 实时协作（单人编辑）

### 9.3 性能要求

- 100 个场景框 + 150 条连线：60fps 平移缩放
- 撤销/重做栈深度 50 步
- 自动保存间隔 30 秒
