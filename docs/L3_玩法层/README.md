## 玩法层职责

玩法层是**L3层**，位于基类层之上。

```
玩法层 = 实例化 + 数值约束 + 规则配置

玩法层提供：
- 具体实例定义（霰弹枪、近战武器等）
- 数值约束（伤害值、AP成本等）
- 玩法规则（胜利条件、缩圈规则等）
- 玩法包配置（大逃杀、夺旗等）
```

## 玩法包设计规范

玩法包是玩法层的具体实现，需遵循以下原则：

1. **数值约束**：所有玩家可见数值严格限制在1-5范围内
2. **基类组合**：通过组合基类层实例生成玩法包
3. **规则配置**：定义玩法包特有的规则和胜利条件
4. **不可违反L1/L2**：玩法层不得违反引擎层和基类层的定义
