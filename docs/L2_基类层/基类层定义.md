# 基类层定义

> **文档性质**：基类层定义，是引擎层与玩法层之间的桥梁。
> **迭代原则**：本定义为初版，会在迭代中不断修正。
> **最后更新**：2026-08-05（基类层定义 v1）
> **依赖**：L1_引擎层/底层引擎架构.md

---

## 一、基类层职责

基类层定义**可组合的基类原语**，不包含具体数值约束，不包含具体玩法配置。

```
基类层 = 实例库 = 可组合的基类原语

基类层提供：
- 基类继承树（定义"是什么类型"）
- 基类嵌套组合（定义"怎么配置"）
- 基类参数接口（定义"可以设置哪些参数"）

基类层不提供：
- ❌ 具体数值（如伤害=3，由玩法层设置）
- ❌ 具体玩法配置（如霰弹枪的射程参数，由玩法层设置）
- ❌ 具体实例（如霰弹枪实例，由玩法层创建）
```

## 二、嵌套与继承原则

### 原则一：继承决定类型，嵌套决定配置

```
// 继承层（类型定义，本质差异）
ShotgunProfile → FirearmType → WeaponType

// 嵌套层（实例配置，玩法参数）
new ShotgunInstance
    ├── attach(shotgun_profile)           ← 继承链
    ├── attach(scatter_pattern, {range:2}) ← 嵌套谱型
    ├── attach(damage, {base:3})          ← 嵌套伤害
    ├── attach(slots, {hands:2})           ← 槽位需求
    └── attach(tags, ['shotgun'])          ← 标签
```

### 原则二：能用嵌套就不要用继承

| 场景 | 推荐方式 | 原因 |
|------|---------|------|
| 霰弹枪的散射谱型 | 嵌套 ScatterPattern | 配置差异，不是本质差异 |
| 霰弹枪的基础伤害 | 嵌套 damage 基类 | 伤害值由玩法层设置 |
| 霰弹枪与其他霰弹枪的射程差异 | 嵌套不同参数 | 同一类型的不同配置 |
| 霰弹枪与其他武器的谱型差异 | 嵌套不同 Pattern 基类 | 谱型是可嵌套的基类 |

### 原则三：继承用于本质差异，嵌套用于配置差异

**本质差异（用继承）：**
- 枪械 vs 近战武器
- 汽车 vs 电瓶车
- 大场景 vs 中场景

**配置差异（用嵌套）：**
- 霰弹枪的散射范围
- 霰弹枪的基础伤害
- 霰弹枪的目标数量

## 三、顶层类型（引擎层 Kernel）

引擎层不知道"武器"、"技能"是什么，只知道这些通用原语：

```
Def（定义/蓝图）
├── kind: 'entity'     → 实体定义
├── kind: 'item'       → 物品定义
├── kind: 'node'       → 节点定义
├── kind: 'link'       → 连接定义
├── kind: 'attachment' → 附属定义
├── kind: 'action'     → 动作定义
├── kind: 'rule'       → 规则定义
├── kind: 'playpack'   → 玩法包定义
├── kind: 'policy'     → AI策略定义
├── kind: 'expr'       → 表达式定义
├── kind: 'schedule'   → 回合表定义
└── kind: 'decision'   → 决策定义

Entity（实体）
├── LivingEntity（活体）
│   ├── Player（玩家）
│   ├── NPC（NPC）
│   └── Creature（生物）
├── Vehicle（载具）
└── Structure（建筑/场景物体）

Item（物品）
├── Weapon（武器）
├── Armor（防具）
├── Consumable（消耗品）
└── Tool（工具）

Node（节点）
├── LargeScene（大场景）
├── MediumScene（中场景）
├── SmallScene（小场景）
└── MicroScene（微型场景）

Link（连接）
└── Portal（门户）

Agent（代理/决策者）
├── Human
├── AI
└── Observer

Attachment（状态/效果）
├── Buff（增益）
├── Debuff（减益）
└── Aura（光环）
```

## 四、基类继承树

### 4.1 武器基类继承树

```
WeaponType（武器基类）
│
├── MeleeType（近战武器）
│   ├── LightMelee（轻型近战）
│   │   └── 示例：短刀、棍棒、平底锅
│   ├── MediumMelee（中型近战）
│   │   └── 示例：棒球棍、撬棍
│   ├── HeavyMelee（重型近战）
│   │   └── 示例：电锯（占2格）、消防斧
│   └── SpecialMelee（特殊近战）
│       └── 示例：电击棒（1伤+眩晕）
│
├── RangedType（非枪械远程）
│   ├── LightRanged（轻型远程）
│   │   └── 示例：飞刀、手里剑
│   ├── MediumRanged（中型远程）
│   │   └── 示例：弓、弩
│   ├── HeavyRanged（重型远程）
│   │   └── 示例：火箭筒
│   └── SpecialRanged（特殊远程）
│       └── 示例：催泪弹、闪光弹
│
└── FirearmType（枪械，独立体系）
    ├── PistolProfile（手枪谱型）
    ├── ShotgunProfile（霰弹枪谱型）
    ├── RifleProfile（步枪谱型）
    ├── SniperProfile（狙击枪谱型）
    ├── SMGProfile（冲锋枪谱型）
    └── MGProfile（机枪谱型）
```

### 4.2 枪械谱型详解

> **2026-08-08 权威变更（本次会话裁决，已获项目所有者授权）**：以下"谱型"指弹道谱型/距离档
> （手枪、霰弹枪、步枪、狙击枪、冲锋枪、机枪各自的距离-威力曲线），与已废除的"攻击形状/形状轴"
> 是两个不同概念，本节保留不变。原表述中的"散射" `pattern` 参数（如
> `attach(pattern, {range: 2})`）已改为武器属性表达，见 4.3。

```
ShotgunProfile（霰弹枪谱型）
├── extends: FirearmType
├── rangeProfile: { 0:2, 1:2, 2:5, 3:6, 4:6, 5:6 }
└── 实例配置：
    new ShotgunInstance
        ├── attach(damage, {base: 3})
        ├── attach(scatter_attribute, {})     ← 散射属性（无目标数上限）
        └── attach(target_scope, 'area')      ← 命中范围内全部目标，不设固定人数上限

RifleProfile（步枪谱型）
├── extends: FirearmType
└── rangeProfile: { 0:2, 1:2, 2:3, 3:3, 4:4, 5:5 }

SniperProfile（狙击枪谱型）
├── extends: FirearmType
├── rangeProfile: { 0:3, 1:2, 2:2, 3:2, 4:3, 5:3 }
└── 特点：远距离优势明显
```

### 4.3 武器属性基类（原"武器谱型基类"，已废止形状分类）

> **2026-08-08 权威变更（本次会话裁决，已获项目所有者授权）**：废除"攻击形状/形状轴"
> （`WeaponPattern` 及其子类 `SingleTargetPattern`/`ScatterPattern`/`ConePattern`/`LinePattern`
> 这一强制三选一分类，以及配套的 UI 攻击形状语义值 `single-target`/`spread`/`area`）。
> 判定为冗余设计：其功能已完全由**武器属性**覆盖，不需要额外的形状分类层。
> 武器默认视为单体攻击（不声明任何属性即隐含单体，不再需要显式的"单点谱型"标签）；
> 散射、扫射、连发等作为**可选武器属性**（能力）挂载，不构成类型身份，也不设命中目标数上限——
> 范围伤害命中数由拓扑与场景占用情况决定（受宪法五并列原则的连接数 ≤5 天然约束），不是武器自带的
> 玩法数值。后续维护者与并行会话请以本文件最新内容为权威依据，并核查
> `.kiro/specs/l2-base-layer-spec`、`.kiro/specs/wakeup-space-items`、
> `.kiro/specs/wakeup-ui-animation` 三个规范及对应代码（`src/l2/**`、`src/class/weapons/`、
> `src/play/**`）的同步变更记录。

```
WeaponAttribute（武器属性基类，可选、可多选、不影响类型身份）
├── ScatterAttribute（散射属性）
│   └── 示例：霰弹枪；命中范围内全部目标，无固定数量上限
├── SweepAttribute（扫射属性）
│   └── 示例：机枪的持续压制射击；命中范围内全部目标，无固定数量上限
└── BurstAttribute（连发属性）
    ├── attach(targets, {max: 由玩法层给出，如突击步枪点射为 2})
    └── 示例：突击步枪的点射、冲锋枪
```

不声明任何 `WeaponAttribute` 的武器（拳头、刀、手枪、狙击枪等）默认是单体攻击，
不需要显式声明"单体"这一分类。

## 十五、基类层的 UGC 操作示例

### 示例 1：创建霰弹枪

> **2026-08-08 权威变更**：`scatter_pattern` 已改为 `scatter_attribute`（武器属性），
> 且散射不设固定目标数上限（命中范围内全部目标），因此示例移除 `targets: 3`。

```
UGC 自然语言输入：
"创建一把霰弹枪，射程2，命中范围内全部目标，伤害3，需要双手"

LLM 解析：
gun_shotgun = new ShotgunInstance()
    .attach(shotgun_profile)
    .attach(scatter_attribute, {range: 2})
    .attach(damage, {base: 3})
    .attach(slot_requirement, {hands: 2})

结果：霰弹枪实例创建完成
```

### 示例 2：创建近战武器

```
UGC 自然语言输入：
"创建一个近战武器，伤害2，挥砍范围1格"

LLM 解析：
weapon_blade = new BladeInstance()
    .attach(melee_profile)
    .attach(damage, {base: 2})
    .attach(melee_range, {radius: 1})

结果：近战武器实例创建完成
```

### 示例 3：创建带状态的武器

```
UGC 自然语言输入：
"这把枪打中后会施加减速状态，持续2回合"

LLM 解析：
weapon_slowgun = new RifleInstance()
    .attach(rifle_profile)
    .attach(damage, {base: 3})
    .attach(status_effect, {
        type: 'slowed',
        duration: 2,
        trigger: 'on_hit'
    })

结果：带减速效果的步枪实例创建完成
```

## 十六、基类层与引擎层的边界

| 类别 | 归属 | 说明 |
|------|------|------|
| Def、Entity、Item、Node、Link、Agent、Attachment | 引擎层 | 通用原语，无具体语义 |
| WeaponType、ArmorType、VehicleType | 基类层 | 有语义的基类定义 |
| DamageType、StatusType、SkillType | 基类层 | 有语义的基类定义 |
| 骰子系统（d6） | 引擎层 | 引擎层已确定骰子类型 |
| 移动状态（MovingToX） | 引擎层 | 运行时状态，由引擎管理 |

## 十七、基类层与玩法层的边界
