## 核心发现与设计决策

### 1. 深冻结断言策略（J-01）
**问题**：投影进入 UI 边界时，是否应该就地冻结未冻结层？  
**决策**：拒绝策略——不做补救性冻结，返回 `PROJECTION_NOT_FROZEN` 诊断。  
**理由**：UI 层不掩盖上游违约，迫使上游修复深冻结逻辑。

### 2. 陈旧意图的处理（J-05）
**问题**：observedRevision 过期的意图是拒绝还是阻止提交？  
**决策**：仍然提交，由权威侧返回 `stale` 结果。  
**理由**：UI 层不做语义判定，只做通道隔离。

### 3. 表现参数的边界（J-08）
**问题**：layoutParams、animationDuration 是否影响描述符可用性？  
**决策**：完全惰性——表现参数不参与任何语义判定。  
**理由**：保证 profile 可替换性，动画时长/布局改变不影响游戏逻辑。

### 4. 选项集 ≤5 不变式的维护（J-13）
**问题**：导航控件（prev/next）是否计入 5 的预算？  
**决策**：计入——导航控件也是"选项"。  
**理由**：简化规则，避免"隐藏"复杂度超出预算。

### 5. 变异测试的价值（Task 11）
**发现**：2 个属性测试有覆盖盲区  
**方法**：注入已知缺陷，验证对应测试失败  
**结论**：变异测试不空转——它暴露了"生成器总是完美"的隐性假设
