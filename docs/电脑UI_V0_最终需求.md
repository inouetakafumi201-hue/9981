# 电脑UI - V0 最终创作需求（统一版）

> **文档性质**：这是给 V0 的**唯一权威需求文档**。所有之前的讨论、草稿、定案稿都已合并至此。
> **使用方式**：直接把此文档复制给 V0，它会理解「我要的是这种感觉」。

---

## 🌍 世界观背景（必须理解）

玩家在《WakeUp》中扮演一名**梦境探索者**，通过电脑终端与五个组织互动：
### 界面整体要求
- 视图构成：正面俯视的电脑显示器界面
- 色调：复古现代感（V0 擅长的「低饱和 + 高对比」）
- 风格：复古模拟感前景 + 全息栏栅视觉效果背景（D-083 已定案）
- 交互模式：应用切割 / 标签页式组织 / 输入框 + 按钮
需求：要像在用一台真的ui模拟和手感具有粗糙信息技术感linux电脑

### 容器结构
```
电脑终端容器
├── 顶栏：LOGO区 + 组织标识 + 权限指示
│   └── 显示当前激活的应用名称
├── 主视图区：应用内容区域
│   └── 动态加载各组织应用的具体界面
├── 侧栏区：快速访问 / 快捷栏
│   └── 塑形栏 / 订购栏（4格）的微型显示
└── 底栏：全局操作面板
    ├── 退出应用
    ├── 刷新/同步
    └── 设置/帮助
```

### 交互语言
- 切割动效：Framer Motion 全屏替换 + 画面抖动过渡
- 按钮：青/绿/金/蓝/红 五色语义
- 滚动：柔和的数值滚动 + 视差微动
- 动画：从不打断玩家的「连续反馈」

| 组织 | 正式名称 | 定位 | 玩家身份 | 质感锚点 |
|---|---|---|---|---|
| 黑市 | **SECDED** | 终端式悬赏商城 | 黑客/交易者 | 极客硬核 + 商业感 |
| 运营商A | **深梦网络.NET** | 佣兵数据看板 | 佣兵员工 | 高级SaaS仪表盘 |
| 运营商B | **星眠通信** | 营销套餐平台 | 订阅用户 | 亮片塑料感 × 促销文案 |
| 研究机构 | **DESIGNER.ai** | 前沿玩法生成 | 研究员 | 黑科技机密风 |
| 政府部门 | **PSYCHO-5** | 梦境取证系统 | 外围卧底 | 极端土到不行 |
| 社区 | **COMMUNITY FEED** | 游戏外框架 | 玩家自己 | 占位灰 |

### 1️⃣ SECDED 终端

#### 质感定位
- **极客硬核 + 商业感**
- 深绿 = 字符终端 × 金属按钮（高档感）
- 不是黑客风，是**高端科技的冷酷感**

#### 界面元素
- **Logo**：左上角「8位渲染骷髅logo」+ 右侧「信用点按钮」
  - 骷髅logo：8×8 像素矩阵，深绿色 (#006600) + 亮绿色 (#00FF00) 高光
  - 开机动画：字符刷屏 + logo闪烁
- **背景**：深绿色终端背景 (#003300) + 扫描线纹理 + 细小的数据流粒子
- **按钮**：金属质感，点击时有「机械按压」的微动画

#### 功能区
##### 悬赏区
- 每个悬赏都写着：**"价值：$XXX" + 经验值条（刷完可获得信用点）**
- 经验值条：灰色底 + 绿色填充，完成后弹出"信用点+1"的气泡
- 倒计时：黄色数字 (#FFFF00)，接近截止时变红 (#FF0000) + 闪烁
- 示例悬赏：
  - "★当今头目  价值$1200 品质S 00:15:00"
  - "★黑客工具  价值$800  品质A 00:08:00"
  - "★记忆涂抹  价值$500  品质B 00:22:00"

##### 商城区
- **货币显示**："信用点"打头，"记忆碎片"底部
- **购买动画**：刷卡 + 充电灯（从左到右扫描）
- **商品列表**：文字描述 + 价格，无图标（保持神秘感）
- 示例商品：
  - "速效恢复剂 - 可以让您的AP瞬间回复3点 - $200"
  - "终极突击剂 - 本局所有属性提升至5，突破容量上限 - $1000"

#### 核心交互
- **刷新商品池**：消耗 10 记忆碎片，动画：终端屏幕抖动 + 字符疯狂刷屏 3 秒
- **订购药水**：点击商品 → 扣除费用 → 订购栏新增图标 + 显示「1~3回合投送」
- **被抢机制**：订单被劫持时弹出红底白字弹窗 + 订单列表缩短 1/3

#### 核心体验（30秒）
```
1. 打开终端 → 看到骷髅logo闪烁 + 字符刷屏动画
2. 浏览悬赏 → 发现"当今头目 价值$1200"，经验值条已填充80%
3. 点击交付 → 弹出"获得信用点+1 + $1200"
4. 进入商城 → 用信用点购买"记忆增强剂"
5. 购买成功 → 刷卡动画 + 充电灯扫描
6. 返回悬赏 → 发现新的悬赏已刷新
```

#### 反差设计
- **高端科技 vs 黑市交易**：界面很高级，但交易内容很地下
- **神秘感 vs 透明价格**：商品没有图标，但价格清清楚楚

### 2️⃣ 深梦网络.NET（运营商A）

#### 质感定位
- **高级SaaS仪表盘**
- 全蓝底毛玻璃 (#1A1A2E) × 透明卡片（V0爆款SaaS风）
- 不是花哨，是**专业的冷静感**

#### 界面元素
- **顶栏**：
  - 佣兵头像（64×64px，正面斜投影，低饱和蓝色调）
  - 佣兵代号：大号等宽字体 (Monaco 24pt)
  - 佣金数字：$3,420（等宽字体，36pt bold）
  - "提现按钮"：蓝色背景 + 白字
- **卡片**：透明背景 + 微阴影 (rgba(255,255,255,0.1))，叠加效果
- **表格**：任务列表 + 完成状态 + 评分

#### 功能区
##### 个人档案卡
- 入职日期：2026-08-01（小一号字体，暗灰 #999）
- 本月任务：7/10（蓝色实线框包裹）
- 佣金倍率：1.35x（拉伸的蓝色背景块）

##### 财务报表
- 本月收入：$2,847.00（等宽 Monaco 16pt）
- 近期结算：
  - #001 击毙目标 → +$450（绿色）
  - #002 提交证据 → +$320（绿色）
  - #003 悬赏交付 → +$1,200（绿色）
- 趋势图：柱状 + 折线，数据点可 hover 显示数值

##### 组织评语
- 文本框高度：160px，灰底 (#16213E) + 斜体
- 字体：8pt Monaco，灰色 #999
- 示例评语："该员工本月表现尚可，但仍有提升空间。"
- 底部签名："—— DREAMCORE HR"

#### 核心交互
- **提现按钮**：点一下弹窗"已提现 $XXX，24h到账" + 充电灯扫描
- **数字滚动**：佣金变化时，数字从右向左滚动（0.5s）
- **加载动画**：快速刷新时出现蓝色加载球
- **升级徽章**：光晕框飘出（从灰到彩），持续 1.5s

#### 核心体验（30秒）
```
1. 打开看板 → 看到"佣金 $3,420"的大号数字
2. 查看任务表 → "本周 4/5 完成 80%"
3. 点击提现 → 弹出"已提现 $200 → 24h到账"
4. 充电灯从左→右扫描，数字滚动 + "滴!"声音
5. 新余额：$3,220
6. 看见升级徽章光晕框飘出（从灰到彩）
```

#### 反差设计
- **专业仪表盘 vs 讽刺文案**：界面很专业，但组织评语很讽刺
- **冷静数据 vs 激动提现**：数字很冷静，但提现时很激动

### 3️⃣ 星眠通信（运营商B）

#### 质感定位
- **亮片塑料感 × 促销文案**
- 圆角矩形塑料感 (border-radius: 12px) × 卡通式按钮（V0最爱的「弹窗式营销」）
- 不是高级，是**商业的浮夸感**

#### 界面元素
- **顶栏**：
  - 套餐卡片（当前套餐高亮，金色边框）
  - "立即续费"按钮：橙色背景 (#FF6B35) + 白字
  - 剩余时间："20 天"（黄色数字 #FFD700）
- **背景**：浅灰色 (#F5F5F5) + 细小的网格线
- **按钮**：圆角矩形，点击时有"弹跳"动画

#### 功能区
##### 套餐对比区
- 4列卡片式布局：
  - **基础版**：免费，功能：基础入梦
  - **标准版**：$2,000/月，功能：REM窗口+2分钟 / 素材槽位+1
  - **专业版**：$5,000/月，功能：REM窗口+5分钟 / 素材槽位+2 / 塑形成功率+10%
  - **佣兵版**：$10,000/月，功能：全解锁 + 快速撤离
- 当前选中：金边框 + 光晕
- 优惠价：闪烁"限时折扣"标签（橙色背景）

##### 账单记录
- 弹窗"账单到底了 → 点开是莫名其妙的高额支出"
- 示例账单："2024/8/15 莫名加收 $400"
- 自动扣款：账单直接扣除，无需确认

#### 核心交互
- **续费动画**：秒达充值 + 金光闪烁（持续 1s）
- **优惠弹窗**：右上角闪烁，点击后出现优惠码
- **升级**：点「升级」时弹"优惠到底了" → 界面切成「会员金光」效果

#### 核心体验（30秒）
```
1. 打开营销App → 看到"标准企业版 剩余20天"
2. 点击续费 → "秒达充值"动画，金光闪烁
3. 弹出"优惠到底了！本月8折" → 界面切成金色
4. 点击账单 → 发现"2024/8/15 莫名加收 $400"
5. 账单自动扣款 → 余额减少
6. 看见"会员特权"徽章亮起
```

#### 反差设计
- **浮夸营销 vs 隐藏扣款**：界面很浮夸，但扣款很隐蔽
- **金光闪烁 vs 莫名其妙**：升级很爽，但账单很迷惑

### 4️⃣ DESIGNER.ai（研究机构）

#### 质感定位
- **黑科技机密风**
- 低饱和终端 (#0A0A0A) + 审核期倒计时 + 神秘感

#### 界面元素
- **顶栏**：
  - 权限等级：LV.3/5（蓝色数字）
  - 剩余生成次数：2/3（绿色数字）
  - 审核队列：1 个待审核（黄色警告）
  - "权限即将到期"警告：橙色 (#FF8C00)
- **背景**：深黑色 (#000000) + 细小的网格线 + 散射的数据流粒子

#### 功能区
##### 需求澄清器
- 玩法包名称输入框：等宽字体，白色
- 核心机制描述：大型文本域，支持多行
- 目标玩家人数滑块：1-1000
- 难度曲线选择：简单（蓝色） / 中等（绿色） / 困难（红色）
- 灵感素材选择器：从素材库检索，弹出式窗口
- "生成"按钮：蓝底光效，点击后出现数据流逆转动画

##### 生成结果区
- 当前状态标签：
  - 审核中：旋转的加载环 + "审核中..."
  - 已通过：绿勾 + "审核通过"
  - 已驳回：红× + "审核驳回"
- 审核进度条：30秒倒计时 + 加急选项
- 结果预览：玩法包名称 + 核心机制摘要 + 可玩性评分（★★★★☆）
- 操作按钮：
  - "试玩"：灰显（需审核通过）
  - "永久解锁"：蓝亮

##### 使用记录
- 已生成的玩法包列表
- 审核状态：通过 / 驳回 / 降级
- 删除 / 重新生成选项

#### 核心交互
- **生成按钮**：点击后出现数据流逆转动画（0.8s）
- **审核期间**：右上角出现"正在处理中"的加载指示器
- **审核完成**：弹出"新玩法包可用"的通知气泡
- **试玩按钮**：点击后跳转到「地图编辑器」的「新建」模式
- **重新生成**：弹出"确认：将替换原作品？"的二次确认

#### 核心体验（30秒）
```
1. 打开终端 → 看到"权限等级 LV.3/5"
2. 填写需求 → 玩法包名称、核心机制、目标人数
3. 点击生成 → 数据流逆转动画
4. 等待审核 → 30秒倒计时
5. 审核通过 → 弹出"新玩法包可用"
6. 点击试玩 → 跳转到地图编辑器
```

#### 反差设计
- **黑科技 vs 审核期**：界面很先进，但需要等待审核
- **神秘感 vs 透明结果**：生成过程神秘，但结果很透明

## 🎬 统一交互规范

### 1. 提现动画（所有应用共享）
- **充电灯扫描**：从左到右，速度均匀，持续 0.8s
- **数字滚动**：等宽字体，数字从右向左补齐，持续 0.5s
- **声音**："滴!"的金属声，在动画结束时播放
- **弹窗**：白底 + 青色边框 + "已提现 $XXX → 24h到账"

### 2. 按钮设计
- **形状**：圆角矩形（4px 圆角）
- **文本格式**：全大写 + 1.2em 字体
- **状态**：
  - 默认：浅灰底 (#F0F0F0)
  - 悬浮：青色底 (#4682B4) + 白字
  - 按下：深蓝底 (#1E3A8A) + 白字
  - 灰显：灰底 (#A0A0A0) + 灰字（不可点击）

### 3. 输入框设计
- **边框**：1px #555 虚线
- **聚焦时**：青色光晕 (#4682B4) 环绕
- **文本**：等宽字体 (Monaco/Courier)
- **占位文字**：浅灰 (#999) + 斜体

### 4. 滚动条设计
- **宽度**：8px
- **轨道**：浅灰 (#E0E0E0) + 半透明
- **滚轮**：圆形 + 悬浮变亮 (#B0B0B0)
- **滚动按钮**：左/右箭头 + 微图标

### 5. 动画规范
- **过渡时长**：0.2s - 0.3s
- **缓动函数**：easeInOutCubic
- **触发时机**：hover / click / state change
