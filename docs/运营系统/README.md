## 表现落点

驻地（出租屋承载物动态、纯白显形、保险箱/书架、VR 证据提交独立图层、真相板）的**实现落点已映射到 `docs/表现系统/09_图形化实现落点.md` §五**（哪些代码、哪些走素材管线、对应哪个库）。本目录文档只定流线与人机交互契约，逐像素线框与库落点归表现侧。

素材塑形相关演出（素材浮现/铭刻、塑形画面）见 `docs/表现系统/03_动画灵感索.md` §十。


## 依赖方向

```text
运营系统 ──选择/装载──> 场景信息 + 玩法包 ──交给──> 三层运行期
```

- 运营系统依赖稳定会话、装载与节奏端口，不读取三层内部数据形状。
- 三层运行期不得反向依赖运营系统。
- 已装载对局的任何状态写入仍经 `OpRegistry.invoke`。
- 创作工具是另一个三层外正交域；运营系统与创作侧只通过发布契约交换经济/权益摘要。
