# 运营系统文档索引

> **定位**：运营系统位于引擎层 / 基类层 / 玩法层的运行期依赖链之外，负责会话调度、局外体验与长期推进。它不是 L4，也不是第四个运行期架构层。

## 依赖方向

```text
运营系统 ──选择/装载──> 场景信息 + 玩法包 ──交给──> 三层运行期
```

- 运营系统依赖稳定会话、装载与节奏端口，不读取三层内部数据形状。
- 三层运行期不得反向依赖运营系统。
- 已装载对局的任何状态写入仍经 `OpRegistry.invoke`。
- 创作工具是另一个三层外正交域；运营系统与创作侧只通过发布契约交换经济/权益摘要。
