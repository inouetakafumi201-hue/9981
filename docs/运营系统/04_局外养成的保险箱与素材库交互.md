## 一、定位与边界

本文档深化局外养成中几处接触面的人机交互：**保险箱**（收藏室）与**书架**（梦境素材库）是功能性承载物，**门缝**（辅助叙事）是叙事面。它们在驻地里是独立承载物（见 `运营系统/03`），方向截然不同——保险箱重**质感与回看**，书架重**检索与切换**，门缝重**世界气味与节奏**。

边界：

- 只定接触面的**形态与人机交互**，不画逐像素线框（表现侧后续专题，保留端口）。
- 不定义经济数值（守创作/02 §七与运营/01 §十）。
- 不推翻既有架构：素材结构守 `创作系统/02`，实例/产权/插槽守 `创作系统/01`，低心智约束守 `L0_规范宪法` 第五/六条。

**接触面一句话**：

- **保险箱 = 质感收藏栏**：本质与普通仓库机制差异不大，但**表现与质感**不同；部分物品有使用价值、也可视为仓库，但不大量融入对局机制。
- **书架 = 检索优先的素材库**：会跟地图编辑**高频切换**，找到素材是最重要的。
- **门缝 = 世界气味**：辅助叙事用的东西，不直接进游戏入口，把世界的气息与主线之间的喘息送进住处。

## 二、保险箱（收藏室）：质感收藏栏

### 2.1 本质定位

保险箱是收藏室的驻地呈现。它存"运营推进中取得、置办或纪念的长期对象"，**本质上与常见物品栏/仓库区别不大**，差异在**表现和质感**——它看起来、摸起来是"放高价值物的地方"，而不是"收纳材料的柜子"。

- 部分物品**有使用价值**，也可以被认为是仓库。
- 但**不服务于大量融入游戏机制**：例如"一些箱子可以在保险箱里开"，属于**未来可做的增量**，本轮不做承诺。

### 2.2 交互骨架（质感优先）

```text
抽屉式平铺 + 左侧类别栏筛选
  每个类别 = 一条带颜色栏目
  点击条目 → 右侧出详情 + 大图
  条目可有交互按钮（如"使用"）
```

- **抽屉式平铺**：一眼看到所有收藏的高价值物，像拉开保险箱抽屉翻看。
- **左侧类别栏**：按类别筛选，栏目**带颜色**（呼应全局颜色语义，见 `表现系统/01`）。
- **点击右侧出详情 + 大图**：选中条目在右侧放大展示，承载"回看/纪念"。
- **有交互按钮**（如"使用"）：部分有使用价值的收藏可按钮触发；没有使用价值的纪念物则只回看。

### 2.3 去仓库感的关键：拒绝堆叠

保险箱与"仓库"的差异**不靠机制、靠表现**，但要守住一条硬边界：

- **拒绝堆叠**：保险箱里**不放材料、不放垃圾**——它是"高价值陈列"而非"收纳桶"。
- **丢弃选项先不做**：非必要不提供丢弃；宁缺毋滥，靠"陈列什么"而非"整理什么"来传达质感。
- 收藏对象**随主线推进逐渐增加**：陈列是渐进式的，玩家回看时能看到自己的推进痕迹。

### 2.4 与人机交互质感

保险箱的 HCI 关键词是**质感**：

- 打开/翻抽屉的时刻要有"贵重感"（材质、光、音）。——细节画法归表现系统，此处只定方向。
- 不追求塔科夫式自由整理、套装演算、逐件带入带出（守运营/01 §4.1 反仓库）。

## 三、书架（梦境素材库）：检索优先

### 3.1 本质定位

书架承载**梦境素材库**（元素 + 蓝本，见创作/02）。它服务于**创作**——搜素材、用素材、构建梦境。它与地图编辑**高频切换**：玩家要一边看素材库，一边回编辑器放东西，来回跳转。

**因此书架的第一要务是检索方便，不是陈列质感。**

### 3.2 核心交互：星标（收藏）置顶

- 素材可以**星标收藏**。
- 排序时，**星标素材在同筛选栏目内排首位**。
- 星标是**素材库内部的快捷订阅**，让常用素材永远在最方便拿到的位置，契合"高频切换"。

### 3.3 检索优先的形态方向

- 浏览以"找到我要的素材"为目标，支持类别/类型/关键字检索。
- 与编辑器切换入口显眼（能快速回编辑器继续放置）。
- 星标置顶 = 低心智（守宪法五条：常用项应收敛、最快达）。

### 3.4 地图编辑器的快捷素材栏（次级入口，纯拖拽）

地图编辑器右侧有一套**次级快捷素材栏**，独立于书架的正式素材库：

- **形态**：未展开时显示 **7 个框**（最近/高频素材，一屏速拖）；展开后进**全量矩阵（70 格）**，展开时「快捷素材」标签本身不再显示，矩阵上方多出**分类筛选工具**与**搜索框**——本质是一个**小型素材库选择器**，只用于拖拽。
- **与正式素材库的分界**：这里**只能拖拽取用**，不能编辑、不能调 LLM、信息密度低；正式素材库（书架）信息更多、可编辑、可调 LLM。改动「在正式素材库编辑」优先于"就近在快捷栏改"。
- **配置方式**：快捷素材栏可在**正式素材库中配置**——把需要的素材拖进去**替换原空位/原素材**即可；配置的是「这 7 格各是什么」，与展开内容独立。
- **拖拽打断工具**：任何时候**拖拽素材会导致当前工具被取消**（拖素材=切到放置素材动作，画图元的笔自动放下）。
- 这层是「取用」，与正式素材库的「取用 + 编辑 + 调 LLM」、研究台的「玩法包制作」构成**越浅越偏取用、越深越偏制作**的单向链，不反向依赖。

### 3.5 正式素材库 = 素材编辑的唯一落点（前 MVP）

单个素材的简单调整（改数值、换表现引用、改名/介绍等）**在正式素材库中完成**——它是「编辑素材」时的可调用对话框，遵循「方便」原则（就近修改，不折返研究台）。见 `创作系统/01` §三「前 MVP 研究台/LLM 职责解耦」。

## 三·五、门缝（世界气味）：辅助叙事载体

### 定位

门缝是第三条接触面，但**不是功能承载物**——它不放素材、不做收藏、不建菜单。它是**世界的气味**：把无法也不应该全部在对局里讲清的事，用「门口被塞进一张纸条」送进住处。

它**不是进入游戏的入口**（不做副本身份、不做一键进主线），纯粹辅助叙事。

### 为什么是门缝，不是信箱

近未来题材里**信箱很怪**——快递、缴费、通信都数字化后，门缝投纸成了残留的、带着体温的动作。门缝塞纸条这个物理动作，比"邮箱"更有生活感，也更贴近"有人趁你不在，撬开这道缝，塞了点东西"的潜伏感。

### 纸条类型（黑色幽默 + 生活气息）

部分主线结束后，**过一段时间**会在门边出现纸条，内容不需要进对局，只是世界在说话：

- **告知书 / 通知**：官方口吻、但内容荒谬（"梦境信号欠费"偏偏送的是纸质通知）。
- **信 / 便条**：来自某个人，一句话的情绪。
- **传票 / 公文**：不知道谁寄的，措辞正规但指向不明。
- **水电费单**：最"无厘头但真实"的生活气——新时代的人还在为几十块的水电单发呆。

基调延续游戏整体的**无厘头 + Z 世代黑色幽默**：越是正经生活化的东西，越衬出"世界其实已经魔幻到没人察觉"。

### 节奏：主线间歇不可连续

- 部分主线的任务**不可连着来**，至少间隔（如 ≥1 分钟，或等下一张纸条出现）。
- 门缝纸条承担**节奏呼吸**：它把"刚打完一段主线"和"下一段主线"之间隔出一个生活空隙，玩家可以在这口气里做局外的事（整理书架、开保险箱、回研究台）。
- 具体间隔、纸条掉落表与文本属于叙事/编排后续，写进设计即认可"主线不可无限连打、需要生活喘息"这一边界。

### 与其它接触面的关系

- 门缝 **不承担**床的入梦入口、信箱的功能入口；它是唯一一条**只叙事、不入口**的接触面。
- 与保险箱（高价值陈列）、书架（素材）、台历/日程（进度）并列，各占一句，互不重叠。

## 四、依附型素材（"属性"怎么填）——既有机制已承接

用户提出一个此前悬挂的难题：**一些属性（如伤害类型）是否可以在编辑时随便填？**

**答案：不需要自由文本。** 检索既有文档确认，机制已经存在，本轮不新造架构层：

- **`创作系统/01` §五 `placeable:false` = 依附类**：中毒、散射属性、穿透伤害等，**不能摆到节点，只能填进别人的插槽**。这些就是书架上"属性/依附型素材"的载体。
- **`创作系统/01` §六 实例插槽填充**：属性经**工作台插槽**填入，`accepts` 类型约束承担搜索压力，`predicate?: Expr` 可选过滤；数值范围由**基类声明夹紧**（推杆滑块，超范围在控件层面即不可能）。
- **`L2_基类层/06` §7.7**："素材（工具箱）= 玩家素材库，单实例化，纯玩法层"——素材**本身就是一个实例**（单 def JSON）。

**结论——"非实例化素材"应改述为"依附型素材"：**

> 属性不是编辑时手打的自由文本，而是**依附型素材（`placeable:false` 的实例）**，经工作台插槽 + `accepts`/`Expr` + 基类夹紧填入。它**不在书架里浏览**——书架只陈列**可放置元素**与**蓝本**；依附型属性归属**工作台/研究台的"依附类分区"**（守创作/01 §五"属必须为依附类设独立分区"），作为词汇被别的实例插槽引用。

这解决了"伤害类型随便填怎么办"：伤害类型 = 一个依附型素材实例，被武器实例的插槽以 `accepts` 约束引用，范围由基类声明夹紧，结构化为词条而非自由文本，且不会出现在书架的可浏览素材里。

## 五、星标 vs 保险箱收藏：两套不混

| | 星标（书架） | 保险箱收藏（收藏室） |
|---|---|---|
| 在哪 | 书架 | 保险箱 |
| 装什么 | 素材库的常用元素/蓝本 | 运营推进的纪念/高价值对象 |
| 目的 | 编辑时快速取用 | 回看、里程碑、推进痕迹 |
| 本质 | 快捷订阅（同一素材列表内的排序） | 独立陈列（另一种容器） |
| 是否进入对局 | 否（只是快捷取用标记） | 否（守运营/01 反带入带出） |

**星标是"排序把常用素材放前面"，保险箱收藏是"把纪念物单独收起来"——两者语义不同，不混为一谈。** 同一素材既可以在书架里被星标置顶，也可以（如果它是纪念物）放进保险箱，互不冲突。

## 六、MVP 范围

| 项 | 状态 |
|---|---|
| 保险箱 | 抽屉式平铺 + 左侧带色类别栏 + 右侧详情/大图 + 可使用按钮 |
| 书架 | 浏览元素/蓝本 + 星标置顶 + 基础检索 + 回编辑器切换入口 |
| 门缝 | 纸条/传票/水电单出现 + 阅读（纯叙事，不入口） |
| 依附型素材（属性）填槽 | MVP 只打通工作台插槽填充（accepts/Expr/基类夹紧，见创作/01） |
| 保险箱"开箱子"等使用型增量 | 不做（可做增量，非承诺） |

本轮明确不做（非否决，是后期专题）：

- 保险箱的完整使用型玩法（开箱、合成等）。
- 素材库高级检索（多条件、语义搜索）。
- 星标的云同步/跨账号。
- 塔科夫式整理、套装演算、对局前配装（守全局反仓库）。
- 门缝的完整纸条掉落表与文本编排（属叙事/编排后续专题）。

## 八、总结

保险箱 = **质感收藏栏**（抽屉平铺 / 带色类别 / 详情大图 / 可使用 / 拒堆叠 / 无丢弃），重回看与推进感；书架 = **检索优先素材库**（星标置顶 / 快速检索 / 与编辑器高频切换）；门缝 = **世界气味**（辅助叙事，不入口，纸条/传票/水电单，主线间歇不可连续）。"属性怎么填"的难题由**依附型素材**承接：属性是 `placeable:false` 的实例，经工作台插槽 + `accepts`/`Expr` + 基类夹紧填入，**不在书架浏览**。星标（快捷订阅）与保险箱收藏（纪念陈列）两套不混。
