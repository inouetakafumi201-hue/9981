# 素材记忆与消耗系统（定案）

> **2026-08-16 定案全链路**。本文定的是「素材如何被带进对局、如何被使用、用什么代价」的完整机制：
> **词条提取 → 合成台（LLM 守门）→ 塑形消耗**，一条从获取到遗忘的自洽链条。
> 成本靠**结构（遗忘）+ LLM 平衡守门**，不靠**估值函数**——玩家看的是语义，机器保证合法性，LLM 翻译成 JSON。
>

## 一、第一性：这个机制为什么存在

玩家的核心诉求是**把自己造出来的东西带进游戏里用**。上传别人的素材可以拦（没有付出），但在研究台/合成台里亲手造的，玩家的渴望拦不住也不该拦——这是创作系统的核心幻想：「我造的机制在我的梦里战斗」。自建房（自己开图）只有少数硬核玩家会去，多数人没有环境与时间，所以必须有一条「把自造带进正规对局」的路，否则创作系统对大多数玩家是死的。

但玩家的**创作欲望 ≠ 创作能力**。大多数玩家不具备「设计自洽玩法」的能力，也不愿意学规则、碰 JSON、理解基类层。传统方案（插槽类型穷举 + 合法性校验）会把心智负担压在玩家头上——这是死路。

**设计约束（本轮反复验证后锁死）**：

1. **不做估值**：玩家带素材进局涉及「强度 × 组合」的开放空间，任何「给单件定值」的体系都必然漏组合涌现（两个中等素材合出超模效果）。平衡不靠算，靠结构 + LLM 守门。
2. **零心智负担**：玩家不需要计算、不需要担心、不需要懂规则。玩家看的是**自然语言语义**（"火焰"、"散射"），不是代码层枚举（`DMG_04`、`weapon.capability.scatter`）。合法性由 LLM 保证，玩家永远不碰 JSON。
3. **反路径依赖**：防「社区抄一个最优解然后全版本用它」，但不用禁表（卡牌式单件管理是高心智负担）。
4. **防「不敢用」**：素材不能变成囤着不用的收藏品——试的代价必须是零，投入必有所得。
5. **可玩性 > 可拓展性**：每一环都要有玩家主动权衡的决策（"哪个值得提取"、"稳还是赌"、"舍得用吗"），不是线性门槛。

## 二、完整链条（三环消耗）

```text
【第一环】提取词条：素材 → 抽离语义词条（烧素材）→ 得词条（文本 + 品质 1-5）
          ↓
【第二环】合成台：基体素材 + 词条 → LLM 看语义 + 品级约束 → 新素材 JSON（烧基体 + 词条）
          ↓
【第三环】塑形消耗：带进局 → 塑形（失败零成本）→ 成功 = 失去成品
```

**三重消耗链路**：提取烧素材 → 合成烧素材+词条 → 塑形成功失去成品。每一环都有决策（哪个抽 / 稳还是赌 / 舍得用吗），不是线性门槛。

**LLM 是唯一的 JSON 生产者**，玩家永远不碰 JSON、不碰合法性校验、不碰基类层。玩家做的是**语义组合**（"我要火焰 + 散射 + 这把枪"），LLM 翻译成 JSON（"好，我给你一把合法的火焰散射霰弹枪，品级 X"）。

## 三、词条（Attribute Token）：语义解耦的核心

**词条 = 从素材中提取的纯语义属性**，是组合的原子单位。它不是 JSON、不是代码层枚举，是**自然语言描述 + 品质档位**。

### 3.1 词条的结构

```
词条 = {
  名称: "烈焰"（玩家可读的自然语言）
  描述: "造成火焰伤害，对易燃目标额外效果"（语义话术，即 JSON 机制的自然语言版本）
  大类: "属性"（玩家记忆锚点，见 §3.2）
  品质: 1-5（档位，影响合成产物强度）
  颜色: 橙红色（品质色，见 §3.4）
}
```

**关键特性**：
- **不保留 JSON**：提取后，词条只保留语义文本 + 品质数字，原素材的 `DMG_04` / `weapon.capability.scatter` 等代码层字段全部丢弃。LLM 在合成时从语义重新翻译成 JSON。
- **命名自由**：词条名称不需要对齐代码层枚举。"烈焰" / "火焰" / "燃烧" 都可以，LLM 认识自然语言，会翻译成 `DMG_04`。
- **白名单提取**：不是素材所有属性都能提取，只有**打词条标签的属性**可提取（设计者预先标记的可提取清单，机器可查）。
- **描述 = 机制话术**：词条的描述是机制的自然语言版本（"施完攻击后获得一个零费移动动作"），它既是玩家可读的机制说明，也是 LLM 从语义解耦成 JSON 的准绳。这是"同构"的核心：**词条行就是成品 JSON 语义组件的可视化**。

### 3.2 词条五大类（玩家记忆锚点 + 软合法性）

**五大类 = 玩家心智的锚点**（掌控感来源），是隐性的玩法限制（带来玩法），不是硬逻辑（跨类由 LLM 软裁）。所有词条的软合法性本质归到 3 个意图维度（技能/状态/强化），但属性太重要单独拆出，防御/机动作为强化分支单独分档：

| 大类 | 本质 | 玩家心智 | 首批词条 |
|---|---|---|---|
| **① 属性** | 强化（跨类融合基底） | "这东西是什么属性" | 烈焰、冰冻、穿透、钝击、锐器 |
| **② 技能** | 技能（动作级能力） | "我的攻击附带什么动作/能力" | 冲锋、散射、快拔、架枪、压制、屏息 |
| **③ 状态** | 状态（临时施加） | "我给目标上什么 debuff" | 中毒、迟缓、眩晕、致盲、虚弱 |
| **④ 防御** | 强化（生存向分支） | "我怎么活下来/更肉" | 减伤、格挡、反弹 |
| **⑤ 机动** | 强化（位移向分支） | "我怎么移动/追击/撤退" | 闪避、潜行、跳跃 |

**为什么 5 类是甜蜜点**：
- **3 类太粗**（强化/技能/状态）：玩家看到"强化"不知道是伤害还是机动，掌控感弱。
- **5 类**：卡在米勒定律上限，每类语义边界清晰（属性=攻击属性、技能=动作能力、状态=debuff、防御=保命、机动=位移），玩家看颜色+图标就能归类，心智负担可控。
- **7 类太细**：玩家要记每类边界，积累感弱（每类都要攒，掉落分流）。

**五大类 vs 跨类融合（关键区分）**：
- **五大类 = 绝对不能乱插的玩法机制限制**。玩家把"减伤"（防御）和"子弹"（武器）硬拼 = LLM 判定语义不相容 → 低品质产物。这是**玩法机制**（玩家学习"乱拼做不出好东西"），不是逻辑错误（LLM 能处理但给差结果）。这就是 LLM prompt 微调就能做到的软合法性。
- **跨类融合 = 词条对宿主的适应性**。"属性"词条可跨宿主（烈焰贴武器=伤害属性、贴防具=抗性、贴实体=元素亲和）；"技能"词条可跨宿主（冲锋贴武器=攻击后追击、贴防具=受击后撤退）。这是词条的属性，不是"乱插"。

### 3.3 词条白名单（首批 22 个）

从基类层 capability/DMG/status 契约提取，每个都对应已定义的 JSON 契约（软合法性 + 简介即机制话术）：

| 大类 | 词条 | 对应 JSON 契约 | 玩法性来源 |
|---|---|---|---|
| **① 属性** | 烈焰 | `DMG_04` | 配"易燃"弱点 |

| | 穿透 | `DMG_03` | 破掩体/多目标 |
| | 钝击 | `DMG_02` | 通用，配"刚体" |
| | 锐器 | `DMG_01` | 通用，配"缝隙" |
| **② 技能** | 冲锋 | `assault_advance` | 攻击后 0 费移动（追击/撤退/风筝，战术深度最高） |
| | 散射 | `scatter_shot` | 近距免瞄 + 群体 |

| **③ 状态** | 中毒 | `status_poisoned` | 持续伤害，叠加燃烧=火烧毒 |

| | 眩晕 | `status_stunned` | 控场 |

**精选原则**：高频使用 + 语义明确 + 组合空间大 + 简介即机制话术（LLM 可解耦）。弹容量、射程 DC 表等内部数值字段**不是词条**，不可提取。

**发展性**：词条库 = 五大类固定 + 每类成员可增量（运营加新词条 = 加一行 JSON 到对应大类，不碰槽位结构）。想加新大类 = 设计决策（开发者级），不是玩家操作。

### 3.4 词条提取（第一环消耗）

- **操作**：玩家选一个素材 → 聚焦某个属性（如"火焰伤害"）→ **失去该素材** → 得到词条（纯语义 + 品质）
- **消耗**：提取即烧掉素材，不可逆。低价素材（记忆成本低）提供大部分词条来源——这让低价素材有了组合生命。
- **品质生成**：词条品质 = 素材语义价值（LLM 评级，见 §二）+ 随机波动。高价素材必出稀有/史诗词条，低价素材大概率出普通词条。

**决策点**：哪个素材值得抽（性价比 vs 稀缺性）、现在抽还是等攒多再抽（提前抽 = 快合成但亏素材）。

### 3.5 词条品质五档（抽卡感第一层）

| 品质 | 名称 | 颜色 | 出现概率 | 来源 |
|---|---|---|---|---|
| 1 | 普通 | 灰白 | 高 | 低价素材、保底 |
| 2 | 优秀 | 绿 | 中高 | 中等素材 |
| 3 | 稀有 | 蓝 | 中 | 中高价素材 |
| 4 | 史诗 | 银 | 低 | 高价素材、突破阈值 |
| 5 | 传说 | 金 | 极低 | 极高价素材、小概率奇迹 |

**概率不对等设计**：高品质词条稀缺（突破阈值的词条很少），这样更高品质的成品就少见（组合不出来 = 天然稀缺）。品质 4-5 词条的稀缺性来自**素材源头**，不是合成随机——玩家要想出传说成品，必须先攒到传说词条，而传说词条只能从极高价素材提取。

## 四、合成台（LLM 守门人）：语义 → JSON 的翻译器

> **界面落点（2026-08-19）**：合成台的**界面载体是研究台**（`docs/运营系统/07_素材库机制与元状态层全设计.md` §六）——词条库（材料收集库）、锻造工作台（改枪式 5 槽）、合成仪式（3 台子特效演出）、塑形备选栏全部在研究台内。本节仍定**机制**（流程/公式/降级/裁决），界面细节见 07。

合成台是整个系统的核心突破：**玩家组合语义，LLM 保证合法性和平衡**。玩家不需要懂规则、不需要知道什么能组合、不需要碰 JSON——LLM 是那个"无限分类专家"和"平衡守门人"。

### 4.1 合成流程（改枪式插槽）

```
1. 玩家在锻造工作台选基体素材（如"手枪"，仅拥有库）+ 词条（最多 5 个，每大类槽位 1 个）
2. 投料：基体 + 词条全部消耗（第二环消耗）
3. 点击「合成」→ 全屏跳进高科技锻造入口 → 3 个台子的合成 UI（见 07 §6.5）
4. LLM 预演/合成进行：组件悬浮摆动/高速旋转/粒子电焊划过（覆盖 LLM 真实消耗时长）
5. 完成：高光爆发 + 成品浮现 → 点开面板 → 收下（成品品级 1-5 + 具体形态）
6. 失败/驳回：成品变灰 → 面板显示解释 → 确定后素材与词条返还（见 §4.4/§4.5）
```

**改枪式插槽（自由 + 限制并存；2026-08-18 定案强化底图感）**：

```
合成台——武器工作台
┌─────────────────────────────────────┐
│  基体：手枪（基础骨架，来自拥有库）     │
│                                      │
│  槽位（= 五大类，固定 5 个）：         │
│  [属性槽] ← 默认「烈焰」（底图感）     │
│  [技能槽] ← 默认「快拔」（底图感）     │
│  [状态槽] ← 空（可选）                │
│  [防御槽] ← 空                        │
│  [机动槽] ← 空                        │
└─────────────────────────────────────┘
```

**改枪式的关键**：
- **槽位 = 五大类**（属性/技能/状态/防御/机动），固定 5 个，不是物理构件。
- **每类槽位 1 个词条**（极致堆料：5 槽全满 = 5 词条素材），不能双重强化（不能放 2 个属性词条）。
- **底图感（2026-08-18 定案）**：槽位**可能预先就有默认词条**（素材自带），拖新词条是「盖上去」。**只替换、不删除**——没有清空槽位操作；把词条拖回词条库/快捷栏 = 默认值自动恢复（像底图弹回来）。空槽可拖入填充，一旦填充只能替换。
- **槽位可空**（不是必须填满，空槽 = 少一个词条 = 低品级但可用——空槽本身就是"这素材在此维度弱"的特性）。
- **拓展性 = 往大类池加词条**（不碰槽位结构）。想加新大类 = 开发者级设计决策。

**心智负担正是从这里降低**：所有素材（武器/防具/实体）都是 5 个固定大类槽位，每槽从对应池选 1 个。玩家不用学"这个素材有什么槽"，永远是"5 大类，每类 1 个词条"。

**实体素材（NPC/场景）同样用改枪式**：
```
合成台——NPC 工作台
┌─────────────────────────────────────┐
│  基体：巡逻守卫 NPC                   │
│  [属性槽] ← 元素亲和（烈焰守卫）       │
│  [技能槽] ← 攻击（范围攻击）           │
│  [状态槽] ← 警戒（感知范围扩大）       │
│  [防御槽] ← 减伤（重甲守卫）           │
│  [机动槽] ← 潜行（潜行守卫）           │
└─────────────────────────────────────┘
```

**玩家零输入**：不能打字、不能写 prompt（防提示词攻击）。LLM 只看材料组合的语义，不接受玩家指令。

### 4.2 成品品级公式（抽卡感第二层）

成品品级决定产物强度上限，是平衡的核心闸门。公式：

```
原始分数 = Σ(词条品质) × 0.4 / 词条数量 + 基体素材价值 × 0.6 + 随机波动

随机波动 ~ N(0, 0.5)  // 高斯分布，标准差 0.5

成品品级 = ceil(max(原始分数, 0))  // 向上取整，最小值 1

品级范围: [1, 5]
```

**参数说明**（2026-08-16 定案）：
- **基体权重 0.6 > 词条权重 0.4**：基体主导（鼓励用好素材做基体），词条是强化方向不是主体。
- **词条分数平分**：多个词条的品质求和后平分，不是累加（3 个普通词条 ≠ 1 个史诗词条）。
- **随机波动 ±0.5 高斯分布**：约 68% 落在 ±0.5 区间内（小波动，下限稳），约 95% 落在 ±1.0 区间（可跨一档，既有惊喜也不至于崩）。**高斯系数是测试重点**，实际分布需根据玩家体感调优。
- **向上取整 + 保底 1**：投入必有所得，不出废品（品级 0）。公式算出 0.3 → 取整到 1。

**品质稀缺性传导**：品级 4-5 成品要求基体 + 词条都是高品质，而高品质词条只能从高价素材提取 → 稀缺性来自源头（攒料难），不是合成随机 → 天然控制高品产出。

### 4.3 弱点 = 素材与生俱来的裂缝（LLM 随机赋予）

**弱点不作为词条**——没人会想给自己组合弱点，玩家永不主动选。但每个成品素材都**与生俱来带着一个弱点**，由 LLM 按品级 + 语义合理性从弱点池赋予。它做三件事：

1. **平衡减分项**：任何素材都不是无懈可击，弱点克制它的某个面向——高品素材配一个"相称的罕见弱点"，防止"最强组合 = 无脑赢"。
2. **随机性的一部分**：同品级同词条组合，LLM 会贴不同的合理弱点 → 玩家合成时不知道"会带什么裂缝"，这是抽卡的隐藏维度。
3. **叙事合理性**：弱点是素材"语义的裂缝"——金属素材配"易蚀"、电子设备配"感电"、火属性素材配"易燃"，玩家看到弱点能理解"为什么这东西是这样"。

**弱点品质规则**：

| 品级 | LLM 贴什么弱点 | 效果 |
|---|---|---|
| 1-2 | 大众弱点（缝隙/刚体） | 便宜——对多数攻击形式不利的弱 |
| 3-4 | 语义相符的稀有弱点（感电/易蚀） | 较强减分，但符合素材语义 |
| 5 | 相称的罕见弱点（脆弱/暴露/迟钝） | 高品不无敌，代价可见 |

**弱点池（10 个，对齐基类层 vulnerability-types）**：缝隙、刚体、易燃、冷脆、易蚀、感电、负重、脆弱、暴露、迟钝。

**玩家体验**：玩家不需要考虑弱点（不合直觉），但它真实存在——在详情页看到成品的"裂缝"，在战斗中会被针对性攻击克制。这是"你的作品不完美"的叙事，也是克制最强组合的结构闸门。

### 4.4 LLM 失败降级与驳回返还

**两类失败，不同结果**（2026-08-18 定案，界面见 07 §6.5）：

| 失败类型 | 触发 | 结果 |
|---|---|---|
| **LLM 输出不合法** | 输出非合法 JSON → 重试 3 次仍失败 | 降级到品级 1 的保底模板（"生成失败，给你一个最基础的产物，材料已消耗"）；保底模板 = 硬编码品级 1 基础素材 |
| **LLM 驳回（语义裁决）** | 词条与基体语义不相容（乱拼） | 成品变灰 → 面板显示解释（"这个组合差点意思"）→ 玩家点「确定」→ **所有素材和词条返还**（不消耗） |

> 区分：**降级**是技术失败（LLM 没给出合法产物，材料照耗、给保底）；**驳回**是设计裁决（玩家乱拼，软惩罚但材料返还——把「乱拼做不出好东西」教会玩家，又不至于摧毁投入，守 §4.5 软合法性）。

### 4.5 乱拼的软裁决（LLM prompt 微调）

**五大类是玩法机制限制，不是逻辑错误**。玩家把风马牛不相及的词条硬拼（如"减伤"贴到"子弹"上），LLM 判定语义不相容 → **产出低品质产物**（"有点但不是好果子"）。这在 LLM prompt 里微调就能做到：

```
prompt 补充规则：
- 词条与基体语义相容（如"散射"贴枪械）→ 正常合成，产物品质按公式
- 词条与基体语义不相容（如"减伤"贴子弹）→ 产物品质降 1-2 档，形态朝"勉强能用但有明显缺陷"的方向生成
- 合理跨宿主的词条（如"冲锋"贴防具 = 受击后追击）→ 正常适配，触发点跟宿主走
```

**这完成了"软合法性"闭环**：5 大类 = 推荐的强组合区（玩家可预期的甜蜜区），LLM = 跨类组合的软裁判（合理跨类接受、乱拼给低品质），玩家自然学会"乱拼做不出好东西"——不需要硬插槽穷举，也不需要玩家学规则。

### 4.6 合成时间与队列

- **真实 LLM 调用时间**：约数分钟
- **演出时长**：60左右秒真实等待 + 精美进度条（仪式感，不人为拖延到几分钟）可异步干其他事情。

### 4.7 决策点（可玩性注入）

- **投什么基体**：好料 = 下限高（最差也是中等产物），烂料 = 下限低（可能出低品但也可能惊喜）
- **投什么词条**：稀有词条 = 必烧掉但产物方向明确，普通词条 = 便宜但产物可能平庸
- **稳还是赌**：材料品质决定产物下限（保底），随机波动决定上限（惊喜）。玩家权衡"我用好料保底还是烂料博惊喜"。
- **空槽 vs 填满**：空槽 = 低品级但可用（"这素材在此维度弱"也是特性），填满 = 高品级但烧更多料

## 五、塑形消耗（第三环）：最后一舞

> **界面落点（2026-08-19）**：塑形备选栏在锻造台界面**最下方**（科技感长条框，固定 5 格、解锁/锁定状态、拖入替换）。本节仍定**机制**。

合成台产出的新素材，可以带进对局使用——这是「最后一舞」。

### 5.1 使用流程

- **带上战场**：从**塑形备选栏**（锻造台界面最下方）取用，占槽位（1–5，至多 5 个，随主线解锁；套餐可加槽，见 `运营/05` §5.2），不消耗。带而不塑形 = 素材完好保留。
- **塑形**：局内动作，清醒度（=体力）低是施法窗口、清醒度高直接不给用（守 [`../L3_玩法层/01_行动轮与体力博弈系统.md`](../L3_玩法层/01_行动轮与体力博弈系统.md) 的既有定案）。
- **失败 / 未塑形出来**：零成本，素材完好保留（**但占用本回合零费动作位**，见 §5.4）。
- **塑形成功**：**即刻失去成品素材**，需要重新合成（走 §四 的合成流程，重新攒基体 + 词条 + 再过一次 LLM）。

**这就是「最后一舞」**：合成出来的东西，用出来就是绝唱。攻略免疫是结构自带的——社区传开最强组合 → 人人都能用一次 → 全部重新攒料 + 重新合成。「公共知识只值一次」，不存在「累积的最优解」，只有「一次性烟花」。版本之子这个词在这个机制里没有定义。

### 5.2 标准件 vs 合成物（双层兜底）

| 类型 | 来源 | 消耗规则 | 用途 |
|---|---|---|---|
| **标准件** | 副本 / 主线剧情直接领取 | 塑形成功也失去，但重刷快、无额外代价 | 兜底「不敢用」，日常可靠选择 |
| **合成物** | 合成台产出 | 塑形成功失去，重新合成需重新攒料 | 高光时刻，「绝境反杀」的神器 |

**双层结构的意义**：标准件便宜可反复（玩家随便用），合成物贵是一次性（玩家权衡"这局值得烧神器吗"）。防「不敢用」的退路在标准件，合成物才是戏剧性峰值。

### 5.3 决策点

- **什么时候塑**：清醒度窗口管理（低体力 = 窗口，泛白区推高体力 = 失败，与缩圈侵蚀天然冲突）
- **带哪个**：槽位 1-5 上限，带标准件稳健 vs 带合成物赌一把
- **舍得用吗**：合成物用了就没，这局值得吗？绝境时刻「最后一舞」的决断

### 5.4 塑形 HUD 与交互流程（2026-08-19 定案）

> 本节定**对局内**塑形的 HUD 形态、交互时序、DC 判定、零费动作位约束。**前置**：玩家已在 `L3_玩法层/01_行动轮与体力博弈系统.md` 完成一个付费动作（移动 / 攻击 / 拾取 / 使用等），依「依附规则」可触发本回合一个零费动作；塑形即零费动作的一种入口。

#### 5.4.1 HUD 形态

- **位置**：行动轮**右上方**（玩家最在意的 UI 区域，与 AP/HP 栏相邻）。
- **形态**：一根长条科技感悬浮组件，由 1-5 个方格横向排列。
- **槽位数**：玩家带入局的素材数（上限 5；不足时显示灰色空槽占位）。
- **空 HUD 规则**：若玩家**未带任何素材进局**，整个组件不出现（行动轮右上方无该组件），不浪费 UI 空间。
- **方格三态**：
  - **空槽**：灰色描边 + `+` 占位（提示玩家可带回素材）。
  - **已带素材**：素材小图（正面俯视图）+ 品级颜色描边（灰白 / 绿 / 蓝 / 银 / 金）。
  - **本回合零费已用**：方格变灰（不可交互，对局结束前都不会再亮起）。

#### 5.4.2 状态机（玩家交互全时序）

| 状态 | 触发 | 表现 |
|---|---|---|
| **悬停** | 鼠标悬停方格 | tooltip：素材名 / 品级 / **塑形 DC**；方格描边发光（品级颜色） |
| **长按起点检查** | 鼠标按住方格，t=0 | 见 §5.4.4 |
| **充能中** | t=0~3s | 素材图标从轻到重晃动 + 方格下方进度条从 0 → 100% + 低频嗡鸣累积音 |
| **充能中松开** | t<3s 松开 | **直接消失，无副作用**，不消耗零费动作位，本回合仍可塑形其他素材 |
| **充能满 → 投点** | t=3s | 行动轮右侧出现 d6 投点 UI（约 1 秒）；**占零费动作位**（无论后续成败） |
| **成功** | 投点 ≥ DC | 纯白特效（约 0.5 秒）+ 物品进左手/右手空槽 或 实体生成在玩家旁无碰撞箱处 + 颜色恢复 + 素材从方格消失 + 方格变回空槽 |
| **失败** | 投点 < DC | 方格红色脉冲（约 0.5 秒）+ 中断短音 + 素材保留在方格 + **本回合此素材不可再次长按** + **本回合零费动作位已用，所有素材不可再塑** |

#### 5.4.3 塑形 DC 公式（d6 投点必须 ≥ DC）

```
塑形 DC = 当前体力值（1-5）+ 品级修正
品级修正：1→+0, 2→+1, 3→+2, 4→+3, 5→+4
```

**d6 投点必须 d6**（不是 d20，不是 2d6）。DC 区间与 d6 成功概率表：

| 体力 \ 品级 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| **1** | DC 1 (100%) | DC 2 (33%) | DC 3 (67%) | DC 4 (83%) | DC 5 (100%) |
| **2** | DC 2 (33%) | DC 3 (67%) | DC 4 (83%) | DC 5 (100%) | DC 6 (17%) |
| **3** | DC 3 (67%) | DC 4 (83%) | DC 5 (100%) | DC 6 (17%) | DC 7 (0%) |
| **4** | DC 4 (83%) | DC 5 (100%) | DC 6 (17%) | DC 7 (0%) | DC 8 (0%) |
| **5** | DC 5 (100%) | DC 6 (17%) | DC 7 (0%) | DC 8 (0%) | DC 9 (0%) |

概率口径：`d6 ≥ DC`，所以 DC 1 = 6/6, DC 2 = 5/6, DC 3 = 4/6, DC 4 = 3/6, DC 5 = 2/6, DC 6 = 1/6, DC 7+ = 0/6。

**设计解读**：
- **体力越低，塑形越易**：体 1 时所有品级都能塑（17%~100%）—— 「清醒度低 = 塑形窗口」的物理解。
- **高品级要求更疲惫**：体 5 + 品 5 = DC 9 = **100% 失败**——「清醒度高直接不给用」（06 §5.1）的精确落地。
- **品级 1 几乎不可能失败**：体 1 全过，体 2-5 都是 17%~83%——低品级不值得塑（产物弱）；高品级难塑但产物强。
- **DC 7+ 不是 0% 区**：塑型是一次标准的DC判定，使用了骰子标准动画，所以会受到强力骰状态的强化。在使用强力骰的情况下，DC7+仍可能成功。

#### 5.4.4 长按起点检查（拒绝条件）

t=0 时按以下顺序检查，**任一不通过即阻止**：

1. **本回合零费动作位已被占用**（之前本回合做过丢弃 / 取消格挡 / 另一素材塑形成功或失败）
   - 阻止：方格不进入充能 + toast「本回合零费动作已用」
   - **不消耗零费动作位**（不占双倍）
   - return
2. **素材是物品，但玩家左手槽 + 右手槽都不空**（任一手空即可；双手武器按 L2/04 §4 占 1 格规则）
   - 阻止：方格不进入充能 + toast「双手已满，无法塑形」
   - **不消耗零费动作位**
   - return
3. **素材是实体**（NPC / 守卫 / 陷阱 / 场景元素等）—— 不需要槽位，直接通过
4. 检查全部通过 → 进入 §5.4.2 充能阶段

#### 5.4.5 零费动作位约束（反 spam 铁律）

> **2026-08-19 收紧**：原 06 §5.1「失败零成本」仅指「素材不消失、不消耗 SP/AP」；本节新增**零费动作位**约束——**无论成败，充能满后即占用本回合零费动作位**。

```
本回合已触发零费动作（成功或失败）
  → 本回合内：
    ├─ 不能再塑形任何素材（同回合不可对同一素材重复尝试 = 「同一回合不可塑同一素材」）
    ├─ 不能再丢弃物品（其他零费动作入口也闭锁）
    ├─ 不能再取消格挡
    └─ 下一个零费动作必须等下一回合的付费动作之后
```

**为什么失败也消耗零费额位**：
- 防 spam：玩家不能 5 个素材全点一遍试 DC（否则浪费三秒 × 5 + 充能中松开 = 0 代价就能穷举）
- 决策成本：玩家必须**先选定哪个素材值得拼**，不能乱试
- 戏剧性：失败本身就是「这一回合你选了这条路，没成」—— 这一回合的零费机会已经被这段尝试消费掉了

**与「充能中松开 = 取消」的边界**：
- 充能 t<3s 松开 → 不占零费位（玩家可以反复长按**试探** UI 反馈，但每次都要重新等 3 秒充能）
- 充能 t=3s 满 → 立刻占零费位（投点之前已占，不允许「后悔」式撤销）

#### 5.4.6 塑形产物落地

| 素材类型 | 落地位置 | 物理/交互规则 |
|---|---|---|
| **物品**（武器 / 防具 / 消耗品 / 盾牌 / 单双手武器等） | 左手槽或右手槽（任一空槽） | 双手武器按 L2/04 §4 占 1 格规则（任一手空即可） |
| **实体**（NPC / 守卫 / 陷阱 / 场景元素） | 玩家旁边无碰撞箱处 | 由 ORCA 寻路层支撑后续互动规则（`L1_引擎层/05` 引擎层 ORCA 三重寻路）；不占用槽位；本回合可立即指挥 |

#### 5.4.7 视觉与听觉契约（表现侧落地）

- **HUD 风格**：长条悬浮科技感组件（具体材质/光效见 `表现系统/01`「驻地演出」节的 HUD 风格基线）
- **方格动画**：
  - 悬停 = 描边发光（品级颜色）
  - 长按 = 晃动（频率随充能递增）+ 下方进度条从格子底部向上充能
  - 成功 = 纯白渐变 0.5s + 方格淡出
  - 失败 = 红色脉冲 0.5s
- **音效**：
  - 充能中 = 低频嗡鸣累积音
  - 成功 = 纯白短爆音（与入梦返回同一种语言，「纯白显形」统一家族）
  - 失败 = 中断短音
- **投点 UI**：行动轮右侧出现 1d6 投点（约 1 秒），与既有 `DC 检测` UI 一致

#### 5.4.8 决策点（与 §5.3 互补：本节聚焦「对局内单回合的塑形决策」）

- **本回合塑哪个**：玩家在 1-5 个素材里挑一个—— 体力低的优先（DC 起步低，成功率大）；高品级的慎重（DC 7+ 失败率高）
- **失败后本回合怎么走**：零费额位已用 → 不能用其他零费动作救场 → 必须走付费动作链
- **成功后的瞬间**：素材消失 + 物品上手 / 实体落地 + 行动轮 AP 状态更新—— 是否在本回合立刻用？AP 还剩多少？



## 六、上传禁令与双 LLM 分工

### 6.1 上传禁令（白嫖通道关闭）

| 导入动作 | 判定 | 能否带进对局 |
|---|---|---|
| **zip 拖进去（上传）** | 一律视为上传 | ❌ 禁止带入 |
| **合成台产出** | 游戏内材料 + LLM 裁决 | ✅ 可带入 |
| **玩法包 LLM 造出来的玩法包** | 游戏内工作台流程（界面=电脑） | ✅ 可带入（玩法包，不是素材） |

**关键澄清**：合成台产物**本质是 LLM 生成的**，但判定标准不是"是否 LLM 参与"，而是**"材料是否在游戏内付出过"**。

- **禁的是**：未经游戏内付出、从局外导入的 LLM 产物（LLM 工具直接生成素材 → zip 导入）
- **不禁的是**：游戏内材料（刷图攒的素材 + 提取的词条）+ LLM 裁决（翻译成 JSON）

合成台的材料是玩家攒的（提取词条要烧素材、合成要烧基体），LLM 只是裁决组合，不是创作源。这跟"玩法包 LLM 造的可带"同理：**付出了就可带**。

### 6.2 双 LLM 分工（明确边界）

| LLM | 用途 | 输入 | 输出 | 玩家输入 | 界面载体 |
|---|---|---|---|---|---|---|
| **合成台 LLM** | 守门人：语义 → JSON + 平衡 | 基体简介 + 词条语义 + 成品品级 | 单个素材 JSON | ❌ 零输入（防提示词攻击） | **研究台**（`运营/07` §六） |
| **玩法包 LLM** | 创作者：生成玩法包 | 玩家自然语言描述 + 四轮采访 | 完整玩法包 JSON | ✅ 可输入（必要交互） | **电脑**（2026-08-19 由造梦舱迁至电脑，见 `运营/07` §7.2） |

**合成台 LLM 不可替代玩法包 LLM**（命名对齐 2026-08-19：原「造梦舱 LLM」→「玩法包 LLM」，载体为电脑）：
- 合成台只能生成**单个素材**（武器/防具/消耗品），语义组合的自由度有限（基体 + 词条）
- 玩法包 LLM 生成**完整玩法包**（地图 + 规则 + 胜负条件 + NPC 配置），创作自由度高、门槛高、面向少数硬核玩家
- 合成台面向大众（满足"定制感"），玩法包 LLM 面向创作者（满足"设计欲"）

## 七、为什么这是答案（突破点）

这个设计的突破在于：**把三个本来互相矛盾的目标一把焊死**。

| 目标 | 传统方案的死因 | 本案的解法 |
|---|---|---|
| **UGC 自由度** | 任意组合 → 平衡爆炸 | 玩家组合语义，LLM 翻译成合法 JSON，品级守门 |
| **平衡可控** | 估值函数漏组合涌现 | 成品品级 1-5 是硬约束，LLM 用世界知识保证"品级 X 该多强" |
| **零心智负担** | 插槽类型穷举 + 合法性校验 | 玩家看自然语言，不碰 JSON；LLM 是"无限分类专家" |

**三角闭合的钥匙 = 词条语义解耦**：词条不是 JSON、不是代码层枚举，是纯文本。LLM 认识自然语言，翻译成代码层是它的活。玩家永远不需要知道 `DMG_04` 是什么。

**对照被否方案**：

| 方案 | 死因 | 本案的位置 |
|---|---|---|
| 设计货币 / 估值体系 | 给单件定值必然漏组合涌现；注册表式开放组合无定义域 | 不需要估值——成品品级由公式 + LLM 守门 |
| 反噬（按实际伤害结算） | 玩家要盯「这一下欠多少」——心智负担 | 不做结算类成本 |
| 禁表 / 单件定级 | 高心智负担；管不住组合涌现 | 不做单件管理 |
| 插槽类型穷举 | 为了合法性去穷举 → 永无止境 | LLM 是合法性守门人，不需要穷举 |
| 局内反噬做平衡阀 | 玩家要计算、会担心 | 反噬不承担平衡功能 |

**平衡 = 结构 + LLM 守门**：三重消耗（提取烧素材 → 合成烧素材+词条 → 塑形成功失去成品）+ 成品品级公式（基体 0.6 + 词条 0.4 + 高斯波动 ±0.5）+ LLM 品级约束（品级 X → 强度映射表）。四条全是机器可查的边界与成本，没有一个环节需要人工判断强度。

## 八、素材获取（可再生前提）

**可再生性是必然前提**：三环都消耗素材（提取烧 → 合成烧 → 塑形失去），来源必须可靠可刷，否则机制转不起来。

| 类型 | 来源 | 获取成本 | 重获取 |
|---|---|---|---|
| **标准件素材** | 副本 / 主线剧情直接领取 | 无 | 多刷几遍即可 |
| **可提取素材** | 对局掉落 / 地图特定位置「记忆」 | 刷几次就有 | 可再生（同一位置重复记忆） |
| **高价素材**（出稀有词条） | 特定副本 / 隐藏位置 / 完成挑战 | 难度高、次数限制 | 可再生但周期长 |

- 标准件（副本反复刷）→ 提取普通词条 or 直接当基体
- 高价素材（挑战 / 稀有掉落）→ 提取稀有/史诗/传说词条 → 合成高品成品

## 九、可玩性验证（每一环都有决策）

经营游戏的可玩性不在"环节少"，在"每环都有有趣的决策"。三环消耗的意义：

| 环节 | 消耗 | 决策点 | 可玩性来源 |
|---|---|---|---|
| **第一环：提取** | 烧素材 → 得词条 | 哪个素材值得抽（性价比 vs 稀缺性）、现在抽还是等攒多再抽 | 词条品质分级（1-5），高价素材必出稀有+ |
| **第二环：合成** | 烧基体+词条 → 得成品 | 投什么基体（好料保底 vs 烂料博惊喜）、投什么词条、稳还是赌 | 成品品级随机（公式+高斯波动）+ 同品级内 LLM 细节随机 |
| **第三环：塑形** | 成功失去成品 | 什么时候塑（清醒度窗口）、带哪个、舍得用吗 | 最后一舞的戏剧性，标准件兜底不敢用 |

**减负的钥匙**：不是删环节，是**把消耗从"负担"转成"决策"**。三环加起来不是三道门槛（攒 → 烧 → 再攒），是三层嵌套决策（选哪个抽 + 稳还是赌 + 舍得用吗）。

**循环周期验证**：刷图攒料 5 局 + 提取 1 次 + 合成等待 15 秒 + 带进局 1 局 = 总周期约 7 局（1-2 小时）。不算太长（节奏不断），不算太短（有积累感）。

## 十、待细化（技术实现与数值调优）

1. **词条白名单的完整清单**：首批 22 个已定（§3.3），完整清单待运营增量。每个词条需补齐：语义描述 + 代码层映射 + 品质生成规则 + 可贴宿主声明。
2. **成品品级公式的高斯系数**：当前 σ=0.5（标准差），实际分布需根据玩家体感调优。关键指标：品级 4-5 出现概率（目标：稀缺但可追求），品级 1-2 出现概率（目标：保底但不泛滥）。
3. **LLM Prompt 的完整 schema**：基类层 weapon/item/status/armor 的完整 JSON schema + 品级强度映射表的详细约束（完整版待技术对接）。
4. **词条语义→代码层枚举的完整映射表**：当前仅示例（词条映射见 §3.3 白名单），完整映射表待词条白名单确定后编写。
5. **素材批量生产工作流脚本落地**：玩法层实例 → 前端素材的转换（LLM 一次性语义评级，见 §4.2 公式同源的语义评级思路），尚未写成脚本，待开发期立项。
6. **素材价值（记忆成本）的量化**：现有设计里"素材价值"指语义评级（LLM grade 1-5），但尚未与 [`05`](./05_局外叙事、证据提交与经济循环.md) 的双货币体系（佣金 + 记忆碎片）完全对齐。待经济系统细化后确定具体数值。
7. **槽位口径裁决**：本机制的战斗塑形槽位（1–5，至多 5 个）与 [`05`](./05_局外叙事、证据提交与经济循环.md) §四证据提交桌面槽位（3–5）、§5.2 套餐加槽位（+1/+2/+3）是否为同一池——待裁决（倾向：分离，战斗 1-5 独立，证据提交另一池；套餐加槽仅影响战斗塑形槽位的上限扩展）。
8. **局内塑形检定的具体规则**：（2026-08-19 已落地于 §5.4）清醒度窗口、DC 公式、零费动作位约束、双手判定、HUD 形态、状态机、音效契约全部定案。后续微调（充能时长 3s 是否调整、品级修正斜率是否需要再次平衡）由 AI 调参专项承载。
9. **弱点池的拓展**：当前 10 个弱点（§4.3）对齐基类层 vulnerability-types，是否扩充待运营增量。

## 十一、与既有系统的接口（不破坏项）

- **1–5 数值铁律 / AP 经济不受影响**：本机制只碰「什么能带进对局」，不碰局内数值。合成产物的伤害/弹容/AP 成本全部守 L0 第四条。
- **记忆碎片货币**：提取词条、合成产物都花记忆碎片（学习成本），货币出口在 [`05`](./05_局外叙事、证据提交与经济循环.md) §五（对局掉落 + 证据提交奖励）。
- **双 LLM 分工守 L2/06**：合成台 LLM 守门人（单素材生成，界面=锻造台）vs 玩法包 LLM 创作者（玩法包生成，界面=造梦舱），边界见 §6.2 与 `运营/07` §六/§7.2。
- **表现侧**：词条提取/合成揭晓/塑形演出守 [`../表现系统/03_动画灵感索.md`](../表现系统/03_动画灵感索.md) §十；品质颜色（灰白/绿/蓝/银/金）守 D-066 全局颜色语义（银金是少量品级高光，不构成严格评级）。
- **塑形概念不混入造梦舱**：本机制的「塑形消耗」（§五，界面=研究台塑形备选栏）与造梦舱（地图编辑器，见 `运营系统/07` §一）**无关**——造梦舱走的是地图编辑路线，塑形只发生在素材被玩家带进对局之后；不要因为「塑形」也含"塑造形状"就被误读为"造梦舱的形状编辑"。两套语义已分裂。

## 十二、机制摘要（快速参考）

```
完整链条（界面落点见 `运营/07`）：
  获取素材（刷图）
    ↓
  提取词条（烧素材 → 词条文本 + 品质 1-5；研究台）
    ↓
  合成台（基体 + 词条 → LLM 看语义 + 品级公式 → 新素材 JSON；研究台合成仪式）
    ↓
  带进对局（研究台塑形备选栏 → 占槽位 1-3，随主线/套餐解锁）
    ↓
  塑形（失败零成本 / 成功失去成品）
    ↓
  重新合成（重新攒料 + 再过合成台）

关键公式（2026-08-16 定案）：
  成品品级 = ceil(max(基体价值×0.6 + Σ词条品质×0.4/词条数 + N(0,0.5), 0))
  品级范围：[1, 5]
  品质颜色：灰白(1) / 绿(2) / 蓝(3) / 银(4) / 金(5)

三重消耗：
  第一环：提取烧素材
  第二环：合成烧基体+词条
  第三环：塑形成功失去成品

LLM 守门：
  玩家组合语义（自然语言），LLM 翻译成 JSON（基类层契约 + 品级强度约束）
  合法性、平衡、自洽全由 LLM 保证，玩家零心智负担

双层兜底：
  标准件（副本刷，便宜可反复）兜底不敢用
  合成物（合成台产出，贵是一次性）是高光时刻
```
