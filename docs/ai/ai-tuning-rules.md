# AI 调参防转圈规则与边界决策指南（ai-tuning-rules）

> 本文件是 `ai-tuning` skill 的强制加载项之一。任何 agent 进入 AI 调参前必须完整阅读，
> 不得凭 memory 想当然或看漏。目标读者可能是资深玩家（调试者），输出须深入浅出。

## 一、防转圈 8 条红线（底线，不可违反）

1. **状态哈希锁定**：复现决策场景必须锁定同一 `stateHash` 快照，防止状态漂移导致归因反复。
2. **单点归因**：单轮只调一个费目，不同时调多个。
3. **迭代预算**：闭环默认上限 12 轮，到上限未收敛即停止，交回完整历史。
4. **环检测**：近 4 轮同一费目被调 ≥2 次 → 判定为环，停止。
5. **回归闸**：每次改动后跑全量 golden 场景，任何原本绿的被弄黄即回滚。
6. **禁碰清单**：玩家可见 1-5 值（vitality 等 `playerVisible:true`）与核心语义锚
   （`deathAnchor` / `exhaustionAnchor` / `lethalWindow`）禁碰，agent 不得修改。
7. **调参历史**：每次改动留 `ParameterTuningRecord`，可回滚。
8. **检查点**：通过 `saveCheckpoint` 回到上一个全绿配置。

## 二、何时必须上交人类（不自行硬调）

- **无解**：12 轮未收敛，可能需改玩法（新费目/新动作/新规则）。
- **回归震荡**：修复某断言必然弄坏另一 golden，暗示断言矛盾。
- **置信度低**：归因置信度 < 0.3。
- **唯一根因禁碰**：唯一根因落在禁碰清单。
- **需新机制**：需要新增费目或新动作的玩法级需求。

## 三、agent 能做什么 / 不能做什么

| 能做 | 不能做 |
| --- | --- |
| 在现有费目内调 `unit` / `scarcity.coefficient` | 发明新费目、新动作、新规则 |
| 受 `tunableRange` 与 `step` 约束地调参 | 修改玩家可见 1-5 值或核心语义锚 |
| 跑断言、归因、回归、记录、报告 | 绕过禁碰清单 / 无限循环 / 弄坏 golden |

## 四、专业状态自检 checklist（skill 载入后必须能答）

- [ ] 我能列出当前所有 golden scenarios 吗？
- [ ] 我知道哪些参数禁碰吗？
- [ ] 我知道防转圈 8 条吗？
- [ ] 我知道何时该上交人类吗？
- [ ] 我能读懂 DecisionTrace 和 ScoreBreakdown 吗？

## 五、输出纪律

- 面向资深玩家，用「问题 → 原因 → 建议 → 影响范围 → 需确认」叙述结构。
- 禁止未翻译的费目术语堆砌（`e:enemy.vitality` →「敌人的生命值」）。
- 每次闭环成功且 golden 全绿，才可把验证断言固化进断言集（`source: tuning-derived`）。
