## 一、唯一生产入口

局外出租屋与局内地图不再拥有两套地图真身。二者统一从完整 `MapBundle` 进入：

```text
发现 manifest
  → 校验包内规范相对路径、依赖、版本、资源存在性与 sha256
  → 解析 Canonical MapData v2 + MapPlay 2.0 + PresentationProfile
  → compileMap
  → prefab.spawn
  → UiSystem projection
  → intent / result / snapshot 通信
```

会话差异只由 `sessionKind`、MapPlay、PresentationProfile 和宿主生命周期表达。出租屋可使用少 UI profile，但少 UI 不是第二套运行时，也不允许手写替代 MapData、实体或交互规则。

## 二、MapBundle 1.0 冻结字段

| 分区 | 必需内容 | 拒绝条件 |
|---|---|---|
| 身份 | `schemaVersion`、`bundleId`、`mapId`、`sessionKind` | 版本不兼容、bundle/manifest/map 身份不一致 |
| 清单 | `ContentManifest(contentKind=map-bundle)` | 重复条目、执行资源、非法 checksum |
| 地图 | Canonical `MapData v2` 与 `entryNodeId` | 入口不存在、地图 id 不一致 |
| 玩法 | `MapPlay 2.0` 与 mapBinding | 指向其他 bundle/入口、直接写规则状态 |
| 表现 | `PresentationProfile` | 缺条目或无法通过 profile 门禁 |
| 资源 | `visualAssetEntryIds`、包内相对路径、sha256 | URL/绝对路径/反斜杠/空段/`.`/`..`、缺文件、checksum 漂移 |

SVG 底图必须作为 `map-visual-asset` 放在包内，由 `MapData.backdrop.image` 或层级 backdrop 使用相对路径引用。禁止 base64 内嵌、blob URL、包外网络回退。

## 三、八类素材与过渡场景

唯一素材逻辑分类沿用已合并地图编辑器设计：`AI 单位 / NPC / 载具 / 容器 / 物品 / 机关装置 / 装饰 / 过渡场景`。展示标签不得驱动逻辑；旧六类只在导入边界按 D-088 的确定性表迁移。

过渡场景是 `MapEdge.transitionInstances[]` 的端点侧实例，每条边 `from`/`to` 各最多一个。边级参数共享，端点实例效果独立；删除、拆分、反向、复制和旧 `transitionWindow` 导入必须保持拓扑引用与迁移诊断完整。

## 四、通信协议 1.0

所有 UI 行为先由当前投影构造 `InteractionIntent`，再封装为 `intent` 包络。包络必须携带：`protocolVersion`、`sessionId`、`mapBundleId`、`requestId`、`idempotencyKey` 与修订令牌。

- `accepted` 必须返回 `committedRevision`；客户端观察到包含该修订的投影后才算完成。
- `rejected` 返回可见性安全诊断，不产生补偿写入。
- `stale` 进入重同步，旧意图不得自动改写后重放。
- 同一 session + bundle + idempotencyKey 只执行一次；同键不同 requestId 为冲突。
- 首次连接、修订漂移或指纹不一致必须请求全量 snapshot；增量投影不能跨 revision gap 猜测。
