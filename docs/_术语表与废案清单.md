# 术语表与废案清单

> 本文档是修订所有设计文档的**唯一事实来源**。所有术语以此为准，所有废案不得再出现在正文中。

---

## 一、核心术语表（按字母序）

### AP（Action Point，行动点）
- **定义**：每回合可执行动作的次数
- **来源**：投点后按差距分配（详见投点机制）
- **铁律**：一个动作永远消耗 **1 AP**，所谓"2 AP 动作"实际是两个 1 AP 动作 + 中间状态（如"撬锁中"）
- **NPC**：复用 AP 价格表，但不复用 AP 随机分配机制，按编号顺序行动

### 倒地（Downed）
**两种倒地，不同机制**：

#### 1. 零血倒地（濒死）
- **触发**：生命值归零
- **状态**：可被处决（令其长眠），**仍参与投点获得 AP**
- **可执行**：仅 **丢弃**（0 AP）与 **爬行**（1 AP）；此外可观战（一旦观战即退出投点）、退出游戏（退出投点，原地不动）
- **爬行规则**：1 AP，可进入或离开微型场景，**不可离开所属的天然场景**
  > 倒地者可以改变"我贴近谁"，不能改变"我在哪个区域"
- **禁止**：攻击、拾取、使用背包、整理、开门、锁门、上车、驾驶、精密交互、使用物品、睡下、起床、站起、主动令自己长眠
- **不能自行恢复**：否则"令其长眠"退化为抢时间，且与睡眠混淆。未来团队模式可加"扶起"（同微型场景，1 AP），但不是默认规则
- **NPC 版本**：僵尸零血倒地，永远不会满血复活

#### 2. 普通倒地（被击倒或主动这么做）
- **触发**：特定技能（如过肩摔）
- **状态**：可移动（爬行）、可站起
- **恢复**：花费 **1 AP 站起**，回到正常状态。

### 防具系统
| 类型 | 效果 | 破损条件 |
|---|---|---|
| **轻型** | 伤害 -1（最低降到 0） | 一次受击后破损 |
| **中型** | 伤害 -1（最低降到 1） | 一次受击后破损 |
| **重型** | 1 伤免疫；2 伤 -1；3 伤 -1 并破损 | 承受 3 伤时破损 |
| **人防盾牌** | 格挡时免疫非重型伤害 | 可抵 2 次（第一次→磨损） |
| **防爆盾** | 格挡时独立 5 血池，不可恢复 | 血池耗尽 |

**格挡规则**：
- 不会回合结束自动取消
- 0 AP 主动取消
- 受击后自动取消

### 感知系统
**当前唯一落地：声音传播**

- **机制**：不同行为产生声音，沿拓扑路径衰减
- **场景影响**：场景类型影响衰减程度
- **AI 触发**：NPC 接收到的感知达到阈值后触发行为（寻声、追逐等）
- **废弃**：感知衰减表、噪音残影

### 感知阈值（NPC 行为触发条件）
- **定义**：NPC 需要接收到的累积感知强度才会触发特定行为
- **应用**：寻声、进入追逐模式的判定标准

### 槽位系统（背包与携带）
```
出生配置：
  双手（2 格）+ 初始背包（2 格）= 4 格

拓展后：
  双手（2 格）+ 拓展背包（4 格）= 6 格
```

**规则**：
- 双手物品只需一只手空着即可使用，**占 1 格**
- 配件（握把、弹夹、瞄准镜）占物品槽，装备到枪上后不算
- 重型物品放入背包仍有负重 buff

### 距离范式（已定案，基准从 1 开始 — D-051）
**定义**：两个活体之间的场景拓扑连接数量（加权），**编号从 1 起算**

```
距离 1 = 贴身，同一微型场景
距离 2 = 不同微型场景，但同一天然场景
距离 3、4+ = 按下列公式累加
  跨天然场景 +1（大场景 ×2）
```

**示例**：
- 我在中场景 A，你在紧邻的大场景 B → 距离 = 2（离开 A）+ 2（穿越大场景 B）= 4

> **基准修订（D-051）**：距离编号已从"0 起算"改为"**1 起算**"，因为"距离 1 = 贴在一起"比"距离 0 = 贴在一起"更符合玩家直觉。这是**纯线性平移**——所有既有 DC 数值与平衡关系完全不变。迁移方法：旧文档中的距离值**全部 +1**。

**适用范围**：
- 枪械距离 DC 判定
- 感知衰减计算
- 移动代价估算

### 谱型（Ballistic Profile）
**定义**：枪械的大类分类，同类枪械趋同属性，应用相同弹道谱

**当前谱型**（待后续补充具体参数）：
- 手枪
- 霰弹枪
- 步枪
- 狙击枪
- 冲锋枪
- 机枪

**配件通配规则**：
- 瞄准镜：全部可装
- 握把：全部可装，目前只有一类
- 弹夹：部分枪械不能装（按谱型定义）
- 消音器：全部可装（待定）

**子弹**：按谱型大类（如"霰弹枪子弹"），不细分口径

### 起床（Wake Up）
- **消耗**：1 AP
- **状态前置**：[睡眠] 或在床上
- **效果**：进入 [清醒] 状态

### 入梦者 / 梦境佣兵
玩家扮演的主视角单位的正式名称

### 死亡背包
- **生成**：玩家死亡后，在原地生成一个**独立创建的容器实体**
- **内容**：存储该玩家的双手物品 + 所有背包槽位物品 + 所有装备
- **属性**：**只出不进**（不能往里放东西）
- **容量**：**不是固定值**。生成时容量 = 该玩家死亡瞬间的物品总数，因此**死亡背包永远是满的**
- **交互**：查看清单不需要 AP

> 注意：不复用玩家身上背着的背包，是全新实体。因为只出不进 + 容量恰好等于内容数，所以不需要"空槽位"概念 —— 取走一件，容量同步减 1。

### 天然场景 vs 微型场景
**必须严格区分的两套正交坐标**：

#### 天然场景（Natural Scene）
- **定义**：地图作者划定的空间骨架，分三档
- **分类**：大场景（≤5 连接）/ 中场景（≤4）/ 小场景（≤3）
- **过渡场景**：连接用，不可长期停留（楼梯、窗户、走廊）

#### 微型场景（Micro Scene）
- **定义**：局部接触空间，附属于天然场景
- **核心作用**：**近战与直接交互的唯一空间前提**
- **"找到 X"的本质**：进入 X 这个实体的微型场景

**微型场景的三种创建者**：
1. **活体**：在大/中场景创建个人微型场景（"空旷地"）
2. **过渡场景**：门/窗创建 1-2 个微型场景（平行双侧，垂直单侧），这 1-2 个微型场景各自的 `props.creator` 都指向同一个过渡场景（同一 Link），但各自的 `parent` 仍分别指向所在那一侧的天然场景——微型场景没有 owner 字段，`creator` 只写入一次仅供溯源，不作为归属或生命周期判断依据
3. **小场景节点**：自带一个共享微型场景（固有属性）

**关键规则（已定案，替代旧"接敌面"概念）**：
- 微型场景**由每个活体各自私有**（大/中场景）。"贴身"是**成对的对称关系**：A 贴身 B ⟺ B 贴身 A
- **贴身成本**：大/中场景 **1 AP**（即"找到"）；小场景 **0 AP**（本来就在共享微型场景）
- **脱离贴身**：1 AP；或移动到别的天然场景时自动解除
- **小场景特殊规则**：所有活体共处小场景自带的共享微型场景，禁止创建个人微型场景（"空旷地禁入"）

**为什么容量上限不会导致"无法解围"**：

3 个僵尸围住玩家 P 时，P 的微型场景已满，但**每个僵尸自己的微型场景只有 1 个占用者（P）**。
救援者贴身**那个僵尸**即可对它近战 —— 这正是"外围的人打外围的敌人"的直觉，
是私有微型场景模型的直接推论。

### 空旷地（Vacant Ground）
**定义**：活体移动到天然场景后，以自身为中心创建的个人微型场景

**大/中场景**：
- "来到空旷地" = 创建个人微型场景，只有你
- 是默认落点（非过渡场景进入时）

**小场景**：
- **禁止创建个人空旷地**
- "来到空旷地"按钮复用 = 移动到小场景自带的**共享微型场景**
- 玩家会快速意识到：小场景的空旷地是大家共享的

**术语复用的设计意图**：
- UI 一致性（同一个按钮文案）
- 语义映射清晰（空旷地 = 场景中央，不在特殊位置）
- 降低心智负担

### 过渡场景阻挡机制
**规则**：过渡场景创造的微型场景上，**任意一侧**有活体或具有 `blocking` 属性的实体 → 整个过渡场景不可通行

**示例**：
- 防守方主动"来到门边"（小场景内 0 AP）→ 门被堵
- 攻击方可用远程/伸长武器攻击门边的敌人
- 杀死门边的敌人 → 门解锁

**平行 vs 垂直过渡**：
- **平行过渡**（门、平窗）：双侧各创建一个微型场景，任一侧被占 → 双向阻挡
- **垂直过渡**（跳窗）：仅上侧创建微型场景，下侧无微型场景 → 单向阻挡判定

> **保留确认（D-045）**：封堵规则**保留**。"双方同时试图穿越如何处理"这一追问**不成立**——回合制下**不存在同时**，行动轮决定了谁先执行，先到者占据，后到者面对的就是已封堵状态。因此**不需要引入优先权竞争或掷骰判定**，实现为简单的占用检查即可。

**伸长属性（Reach）**：
- 武器具有此属性时，可以攻击**同一过渡场景另一侧微型场景**的目标
- 例如：站在窗 A 侧，攻击站在窗 B 侧的敌人
- 所有远程武器无视过渡场景限制（子弹穿窗）
- **谁有伸长**：棍棒、撬棍、棒球棍（长杆），短刀、平底锅（轻型近战，否则不如拳头）
- **谁没有**：拳头、电锯等重型钝器（需要全力挥动，无法隔窗）

> **术语（D-043）**：本属性的正式术语是**伸长**，此前写作"延长"的表述已更正。

### 体力（Stamina）
- **定义**：使用强力骰的资源
- **消耗时机**：投骰前承诺（切换滑块档位）
- **恢复方式**：
  1. 投点失败（获得 0 AP）→ 体力退还
  2. 睡眠（在床上）→ 体力每回合结束恢复1
  3. 令其长眠（处决倒地敌人）→ 体力回满
- **NPC**：有独立的"强力骰"概念，但不复用玩家的体力/AP 随机机制

### 微型场景状态
**定义**：一个微型场景可定义为具有火/油/水/电的状态

**应用**：环境效果、特定物品/技能的前置条件

### 流程（Action Flow）
**替代旧名"行动坐标系"**

**定义**：标准化的动作执行流程，用于复用和验证

**示例**：
- 开门流程
- 射击流程（瞄准判定 → DC 检定 → 伤害结算）
- 精密交互流程（启动 → 持续 → 完成/打断）

### 令其长眠（Execute / Eternal Sleep）
- **前置条件**：目标处于**零血倒地**状态，且在近战距离（同微型场景）
- **消耗**：1 AP
- **效果**：目标死亡 + **执行者体力回满**
- **视觉描述**：插入蓝色仪器
- **世界观隐喻**：从目标梦境中抽取清醒度 / 借道梦境主机导出记忆

**例外**：
- 僵尸在毒区外因毒气而死 → 直接死亡消失，**不能**令其长眠获得体力

### NPC 守卫范式（已定案）
**流程闭环**：
1. **初始状态**：醒来 → 进入巡逻
2. **触发条件**：感知阈值达标 → 寻声 / 追逐锁定
3. **解除条件**：
   - 追逐：到达最后一次看见玩家的位置，仍未进一步发现 → 返回巡逻
   - 任何时候无事可做 → 尝试返回巡逻轨道
4. **追逐锁定**：追逐阶段不会被其他声音影响

**巡逻线**：属于地图的一部分，固定不变

**僵尸血量分档**（待细化）：
- 3 血（常规）
- 2 血（敏捷）
- 1 血（敏捷）

## 三、重大设计变更（影响多文档）

### 1. 一个动作永远 1 AP
**受影响文档**：02, 04, 05, 08

**具体改动**：
- 删除所有"2 AP 动作"表述
- 改写为"两个 1 AP 动作 + 中间状态"（如撬锁 → 成功撬锁）
- UI 不能把 0 AP 和 1 AP 动作放同一菜单

### 2. 天然场景 vs 微型场景术语重建
**受影响文档**：03（全文）, 04, 05, 08

**具体改动**：
- 小场景不是"Micro Scene"
- 微型场景独立成节
- "找到"机制重写
- 五并列拓扑只挂在天然场景上

### 3. 尸体系统 → 死亡背包
**受影响文档**：04, 05

**删除内容**：
- 搜尸动作
- 拖拽尸体
- 尸体作为容器的所有描述

**新增内容**：
- 死亡背包实体定义
- 只出不进属性
- 查看清单 0 AP

### 4. 感知系统简化
**受影响文档**：07, 02

**删除内容**：
- 感知衰减表
- 噪音残影
- 视野 FOV 计算

**保留内容**：
