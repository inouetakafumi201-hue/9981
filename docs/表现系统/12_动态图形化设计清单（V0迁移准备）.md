# 动态图形化设计清单（V0 迁移准备）

> **性质**：**给 V0.dev 的自然语言设计清单（不依赖具体时长、可视觉调整）**。本文档把 `01_图形化与UI.md` + `03_动画灵感索.md` 里的视觉与交互后果整理成一份"V0 能直接读懂的动效描述"，重点是**自然语言描述 + 复用母题 + 全流程穷尽**。
> **最后更新**：2026-08-19
> **依赖**：`01_图形化与UI.md`、`03_动画灵感索.md`

## 一、复用动效母题库（核心词汇表）

这些母题是可复用的视觉语法，只换语义色、方向和强弱，不换骨架。V0 实现时用这些母题的组合，不要每次重新发明。

### 1.1 过渡母题

| 母题 | 感受描述 | 适用场景 | 语义色 |
|---|---|---|---|
| **慢白幕** | 画面被柔软的奶白/纯白慢慢吞没，再慢慢把细节吐出来 | 入梦、床显形、过载逼近、纯白边界、重大揭晓、加载完成 | 奶白 `#FFF8F0` / 纯白 `#FFFFFF` |
| **闪白幕** | 像闪光弹一样瞬白一下，然后带着余辉退回去 | 传送、命中确认、爆发、证据揭示、系统通过、强反馈 | 纯白 `#FFFFFF` |
| **黑幕收束** | 画面从四周压黑，或者直接落黑，再从黑里重新长出下一状态 | 退出、失败、断线、暂停、读档、硬切 | 黑 `#000000` |
| **余辉淡出** | 画面从高饱和退回低饱和，像声音被抽走 | 战后、状态解除、离开危险区、回到驻地 | 保持原色系，降饱和度 |
| **轮廓显影** | 先有边缘和阴影，再有实体和细节 | 角色出现、物件掉落、卡片解锁、节点揭露 | 从 20% 不透明度到 100% |

### 1.2 反馈母题

| 母题 | 感受描述 | 适用场景 | 语义色 |
|---|---|---|---|
| **语义高亮** | 边缘发光、材质凸起、内部微亮 | 可通行、可交互、当前焦点、可恢复、可点击 | 根据语义：中性灰白、橙色 AP、紫色 SP、珊瑚色近战、青色 UGC |
| **震动回弹** | 不合法操作先轻轻一弹，再回到原位 | 无 AP、无权限、拖拽失败、路径被挡、目标无效 | 无色，纯位移 |
| **列表重排** | 不是硬跳位置，而是项与项互相让位 | 轮次栏、通知、诊断、背包、技能树、玩法包顺序 | 无色，纯位移 |
| **颗粒化消失** | 状态、物品、实体碎成尘、屑、光点散掉 | 消耗、破损、死亡、解除、提交 | 语义色的 50% 不透明度粒子 |

### 1.3 梦核主视态母题

| 母题 | 感受描述 | 适用场景 | 语义色 |
|---|---|---|---|
| **低饱和泛灰** | 画面整体降饱和，色温偏冷，像雾蒙蒙的清晨 | 梦境对局中的常态底色 | 全局 `filter: saturate(0.7) brightness(0.9)` |
| **进出倒放** | 进入梦境时正放，醒来时倒放同一段 | 床 → 纯白显形 → 对局；对局 → 纯白收束 → 床 | 无色，纯时间轴 |
| **余辉拖尾** | 移动、攻击时留下短暂的半透明残影 | 快速移动、冲刺攻击、投掷 | 原实体颜色的 30% 不透明度 |

## 二、全流程动效穷尽（不漏任何环节）

### 2.1 启动与回到出租屋

**启动**：
- 不做主菜单。先黑后亮，或先白后落回房间轮廓。
- 第一次进入可以更仪式化（慢白幕 + 轮廓显影），后续就轻一些（直接淡入）。

**房间可交互物**：
- 床、匹配机、研究台、电脑、书架、保险箱都应有"可用/不可用"的呼吸感。
- 可用时：边缘发光（语义高亮），光强度缓慢波动（呼吸）。
- 不可用时：变灰，无发光。
- 悬停时：高亮增强 + 轻微上浮（3px）。
- 点击时：轻微压缩（scale 0.95 再回弹到 1）。

### 2.2 匹配、等待、就绪

**匹配机交互**：
- 匹配机是信息密度核心，床是进入侧。
- 床未就绪时：灰色、安静、无光。
- 匹配完成后：床亮起（语义高亮），边缘发光。
- 躺下床时：睡眠姿态动画（身体慢慢躺平，0.5 秒）。

**影子大厅**：
- 不要重载新场景，用半透明影子、静止等待、轻微呼吸来表达。
- 其他玩家：半透明剪影（60% 不透明度），无细节。
- 就绪玩家：剪影变实（100% 不透明度）。
- 等待中：轻微上下浮动（±2px，周期 2 秒）。

### 2.3 入梦、返回、纯白显形

**梦 → 实（醒来）**：
1. 床必在（床是固定实体，全程不消失）。
2. 人形纯白显形（约 1 秒，轮廓显影母题）。
3. 纯白被推向床（颜色从纯白滚动回原色，沿曲线，不是瞬跳）。
4. 人物在床上复原色彩（饱和度从 0 → 100%）。
5. 起床演出（身体坐起 → 站立，可跳过）。

**实 → 梦（入梦）**：
1. 床从平地被翻起/浮现（轮廓显影母题）。
2. 人 + 床整体纯白（慢白幕母题，约 0.5 秒）。
3. 复原色彩（从纯白滚回原色）。
4. 人物从床跳下进入梦境（跳跃落地，尘土扬起）。

**纯白 vs 其他白**：
- 纯白显形是高冲击过载感（如闪光弹），短暂、带光辉。
- 常态底色是灰白 `#F5F5F5`，不是纯白 `#FFFFFF`。

**可跳过**：往返演出允许跳过，不影响规则装载。跳过时直接硬切到最终状态（黑幕收束母题）。

### 2.4 对局中的每个动作

#### 移动与位移

**正常移动**：
- 跳跃式位移：角色从地面跃起，再落地。
- 曲线：抛物线（y 先上升再下降），x 线性。
- 落地时：轻微压缩（scale y 0.9 → 1，持续 0.1 秒）+ 尘土扬起（颗粒化消失母题，3-5 个灰色粒子）。

**重物移动**：
- 低矮跳跃（高度降低 60%）。
- 落地更重：压缩幅度更大（scale y 0.8 → 1）+ 尘土更多（8-10 个粒子）。

**迟缓移动**：
- 拖曳感：慢启动、慢停止（ease 曲线调整为 `[0.65, 0, 0.35, 1]`）。
- 轻微拖尾（余辉拖尾母题，30% 不透明度残影）。

**快步跳移动**（攻击前冲）：
- 更高的跳跃（高度 +100%）。
- 更快（时长缩短 30%）。
- 落地更有力（压缩 + 更多尘土）。

#### 转身与朝向

**转身**：
- 单一左右朝向维度（无八向）。
- CSS `scaleX(-1)` 翻面，持续 0.1 秒。
- 只有特定事件触发转身（攻击、被攻击、新玩家进入时随机几人转向）。

#### 近战攻击（三动画模型）

**① 快步跳移动到目标面前**：
- 从原位冲到目标面前（停在目标前方 20px）。
- 快步跳移动曲线（见上）。

**② 攻击 + 受击**：
- 攻击者：身子前倾（rotate -10°），武器倒下前戳。
- 目标（无招架）：红色闪烁（opacity 1 → 0.5 → 1，持续 0.2 秒）+ 向后位移 10px。
- 目标（招架触发）：全屏动画（擒拿/招架演出，见 §2.8 全屏动画）。

**③ 恢复对峙**：
- 攻击后大家按站位、以中心点为基准各走一小步，重新回到对峙状态。
- 向心移位：每个人沿"当前位置 → 群体中心"方向移动到最近可站位。
- 曲线：缓入缓出（ease `[0.42, 0, 0.58, 1]`），持续 0.3 秒。
- 不改朝向（后退、前进都合理）。

#### 远程攻击

**瞄准状态**：
- 悬停瞄准者时：显示紫色点线指向目标（低显著性）。
- 不用头顶感叹号（见 `01` §瞄准状态）。

**射击**：
- 后坐力：攻击者轻微后退 5px + 身体后仰（rotate 5°），持续 0.1 秒。
- 枪口火：橙色闪光（闪白幕母题，但只在枪口位置，半径 10px）。
- 弹道：不画弹道线（瞬时命中），只在命中点显示闪白（闪白幕母题，半径 20px）。
- 目标受击：同近战受击（红色闪烁 + 后退）。

#### 拾取、丢弃、整理

**拾取**：
- 物品从地面飞向背包（曲线：先上升 20px 再向背包位置，持续 0.2 秒）。
- 背包图标：轻微弹跳（scale 1 → 1.1 → 1）。

**丢弃**：
- 物品从背包飞向地面（曲线：抛物线，持续 0.3 秒）。
- 落地时：小尘土（3 个灰色粒子）。

**整理背包**：
- 列表重排母题：物品间互相让位，不是硬跳。
- 不合法拖拽：震动回弹母题。

#### 撬锁、开锁、上车、下车

**撬锁**：
- 进行中：锁图标轻微抖动（±2px，周期 0.5 秒）。
- 完成：锁图标变绿 + 短促闪烁（闪白幕母题，半径 15px）。
- 失败：锁图标变红 + 震动回弹。

**上车/下车**：
- 车辆图标高亮（语义高亮母题）。
- 角色淡出（opacity 1 → 0，持续 0.2 秒）。
- 车辆内人数 +1/-1 显示更新。

#### 蹲下、起立

**蹲下**：
- 角色高度变化（scale y 1 → 0.7，持续 0.2 秒）。
- 姿态图标变化（站立 → 蹲伏）。

**起立**：
- 角色高度恢复（scale y 0.7 → 1，持续 0.2 秒）。

### 2.5 投点阶段

**强力骰 + 逆转推挡滑块**：
- MVP 3 档推挡滑块（0/1/2）；`+3极限爆发` 仅保留为未来评估文本，不进入可选交互。
- 推到不同档：充能感、光效、颜色浓度、粒子都不同。
- 强力骰：橙色系，档位越高光效越重。
- 逆转：紫色系，档位越高光效越重。

**骰子悬空 + 横条生长**：
- 骰子只在当前行动者右侧悬空出现。
- 横条三段式：
  1. 灰白伸出（从左到右，线性，持续 0.5 秒）。
  2. 强力骰特效：右侧显示 +1/+2 图标 + 伸长速度比其他人快 1.5 倍。
  3. 统一刷色：所有条伸完后，从左侧高光刷入颜色（像水波，持续 0.3 秒）；强力骰部分泛红。

**横条有格状刻度、无上限框**：
- 格子间距固定，长度由实际点数决定。
- 刻度线：灰色竖线，10% 不透明度。

### 2.6 轮次栏与状态条

**轮次栏三种呈现状态**（D-064）：
- **标准战斗**：完整轮次栏，每个玩家一行，显示 AP/HP/SP/弱点图标。
- **一人模式**：简化为顶部单行，只显示自己的状态。
- **少 UI 模式**：驻地活动，轮次栏隐藏或折叠为角落小图标。

**AP 耗尽**：
- 仅变灰（降饱和度 + 降亮度），不移出轮次栏。
- 3 秒倒计时：数字从 3 → 2 → 1，每秒跳一次。

**HP/SP 条变化**：
- 减少：条从右侧收缩（线性，持续 0.3 秒）+ 红色闪烁（HP）或紫色闪烁（SP）。
- 增加：条从左侧伸长（缓入缓出，持续 0.5 秒）+ 绿色闪烁。

**弱点图标**：
- 头顶常驻（公开信息）。
- 图标悬浮：轻微上下浮动（±1px，周期 2 秒）。
- 触发时：图标放大 + 闪烁（scale 1 → 1.3 → 1，持续 0.4 秒）。

### 2.7 同场景移动、对峙与点状扎堆

**同场景移动**：
- 角色在同一群体内移动时，视觉上要保持顺滑、自然、尽量不穿模。
- 遇到其他活体时，不要出现生硬卡死感，动作应有轻微绕让。

**恢复对峙**：
- 任何一次动作扰动后，群体会向中心轻微回拢，重新站成一撮。
- 这种回拢不需要显式解释成算法，只要视觉上像“大家重新站稳了”即可。

**泛光圈**：
- 每个点状群体都可用一个半透明圆形光圈表达。
- 人数越多，光圈越大。
- 两个光圈不要重叠；如果靠近，就让它们看起来会自然退让开。

**碰撞箱可视化**（调试模式）：
- 仅在调试环境下显示淡淡的圆形阴影。
- 正常玩家视角不需要看到它。

### 2.8 全屏动画（仪式感强的四项）

**翻窗**：
- 全屏骨骼动画（约 0.8 秒）。
- 角色从窗户翻过，身体翻转，落地压缩。
- 背景模糊（backdrop-blur）+ 暗化（brightness 0.6）。

**跳窗**：
- 全屏骨骼动画（约 0.6 秒）。
- 角色从窗户跳下，空中翻转，落地压缩 + 尘土。

**令其长眠**：
- 全屏骨骼动画（约 0.5 秒）。
- 目标倒地（旋转躺平，持续 0.4 秒）。
- 蓝色光效（从目标扩散，半径 50px）。
- 攻击者清醒条瞬间填满（绿色高光刷入）。

**招架触发**（被近战攻击时）：
- 全屏擒拿/招架演出。
- 珊瑚色近战主语义（攻击者边缘发光）。
- 紫色约束边缘（目标被束缚感）。
- 持续约 1 秒。

**可跳过**：所有全屏动画允许跳过（按空格或 ESC），跳过后直接硬切到最终状态。

### 2.9 结算、淘汰、观战、回流

**胜负揭晓**：
- 梦醒式大揭幕：慢白幕母题（画面被奶白吞没 → 结算面板显影）。
- 胜利：金色高光（闪白幕母题 + 金色粒子上浮）。
- 失败：黑幕收束母题（画面压黑）。

**淘汰**：
- 轻量：角色变灰 + 半透明（60% 不透明度），不做整局终结演出。
- 观战标识：头顶"观战中"文字（灰色，10pt）。

**奖励飞入**：
- 金币/晶片从事件源飞入货币栏（曲线：抛物线，持续 0.5 秒）。
- 货币数字往上跳（从旧值到新值，持续 0.3 秒，数字滚动）。

**回到出租屋**：
- 更安静的白回流或黑收束（余辉淡出母题）。
- 不要和入梦用同一套演出（回流更克制）。

### 2.10 证据、经济、收藏

**证据提交**：
- 不是另起一套仓库，而是白虚空里的槽位点亮。
- 素材嵌入：轮廓显影母题（槽位从半透明到实体）。
- 板块拼合：拼图碎片从四周飞向中心（曲线：缓入缓出，持续 0.8 秒）。

**真相板**：
- 空缺填补：缺失的板块从半透明到实体（轮廓显影母题）。
- 板块点亮：填补后高亮闪烁（闪白幕母题，半径 30px）。
- 关系连线出现：从板块 A 到板块 B 画线（线条生长，持续 0.5 秒）。

**货币飞入**：
- 同奖励飞入（见 §2.9）。

### 2.11 创作工具、编辑器、诊断

**工具动效与战斗区分**：
- 更干净、更利落。
- 不要把对局里的白幕、爆闪直接搬进工具。

**吸附与对齐**：
- 拖拽物接近对齐线时：磁铁吸附（最后 5px 快速移动，持续 0.1 秒）。
- 对齐线：青色虚线（#00D4AA 的 50% 不透明度）。

**红黄诊断**：
- 错误：红色边缘闪烁（持续 0.3 秒，循环 2 次）。
- 警告：黄色边缘闪烁。
- 通过绿勾：绿色圆圈 + 白色勾（轮廓显影母题，持续 0.4 秒）。

**发布锁定**：
- 锁定按钮：灰色 + 锁图标。
- 锁定动画：锁从开启到闭合（rotate 0° → 45°，持续 0.2 秒）。

**无效落点回弹**：
- 震动回弹母题（拖拽物先往落点方向弹 5px，再回到原位）。

### 2.12 断线、重连、空状态、错误

**断线**：
- 黑幕收束母题（画面从四周压黑）。
- 中心显示"连接中断"文字 + 旋转加载图标。

**重连中**：
- 旋转加载图标（无限旋转，线性）。
- 不要只给一个转圈，要有文字说明。

**空状态**：
- 空背包：灰色背包图标 + "背包是空的"文字。
- 空任务：灰色任务图标 + "暂无任务"文字。
- 空证据：灰色槽位 + "尚未收集证据"文字。

**错误提示**：
- 红色边缘闪烁 + 错误文字（见红黄诊断）。
- 无 AP：动作按钮变灰 + "AP 不足"提示。
- 无权限：震动回弹 + "无权限"提示。
- 路径被挡：震动回弹 + "路径被活体阻挡"提示。

## 三、边角状态与交互细节（容易漏的）

### 3.1 Hover / Focus / Selected / Active / Disabled

| 状态 | 视觉 | 持续时长 |
|---|---|---|
| **Hover** | 边缘发光（语义高亮母题）+ 轻微上浮（3px） | 立即（0.1 秒过渡） |
| **Focus** | 边缘发光 + 更强的高亮（亮度 +20%） | 立即 |
| **Selected** | 边缘发光 + 实心边框（2px） | 立即 |
| **Active**（按下） | 轻微压缩（scale 0.95） | 0.1 秒 |
| **Disabled** | 变灰（饱和度 0 + 亮度 0.6）+ 无发光 | 立即 |
| **Pending**（加载中） | 旋转加载图标 + 半透明（70%） | 立即 |
| **Locked** | 变灰 + 锁图标 | 立即 |
| **Interrupted** | 红色闪烁（opacity 1 → 0.5 → 1）+ 震动（±2px） | 0.3 秒 |

| 重试中 | 旋转加载图标 + "重试中..." | 必须有文字 |

### 3.3 Reduced Motion（可访问性）

用户开启 reduced motion 时：
- 所有动画持续时长缩短 70%（例如 0.3 秒 → 0.1 秒）。
- 移除跳跃曲线（改为直线位移）。
- 移除粒子效果。
- 移除余辉拖尾。
- 保留颜色变化、不透明度变化（这些不会引起眩晕）。

CSS 实现：
```css
@media (prefers-reduced-motion: reduce) {
  * {
    animation-duration: 0.1s !important;
    transition-duration: 0.1s !important;
  }
}
```

### 5.1 移动动画

```
实现一个角色移动动画（跳跃式位移）：
- 从起点 A 到终点 B，沿抛物线移动
- Y 轴：先上升 20px 再下降到终点（抛物线）
- X 轴：线性移动
- 持续 0.3 秒，ease 曲线 [0.4, 0, 0.2, 1]
- 落地时：轻微压缩（scaleY 0.9 → 1，持续 0.1 秒）+ 3-5 个灰色粒子扬起
- 用 Framer Motion 的 animate 实现
```

### 5.2 攻击动画

```
实现一个近战攻击的三段动画：
1. 快步跳移动到目标面前：
   - 从攻击者位置冲到目标前方 20px
   - Y 轴高跳跃（峰值 40px）
   - 持续 0.2 秒
2. 攻击 + 受击：
   - 攻击者：身体前倾（rotate -10°）
   - 目标：红色闪烁（opacity 1 → 0.5 → 1，持续 0.2 秒）+ 向后位移 10px
3. 恢复对峙：
   - 攻击者和目标都向群体中心移动一小步
   - ease 曲线 [0.42, 0, 0.58, 1]，持续 0.3 秒
- 三段动画串行执行
- 用 Framer Motion 实现
```

