判定标准（机制是否需要图形化设计）：
1. **玩家会看到/感受到**的机制（排除纯内部结构）；
2. 在当前 MVP 对局/驻地/创作工具中**必然或可能发生**；
3. 四个图形化域（曲线/帧/全屏/粒子）或 UI 层对它有**可落地的表达**。

缺口分级：**P0** = 当前机制必然发生、玩家可见、现有设计零覆盖；**P1** = 当前机制存在、现有设计零覆盖或仅类别性覆盖、值得补；**P2** = 未来玩法包/后置模块支持、现在只登记。

## 四、P0 设计（当前机制必然发生，必须补）

### 4.1 终局与结算（J 子节）

**终局判定（胜负/平局）**：全屏"梦醒"演出，0.8–1.2 秒、可跳过。纯白涌出/聚拢（`dream` 纯白 token，与出生纯白显形同一"入梦/梦醒"语汇）→ 结果板**斜切滑入**（07 §五 P5 动态：`skewX` + spring）——胜/负/平局大字 + 最终排名 + 结算摘要。

- 全屏认知判据通过："结果画面"是正常游戏认知（出生/入睡同级，每局一次，不滥用）。
- 胜负由 OutcomeDef 判定（`after:outcome`），表现只重演结果。

**淘汰转观战**：不播终局全屏。被淘汰者视角**淡出 + 推离梦境**（半秒），镜头切观战自由模式（09 镜头观战移动），轮次栏该玩家条目**退场动画**（缩出/淡出）。顶部回合照常推进。淘汰者只被"轻推出"，不做悲壮演出——避免误导其以为还能影响战局。

**结算发奖 / 货币入账**：结算摘要内货币入账动画——佣金（美元）**金色硬币弹跳 + 计数滚动**（S5 放大揭示）；记忆碎片（能力货币）**蓝色晶片飞入**（stamina 蓝=能力域）。货币总量可超 5（运营/01 已豁免），但入账动效低心智：一笔一笔弹，不做复杂换算动画。

**死亡 / 退出本局**：零血倒地者退出=角色**淡出消失**（轻演出）+ 轮次栏条目退场；观战（可选）=转观战镜头。

### 4.2 状态解除反馈（C 节补）

状态附加已有绿/红/紫粒子，解除没有。补齐为**与附加对称但更低显著**：

- **自然到期**（duration 结束/时间解除）：状态图标**静默淡出**，不打断、不提示——"效果到期"是预期内的事，不需要观众。
- **被克制解除**（火焰解除冰冻等）：**解除闪现**——状态图标闪一下高亮（0.2 秒）后消失 + 对应材质微粒子（冰解=碎晶、火灭=烟、毒散=绿雾）。因为它是玩家主动操作的结果，值得一个正反馈；但**只对状态持有者与施解者可见**（隐藏信息不泄露纪律：其他玩家不需要知道"你被火解了冻"）。
- **主动取消**（0 AP 取消格挡）：已有盾牌归位曲线，不新增。

### 4.3 经济与决策交互（K 子节）

**资源转换网关统一语义**：合成台/投币机/贩卖机/商店都是"消耗 X 换 Y"——统一**紫色边缘发光**（01 视觉定律 4：紫色=关系约束/网关）+ 转换演出（消耗品飞入 + 产物弹出）。三种网关并列：资源转换（本设计）/ 检定（撬锁橙进度）/ 条件（锁门高亮），共用紫色身份识别、演出各自区分。

| 网关 | 演出（曲线为主） |
|---|---|
| 商店购买 | 货币飞入收银处 + 商品从货架滑出到手/背包（P1+P4）+ 入账音；动态定价=价格标签变绿（C6） |
| 合成台 | 材料缩小飞入台面（S4）+ 台面短促光晕（C2）+ 产物放大弹出（S5）+ 生成粒子 |
| 自动贩卖机 | 投币 + 商品从出口滑出 + 落柜弹一下（P4） |
| 赌博机 | 转轮滚动（R4）+ 揭示放大停顿（S5）+ 结果粒子；随机结果由规则投影，表现只重演 |
| 玩家交易（双向确认） | 交易面板滑出（07 承载）+ 双方各一条确认条 → 确认后两条物品图标交叉飞向对方（同事务原子）；拒绝=面板收回；超时=default/void 灰白小徽章 |

**Decision 征求输入**（投票/投降/战利品分配/协作动作/反应技）：非当前行动者收到**右下角滑入的征求卡**（低显著，不阻塞当前操作），内容 + 超时倒计时条（复用 autoAdvance 倒计时样式）+ 快捷键。超时降级灰白小字。**待答期间可继续行动，不锁屏**——这是内核"决策铁律（永不阻塞）"的表现层镜像。登记归 01/09 管辖（UI 层活），03 只登记语义。

**指令排队**：已排队未解算意图在动作菜单旁一条**小队列条**（1–3 个图标顺序排列），执行一个前移一个；暗押条目用"？"背面向（不泄露隐藏信息）。低显著。

**暗押揭示**（格斗对拼/猜拳）：对拼揭示时刻=两个悬空卡牌**翻转揭示**（R4）+ 依 resolveOrder 依序解算（先解算者先出结果；后发先至用小箭头指示解算顺序）。揭示前对他人不可见（D-032 招架同类纪律）。

### 4.4 货币入账（并入 4.1）

双货币视觉锚：**美元=金色**（贵重/生存/佣金，复用 04 保险箱"贵重感"金色高光）、**记忆碎片=蓝色晶片**（能力/清醒域，stamina 蓝）。获取时从事件源飞出到货币栏；消费时从货币栏飞出到目标（订阅付费、学习付费、黑市消费）——同一套"货币飞行"曲线，方向相反。

## 五、P1 设计（当前机制值得补）

### 5.1 "找到 / 脱离贴身"衔接（五节补）

1 AP 找到（进入对方微型场景）= 你的图标**跳跃扑向目标**（P1）+ 两个泛光圈**融合成一个**（光圈合并曲线）+ 接敌面卡槽从"各占"变"共用"（01 §五·5：同微型场景共用接敌面）。脱离贴身（1 AP 或离场）= 反向：光圈分离 + 卡槽分开。这是"贴身关系建立/解除"的专属衔接，不是普通移动——玩家的心智里"找到"是一个独立的战术动作（花 1 AP 才能近战），值得有独立演出。

### 5.2 弹夹 / 弹药可视化（D 节补，玩法层已定案）

**玩法层定案（2026-08-16，已落 `L2/04`）**：弹容量 = 枪的固有属性，子弹默认满；六类枪械容量 = 霰弹枪 3 / 手枪 3 / 狙击枪 4 / 冲锋枪 4 / 步枪 4 / 机枪 5；弹匣 = 分类别消耗品，手持同谱型枪时从背包使用 → 一次性装满 + 本体消耗；留出扩容弹夹配件空间。表现侧对齐：

- 枪械图标下方一条**弹夹格**，容量 = 枪的固有弹容量（3/4/5，全在 1-5 内）——弹药量是玩家可见数值，1-5 铁律硬约束。
- 射击=逐格熄灭（每次射击 1 发）；余量 0=空夹警示 + 射击灰显；换弹（用同谱型弹匣）= 清空 → 一次性装满 + 弹匣图标飞出消融（S4）。

### 5.3 连接与席位（L 子节）

- 掉线转 AI 托管：头像挂"AI 托管"角标（灰半透明，低显著）+ 行动走 AI 决策（复用 09 NPC 行动阶段标识）。
- 回归：角标消失 + 头像回色 + "你已重新连接"通知（07）。
- 中途加入：角色**纯白显形**落入出生点（出生演出语汇统一）。
- 观战转参战：淡入恢复操作权 + 镜头焦点切回。

### 5.4 学习（洞察）基础反馈（十节补）

被剔除的"刻录动画"（§Ⅻ 杀鸡儆猴）不复活，但机制本身（创作/02：持续注视 + 洞察点数 + 惊动守卫）仍需玩家可读的反馈。替代设计：

- 目标元素周围一圈**细进度环**（注视期间缓慢画满，非"刻录感"花活）；
- 洞察点数消耗=蓝点飞出；
- **风险提示**=进度环随注视时长缓慢转黄（警戒语义，暗示"再盯会惊动守卫"）；惊动时守卫头顶 ❓ 状态气泡（复用八节）。
- 克制、低显著、无粒子堆叠（探索动作不是战斗）。

### 5.5 武器 / 物品耐久磨损（C 节补）

防具破损已有（龟裂变色 + 碎裂粒子），武器同款：磨损=物品图标一道裂纹变色；耐久归零=龟裂 + 碎裂粒子 + **自动卸下**（掉回手/背包，E 掉落曲线）。共用一套"耐久破损"配方，不单开。

### 5.6 死亡 / 退出本局（并入 J）

见 4.1 第四段。
