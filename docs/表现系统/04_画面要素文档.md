## 〇、一句话定位

**对局画面 = 一张"像素棋子 + 简笔画场景"的低饱和对战棋盘，叠加一套用"高饱和语义色 + 边缘发光 + 极简像素 UI"表达的 HUD。** 视野中心是一层可移动的简笔画场景（节点区域 + 像素实体 + 门户图标），四周与角落由常驻/上下文 UI 围起来，供玩家做决策、看数值、看状态、反应。

布局地平线（画面硬分区，UI 都锚在这条地平线上，不悬浮乱跑）：

```text
┌────────────────────────────────────────────────────────────────┐
│ 顶部条：回合指示器 / 你的回合徽标 / 玩家行动阶段                  │
│ （少UI/一人模式时可隐藏，只剩必要文本）                          │
├──────────────── TE R A I N ▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓ ──────┤
│ 左边栏 │ 主对战画布（低饱和简笔画背景 • 前景高饱和像素实体）     │
│ 轮次栏  │   ┌场景节点区域(淡色填充,接敌面卡槽包着)┐              │
│ (常驻)  │   │  像素棋子(玩家/NPC/僵尸/载具)    │ 门户图标         │
│ 头像清单 │  │   头顶弱点图标 ███ 泛光圈         │ (灰白/紫/白)    │
│ 心+蓝柱 │   │   边缘发光高亮所选节点            │                 │
│ (投点就在 │  └───────────────────────────────┘                 │
│  这里播)  │     右下：附赠(0AP)动作面板 + 切换按钮               │
│          │   AP耗尽后：零费菜单 + 结束回合(3s倒计时)             │
│          │   点击目标→上下文动作菜单（攻击/找到/查看…）         │
└────────────────────────────────────────────────────────────────┘
```

主体（游戏内容）在**画布层**，决策/数值/状态在**UI 层**；二者靠"边缘发光 + 语义色"明确区分可交互与不可交互。

## 一、色彩板（一切 UI 元素取色，不许另造主色）

> 完整权威见 `01` §五条视觉定律 1。这里只给单行速记 + 主要 UI 落点。**主色不许因切换界面改义**；金银只作高光/描边，不构成评级阶梯。

| 语义色 | 速记 | 主要 UI 落点 |
|---|---|---|
| **红** | 生命减损 / 伤害 / 致命 | HP 条、伤害数字、坠落 D#、毒圈、致命后果预览、受击闪 |
| **蓝** | 清醒值 / 体力 / 处决 / 科技 | SP（清醒）条、强力骰、令其长眠光效、可处决蓝闪 |
| **黄** | 感官 / 警戒 / 需要主动注意 | 噪音源、巡逻、警戒范围、有线索需留意 |
| **橙** | **AP** / 消耗 / 进行中 | AP 徽标与计数、AP 成本数字、检定进度、倒计时 |
| **绿** | 安全 / 正面 / 免费 / 让利 | 拾取、已开的门、0AP、Free、正面状态、折扣 |
| **紫** | 关系约束 / 远程 / 条件入口 | 网关/条件、射程/瞄准紫点线、擒抱/招架约束、上锁门 |
| **珊瑚** | 近战 / 格斗 / 暴力 | 近战目标标定、格斗动作、近战威力演示 |
| **青** | 社交 / UGC / 创作来源 | 对话、组队、创作者入口、创意工坊角标 |
| **灰** | 冷却 / 延迟 / 不可点击 | 冷却中、等待生效、不可达节点（扁平无高光） |
| **灰白** | 可交互但受制于当前状态（高光材质感） | 门户默认、可点击冷却节点高光；平时灰白、悬停亮起 |
| **纯白/奶白** | 梦境边界 / 过载 / 入睡 | 入梦幻境氛围、床显形、过载纯白（高冲击闪光） |
| **金/银** | 品级高光 | 高级动作、宝物、重要对象的描边/高光（非阶梯） |

**边缘发光交互语法**（`01` §视觉定律 2：悬停/高亮的交互语言）：白光=可通行、黄=警戒、橙=进行中、红=致命、蓝=可处决、紫=网关/远程、珊瑚=近战、绿=安全/拾取、青=UGC。可点击对象必须高光+凸起+材质，不可点击扁平无高光。

## 二、常驻 UI（始终可见，除非少 UI / 一人模式折叠）

**这些是第一步先画出来的骨架**，任何一版 UI 样图都该有它们：

| 常见要素 | 分布 | 内容 | 视觉要点 |
|---|---|---|---|
| **轮次栏（最重要的 UI 组件，D-036）** | 画面**左侧常驻** | **每个轮次 = 一个独立的轮次框**（框可有形状，因切换有形态动画）；每框 = 排名 + 玩家头像 + 名字 + **生命值(红五格)** + **清醒值(蓝五格)** 离散柱 | **轮到的人 = 高亮**（反光感，非普通描边亮起）；**玩家自己的框比他人大/粗约一个骰子宽度**，其清醒/体力带反光高光，但颜色规则与他人一致；已行动者**变灰/降饱和**（D-035）。**骰子图标 = 悬空图标、不固定绑在轮次栏**：只在统一投点/某行动投点时于轮次栏右侧出现；投完右侧射出一根条、多人并排成**横向条状对比**（玩家条从轮次栏右侧延伸、骰子在上图层）；按行动轮排名实时排序 |
| **回合指示器** | **顶部条** | `回合 5 \| 玩家行动阶段 \| 玩家A回合`；轮到你横幅 `⚡ 你的回合！ 剩余 AP: 2` | 顶部一条，简洁文本；NPC 行动时显 `NPC行动阶段/僵尸移动中...` |
| **动作面板** | **右下**（付费动作） | `可用动作(剩余AP:2)` 纵向列表：动作行 = 图标 + 文字 | **动作行右侧不显示 AP 成本数字**（任何行动右侧不显示 1AP/n AP）；0AP 与 1AP **绝不混在同一菜单**；不足AP项扁平灰无高光；右上"切到零费"按钮（D-042）；成本改由灰态/语义色表达，顶多后期加备注列 |
| **状态栏 / 图标栏** | 随玩家头像（画布或栏内） | 头顶**弱点图标常驻**（D-031，Z 5 附近）；状态图标（格挡/重装…) | 正面=绿、冷却=灰、关系约束=紫、损害/致命才用红；招架**无任何标识**（真隐藏） |

> 少 UI 模式隐藏除"节点移动 + 局部交互 + 必要文本"外的全部；一人模式不移动不竞争，只突出玩家状态栏（`01` §轮次栏三种呈现状态）。

## 三、地图可视化要素（画布层，游戏内容主体）

| 要素 | 内容 |
|---|---|
| **背景图** | **简笔画、低饱和**（前景像素高饱和；叠层分离） |
| **节点区域** | 淡色填充，**接敌面卡槽**环绕（大5/中4/小3，占用显示敌人头像缩略图）；两玩家同点共用一个卡槽 |
| **实体** | **像素棋子**（玩家/NPC/载具/僵尸），各带碰撞箱（淡圆阴影）、**头顶弱点图标常驻** |
| **门户图标** | 楼梯🪜/梯子⬆️/窗户🪟/门🚪/跳台⬇️；**灰白+白光**=无条件通行，**紫**=上锁/有条件；悬停显"箭头方向+AP成本(橙)+D伤害(红)"徽章 |
| **叠层视图** | 竖向门户（楼梯）屏幕对齐；当前楼层全彩，上层/下层以**透明度**显示（如 3F 全彩 / 2F 30%）；距离>2 不显示；跨层连线默认不画、悬停亮起 |
| **移动模式** | 可达节点**白光边缘**、门户**虚线**、**橙色 AP 数字**；不可达节点扁平灰 |
| **攻击模式** | 远程**紫点线/射程**、近战**珊瑚**接触范围、伤害预览与致命后果**红**；窗户等高线(losBridge)亮起、障碍变暗 |

## 四、交互与上下文 UI（点击/悬停时出现，不停留在默认画面）

| 要素 | 触发 | 内容 | 视觉 |
|---|---|---|---|
| **上下文动作菜单** | 点击目标时弹出 | 攻击/找到/查看装备（敌人）；令其长眠/查看（倒地）；拾取/检查（地面物）；上车/检查（载具） | 半透明小面板，动作行带色 |
| **悬停提示 Tooltip** | 悬停节点/门户/物品 | 教室A(中场景)/连接/包含/玩家/接敌面2/4；门户成本后果；物品伤害/标签/占用/特殊 | 卡片，语义色徽章 |
| **投点面板（就地）** | 投点阶段 | 骰子🎲[投掷] + **强力骰推挡滑块** + **逆转推挡滑块** + 结算结果(投点→AP→排名) | **在轮次栏状态条旁就地播**（非独立弹窗 D-036）；**两个滑块都是可往上推 1–2 档**的推挡(`强力骰`橙/AP加注、`逆转`紫/反制)，**不同档位特效不同** |
| **距离 DC 显示** | 瞄准/枪械射击 | 目标/武器/距离/命中 DC；`🎲投d6≥4→命中(2伤)`、`≥6→翻倍(4伤)`；消耗 AP + 距离 DC 表 | 攻击预览卡片，紫射程+红伤害 |
| **负重提示** | 携带重型物 | `⚠️[重装] 大场景移动+1AP` + 来源（电锯·背包） | 人物"重"标记 + 移动预览自动加 AP |
| **瞄准点线（低显著）** | 悬停瞄准者 | 一条**紫点线**指向其瞄准目标 | 仅悬停出现，**无感叹号** |

## 五、物品栏 UI

- **槽位布局**：人物剪影居中；双手位 `💪──O──💪`、防具/盾牌位、`左手|右手` + `初始|背包` 四格；拓展后加 `🔪|绷带|弹夹|…` 横向条。**出生空手进场**（D-041），图标仅示意。

## 六、图块/形态语言（画"质感"的要点）

给 Image-2 的提示尽量带这几条"质感指令"，让它输出符合本项目而不是通用手游 UI：

1. **像素 + 简笔画双风格叠加**：前景像素（32×32，可稍大 64×64），高饱和；背景简笔画粗笔触低饱和；UI 面板介于其间、半透明、让背景透一点。
2. **离散柱状、不用细长连续血条**：生命 5 格 / 清醒 5 格 / AP 几格，都是分段小方块（像素块），不是细长条。
3. **边缘发光代替按钮**：可交互物是"描边 + 内发光"，不可交互是"扁平淡线条"。
4. **低心智性 + 高对比**：主体即第一眼的决策所需（下一步能做什么 + 这回合还有多少 AP + 谁剩多少血），其余压低。
5. **克制、暗调、略冷**：同一画面主功能色最多集中 3–4 种，其余用灰阶承载；整体偏梦境/清醒对峙题材的暗雅，不是鲜艳卡通。

## 七、投稿提示词模板（把上面汇编成一条） + 迭代法

**一条"UI 骨架样图"参考提示词（示例，可整段拿去调）**：

> **目标**：一张 1080p（1920×1080）对局战斗画面，**俯视平面视图（top-down plan view；平面轮廓+落地阴影，无前脸/侧脸/顶面/斜投影纵深）**。前景 = 高饱和 **像素风** 人物棋子（32–64px）站在低饱和 **粗描边简笔画** 场景节点上；地图背景低饱和、略冷暗调。HUD 严格分层：**左侧常驻"轮次栏"= 一列独立的轮次框**（每框 = 行动排名+头像+玩家名+红5格生命+蓝5格清醒）；**轮到谁：那个框高亮（反光感）**；**玩家自己的框比他人更宽更粗约一个骰子宽度、其清醒体力带反光高光**、颜色规则与他人一致；已行动者整行灰色降饱和。**一枚骰子图标悬空在轮次栏右侧**（平时不出现、统一/行动投点才悬空出现），投完从骰子右侧射出一根横条、多个玩家并排成横向条状对比，玩家的条从轮次栏右侧延伸出来、骰子在上层。**顶部细条**：`回合 5 | 玩家行动阶段 | 玩家A回合`。**红色五格生命、蓝色五格清醒**用离散块。**右下角付费动作面板**：`可用动作（剩余AP:2）` 若干行 = 像素图标+文字，**行右侧不显示 AP 数字**；右上"切零费"小按钮。**投点小面板就地含两枚推挡滑块：强力骰（橙，可上推1–2档，档位越高光效/充能越重）+ 逆转（紫，可上推1–2档）**。地图上：节点白光描边=可达、门户节点带图标、一个玩家头顶**飘着弱点小图标**。可交互=边缘发光、不可交互扁平。颜色只用：橙=AP、红=生命/伤害、蓝=清醒/体力、绿=可达/免费、紫=远程/条件反制、珊瑚=近战、灰=不可用、青=UGC；金银只做高光。**整体克制、暗调、半透明UI、反光高光、低心智性，一屏一眼能懂"我还能做什么、谁剩多少血、谁现在行动"。**

**迭代法**（Image-2 只当认知具现器）：出第一版 → 你圈改（布局/遮挡/配色/风格）→ 把圈改意见 + 上一版图作参考（图生图）→ 出下一版 → 收敛。收敛到一版"大家都认可的对局画面认知图"后，它只作参考，**实现仍走代码**（声明式组件树 + token 注册表，见 `00` / `01` 相关约定），素材只在零渲染继承不到的静态精细处补位。
