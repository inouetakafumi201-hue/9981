## 一、架构定位：承上启下的一层

### 1.1 单局运行视角的完整链条

```text
引擎层（Kernel）     原语：ECS、Op、Query、Expr、Hook、事件、持久化
  ↓
基类层（Class）      实例库：可枚举、可组合、不含具体玩法语义
  ↓
玩法层（Play）       规则组合：1-5 数值、流程、胜负、地图数据、策略
  ↓
整合层（LoadingRuntime）  "已装载对局"的生产面：组合根 + 对局外壳 + UI 宿主 + 事件出口
  ↓
表现层（Presentation）   本层：承上启下，节点与关系、ORCA、编排、端口面
  ↓
渲染交互层（Render）      V0 生成的壳层/组件/动效；零游戏逻辑，只消费表现层暴露面
```

> **本层的定性（用户定义，2026-08-19）**：
> - 表现层在整合层之上、渲染交互层之下，**承上启下**。
> - 它包含**所有的节点和关系**，ORCA 算法全面在这运行。
> - 它**不隔离一切玩法**，只负责把玩法结果翻译成可感知、可交互的呈现——动画、位移、朝向、反馈、演出，全部是"规则结算结果的视觉重演"（01 §实现约束）。
> - 它暴露给渲染交互层的，是**只读数据面 + 命令面**，不是玩法内部形状。

### 1.2 与 L0 第十三条的关系（待裁决）

- L0 第十三条把表现系统定义为**正交域**（"不是规则链第四层"）；整合层也明确"不是第四运行层"。
- 本文档新增的是：表现系统在"已装载对局运行链"里有一个**承上启下的正式位置**（整合层之上、渲染层之下）。这与"表现系统不改变规则位阶"**不冲突**——表现层只消费只读投影、只发意图、从不拥有权威写权。
- **待 owner 裁决项（D 编号预留）**：是否把"表现层/渲染交互层"作为 L0 第一/十三条之外的**运行链条命名**补入宪法；未裁决前，本文档与主状态板按"表现系统正交域 + 承上启下的运行链位置"并存表述，不改宪法正文。

### 1.3 边界铁律（沿用既有纪律）

| 方向 | 表现层做 | 表现层不做 |
|---|---|---|
| 下·整合层 | 消费 `after:*` 语义事件、7 端口投影、把意图经唯一判罚路径提交 | 不持有 `OpRegistry`/`WorldStateHolder`；不本地扣 AP、不裁决命中、不推进回合（38.4） |
| 内·自己 | 空间层 + 算法层 + 编排层 + 端口面（见下） | 不发明规则语义；动画与规则结算解耦（`after:*` 投递时规则已完成） |
| 上·渲染层 | 暴露只读数据面 + 命令面；渲染层只消费命令 | 不暴露内部算法细节；渲染层不得反向写表现层状态 |

## 二、表现层内部四块

### 2.1 分层

```text
┌────────────────────────────────────────────────────┐
│ 端口面（Ports）                                    │
│  · 下行：UiSystemPorts（projection/events/actionQuery/ │
│          revision/actions/pendingContracts/diagnostics）│
│  · 上行：空间投影面（只读数据）+ 命令面（命令式 API）   │
├────────────────────────────────────────────────────┤
│ 编排层（Choreography）                             │
│  · MoveChoreographer / AttackChoreographer /       │
│    StandoffResolver（恢复对峙 + 传染调度）          │
│  · 交权硬同步（轮权交接必须等演出停）               │
│  · 不可动实体静默迁移桥（emitRelocatableSignal）    │
├────────────────────────────────────────────────────┤
│ 算法层（Algorithms）                               │
│  · 可通行域预运算（段1，Web Worker）               │
│  · A* 点对点寻路（段2 骨架）                       │
│  · ORCA 避障（段2 实时）                           │
│  · 恢复对峙 + 传染式连锁                            │
│  · 泛光圈重叠检测 + 朝向计算                        │
├────────────────────────────────────────────────────┤
│ 空间层（Spatial）                                  │
│  · CollisionRegistry（碰撞箱注册，表现层自管）      │
│  · ClusterStore（对峙群 / 微场景点，节点关系载体）  │
│  · spatialStore（可通行域 / 位置 / 图层）           │
│  · facingStore / glowStore                          │
└────────────────────────────────────────────────────┘
```

> **"所有的节点和关系"落点**：节点（天然场景/微型场景的对峙群、容器、载具）与关系（过渡连接、容纳、影响）在表现侧统一表达为：
> - **对峙群 Cluster**（一群活体 + 中心 + 泛光圈）——微型场景的表现侧载体；
> - **图层 Layer**（`04_图层动态设计`：Z 轴叠层、贴纸、透明度函数）——天然场景/楼层/三界外独立层的视觉载体；
> - **连线 EdgeView**（`MapEdge` 的曲线/方向/阻塞）——过渡连接的表现侧载体。
> 表现层**不知道**玩法层微型场景 Node 内部形状，只从 `after:*` 事件负载与空间投影得知"哪些实体同群、中心在哪、谁连谁"。

## 四、向上：渲染交互层暴露面

### 4.1 空间投影面（只读数据，渲染层订阅/读取）

```typescript
/** 图层（04 §图层：Z 轴叠层 + 透明度函数 + 贴纸） */
interface LayerView {
  readonly layerId: string;
  readonly label: string;
  readonly height: number | null;        // null = 三界外独立层，恒不透明
  readonly opacity: number;              // 由焦点图层 + 透明度函数派生
  readonly isFocused: boolean;
  readonly stickerIds: readonly string[]; // 贴纸（实体/节点/连线/背景图）
}

/** 节点（天然场景/对峙群的表现侧） */
interface NodeView {
  readonly nodeId: string;
  readonly kind: 'scene' | 'micro-cluster' | 'container' | 'vehicle';
  readonly position: Vec2;               // 归一化坐标（MapNode.at）
  readonly layerId: string;
  readonly accessibleLabel: string;
  readonly interactable: boolean;
}

/** 连线（过渡连接） */
interface EdgeView {
  readonly edgeId: string;
  readonly from: string;
  readonly to: string;
  readonly directionality: 'bidirectional' | 'unidirectional' | 'one-way-down' | 'one-way-up';
  readonly path: readonly Vec2[];        // 手绘曲线，沿路动画
  readonly blocked: boolean;             // 过渡阻挡（任一侧被占）
}

/** 实体（角色/载具/物品） */
interface EntityView {
  readonly entityId: string;
  readonly definitionId?: string;
  readonly layerId: string;
  readonly position: Vec2;
  readonly collisionRadius: number;      // 碰撞箱半径（调试/命中反馈用）
  readonly facing: 'left' | 'right';
  readonly posture?: string;
  readonly statusIds: readonly string[];
  readonly spriteRef: string;            // 素材挂载引用
  readonly highlighted: boolean;
}

/** 对峙群（微场景点）泛光圈 */
interface ClusterView {
  readonly clusterId: string;
  readonly center: Vec2;
  readonly glowRadius: number;
  readonly entityIds: readonly string[];
  readonly overlapping: readonly string[]; // 与哪些群的光圈重叠
}

/** 地图背景贴纸 */
interface TileView {
  readonly tileId: string;
  readonly layerId: string;
  readonly imageRef: string;
  readonly transform: { scaleX: number; scaleY: number; tx: number; ty: number };
}
```

**数据来源**：全部来自表现层自己的空间层（ClusterStore/spatialStore/facingStore/glowStore）+ 整合层 7 端口投影 + MapData（编译产物）。渲染层不自己算距离/容量/阻挡/负重/目标范围（Requirement 14.3 的 UI 边界纪律延续）。

### 4.2 命令面（命令式 API，渲染层调用）

```typescript
interface RenderCommandApi {
  // 实体
  spawnEntity(view: EntityView): void;
  despawnEntity(entityId: string): void;
  moveEntity(entityId: string, path: readonly Vec2[], opts?: { curve?: 'normal' | 'heavy' | 'slow' | 'dash' }): Promise<void>;
  setFacing(entityId: string, facing: 'left' | 'right'): void;
  playPosture(entityId: string, posture: string): Promise<void>;   // 16 帧姿态
  // 演出
  playAttack(actorId: string, targetId: string, hitResult: 'hit' | 'miss' | 'parry'): Promise<void>;  // 三动画
  playEffect(effectId: string, params?: Record<string, unknown>): Promise<void>;   // 偷师板效果库
  playStandoff(clusterId: string, targets: Map<string, Vec2>): Promise<void>;      // 恢复对峙位移
  playFullscreen(ceremonyId: string): Promise<void>;               // 全屏动画（翻窗/跳窗/令其长眠/招架）
  // 反馈
  playHitFeedback(entityId: string, kind: 'hit' | 'weakness' | 'blocked'): Promise<void>;
  showToast(message: string): void;
  playAudio(audioId: string, params?: { volume?: number; loop?: boolean }): void;
  // 图层/镜头
  switchFocusLayer(layerId: string): Promise<void>;                // 焦点图层 + 镜头跟随
  focusEntity(entityId: string): void;
  // 微型场景地面承载椭圆；逻辑生命周期和命中语义见 15 号设计
  updateGroundGlowFootprint(footprint: GroundGlowFootprint): void;
  removeGroundGlowFootprint(footprintId: string): void;
  // 结算/状态
  showOutcome(outcome: { name: string; scope: string; rank: number | null }): void;
  updateTurnOrder(entries: readonly TurnOrderEntryView[]): void;
}
```

> **与偷师前端指令集的衔接**：渲染层由偷师前端（`12_v0.dev前端偷师体系设计.md`）生成，其**命令面板 = 指令集**（`AnimationCommands.playAnimation / playEffect / switchScene`）。表现层命令面就是这些指令的**真实实现落点**——接线时把渲染层的 mock 指令替换为 `RenderCommandApi` 的真实实现（10 §接线原则 1：前端结构不改，逻辑全换）。

### 4.3 双向约束

- **渲染层不得反向写表现层状态**：渲染层只消费命令 + 订阅投影；不持有 `spatialStore`/`facingStore` 的写权（延续 01 §表现系统只读纪律）。
- **命令可重放/可跳过**：所有演出命令都是"规则结算结果的视觉重演"，可跳过（全屏动画 ESC/空格跳过）、可降级（reduced motion / 性能降级为直线位移），跳过不影响规则。
- **MapPlay 语义时间线入口**：地图玩法文件只能提交已登记 `presentationRef`，由表现层解析为命令；不得在地图 JSON 内联 `RenderCommand`。每条公共表现能力必须有稳定参数 Schema、start/complete/cancel/timeout 生命周期、卸载清理与静态终态。
- **UGC 可配置性义务**：任务清单、倒计时、提示、场景切换、遮罩、镜头、动画和音频组件必须足够参数化。新地图需求若只能修改渲染组件实现，应先扩充公共组件/API，再由 MapPlay 配置调用。

## 五、不可动实体静默迁移桥（唯一跨层耦合）

沿用 `11_` §十一 与 `01` §静默归位：

| 层 | 角色 |
|---|---|
| **表现层** | 只作搭桥信号源：识别"可动对峙群中心已飘离其上不可动实体足够远"（`detectDriftedImmovables`），上送 `presentation:immovable-relocatable` 信号 |
| **玩法层/数据层** | 归属改写：把归属脱节者改归到最近同天然场景微场景点；**静默，无归位动画** |
| **表现层** | 继承结果：把该实体从旧对峙群挂到新对峙群（`clusterId` 更新），不播放位置动画 |

表现层不隔离玩法——这条桥正是"表现层感知节点关系、但不裁决玩法归属"的边界示例。

## 六、实现顺序（定稿）

```
① 偷师前端（渲染层，零逻辑）
    12_ 完整方案：偷师板 → 偷师前端 → 命令面板/指令集 → 提取动画效果库
    · 产出一份真实存在的"渲染交互层"：壳层结构、动效、命令面板
    · 命令面板的指令集 = 表现层命令面的雏形（形状在接线时校验）
② 接线（10%）
    · 把渲染层的 mock 数据/伪回调替换为真实端口
    · 指令集 → RenderCommandApi 真实实现（消费 after:* 事件 + 空间投影）
    · 对局 HUD 接 projection/actionQuery/revision/actions；spaceItems/ai 端口通电
    · 术语映射表：v0 文字 → 项目术语 → 对应端口（10 §2.2）
③ 全面实施表现层（四块）
    3.1 空间层：CollisionRegistry + ClusterStore + spatialStore/facingStore/glowStore
    3.2 算法层：可通行域（Web Worker）→ A* → ORCA → 恢复对峙+传染 → 泛光圈/朝向
    3.3 编排层：Move/Attack/Standoff 编排器 + 交权硬同步 + 不可动迁移桥
    3.4 端口通电：spaceItems/ai 接线；渲染层命令面全面对接
```

> **为什么渲染层先行**：渲染层先建好，表现层命令面才有**真实消费者**；接线时直接验证"命令面形状是否合理"，避免表现层先建、渲染层接不上返工。这也是 12_ D-082/D-084（偷师前端完全阉割逻辑、偷师板优先）的延续。
