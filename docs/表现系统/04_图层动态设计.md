## 〇、一句话定位

**图层是"叠层分离"（前景像素 / 背景素描），不动规则状态。**

图层系统的职责是**管理 Z 轴方向的视觉呈现**——哪些对象在同一平面、哪些对象在不同楼层、玩家如何在图层之间移动、以及如何通过透明度让玩家看到"当前层 + 上下层的半透明预览"。图层是纯视觉概念，不改变规则状态、不影响寻路逻辑（寻路由拓扑连接决定）。

---

## 一、图层系统的核心概念

### 1.1 图层 = 空画布 + 贴纸

**图层不是"楼层"**：
- **楼层**（1F/2F/3F）是现实世界的物理概念，对应建筑的分层
- **图层**（Layer）是表现系统的渲染概念，对应 Z 轴的视觉分层
- 一个楼层可能有多个图层（例如：地面、桌面、天花板吊灯）
- 一个图层可能跨越多个楼层（例如：贯穿 1F-3F 的电梯井）

**图层的组成**：
- **空画布**：一个有 height 值（或留空）的虚拟平面
- **贴纸**：放置在该图层上的所有对象（实体、节点、连线、背景图）

### 1.2 height 模型（2026-08-15 定案）

> **权威来源**：devboard-spec-landed memory + `创作系统/01` §九 L.1-L.10

**height 的语义**：
- `height`：任意正小数（例如：0.5、1.0、2.5、10.3），**可以留空**
- **留空 = 三界之外独立层，无透视关系**（例如：UI 图层、特效图层）
- **参与透视的 height 自动去重**：多个对象声明相同 height → 视为同一图层

**透明度函数**（表现层规则，非编辑器规则）：
```
opacity = min(1, |Δheight| × 0.1)
```
- 差值 = 0 → 透明度 100%（完全不透明，当前图层）
- 差值 = 1 → 透明度 90%（微透明）
- 差值 = 5 → 透明度 50%（半透明）
- 差值 = 10 → 透明度 0%（完全隐藏）
- 差值 > 10 → 透明度 0%（完全隐藏）

**三界之外独立层**：
- `height = null`（留空）→ 永远 100% 不透明，不参与透明度计算
- 典型用途：UI 图层、全屏特效、常驻界面元素

## 二、对局中的图层动态（玩家视角）

### 2.1 叠层视图（Layered View）

> **设计原则**：基于 `01` §叠层视图 + `00` §一·画风基调"前景像素 + 背景素描"

**视觉呈现**：
- **当前图层**：100% 不透明，全彩显示
- **相邻图层**（Δheight = 1~2）：90%~70% 透明度，颜色饱和度保持
- **远离图层**（Δheight = 3~9）：60%~10% 透明度，颜色饱和度保持
- **极远图层**（Δheight ≥ 10）：完全隐藏（不渲染，节省性能）

**为什么不降低饱和度**：
- 降低饱和度会让玩家误以为"这个对象不可用"（灰色 = 冷却/延迟，见 `01` 颜色语义）
- 透明度足以传达"这个对象在另一层"，不需要额外的视觉暗示

**三界之外独立层的特殊处理**：
- `height = null` 的图层永远 100% 不透明，始终可见
- 例如：轮次栏、动作菜单、状态图标、小地图——这些 UI 元素不应该因为玩家在 2F 就变透明

### 2.2 当前焦点图层的判定

**当前焦点图层 = 玩家视角的中心图层**

**判定规则**：
1. **对局焦点模式**（默认，自动跟随）：当前行动主体的 height → 当前焦点图层
2. **观战自由模式**：玩家点击轮次栏中的其他角色 → 切换到该角色所在图层（见 §2.3）
3. **编辑器模式**：编辑器当前选中的图层（见 §三）

**焦点图层切换时机**：
- **轮权交接**：下一个行动主体在不同图层 → 焦点图层自动切换（配合镜头平滑追随）
- **玩家移动到不同图层**：当前行动主体通过楼梯/电梯/传送门移动到新图层 → 焦点图层跟随
- **点击其他角色**（观战自由模式）：玩家点击轮次栏中的其他角色 → 切换到该角色图层

**焦点图层切换的过渡**：
- **透明度过渡**：所有图层的透明度平滑过渡到新的目标值（0.5 秒 ease-in-out）
- **不是瞬变**：避免视觉上的闪烁或突兀感

### 2.3 观战自由模式的图层切换（直接点轮次栏）

> **人机交互改进**：不做独立图层面板，直接点击轮次栏中的其他角色切换视角

**交互流程**：
1. **进入观战自由模式**：按 `Tab` 或点击"观战"按钮
2. **点击轮次栏中的其他角色头像** → 镜头切换到该角色 + 焦点图层切换到该角色所在图层
3. **点击自己的角色头像 or 按 `Esc` or 再按 `Tab`** → 退出观战，回到自己的视角

**为什么不做独立图层面板**：
- 图层切换的本质是"我想看其他角色在做什么"，不是"我想看第 3 层有什么"
- 玩家不关心抽象的"图层 3"，只关心"那个角色在哪"
- 轮次栏已经列出了所有角色，直接点击即可，不需要多一层 UI

**轮次栏的视觉反馈**：
- **当前焦点角色**：头像高亮 + 边框加粗（金色反光，见 `01` §轮次栏设计）
- **不同图层的角色**：头像右下角显示小图标（楼梯图标 + 层数差，例如 "↑2" 表示在上 2 层）
- **点击后**：镜头平滑移动到目标角色 + 透明度过渡（0.5 秒）

### 2.4 跨层交互的高亮规则（核心机制）

> **关键原则**：高亮可点击的要素（逻辑上允许交互的），只要层级差距 ≤9，就照常高亮，**不受透明度影响**

**高亮判定**（优先级高于透明度）：
- **|Δheight| ≤ 9**：对象在逻辑上可交互 → **高亮显示**（边缘发光 + 100% 不透明，见 `01` §边缘发光交互语法）
- **|Δheight| > 9**：对象完全隐藏 → 不高亮、不可交互
- **height = null**（三界之外独立层）：不与任何层交互 → 不高亮

**为什么是 ≤9**：
- 透明度函数在 Δheight = 10 时完全隐藏（opacity = 0）
- 所以交互判定的边界是 9（最后一个可见的层级差）
- 这保证了"看得到就能交互"的一致性

**高亮的视觉表现**：
- **边缘发光**（白色，2px，见 `01` §边缘发光交互语法）
- **对象本身 100% 不透明**（即使所在图层按透明度函数应该是 50%）
- **悬停提示**：显示对象名称 + 层级差（例如："敌人狙击手 (↑3)"）

**典型场景**：
1. **玩家在 1F，敌人在 4F**：
   - Δheight = 3，按透明度函数应该是 70% 透明
   - 但如果该敌人可被射击（规则允许），则**高亮显示 + 100% 不透明**
   - 鼠标悬停显示："敌人狙击手 (↑3)"

2. **玩家在 5F，物品在 6F**：
   - Δheight = 1，按透明度函数应该是 90% 透明
   - 如果该物品可被拾取（规则允许），则**高亮显示 + 100% 不透明**

3. **玩家在 1F，物品在 12F**：
   - Δheight = 11，超过 9 → 完全隐藏，不高亮，不可交互

**逻辑判定 vs 视觉呈现的优先级**：
```
高亮可交互（规则允许 + Δheight ≤9） > 透明度函数（纯视觉）
```

**实现要点**：
- 高亮判定由**规则层**提供（例如：`canInteract(entity, target)` 返回 true/false）
- 表现层只负责"把规则层说可以交互的对象高亮显示"
- 透明度函数只影响"不可交互的对象"和"背景装饰"

**图层面板内容**：
| 元素 | 描述 |
|---|---|
| **图层缩略图** | 每个图层的俯视缩略图（64×64 像素） |
| **图层名称** | 1F / 2F / 3F（或自定义名称，如"地下室""屋顶"） |
| **当前焦点标记** | 当前焦点图层用金色边框高亮 |
| **实体数量** | 每个图层上的实体数量（例如："3 个敌人"） |

**手动切换操作**：
- **按 `1/2/3` 键**：快速切换到对应图层（1=最底层，2=中间层，3=最顶层）
- **点击图层缩略图**：切换到该图层
- **滚轮滚动**（在图层面板上）：上下切换图层

**手动切换的限制**：
- 只在**观战自由模式**下生效
- **对局焦点模式**下，图层自动跟随当前行动主体，不能手动切换

## 三、编辑器中的图层交互（创作者视角）

> **设计原则**：基于 `创作系统/01` §九图元穷举 + devboard-spec-landed memory

### 3.1 编辑器的"当前图层"概念

**当前图层 = 编辑器当前选中的工作图层**

**当前图层的特权**：
- **只有当前图层及以下可见可交互**（memory："当前图层只有当前级以下可见可交互"）
- 高于当前图层的对象**完全隐藏**（不渲染，避免遮挡）
- 低于当前图层的对象**半透明显示**（按透明度函数）

**为什么这样设计**：
- 避免"上层对象遮挡下层编辑"的问题（例如：编辑 1F 时，2F 的天花板不应该挡住视线）
- 保持视觉清晰，让创作者专注于当前正在编辑的图层

### 3.2 图层切换（编辑器）

**切换方式**：
- **按 `1/2/3` 键**：切换到对应图层
- **图层面板**：点击图层名称或缩略图
- **滚轮滚动**（按住 `Alt`）：上下切换图层

**切换效果**：
- **瞬时切换**（不是平滑过渡，编辑器优先效率）
- 高于当前图层的对象立刻隐藏
- 低于当前图层的对象立刻变为半透明

### 3.3 贴纸锁定机制

> **权威来源**：devboard-spec-landed memory："贴纸点确定锁定不可再选"

**锁定规则**：
- 对象放置到某个图层后，**锁定到该图层**
- **不能拖拽到其他图层**（避免误操作导致对象"飘"到错误的图层）
- 要移动到其他图层，必须：
  1. 选中对象
  2. 右键菜单 → "移动到图层..." → 选择目标图层
  3. 或：剪切（Ctrl+X）→ 切换到目标图层 → 粘贴（Ctrl+V）

**为什么锁定**：
- 防止"拖拽时误触图层切换键"导致对象跳到其他图层
- 让图层归属明确，避免混乱

### 3.4 跨层可见性与交互

**可见但不可交互**：
- 低于当前图层的对象**可见**（半透明），但**不可选中、不可编辑**
- 例如：编辑 2F 时，1F 的对象半透明显示，但点击无效

**完全隐藏**：
- 高于当前图层的对象**完全隐藏**（不渲染）

**例外：跨层连线**：
- 连接不同图层的连线（例如：楼梯连接 1F 和 2F）**始终可见**
- 默认半透明显示（30% 不透明度）
- 悬停时亮起（100% 不透明度）

### 3.5 漏风透底问题

> **权威来源**：devboard-spec-landed memory："漏风透底但 height 半透明照样激活"

**问题**：当前图层没有背景图时，可以"透过"看到下层对象

**解决方案**：
- **不是 bug，是 feature**：允许创作者看到下层对象，帮助对齐
- 下层对象仍然按透明度函数显示（半透明）
- 下层对象**不可交互**（点击穿透到当前图层的空白）

**障碍物提示**：
- 拖拽对象到"透明处"（无背景图的区域）时，如果该位置在下层有障碍物（物理遮挡框），显示**淡红色半透明提示**
- 提示内容："下层有障碍物"
- **不阻止放置**，只是提示（创作者可能故意这样设计）

## 四、跨层动画与过渡（四种类型）

> **设计原则**：图层变换的动态是复杂的，按触发方式和表现归类为四种

### 4.1 类型一：坠落

**触发条件**：
- 玩家被击退/跳下/失足，从高层掉到低层
- 通常是**非自愿**的移动（被动触发）

**动画序列**：
```
1. 玩家离开当前图层节点（被击退或跳跃）
2. 自由落体动画：
   - 人物垂直下坠（Y 轴位置快速降低，见 `03` 曲线配方 P5-竖向位移）
   - 人物 height 值连续变化（从起点 height → 终点 height）
   - 所有图层的透明度实时重算（玩家正在穿越多层）
3. 落地：
   - 人物落地冲击动画（受击姿态，见 `03` §一·C 受击）
   - 焦点图层切换到落地层
   - 可能触发摔伤判定（规则层）
```

**视觉特征**：
- **速度快**（重力加速度感）
- **人物姿态变化**：从站立 → 下坠姿态 → 落地受击
- **多层穿透**：如果坠落跨越多层（例如从 5F 掉到 1F），玩家会看到"快速穿过"中间层的效果

### 4.2 类型二：位移（电梯/梯子）

**触发条件**：
- 玩家乘坐电梯、爬梯子等**机械装置**
- 是**自愿**的、**可控**的移动

**动画序列**：
```
1. 玩家进入电梯/梯子（点击交互）
2. 位移动画：
   - **人物动画完全不动**（站立姿态保持，或播放"扶梯"循环动画）
   - 人物 height 值平滑变化（匀速上升/下降）
   - 焦点图层跟随人物 height（所有图层透明度实时重算）
3. 到达目标层：
   - 人物走出电梯/梯子
   - 焦点图层锁定到目标层
```

**视觉特征**：
- **速度匀速**（机械装置的稳定感）
- **人物姿态不变**（强调"被动移动"，不是自己跳跃）
- **电梯特例**：如果是封闭电梯（内部看不到外部），则电梯内部是独立的"封闭空间"，外部图层完全隐藏

### 4.3 类型三：楼梯（阶梯式跳跃 + 大小变化）

**触发条件**：
- 玩家走楼梯（自愿移动）
- 楼梯连接相邻图层（通常 Δheight = 1）

**动画序列**：
```
1. 玩家走到楼梯入口（当前图层）
2. 楼梯动画：
   - 人物**一跳一跳**前进（跳跃曲线，见 `03` 曲线配方 P1-近距移动）
   - 每跳一次，人物**大小阶梯式变化**：
     * 上楼：每跳一次缩小 5%（模拟"远离镜头"）
     * 下楼：每跳一次放大 5%（模拟"靠近镜头"）
   - 人物 height 值逐步变化（每跳一次，height += 0.2）
   - 切换到新图层时，恢复原大小（100%）
3. 到达目标层：
   - 人物恢复原大小（如果还没恢复）
   - 焦点图层切换到目标层
```

**视觉特征**：
- **节奏感强**（一跳一跳，不是平滑移动）
- **透视感**（大小变化模拟远近）
- **适用范围广**：独立图层、不互相遮挡图层、互相遮挡图层皆可

**为什么大小变化**：
- 模拟"走楼梯时远离/靠近镜头"的透视效果
- 让玩家直观感受到"我正在改变高度"
- 增强空间感

### 4.4 类型四：传送（瞬间切换）

**触发条件**：
- 玩家使用传送门、魔法传送、或特殊机关
- 通常跨越**大距离图层**（Δheight > 2）或**独立图层之间**

**动画序列**：
```
1. 玩家走到传送门（当前图层）
2. 传送演出：
   - 传送门打开动画（全屏动画 or 粒子特效，见 `03` §三·门户）
   - 人物淡出（opacity 100% → 0%，0.3 秒）
   - **焦点图层瞬间切换**（不是平滑过渡）
   - 目标图层的传送门打开
   - 人物淡入（opacity 0% → 100%，0.3 秒）
3. 到达目标层：
   - 人物从传送门走出
   - 焦点图层锁定到目标层
```

**视觉特征**：
- **瞬间切换**（不展示中间层）
- **强烈的"断裂感"**（强调这是非常规移动）
- **适用场景**：独立图层之间、互相遮挡的图层、或超远距离（例如从 1F 传送到 10F）

**传送门的视觉设计**：
- 传送门是**特殊对象**，有自己的 height 值
- 传送门发光（白色边缘发光，见 `01` §边缘发光交互语法）
- 悬停提示："传送到 地下室 (↓5)"

### 4.5 跨层射击的弹道表现

**视觉表现**（补充 §2.4 高亮逻辑）：
- **子弹/箭矢飞行轨迹**：
  - 沿直线飞行（紫色关系线，见 `01` 颜色语义）
  - 子弹的透明度跟随所穿越的图层（从 100% → 目标图层的透明度）
  - 命中目标时，目标短暂高亮（100% 不透明，0.2 秒）

- **规则判定 vs 视觉呈现**：
  - **规则层判定是 3D 的**（考虑实际 height 值，射线检测是立体的）
  - **视觉层只负责"让玩家看到弹道"**（透明度变化只是视觉效果）

## 五、图层与规则系统的解耦

> **设计原则**：基于 `00` §二·原则一"图层不改变规则状态"

### 5.1 图层是纯视觉概念

**图层不影响规则**：
- 寻路逻辑**不依赖图层**，只依赖拓扑连接（见 `01` §前端动态图形化）
- 射线检测**是 3D 的**，考虑实际的 height 值，不是视觉上的透明度
- 伤害计算、状态判定、AP 消耗**与图层无关**

**例子**：
- 玩家在 2F，射击 1F 的敌人 → 规则层判定"射线是否穿过障碍物"（3D 几何），不是"图层是否可见"
- 玩家在 1F，听到 2F 的枪声 → 音效系统判定"3D 距离衰减"（见声音子系统），不是"图层透明度"

### 5.2 height 值的规则语义

**height 只有一个规则语义：高度差影响射线检测**

**射线检测规则**：
- 从点 A（height = h1）射向点 B（height = h2）
- 射线路径上的所有障碍物（物理遮挡框），只有当其 height 在 `[min(h1, h2), max(h1, h2)]` 范围内时，才会阻挡射线
- **这是规则层逻辑，不是图层系统的职责**

**图层系统不参与规则判定**：
- 图层系统只负责"渲染时，哪些对象应该半透明"
- 不负责"规则层判定时，哪些对象应该被考虑"

## 六、图层与其他子系统的协同

### 6.1 与镜头系统的协同

> **已在镜头子系统设计**：`02_镜头动态设计.md` §八

**镜头负责 XY 平面，图层负责 Z 轴**：
- 镜头：追随、缩放、切换焦点（XY 平面）
- 图层：透明度、图层切换、跨层动画（Z 轴）

**焦点对象的图层高亮**：
- 当镜头聚焦某个对象时，**该对象所在图层的透明度提升到 100%**（即使与当前焦点图层相差很大）
- 这是"临时可见性提升"，不是改变图层的 height 值
- **判定：不违反职责边界**（图层系统允许根据焦点调整透明度）

### 6.2 与声音系统的协同

> **已在声音子系统设计**：`03_声音动态设计.md` §四

**声音的 3D 定位不受图层透明度影响**：
- 音源在 2F，玩家在 1F → 音效音量按**实际 3D 距离**衰减，不是"图层透明度"
- 即使 2F 完全隐藏（Δheight ≥ 10），玩家仍然能听到 2F 的枪声（如果距离足够近）

**例外：视觉音效提示**（无障碍功能）：
- 开启"视觉音效提示"后，屏幕边缘显示音源方向箭头
- 箭头的透明度**与图层透明度一致**（例如：2F 的枪声箭头半透明）

### 6.3 与动画系统的协同

**动画播放不受图层透明度影响**：
- 对象在半透明图层上播放动画 → 动画正常播放，只是整体半透明
- 例如：1F 的敌人在 2F 玩家视角下是半透明的，但其"受击动画"（红色闪烁）仍然正常播放

**跨层动画的特殊处理**：
- 玩家从 1F 移动到 2F（跨层移动）→ 玩家的透明度在移动过程中逐渐变化（见 §四·4.1）

## 七、性能优化

### 7.1 渲染剔除

**完全隐藏的图层不渲染**：
- Δheight ≥ 10 的图层 → 完全不渲染（节省 GPU 资源）
- 只渲染"当前焦点图层 ± 9 层"的范围

**例外：三界之外独立层**：
- `height = null` 的图层永远渲染（UI 元素、特效图层）

### 7.2 透明度缓存

**预计算不透明度表**：
- 对于每个可能的 Δheight 值（0~10），预计算透明度
- 存储在查找表中，避免运行时重复计算

```typescript
const OPACITY_TABLE = [
  1.0,  // Δheight = 0
  0.9,  // Δheight = 1
  0.8,  // Δheight = 2
  0.7,  // Δheight = 3
  0.6,  // Δheight = 4
  0.5,  // Δheight = 5
  0.4,  // Δheight = 6
  0.3,  // Δheight = 7
  0.2,  // Δheight = 8
  0.1,  // Δheight = 9
  0.0,  // Δheight = 10+
];

```

### 7.3 图层切换的批处理

**焦点图层切换时，批量更新透明度**：
- 不是逐个对象更新透明度，而是按图层批量更新
- 所有同一图层的对象共享同一个透明度值

## 八、图层的数据契约（与地图编辑器的接口）

> **权威来源**：devboard-spec-landed memory："floor→layerId 迁移、floors→layers 为契约扩展独立专项"

**当前数据结构（旧）**：
```typescript
interface MapNode {
  id: string;
  floor: number;  // 整数：1 = 1F, 2 = 2F, ...
  // ...
}

interface MapData {
  floors: number;  // 总楼层数
  // ...
}
```

**目标数据结构（新，契约扩展独立专项）**：
```typescript
interface Layer {
  id: string;              // 图层 ID（例如："layer_1f", "layer_2f"）
  height?: number;         // 可空：留空 = 三界之外独立层
  name?: string;           // 可选：图层名称（例如："1F 地面", "2F 走廊"）
  backgroundImage?: string; // 可选：该图层的背景图
}

interface MapNode {
  id: string;
  layerId: string;  // 指向 Layer.id
  // ...
}

interface MapData {
  layers: Layer[];  // 图层列表
  // ...
}
```

**迁移规则**：
- `floor: 1` → `layerId: "layer_1f"`, `layers: [{ id: "layer_1f", height: 1.0 }]`
- `floor: 2` → `layerId: "layer_2f"`, `layers: [{ id: "layer_2f", height: 2.0 }]`

**后向兼容**：
- 旧地图数据仍然使用 `floor` 字段 → 自动转换为 `layerId`（编译期）
- 新地图数据使用 `layerId` + `layers` → 完整支持 height 模型

## 九、用户设置（无障碍支持）

### 9.1 图层透明度设置

**可调节参数**：
- **图层透明度强度**：0% ~ 100%（默认 100%）
  - 100%：按公式 `opacity = max(0, 1 - |Δheight| × 0.1)`
  - 50%：按公式 `opacity = max(0, 1 - |Δheight| × 0.05)`（透明度减半，更容易看清其他图层）
  - 0%：所有图层都 100% 不透明（无障碍模式：完全禁用图层透明度，所有图层叠加显示）

### 9.2 图层切换提示

**视觉提示**：
- 焦点图层切换时，屏幕中央显示**图层名称**（例如："2F"）
- 持续 1 秒后淡出

**音效提示**：
- 焦点图层切换时，播放**提示音**（上升音阶 = 上楼，下降音阶 = 下楼）
