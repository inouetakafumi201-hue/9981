# 动画灵感索（使用场景穷举）

> **性质**：**灵感探索文档（灵感索）** —— 对四种动画（**曲线 / 帧 / 全屏 / 粒子**）的全部使用场景做"事无巨细"的穷举。它是一座**灵感仓库**，不是权威契约；正式铺开前端时，从这座仓库里挑取、减负、落实到具体动画管线。颗粒度像灵感本身就是"具体到一拍一个动作、一个曲线参数"这样细。
> **状态**：灵感索（穷举草稿）。所有条目都来自对本作玩法机制的逐个扫描（攻击/移动/状态/载具/门户/回合/警戒），绝大多数"怎么播"是**我的竞合设计判断**，待后续真正实现时取舍。
> **四种动画**（定义，见 `docs/表现系统/01_图形化与UI.md`，此处只作穷举）：
> - **曲线动画** = 对图标的**画面变换**（挤压 / 旋转 / 放大 / 缩放 / 位移 / 变色 / 蒙版等），**不使用任何素材**。
> - **帧动画** = 通过改变**已存储的帧**实现（换帧 = 换图片）。
> - **全屏动画** = 带**全屏闪过特效** + 特效框内部**图片/视频/骨骼动画**；地图上可能无真动画或极简。
> - **粒子动画** = 粒子的发射 / 运动 / 消散（空间弥漫型效果）。
>
> **使用原则（方向）**：帧动画**尽量克制**（只在确需身体/姿势细节处用）；曲线动画是**绝对主力**（不碰素材、扩展性强、让游戏独特而灵动）；全屏动画**不滥用**（只留给仪式感动作，D-026 已定为 4 项 + 床/睡觉演出）；粒子动画用在"空间弥漫"处，成本低但不铺满。
>
> **来源调研**：本索覆盖的对局动作清单来自 `L3_玩法层`、`L2_基类层`（02/03/04/06/07）、`L1_引擎层`（05/06/元机制内核Spec）、`表现系统/01、02`、`运营系统/03、04、01`、`创作系统/01、02`、`叙事设定/00`、`src/class/weapons/index.json`。凡涉及动画的权威约束（隐藏信息不可泄露、动画与规则解耦）不在此重复，见 `表现系统/01`。
>
> **本文结构**：四大节（曲线/帧/全屏/粒子）是按"动画类型"穷举；**交叉编目（第 Ⅴ 大节）是把每个玩法机制反过来一次过"它该怎么播"**。两大方向互为索引：从"我想做曲线动画"查第 Ⅳ 大节的配方库，从"某个机制该怎么播"查第 Ⅴ 大节的机制清单——两者都要，才能既覆盖新机制、又保证灵感索逐步补充。

## 〇、灵感索的使用方法与查表路径

**构建动画的三种入口**（来自 `02_动画音效与反馈.md` 的定义与映射约束）：

1. **从语义到配方**：前端拿到一个 `actionSemanticId`（如 `action:ranged-attack`）→ 查 `ActionPresentationBinding` 找到 `animationRecipeId` → 落到对应配方。灵感索负责把"配方"这一层写厚，让你在写 `animationRecipeId` 时知道有哪些可选的曲线/帧/全屏/粒子的"做法"。
2. **从机制到演出**：一个新的玩法机制落地时，先在**第五大节逐机制清单**里想"它的主力动画是什么、叠加什么、要不要全屏/帧"，再回第三/四大节的配方库挑具体"怎么动"的细节。
3. **从已知配方到新配方**：本索的曲线配方库（第四大节）按"物理/情绪意图"穷举了十几条曲线"做法"，任何新机制只要对得上某个意图，就能立刻套用。

> **避免重复劳动**：`表现系统/02` 的 `ACTION_ANIMATIONS` 已登记了 6 个稳定语义→配方的官方绑定（move / ranged-attack / climb-window / jump-window / execute-sleep / parry-triggered），粒子的"最小高价值粒子集"也已在 `02` §七定案（灰尘/血液/枪口火焰/碎玻璃/蓝光）。本文只负责**把每个机制的"怎么做"灵感填厚**，不重复登记绑定表。凡出现"这里要有一个配方名"，都是建议性的配方 ID，正式确立以 `02` 的映射表为准。

**四类动画的血肉分工**（快速记忆）：
- **粒子** = 空间里"弥漫、爆一下、飘散"的体积感（不属于任何单个实体）。

> **设计不含图标 / 小素材（重要边界，2026-08-14 定案）**：本项目**任何设计都不包括"简单图标、小例子"这类图案/小素材**。可以被接受的小图标**只是曲线动画的附属**，不算非曲线动画——因为它们总是伴随一个真正的曲线动画存在：
> - **头顶"ZZZ"**：不是独立的非曲线动画；因为该单位同时有**缓缓点头的曲线动画**（睡眠呼吸）。
> - **换弹闪烁图标**：不影响其曲线动画——换弹的**真正演出是曲线**（枪口下倾 30° 抖两下回正，见 D 攻击），图标只是提示。
> 所以本文档的动画类型里**不把图标列入**；图标是小素材，只在"伴生曲线"时出现，不单列为动画。
- **曲线** = 单一图标自己的变换（挤压/转向/位移/变色）。
- **帧** = 角色姿态的精细形态（弯腰/蜷缩/趴/躺/跨步）。
- **全屏** = 全屏闪过的高冲击仪式（翻窗/跳窗/处决/招架/出生/入睡/传送）。
- 通常**粒子叠加在曲线之上**（受击 = 曲线后仰 + 命中点粒子），二者不是替代而是配。

**一致性约束**（视觉定律见 `01` §1，此处只提影响动画配色的要点）：
- 配色按语义定：红=伤害/致命、蓝=清醒/处决/科技、橙=AP/进度、绿=正面/安全、紫=网关/远程/关系约束、珊瑚=近战/格斗、青=UGC/创作、灰=冷却/延迟、纯白/奶白=梦境边界与过载、金/银=品级高光。
- 边缘发光作交互语法（白光=可通行、黄=感官/警戒、橙=进行中、红=致命、蓝=可处决、紫=网关、珊瑚=近战、绿=安全/拾取、青=社交/UGC）；可点击对象必须高光凸起，不可点击扁平无高光。
- 动画失败/跳过必须不改变结算结果；表现不写规则状态。

## 一、曲线动画使用场景穷举（主力，不碰素材）

> 曲线动画 = 对图标的**挤压 / 旋转 / 放大 / 缩放 / 位移 / 变色 / 蒙版**等画面变换。按"它的物理/情绪意图"分组，颗粒度细到"一个动作一拍一拍怎么动"。

### A. 移动节奏（跳跃式移动是唯一定形，`02` §二程序化移动）

本作**唯一移动形态是"跳跃式移动"**（提起+落下的弧线，非滑行，`ProceduralMoveSpec`：`durationMs/arcHeightRatio/rotationDegrees/landingSquashRatio/emitLandingDust`，`easeOutCubic(progress)+sin(π·progress)·arcHeight`）。以下移动状态**都是用户临时起的参考名**，是否全部实装待定，但给了"不同状态节奏不同"的穷举维度：

| 移动状态 | 跳跃距离 | 跳跃高度 | 节奏/速度 | 表现性 | 典型触发 |
|---|---|---|---|---|---|
| **迟缓** | 小 | 低 | 慢、沉重 | 拖沓、负重感 | 重装、负重、[迟缓]状态 |
| **标准** | 中 | 中 | 适中 | 正常 | 普通行走 |
| **跨步** | 大 | 较高 | 较快 | 果决、冲刺 | 近战前冲、跨越、追逐发起 |
| **蹒跚** | 小 | 低 | 不稳、忽快忽慢 | 眩晕、踉跄 | 受击晕眩、状态异常、濒死 |
| **奔跑** | 大 | 高 | 快、急促 | 逃离、追击 | 躲避、追逐、逃跑 |

**一拍的动作（曲线）**：
- 一提（scale/position 上移）→ 一落（下移 + 落地瞬间**挤压压扁**）→ 落地**反弹小起伏**（overshoot）→ 后脚收起。整段是 position + scale 的曲线，**无帧**。
- 不同移动状态，只换"一提的高度/一落的距离/一提的时间"这组参数，就能表达迟缓 vs 奔跑的迥异节奏。
- **慢/重物**：跳跃曲线本身**单独定义**（迟缓/重物的行动跳跃曲线是另一条，与普通跳跃不同），体现"这个单位挪动要费力"。
- **负重（[重装]）**：走路曲线换"迟缓"的那条（沉、慢）。

> **过载不产生"移动"曲线**：过载（体力>5）是**不可移动**的状态（规则上它失去本回合行动权），所以不存在"过载的移动曲线"。它的表现在**站立摇晃**（见 B 姿态转变），不是移动。

**脚下粒子**：跳跃落地时**可选**脚底淡淡粒子（尘土/光点）。非每次播放，只在强调落地/重物/狂奔时。

**移动类型个案**（各自"怎么动"的曲线特化）：
- **爬行**（倒地状态下移动）：沿用**"像虫子一样弹性伸缩往前爬"**的大胆提案（见 B 姿态转变）：倒地状态下身体像虫子一样**伸缩弹动**，向前一段一段地挪，弹性频率要**快**，正好让人绷不住；拖痕粒子保留（身后一段淡痕）。正常画会生硬，要真动画实现——**谨慎，先搁置，等有真动画（帧/程序）再实现**，当前不承诺用纯曲线完成。延迟由规则投影的时序/成本决定（`02` §六）。
- **载具驾驶移动**：整辆**车沿路径做跳跃式位移**，弧高比角色大、落地更"重"（车体落地 squash），可选轮下扬尘粒子（见第 Ⅳ 大节配方 P1 重装版）。
- **推车（电瓶车）**：玩家在车前做"推"的姿态 + 车体整体前移，人车绑定，一小段一小段地顿挫前移（推一下就挪一格）。
- **跨楼层移动**：经门户（楼梯/梯子/门/窗）在楼层间前进（见 G 门户）。

### B. 姿态转变（图标/身体本身的变化）

- **朝向**（单一左右）：转身 = 图标在左右朝向间**旋转或翻面**。单一左右轴，不做过场回旋（见 `01` 朝向规则）。**只有事件才触发转向**（攻击后改向朝向我），新玩家进入只让随机几人转向，不全员转头。
  - **朝向系统的完整判定（索引，不在此展开）**：移动 / 攻击 / 交互这类**必然朝向目标**的动作，其转向是毫无疑问的（朝向目标即可），**转向本身不需要设计**——朝向的重点是**逻辑判定**（哪些动作必须转向、哪些不转、哪些随机几人转、朝向如何影响后续动作），它应被**单独设计**（未来单开朝向设计文档），本索只在此索引/预留，不把朝向展开为动画演出。
  - **朝向系统的完整判定（转向逻辑，另立索引）**：移动、攻击、交互这类"必然朝向目标"的动作，转向是毫无疑问的——朝向的重点是**逻辑判定**（哪些动作必须转向、哪些不转、哪些随机几人转），它可单独设计，**不作为动画演出展开**。此处只索引/预留。
- **站立摇晃（非移动的原地摇摆，替代"过载/睡眠"等）**：当单位在某些状态下**不能移动**（过载失去行动权、睡眠站立、眩晕等），表现为**原地站立略略摇摇晃晃**——身体中轴的轻微左右摆 + 重心微晃的呼吸式曲线，循环播放（不前进）。**这是"静止但有生命感"的演出**，而不是移动。**过载**尤其如此：它不可移动，只有这一种摇摆。
- **睡眠（站立/床侧）**：睡眠单位同样不移动，表现为**缓缓点头的呼吸式曲线**（配合头顶"ZZZ"小图标，见 §〇 图标/小素材说明），持续播放。
- **前倾 / 后仰 / 复位**：身体整体绕脚部枢轴**倾角变换**。前倾=进攻/压低，后仰=受击/后退。
- **上下（跳/落）**：跳跃一提一落（同 A 一提一落，粒子在落点）。

  - **起身**：从床跳下、从倒地站起 = 蹲/坐/躺的姿态角度 → 站立角度的曲线过渡。
- **挤压/放大（阶梯式缩放）**：高地/洼地框内阶梯式轻微放大/缩小（表现层地形微调，见 `01` 高低地）。踩上高地框内一步一阶地微微变大，走洼地一步一阶地微微缩小，像在一步步上下台阶——是用**缩放曲线**做"阶感"而不是瞬间跳变。
- **受击**：受击瞬间**小幅挤压压扁** + 后仰（见 C）。
- **蹲下 / 起立**：角色高度变化（scale.Y 压缩/拉回），0.2 秒（D-047）；蹲下被击中即取消站起、进度不保留（起立被打断动画）。
- **被撞击**：受撞击实体整个**后仰 + 位移**（见载具）。

**微观场景内的姿态**（D-047 姿态物理拓扑）：站立（32-48px）→ 蹲下（24px）→ 倒地濒死（躺倒+蓝色边缘闪烁可处决）→ 倒地击倒（躺倒无蓝闪）→ 睡眠（床上+Z）。高度变化用曲线（0.2 秒蹲下/起立）。

### C. 受击 / 反馈（图标的"被打了"反应）

- **受击**：目标**红色闪烁（短暂变色，复用红=伤害语义）** + **向后位移一小段** + 可能撞上物理遮挡。位移/闪烁是曲线（变色+位移）。
- **命中 / 未命中**：命中的那一拍**短促刺痛**（缩小再回弹 = squash & stretch）；未命中 = 无受击反馈（只消耗弹药）。
- **击退**：受击后退的方向性位移 + 落地小挤压。
- **装备脱落**：目标手上物品**掉出并落地弹一下**（物品的位移+旋转曲线）。
- **防具破损**：盾牌/防甲在破裂瞬间**龟裂感变色 + 碎裂粒子**（见粒子）。
- **招架成功**：招架者**盾/刃挡下**，用"挡下的一顿 / 一道微光"曲线动画表达；招架静默（远程/不可招架）则**零动画**。
- **举盾格挡 / 取消格挡**：身体前倾 + 盾图标旋转到一个挡姿/归位；格挡受击后自动取消=盾归位。
- **失衡**：准备动作（招架/瞄准/举盾）被破除 → 图标**闪烁熄灭**（它们"垮下来"），状态栏对应图标变灰/消失。
- **盾牌破损两阶段**（人防盾 2 耐久）：一次受击→[磨损]、二次→[破损]，表现为盾面一道裂痕→碎开（见粒子），每阶段配龟裂变色。

### D. 攻击动作（近战/远程的核心演出）

**近战三动画模型**（`01` 已定）：
```
跨步（前冲）到单位面前
  → 身体向前倾（倾角曲线）
  → 近战武器由竖直转向倒下（旋转曲线）
  → 向前戳一段距离（平移曲线）
  → 缩回同时：武器角度复位（旋转回）+ 角色倾角复位（倾角回）
```
整段**零帧、零素材**，纯曲线（前倾 + 武器倒下 + 前戳 + 复位）。所有数据来自图标的变换，这是曲线动画的教科书。第三段"恢复对峙"见第 Ⅴ 大节 Z 项（向心收敛原语）。

**近战配方语料**（每把近战武器/每个动作给一条"怎么动"的曲线配方）：
- **配方 A · 挥砍**：短弧线挥动 + 轻微前冲 + 目标红色受击反馈 + 命中点短促粒子（见粒子）。
- **配方 B · 突刺**：直线压缩/伸展（前刺时武器+身体一起前伸，缩回时复位）+ 命中点短促粒子。
- **配方 C · 横扫**：较宽弧线挥扫，可用于散射式视觉（一记横扫扫一片）。
- 每种配方可配不同倾角/前冲速度/复位速度，做出快攻/重击/横扫的差异。
- **重型近战**（电锯/消防斧/电击棒）：蓄力感更重（前摇拉长 + 前冲更猛 + 落地 squash 更大）；电锯可配持续震动的锯齿抖动曲线；电击棒命中叠一段蓝色/黄色电光粒子。

**伸长（Reach）攻击**：轻/中型近战可隔过渡场景攻击另一侧——表现就是**跨窗/跨门挥击**，武器伸长越过门口那条线刺向内侧目标。

**远程非枪械（飞刀/弓弩）**：**投掷物位移曲线**（掷出 → 弧线飞行 → 命中），被投出的物件做抛体运动（位移+旋转）。命中再叠加目标的受击反馈。
**远程枪械（射击）**：**身体后坐（小幅后仰）+ 枪口火光粒子** + 命中目标受击反馈；未命中无目标反馈。枪械后坐是曲线（后仰复位）。
- **手枪**：短促一次后坐。
- **步枪**：后坐更明显、持续抖动、连续火焰，命中次数完全取自规则事件（`02` §四.2）。
- **散射（霰弹枪）**：枪口**大面积扇形粒子/冲击**（见粒子），命中会对目标微型场景所有单位给受击反馈。
- **扫射（机枪）**：**持续小幅后坐抖动 + 连续命中目标**（快速多次受击闪烁）。
- **架枪 / 屏息 / 快拔**：武器**进入一个持姿**（架枪=有依托的稳定持姿，快拔=从背包到手上的切换动画）。
- **突击推进（冲锋枪）**：打一枪后**急冲（跨步）换位**到下一步。
- **处决 / 令其长眠**：全屏仪式（见全屏动画），命中为蓝色"导流"光效 + 清醒条回填的粒子。

**六类枪械战术能力**（D-071，各自一个"持姿/切换"曲线配方，见第 Ⅳ 大节配方库 M 组）。

**格斗模块（过肩摔 / 夺取武器 / 重拳 / 挣脱）**——每招都是对方身体的一段位移 + 朝向变化：
- 重拳：一拳前冲 + 目标后仰 + 目标位移。
- 过肩摔：抓取 → 身体旋转借力 → 目标翻转过肩平摔落地（目标整段是位移+旋转曲线的"被摔"）。
- 夺取武器：目标手上武器"被抽走"（物品位移+旋转），随后在手间切换。
- 挣脱：解除接触 + 双方后退一步拉开距离。

**弱点系统反馈**（L3/01 §4）：
- 弱点图标**常驻飘在角色头顶**（悬停显示克制关系）；命中克制伤害类型时触发弱点效果。
- **弱点效果**：装备脱落（见上方）/ 对方体力 +1（蓝块+1）/ 被命中方行动轮 -1（轮次栏条目下移）。弱点效果**不可被招架/格挡阻挡**——盾牌挡住伤害数值但随后失衡闪烁。
- 10 伤害类型 × 10 弱点类型：不同命中粒子/受击反馈（见粒子，火焰=火、冰冻=霜、电流=电光、毒素=绿雾、凋零=灰粒、侵蚀=白粒、精神=波纹等）。

**招架 / 失衡**（L3/01 §5-7）：
- 招架触发（仅被近战攻击拦截时）：全屏擒拿/招架演出（见全屏）；被远程/不可招架命中则**静默失效**，零动画零提示（真隐藏）。
- 失衡：被招架/弱点命中 → 破除举盾/招架/瞄准等准备动作 → 对应图标闪灭/变灰，持续到回合结束。

### E. 拾取 / 使用 / 物品

- **拾取**：物品**飞向背包 / 手部**（位移 + 缩小，0.2 秒），落地前即收。
- **丢弃**：物品从手上**脱离并落向地面**（位移+旋转+落地弹一下）。
- **使用消耗品**：物品**缩小/消融**（被"用掉"，scale 缩小到消失）+ 玩家身上一个正向变色/柔和光。
- **换弹（通用曲线，适配一切枪械）**：枪口**向下低约 30°** → **像换弹一样抖两下** → **回正复位**。定这条通用曲线，是因为**它不挑枪型**（手枪/步枪/机枪/狙击都能用同一个曲线表达"换弹"）。可叠一个闪烁的换弹图标提示（图标只是附属，不影响这是曲线动画）。
- **插槽填充**：物品移入插槽位 + 新槽位**高亮确认**（scale 弹一下）。
- **折叠/展开（自行车/床）**：物品↔实体的显式转换 = **平铺图→立起/展开**的缩放+旋转变形曲线。
- **掉落**：物品从实体身上**掉出落地**（同丢弃的下落曲线）。
- **开箱/储物柜**：箱盖旋转开合 + 内容物小图标弹出；上锁则先走撬锁/破锁/开锁（见下）。
- **搜尸（死亡背包）**：尸体旁弹出全息清单（0 AP 查看），清单表像"半透明的行李"。
- **撬锁 / 破锁 / 开锁**：
  - 撬锁 = 锁图标**摆动的撬动动画** + 橙色进度条缓慢推进（2 个 1AP：开始→[撬锁中]→完成）；完成瞬间锁图标变绿+短促闪烁。
  - 破锁 = 捶打震动 + 锁与门一起碎裂（近战破坏，见粒子碎屑）。
  - 开锁（钥匙）= 钥匙插入转动的旋转曲线，锁扣弹开。
  - 被打断/受击/主动取消：进度不保留，撬动动画中断复位。

### F. 状态 / 资源反馈（→ 归 UI 层，见下方边界）

> **本节不是曲线动画**。生命/清醒/AP 柱状、状态图标、强力骰、回合流程等**状态/资源反馈归 UI 层**（状态栏与行动轮并在一起，是轮次栏/状态栏组件，不是画布上的实体图标曲线变换）。F/H 这类"回合流程/状态反馈"一律交回 UI 层，此处不再展开。以下保留的是个别**确实作用于实体图标**的状态姿态（非 UI 条）：

- **倒地（濒死/击倒）**：身体**旋转躺倒**（0.4 秒），蓝色处决闪烁（濒死）vs 无闪（击倒）。颜色闪烁是变色曲线，零血倒地本地玩家屏幕边缘轻微压暗（不遮挡关键动作）。
- **站起 / 被拉起来**：身体躺姿角度 → 站立角度的曲线过渡。
- **隐蔽 / 察觉**：隐蔽=角色**变淡 / 移到阴影**（透明度+变暗）；被察觉时**恢复正常 / 高亮**。

### G. 门户 / 空间过渡

- **移动**：沿贝塞尔行动线**跳跃式位移**（A 的跳跃曲线，沿着路径）。
- **楼梯 / 爬楼**：沿楼梯路径**逐级上/下**（位移走楼梯轨迹；竖向叠层时屏幕坐标对齐的位移）。
- **爬梯**：垂直**上下位移**（梯子上攀爬轨迹）。

- **翻窗 / 跳窗**：全屏仪式（见全屏），含碎玻璃粒子与跨越。
- **坠落伤害**：角色**下坠位移曲线**（起跳到落地）。

- **过渡场景被挡**：任一侧被活体/blocking 占用 → 整过渡不可通行，门户图标变灰白/红色禁止；悬停门户显示成本徽章（橙AP/绿Free/红伤/紫网关/橙进度）。
- **门锁网关**：条件网关（持钥匙）时钥匙/锁图标高亮提示；缺条件则灰白不可点。

## 二、帧动画使用场景穷举（克制，只留姿态/细节）

> 帧动画**尽量克制**：绝大多数动作能用曲线动画（变换）表达，帧动画只在**确需角色身体/姿势的精细细节**、且玩家能看清的时候才用。逐条给出"为什么要用帧、而不是曲线"。**核心判据**（见 `03` 原判据 + 前端动态图形化）：**当一个动作需要"玩家的眼睛读懂角色正在做的形态"（弯腰、蜷缩、跨步、趴、躺），且曲线变换不足以表达这个"形态"时才用帧**。纯"动一下、变个向、位移、缩放"一律曲线。

### 确需精细姿态的帧

- **受击帧**：角色被打时**身体的疼痛姿态**（不是简单后仰，而是一个"被打得弓起来的"姿态帧）。曲线只能做后仰/位移，做不出"蜷一下"的表情级细节，才需要受击帧。
- **近战攻击决定性一击帧**：若某把武器/某招需要一个"帅气的致命姿态"作为高潮（不是每个近战都用，只在关键挥击），用帧。
- **攻击前摇/后摇的特写**：确认/payoff 抓拍类动作要看清肩/臂/刃的转动（如狙击架枪、处决前深呼吸），用帧。
- **架枪/屏息持姿特写**：狙击屏息、步枪架枪需要一个"稳定持姿"的前摇特写帧（`03` 已提，此处单列，因为它是六类持姿里唯一"要看清姿态"的）。
- **翻窗/跳窗的身形**（全屏内部的骨骼/帧，见全屏）：跨越窗台时角色的身体跨越姿态，需要帧或骨骼。
- **睡眠姿态**：配合床匹配机，床上的躺卧姿态（`01` §4 睡眠地位，简化帧）。
- **化床/其他精细状态**：如入梦的躺/坐过渡，需要帧补足。
- **姿势类弱点姿态**（如爬行时"趴着挪"、翻越时"跨腿"）：需要帧表达"形态"。

### 曲线不够、需补帧的场景

- **起床动作生硬时**：起床若（曲线）测试生硬（凭空翻起很假），**加帧动画**补足"人从床上撑起、坐起、下床"的过渡。**先用曲线，测出生硬再补帧**（见全屏/出生演出）。
- **受击后退撞墙的"撞"细节**：后退撞上物理遮挡的"撞击"瞬间，用一帧"撞停"姿态 + 粒子。
- **倒地爬行的挪动**：倒地的爬行动作（蹒跚挪动的身体姿态），曲线做不出"趴着挪"，补帧（或程序拖拽 + 拖痕粒子，见 `02` §六"少量循环帧或程序化拖拽"）。

## 三、全屏动画使用场景穷举（仪式感，难得）

> 全屏动画 = 全屏闪过特效 + 特效框内部图片/视频/骨骼。它是**高成本、高冲击**的手段，滥用会让玩家疲劳。**D-026/D-032 已定为 4 项**，另加出生/入睡/传送等世界级演出。

### D-026 / D-032 定案的四项（仅四项，0.5–1 秒）

| 全屏动作 | 触发 | 表现 |
|---|---|---|
| **翻窗** | 攀爬翻窗（2 AP，低→高） | 全屏跨越演出 + 碎玻璃粒子 |
| **跳窗** | 下跳（0 AP，高→低） | 全屏下坠演出 + 落点伤害后果 |
| **令其长眠** | 对零血倒地目标处决 | 蓝色"导流/插头"仪式，唤醒条回填 |
| **招架触发** | 仅被近战攻击 | 珊瑚主色 + 紫约束边缘的擒拿/招架演出 |

> **招架静默**：被远程/不可招架伤害命中时**零动画、零提示**（招架是隐藏信息，见 `01` —— 不能用全屏动画向对手泄露）。

**四项的声明式驱动**：用 `CeremonialTimeline`（track: ceremonial/overlay, blockingUntil: complete/skipKeyPressed, frames[]）驱动，可跳过（`01` §动画编排）。例如 `ETERNAL_SLEEP_TIMELINE`：0ms target_collapse → 200ms blue_glow → 400ms stamina_refill。"令其长眠" 默认不允许 UGC 替换核心语义。

### 世界级 / 出生演出（曲曲线转帧的候选）

- **玩家出生（开局）**：
  - 凭空出现一张床和躺在上面的人。**此时他们是纯白的**，然后**慢慢褪色**（曲线：纯白→上色，蒙版/变色）。
  - 人**从床上跳下来**（起身 = 躺姿角度→站姿角度的曲线）。
  - = **两个标准曲线动画拼接**：褪色 + 跳床。若测试后起身生硬，**加帧动画**补足撑起/跨下（见帧动画）。
- **入睡演出（就绪）**：在床侧，只在匹配机就绪床可交互后才播放的**就绪演出**（不提前播）。配合睡眠姿态。
- **纯白显形 / 往返传送**（`03`/`01`）：现实↔梦境用纯白显形做门，约 1 秒，多帧曲线不僵硬，可跳过。床是固定实体不消失。
  - **梦→实**：床必在 → 人形纯白显形(约1秒) → 纯白被推向床（颜色滚动/曲线）→ 人物在床上复原色彩 → 起床演出。
  - **实→梦**：床从平地被翻起/浮现 → 人+床整体纯白 → 复原色彩 → 人物从床跳下进入梦境。
  - **床显形**：实→梦时床从平地被翻起/浮现（曲线+"床翻起"的形态）。
  - 纯白是短暂高冲击过载感（如闪光弹），不做常态底色。
- **影子大厅**（联机匹配完成入梦前）：玩家在驻地"站桩"等待，看到彼此**影子**，不重载场景（可做成淡淡的影子粒子/轮廓淡入）。

### 全屏演出的承载

- **声明式时间轴**：全屏演出用 `CeremonialTimeline`（track: ceremonial/overlay, blockingUntil: complete/skipKeyPressed, 关键帧列表）驱动，可跳过（`01` §动画编排）。
- 全屏演出是 4 帧实例的驱动方式（target_collapse / blue_glow / stamina_refill 等）。
- **队列与合并**：多个演出同时到达按显著性与因果顺序排队或合并，不丢失规则结果（跳过只影响播放不影响结算）。

## 四、粒子动画使用场景穷举（空间弥漫）

> 粒子 = 粒子的发射/运动/消散。用在"空间弥漫、局部爆发、氛围点缀"处。成本低但不铺满——粒子是"调味"，不是主菜。**最小高价值粒子集**已在 `02` §七定案：灰尘（落地）、血液（生命伤害）、枪口火焰（远程）、碎玻璃（翻窗/破窗）、蓝光（令其长眠）。粒子不承载语义结果，关键结果须有图标/文字/音频（`02` §七.2）。

### 局部位爆 / 命中 / 接触（空间的一点突然爆发）

- **命中点短促粒子**：近战命中瞬间、枪击命中点，一小撮光/血/屑粒子爆一下很快消失。血=生命伤害（红）、电=灼伤/电击（黄）、冰=碎晶（白蓝）、毒=绿雾、辐射=绿眩、凋零=灰粒、侵蚀=白粒、精神=波纹等——按伤害类型换色。
- **受击碎片**：防爆盾破碎、玻璃破裂时炸开的**玻璃屑/碎片粒子**（翻窗/跳窗、破盾）。
- **枪口火光**：射击瞬间枪口的火光粒子（一帧火苗 + 烟）。
- **散弹扇形**：霰弹枪的大面积扇形粒子区，扫过一片。
- **装备脱落**：物品掉出时一小撮"掉落的土/光"。
- **燃烧区/毒雾/辐射区**：区域环境粒子（见空间弥漫）。
- **爆炸 / 载具殉爆**：重冲击的爆炸粒子（火球 + 碎片 + 冲击波圈），配重震动（见载具）。

### 空间弥漫 / 轨迹

- **脚下行走粒子**：跳跃落地/狂奔时脚底淡淡的尘土或光粒（强调落地与移动节奏）。
- **爬行拖痕**：倒地爬行时身后一段淡淡的拖痕粒子（or 地面擦痕）。
- **角色移动光迹**：~~高速/瞬移时留下一道淡淡的残影/光迹（若需要强调位移）。~~ **（已剔除，见 §Ⅻ 杀鸡儆猴）**
- **技能/区域效果**：区域环境的粒子（毒雾、燃烧、辐射区、梦境侵蚀的淡白弥漫）。

### 氛围 / 环境

- **梦境侵蚀三态的粒子**：淡白→泛白→纯白，可用弥漫飘的白粒子表达"世界在变白"。
- **进入/离开某状态**：附加正面/负面状态时，角色身上短暂淡入的粒子（绿=正面、红/紫=负面、白=过载）。
- **起床时的粒子**：褪色醒来时一圈淡淡的白/尘粒子（出生演出辅助）。
- **传送粒子**：纯白显形/床显形的白色弥散（辅助全屏/曲线演出）。
- **影子大厅的粒子**：联机等待时对方淡影子 + 淡淡粒子轮廓。

### 粒子与曲线/帧的分工

- **粒子**负责"空间里弥漫、爆一下、飘散"的体积感（它不属于任何单个实体）。
- **曲线**负责"单一图标自己的变换"（挤压、转向、位移）。
- **帧**负责"角色形态的精细姿态"。
- 通常**粒子叠加在曲线之上**（命中时 = 曲线受击后仰 + 粒子爆点一起），两者不是替代而是配。

> **粒子的定位**：粒子是**百搭活计**——它几乎能用在任何效果上叠氛围，但**它无法直接代替动作干事**（粒子自己不会"做"一个攻击/移动/状态，它只是给既有的曲线/帧/全屏动作"加体积感"）。只要**不过度**（不铺满、不替代关键结果）就没意见；关键结果仍需图标/文字/音频承载（`02` §七.2）。

### 成本序修正与全屏认知判据（2026-08-14 定案）

**克制序 = 帧 > 全屏 > 粒子 > 曲线**（帧最贵、最克制；曲线最放开）：

- **帧动画最贵**：它是 UGC 的**持续负担**（每帧都要维护/生产，创作者难以对齐），只能维持**一个小集**；未来有条件才持续补帧，替换比较生硬的曲线动画。**没有注册帧动画的地，就用默认代码曲线动画兜底**。帧=未来可选增强，不是初始必备。
- **全屏动画次贵**：它是**复杂交互的"逃课"手段**——当某个交互逻辑复杂到"画几帧都不知道怎么画、还要跟窗台/几何交互、合理实现太可怕"时，一张全屏富视听质感的演出比逐帧画更省也更直观。

**全屏使用的认知判据（决定"该不该上全屏"）**：

> 人们认知里的全屏动画 = **漫画风的特殊动作 / 特殊演出**；它可以是形象的，也可以是抽象的，但必须**符合一般认知**，像"正常游戏里会有一格漫画特写"的那种对象才用全屏。

**符合全屏认知（可上）**：破窗（正面对角色、破窗而入的单张张力图）、破门（门内视角踹门 / 斧子轰门抽象漫画）、翻窗 / 跳窗、处决/令其长眠、招架触发、出生 / 入睡、传送。
**不符合全屏认知（不上，改用别的手段）**：载具爆炸（物理常态事件，用**通用爆炸贴帧 + 破坏后帧**更省更对味）、普通破坏、换弹（用**闪烁图标 + 音频**即可）、各类常态反馈。

**两个省力杠杆（先用，再谈高成本动画）**：

> 一个动作能否用"一个闪烁图标 / 一个抖动曲线 + 一点音频"就表达清楚？能 → 就不要为它做帧或全屏。

- **抽象化**：换弹 = 一个闪烁的弹匣图标即可，不做换弹动画。
- **音频 + 单对象微反馈**：很多射击游戏"单手换弹"就是把整把枪放腰间**抖一下**（一个曲线抖动）+ 换弹音，不需要帧、不需要全屏。

## Ⅳ、曲线动画配方库（把曲线动画的"做法"穷举成可复用零件）

> 曲线动画是主力，因此值得给它单独建一个**配方库**——所有曲线动画的本质是几种画面变换（挤压/旋转/放大/缩放/位移/变色/蒙版）按不同速度/次序/重复组合。下面这些是穷举出的"原子曲线配方"，任何机制都能从中挑、组合。每条的 `durationMs`/弧度/参数是**灵感级的建议值**，不是定案；正式实现以 `ProceduralMoveSpec` 及表现 Profile 为准。曲线动画全部不碰素材、零帧。

### P 组 · 位移动画（Patrol / 位移）
- **P1 跳跃式位移**（唯一定形）：一提→一落→落地 squash→overshoot→后脚收起。参数：arcHeight 一提高度、distance 一落距离、duration 一提时间。各移动状态换这组参数即得迟缓/标准/跨步/蹒跚/奔跑。重物单独一条（慢沉）。
- **P2 拖拽位移**（爬行）：arc 极低或零 + 拖痕粒子，挪一下停一下（趴着挪）。
- **P3 弹道位移**（投掷物/被摔/被撞）：抛体运动（位移+旋转），多用于被投出/被打出/被摔出。
- **P4 回弹位移**：落地后小 overshoot 弹一下（拾取物落地、装备掉落落地）。
- **P5 推载位移**（推车）：人推 + 车整体顿挫前移。

### S 组 · 缩放/挤压（Squash & Stretch）
- **S1 squash & stretch 刺痛**：击中的一拍缩小再回弹（命中反馈，短）。
- **S2 挤压压扁**：落地/受击瞬间 scale.Y 压一下（落地 squash、重物落地）。
- **S3 阶梯缩放**：高地/洼地一步一阶微放大/缩小（上下台阶的阶感）。
- **S4 变小消融**：物品被用掉/缩小到消失（消耗品、拾取收包）。
- **S5 放大揭示**：骰子点数揭示放大停下的那一跳、槽位填充新物品高亮弹一下。
- **S6 蹲下压缩**：scale.Y 压到 0.6（蹲下）/ 拉回（起立），0.2 秒。
- **S7 平铺→立起**：折叠自行车/床展开时平面图做缩放+旋转的直立变形曲线。

### R 组 · 旋转（Rotation）
- **R1 转身翻面**：单一左右轴旋转/翻面，无回旋。
- **R2 倾角变换**：身体绕脚部枢轴前倾/后仰/复位（进攻压低 / 受击后退）。
- **R3 武器倒伏**：近战武器由竖直转倒下（攻击戳刺）、格斗借力旋转（过肩摔）。
- **R4 滚动旋转**：骰子滚动、门图标旋转开合、撬动摆动、钥匙插入转动、物品旋转抛体。
- **R5 躺倒降距**：身体从站立旋到躺倒角度（0.4 秒倒地）、躺姿→站姿（起身）。

### C 组 · 变色/光照（Color / Glow）
- **C1 受击红闪**：受击瞬间短暂变红再复原（伤害语义）。
- **C2 正向光晕**：回复/正面附加绿色柔和光晕（scale 微放大 + 变色）。
- **C3 蓝闪可处决**：濒死倒地角色蓝色边缘闪烁（可处决状态）；击倒则无此蓝闪。
- **C4 飘顶弱点图标**：头顶常驻弱点图标，悬停显示克制克制关系（低显著）。
- **C5 蒙版颜色渐变换挡**：环境整体颜色的蒙版渐变（梦境侵蚀淡白→泛白→纯白、缩圈）。
- **C6 高亮/凸起**：可点击对象边缘发光凸起、选中高亮、进行中橙色。
- **C7 冷却灰填 / 变灰降饱和**：冷却图标灰色慢填充、已行动轮次栏降饱和。

### M 组 · 状态持姿/动作姿态（Motion，细分为六类枪械战术能力等"持姿"配方）
- **M1 快拔**：背包武器与手部物品瞬间交换（瞬掏换位）。
- **M2 架枪**：进入有依托的稳定持姿。
- **M3 压制射击**：持续小幅后坐抖动 + 连续命中闪烁。
- **M4 散射**：枪口大面积扇形粒子/冲击。
- **M5 屏息**：瞄准态下屏息持姿（前摇特写可帧）、开枪 DC -2。
- **M6 突击推进**：射击后急冲跨步换位。
- **M7 拉弓/蓄力**：远程非枪械瞄准/蓄力（拉弓举刀）、瞄准圈紫色点线悬停。
- **M8 负重姿态**：负重状态走路换沉缓曲线 + 喘息粒子（可选）。

> **F 组（回合/结算反馈）已删除**：投点/骰子、轮次重排、AP/HP/SP 柱状、状态图标、状态附加、强力骰滑块——这些**是 UI/状态栏的事**（状态栏与行动轮并在一起），不属于曲线动画；它们是 **UI 的活**（轮次栏/状态栏组件），不是在画布上对实体图标的曲线变换。因此 F 组不在此文档（曲线配方库）中出现；状态/资源反馈一律交回 UI 层。

> **配方与 `ActionPresentationBinding` 的关系**：这些配方名是灵感级的"做法建议"。正式写 `animationRecipeId` 时从 `02` §五的绑定表 + 降级顺序（指定→同类默认→程序化反馈→图标文字）选。配方之间可叠加（粒子盖在曲线上），可参数化复用（同配方换 duration/弧度表达不同强度）。

## 五、空间场景 / 环境动画

> 除单实体/单动作外，本作还有**地图/场景层面**的动画（扩自空间系统与驻地的呈现）。

- **楼层/垂直空间**：上下层**透明叠层**呈现，跨层动画连续；竖向门户两端可视锚点悬停显示，跨层视线（losBridge）悬停连线。
- **缩圈预告**：提前 1 轮公开缩去哪个天然场景——地图上该场景**边缘红色/白色闪烁预告**，缩圈时一次性收缩动画 + 环境换挡。

## 六、驻地 / 局外（meta）动画

> 驻地 = 出租屋现实地图主界面，各实体担不同入口职责（床A蓝/床B珊瑚/床C青、匹配机、研究台、电脑、书架、保险箱、门窗）。下面穷举驻地的动画场景。

- **出租屋拓扑导航**：可用实体高亮、可点击边缘发光；少UI模式。
- **匹配 / 入梦流程**：匹配成功 → **影子大厅**（站桩等彼此影子，淡影子/粒子轮廓）→ 入梦（纯白显形→起床，见全屏世界级）。
- **保险箱（收藏室）**：抽屉式平铺、带色类别栏；**打开/翻抽屉瞬间要有"贵重感"**（材质/光/音）；渐进陈列随主线推进增加；拒堆叠、无丢弃。抽别会"沉重地滑开"（曲线+高光）。
- **书架（梦境素材库）**：星标收藏置顶；素材/蓝本可星标；与地图编辑器高频切换——**共用一组"切换备用动画"（只留端口不画线框）**，素材卡片拖入编辑器右侧速拖素材栏（7格→展开70格矩阵，拖素材=切放置素材动作，画图元笔自动放下）。
- **研究台 / 电脑 / 床的职责映射**：研究台=工作台、电脑=地图编辑器、书架=素材库（青）、保险箱=收藏室；床=装载入口（三床分工蓝/珊瑚/青）。切换交互时有统一的"入口高亮/淡入"。
- **一人模式/少UI**：无操作自动流逝空回合、自动推进；隐藏轮次栏/HP/SP/AP/战斗面板，只留节点移动局部交互文本。`PresentationProfile.pacingPresentations='minimal-ui'`。
- **素材 (material) / 学习(洞察) / 塑形机制**：梦境素材="从别人潜意识固化的记忆碎片"——**素材卡片从无到有浮现/录入**；学习元素=记忆刻录（需持续注视），眼睛注视时素材边框"从清晰到铭刻"的高亮/刻痕小动画；洞察点数消耗时素材微光消散一点。注：塑形/编辑工具侧的"样条塑形/Catmull-Rom、fire-and-forget 点击线追加"归创作系统（须在梦内维持清醒度的检定），此处只提其素材收集中与动画相关的一瞬。

## 七、创作 / UGC 系统动画

> UGC 侧动画主要落在**编辑器、验证、编译、装载、审核、分享**的界面反馈，以及对局内"UGC 生效"的呈现。玩法的表现侧约束见 `02` §十二（UGC 动画与音效指南：创作者只需静态图标+从已发布配方选绑定+替代文本；高级定制才有自定义帧/音效/粒子/Profile）。

- **形象编辑工具**：像素编辑器（32×32 武器 / 64×64 载具），画笔/橡皮/填充的网格高亮反馈；左侧绘制、右侧三入口（自行绘制/样板库/上传）切换动画。
- **地图编辑器诊断呈现**：诊断列表按 severity 分组；点击诊断**摄像机飞到问题元素**，元素红/黄边缘闪烁高亮；右侧显示 correction。"摄像机飞行+"红黄闪烁"是这个系统的核心动画。
- **编辑器图元颜色复用霓虹边语义**：白=可交互、黄=选中、红=错误、蓝=合法落点。
- **玩法包装载拖拽**（D-073）：直观的先后顺序列表表达装载顺序/覆盖优先级（无名重装载：后装覆盖先装、剔除=重装载、剩 ID 退役）——拖拽某包上下改变优先级，**全程不报错**地重排。
- **静态验证流水线**：验证进度动画、错误逐条红色诊断出现、构造通过时绿色通过勾；验证进度条。
- **编译 / 复杂度评分**：compile 完成（tier: standard/advanced）→ 复杂度评分条（profile×10+map×50+rule×100）+ 支付界面分档。
- **分享/审核/分发**（双轨生态）：上传进度、审核状态角标（青）、内容包哈希/增量下载、装载动画。
- **LLM 创作风控**：关键词计分/注入检测 → 风控弹窗分数提示、草稿保留提示（弹窗强调"这不是封号，是提示"）。
- **UGC 角标（青）+ 高级角标**：仅自建房/单机上下文出现。
- **对局内 UGC 生效**：一台新玩法包在自建房/单机里运行时，其独特素材/音效/表现 Profile 直接替换默认（用法相同、观感不同）——UGC 只改变感知方式，不改变命中/伤害/AP/目标/状态（`02` §十二.4）。

## 八、感知 / 警戒 动画（声音传播 + 视野 + AI 状态机）

> 本作的隐蔽与感知是一套"声音传播等级 + 视野 + AI 状态机"机制（空间系统 03、AI 系统 07）。它们的动画是**给玩家看的氛围/信息**，同时也是 NPC 被触发的"信号"。

- **声波传播**：声音产生（开枪、爆炸、叫喊、尖叫鸡、重低音音响）→ 场景类型阻尼（大0.3/中0.5/小0.7/过渡0.4）递归衰减 → **声波圈扩散 + 逐级衰减的淡圈**，到达听阈则高亮"谁听见了"。
- **尖叫声源物品**：尖叫鸡、重低音音响=**制造声音引诱**——音源本体高亮抖动"在叫"（曲线抖动），声波圈扩散（见上）。
- **NPC 视野**：`canSee`（视力≥2 且同微型场景）→ **视野锥/侧向遮挡**（别家不可见时角色头部视角锥可视化或仅暗示）。
- **NPC 巡逻**：守卫范式状态机（睡眠→巡逻→寻声→追逐→攻击）→ **头顶状态气泡**切换（Zzz=睡眠、👁=巡逻、❓=寻声、❗=追逐、⚔=攻击）、路径移动、追逐冲刺动画。
- **追逐 / 锁定**：NPC 追逐锁定后忽略其他声音——锁定时 NPC 头顶**锁定标记**、只朝目标移动（追踪速度明显快于巡逻）。
- **僵尸追逐**：`chaseNearestLiving` 朝最近玩家移动，A*/Dijkstra 路径；死亡不掉落（纯消失淡出）。
- **隐蔽 vs 被找到**：进入隐蔽=角色变淡/移阴影 + 热区高亮；被"找到"=恢复正常/高亮；主动行为（攻击、造大声）解除隐蔽。

## 九、载具 / 车辆动画专项

> 载具是本作的重头视觉对象。这里把载具从上车到损毁的完整生命周期动画穷举一遍。

- **上车 / 下车 / 换座**：车辆图标高亮 + 角色**淡入淡出到车内**（0.2 秒）；换座=车内头像移动。
- **驾驶移动**：车辆沿路径跳跃式位移（P1 重装版：弧高大、落地重）+ 轮下扬尘。
- **撞击**：瞄准起手（1 AP）→ 车头对准的**蓄力/前冲** → 撞击目标**后仰+位移**（汽车固定 3 伤+自损 1；电瓶车 2 伤）+ 车头撞击粒子。
- **车上近战**（电瓶车独有）：车旁挥击。
- **爆胎**：最多 4 轮胎、免疫 2 点以下伤害、每爆一胎 HP 上限 -1 —— 轮胎爆裂时**巨响 + 胎瘪 + 车身歪斜**（曲线）+ 爆胎粒子；近战破胎须蹲下（S6 蹲下）+ 震击动画。
- **载具损毁两阶段**：生命归零→[损毁·燃烧]（起火火焰粒子 + 警告）→ 下回合爆炸（对天然场景全员 3 伤、乘员移出、货舱掉落、实体转不可驾残骸）——**殉爆=重冲击**（爆炸粒子 + 冲击波圈 + 重震动 + 火焰残骸持续冒烟）。
- **半掩体**：载具为车内乘员提供半掩体——车内减伤提示高亮；车毁掩体消失。
- **锁门 / 解锁**：车门落锁动画（锁扣弹起/收回）；外部可撬锁/破锁/钥匙（同物品撬锁举）。
- **推车**（电瓶车）：P5 推载位移。
- **货舱 / 后备箱**：车内直接访问 / 车旁 1 AP 打开后备箱——**后备箱盖升起** + 内容物弹出/放入。
- **折叠自行车**：S7 平铺→立起（展开）/ 收起折叠；骑行时角色坐姿 + 车轮转动。
- **车辆可动性随驾驶状态**：有人驾驶=可动实体（参与 ORCA 受扰动）；无人=不可动实体（仅作硬边界，行动轮结束静默归位）——表现上是车辆"活/死"的微视觉差（可动=引擎怠速微动，不可动=静止）。

## 十、UGC / 素材 / 塑形（世界观级演出补充）

> 梦境/现实/素材的世界观表达，动画是核心载体。放一处讲透"哪些机制要有世界观级演出"。

## Ⅻ、从灵感库到前端的落地建议（什么时候开始挑）

> 本索是"越攒越厚的工具箱"，不是要一次铺完的清单。前端落地时建议：

1. **先定必做**（保证玩法可读）：移动跳跃曲线、受击反馈、投点、状态图标、AP/HP/SP 柱状图、拾取/丢弃、近战三动画、远程后坐、倒地/站起。这些是玩法不覆盖就"看不懂发生了什么"的最小集。
2. **再挑高辨识度**（让游戏灵动）：出生演出、梦境侵蚀三态、过载纯白、令其长眠全屏、翻窗破窗全屏、声波圈、弱点头顶图标。这些是"独特而灵动"的招牌。
3. **最后补齐氛围**（锦上添花）：粒子弥漫、保险箱贵重感、影子大厅等。
4. **做减法看交叉编目表**：砍"值得全屏=否"里成本最高的；优先保留"能让玩家一眼看懂机制后果"的那一拍。**帧一律默认曲线兜底，全屏严格走全屏认知判据。**

> **明确剔除（已判为不采用，杀鸡儆猴）**：粒子铺满、素材"刻录/眼珠注视"动画、残影光迹（常态移动花哨）、给载具爆炸上全屏动画。这些投入成本高、对可读性无贡献、且"膈应/诡异"——要么降为区间最小粒子集（`02` §七），要么用通用贴帧 + 曲线表达。
4. **做减法看交叉编目表**：砍"值得全屏≤ 否"里成本最高的；优先保留"能让玩家一眼看懂机制后果"的那一拍。
