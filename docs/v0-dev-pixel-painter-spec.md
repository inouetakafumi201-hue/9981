# 像素绘制器（Pixel Painter）· V0.dev 投喂 Spec

> **用途**：把「像素绘制器」编译成一份 V0.dev 可直接消费的实现底稿。它是**独立、高度解耦的悬浮窗组件**，不归属素材库或研究台任何一个界面——两个界面都只负责「打开它并接收结果」。
> **接线前置**：组件是纯前端工具；保存时把修改后的贴图**交给动作通道**（`src/meta-state/`），组件自身不持有素材数据、不写库。底图（`initialTexture`）由调用方传入，组件只画、不取、不洗。
> **版本**：v1（2026-08-19 定案，D-085）

---

## 一、项目定位

### 这是什么

一个**像素点阵绘制器悬浮窗**，让玩家修改素材的贴图——v1 用途是给**合成素材**改贴图（素材库选中合成物 → 调出绘制器）；组件本身与调用方解耦，未来形象编辑器、新建组件入口都可复用。

### 不是什么

- ❌ 不是 PhotoShop（无图层、无选区、无滤镜、无文字）
- ❌ 不是素材清洗器（不抠边、不降噪、不增强——收到什么画什么）
- ❌ 不是素材库/研究台的内部件（独立组件，任何界面可挂）
- ❌ 不是多素材批量工具（一次只编辑一个素材）

### 核心设计理念

1. **解耦**：组件只认 `open / materialId / initialTexture / onClose / onSave` 五个输入。谁调用、调用几次、从哪个界面调，组件一概不关心。
2. **轻量手感**：128×128 点阵 + 缩放滑条 + 常用色/可调色取色板 + 画笔/橡皮/取色器/撤销重做，一次打开就能画，没有学习成本。
3. **在底图上画**：`initialTexture` 有效 → 铺底后在其上叠加绘制；`null` → 空画布。**组件不判断底图质量**——判定由数据层做，组件只执行。
4. **V0 兼容**：V0 生成的像素组件贴图未切硬边（边缘软、半透明过渡）。所以默认**空画布启动**没问题；载入接口保留，接线时由数据层决定传不传底图。

### 参考风格

- 与素材库/研究台一致的「像素前景 + 全息投影背景」：悬浮窗 = 半透明暖光全息浮层（边缘泛光、微微闪烁），不是暗黑科技终端。
- 画布本身 = 标准像素编辑器观感（棋盘格透明底 + 硬边像素点阵）。

## 二、视觉风格与色彩规范

### 2.1 画风基线

- 悬浮窗面板 = 半透明暗调（暖黑）全息浮层，边缘泛光（青或暖金描边），轻微浮起阴影。
- 画布 = 像素点阵，**硬边渲染**：缩放后依然像素分明、绝不模糊（`image-rendering: pixelated`）。
- 透明像素 = 低对比棋盘格（conic-gradient 或双色小方块，灰/深灰）。
- 工具栏/取色板 = 与主界面同质感的小图标 + 色块，不发明新交互形态。

## 四、逐区功能需求

### 4.1 顶栏

- 标题「像素绘制」+ 当前素材名称（小字灰白）。
- 右上关闭 X（等同 Esc / 底部「关闭」）。

### 4.2 工具栏（左侧竖排）

- **画笔**（默认选中）：点击/拖动在画布上落像素，用当前色。笔刷大小固定 1×1（轻量，v1 不设笔刷尺寸切换）。
- **橡皮**：点击/拖动把像素擦为**透明**（露出棋盘格或底图）。
- **取色器**：点击画布某像素 → 取该像素颜色为当前色（画笔自动切回）。
- **撤销 / 重做**：图标按钮，快捷键 Ctrl+Z / Ctrl+Y（macOS ⌘Z / ⌘⇧Z）。
- 选中工具 = 青描边高亮；其余扁平灰。

### 4.3 画布

- **规格**：128×128 像素点阵，每个像素一格。**不可改尺寸**（无新建尺寸选项）。
- **缩放滑条**（画布正下方横条）：范围 **2x–16x**，默认 **8x**；左右拖动实时缩放画布显示；右侧显示当前倍率数字。滑条两端 − / + 小按钮，步进 1x。
- **网格线**：缩放 ≥4x 时显示 1px 浅灰网格线；<4x 不显示（防噪点）。
- **视口滚动**：画布放大超出视口时可滚动（横向/纵向拖滚动条或空白拖拽平移）。
- **硬边渲染**：缩放后像素边缘锐利（`image-rendering: pixelated`），禁止模糊插值。

### 4.4 取色板

- **两排固定常用色**：语义色 12 格 + 中间色 8 格（色值见 §2.2），点击即设为当前色。
- **当前色**：一个色块 + 十六进制码（如 `#FF8800`），只读展示。
- **自定义格**：8 格。点击「添加到常用」把当前色存入自定义格（满 8 格后替换最旧一格，同色不重复入格）。自定义格可点击取用、可右键移除。
- **调色面板**：色相条 + 饱和度滑条 + 明度滑条（或一个色相环 + 两个滑条，择审美更优者）；调出的颜色即时成为当前色并预览。

### 4.5 底图载入（V0 兼容关键）

- `initialTexture` 传入有效 dataURL → 载入为画布起始状态（按 128×128 铺满，超界裁剪、缺像素透明）；画笔在其上叠加，橡皮擦出透明露出底图或棋盘格。
- `initialTexture` 为 `null` / 缺省 / 无效 → **空画布**（全透明）启动。
- **禁止**：组件不得自动清洗、裁剪、抠边、放大增强底图；不得把底图模糊化或套滤镜。数据层判定底图质量，组件只做「有就铺、没有就空」。

### 4.6 保存与关闭

- 底部动作排：左「关闭」灰白次按钮，右「保存」青主按钮。
- **保存** → 输出 `{ materialId, texture }`（`texture = { width: 128, height: 128, dataUrl }`）→ 交给调用方注入的 `onSave` → 关闭悬浮窗。
- **关闭**：无未保存修改 → 直接关；有修改 → 轻确认「丢弃未保存的修改？」（小确认浮层，确认才关）。
- Esc 等同关闭；Ctrl+Z / Ctrl+Y 撤销重做。

## 六、核心交互逻辑

### 6.1 交互伪代码

```typescript
// 打开：调用方传入 materialId + initialTexture
<PixelPainterOverlay
  open={painterOpen}
  materialId={targetId}
  initialTexture={textureOrNull}
  onClose={() => { painterOpen = false; }}
  onSave={({ materialId, texture }) => {
    actions.materialSetTexture(materialId, texture);  // 动作通道，非合成物会拒绝
    painterOpen = false;
  }}
/>

// 画笔：mousedown 落笔，mousemove 连续画，mouseup 收笔入撤销栈
function onCanvasPaint(x, y, color) {
  canvas.putPixel(x, y, color);      // 像素级写入
  dirty = true;
}

// 缩放：滑条值 → 画布显示倍率（2–16x，硬边渲染）
function onZoom(z) {
  zoom = clamp(z, 2, 16);
  canvas.style.width = 128 * zoom + 'px';   // image-rendering: pixelated
}

// 撤销：historyStack.pop() → 重绘整幅
// 取色器：读取该像素 RGBA → currentColor（含 alpha 转 hex）

// 保存输出
const texture = { width: 128, height: 128, dataUrl: canvas.toDataURL('image/png') };
onSave({ materialId, texture });
```

## 七、数据结构（接线清单）

### 7.1 组件 props 契约（硬性接口，不可改）

```typescript
export interface TextureData {
  width: 128;
  height: 128;
  dataUrl: string;                 // PNG dataURL（RGBA，透明保留）
}

export interface PixelPainterOverlayProps {
  open: boolean;                    // 显隐
  materialId: string;               // 目标素材 id
  initialTexture?: TextureData | null;  // 底图；null/缺省 = 空画布
  onClose: () => void;              // 关闭（丢弃未保存修改）
  onSave: (result: { materialId: string; texture: TextureData }) => void;
}
```

### 7.2 真实端口映射（接线时替换）

| 调用方数据 | 真实端口 | 类型 | 方向 |
|---|---|---|---|
| 素材库/研究台打开绘制器 | 本界面本地状态 `painterOpen + targetId` | 本地状态 | — |
| 底图 | `projection.materialTexture(id)` | `TextureData \| null` | 只读 |
| 保存写贴图 | `actions.materialSetTexture(materialId, texture)` | 动作通道 | 写（非合成物拒绝） |
| 研究台「绘制贴图」跳转 | 三界面切换路由 `switchToLibrary(materialId, { painter: true })` | 注入回调 | 动作 |

## 九、风险与兜底

### 9.1 已知冲突

- **冲突 1**：V0 可能把绘制器做成素材库内部组件（耦合），或把「保存」直接写库。
  - 处置：组件只认 props + onSave，写库一律走动作通道（§7.2）；素材库/研究台只负责打开与接收。
- **冲突 2**：V0 可能自动清洗/抠边底图，或给画布加滤镜/模糊。
  - 处置：明确禁止（§4.5）；底图质量判定在数据层，组件收到 null 就画空布。
- **冲突 3**：V0 可能扩出图层/选区/魔棒/文字/旋转镜像等高级功能。
  - 处置：明确不做（§十），v1 只做画笔/橡皮/取色器/撤销重做。
- **冲突 4**：V0 可能把缩放做成「改画布真实分辨率」而非显示倍率。
  - 处置：画布固定 128×128，缩放只改变显示大小（CSS 缩放 + pixelated）。

### 9.2 技术债登记

- **债务 1**：底图质量判定（是否铺底）在元状态层数据侧实现；V0 阶段一律传 `null`（空画布）。
- **债务 2**：自定义色格未做云同步（仅 localStorage），未来若跨端再议。
- **债务 3**：笔刷固定 1×1；未来笔刷尺寸/对称绘制/网格对齐为增强项。

## 十一、技术建议与示例素材

### 11.1 技术建议

- **画布**：单个 `<canvas>`（128×128 内部分辨率），绘制用 `putImageData` 或像素级 `fillRect(1px)`；显示层用 CSS 缩放 + `image-rendering: pixelated`。
- **透明棋盘格**：CSS `conic-gradient` 双色小方块背景（低对比灰）。
- **撤销栈**：快照栈（整幅 128×128 ImageData 快照，上限 50 步），入栈时机 = 每次「笔触结束」（mouseup）。
- **取色板**：色相条用渐变 canvas 或 CSS gradient + 拖拽；饱和/明度两滑条即可，无需复杂色域模型。
- **Radix**：Dialog（悬浮窗）、Tooltip、Slider（缩放滑条）、Popover（调色面板）。
- **Zustand**：组件内 store（工具/颜色/缩放/历史/脏标记），不挂全局。

### 11.2 示例场景

- 素材库：选中合成素材（如「烈焰散射手枪」）→ 详情浮层点「绘制贴图」→ 悬浮窗打开（空画布）→ 玩家把枪身涂成金色 → 保存 → 素材库卡片图标更新为新贴图。
- 研究台：合成完成 → 成品面板点「绘制贴图」→ 自动收下并切到素材库、选中该成品 → 悬浮窗打开 → 修改 → 保存。
