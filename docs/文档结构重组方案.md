## 重组执行顺序

### Step 1：创建目录结构
```
新建 docs/L1_引擎层/
新建 docs/L2_基类层/
新建 docs/L3_玩法层/
新建 docs/L_参考/
移动 docs/_归档/* → docs/L_归档/
```

### Step 2：合并同名文档（v1 + v2 → 合并版）

| 原文件 | 合并为 |
|--------|--------|
| 02_游戏机制.md + 02_游戏机制系统_v2.md | L2_基类层/02_游戏机制.md |
| 03_空间系统设计.md | L2_基类层/03_空间系统.md |
| 04_物品与装备系统.md + 04_物品与装备系统_v2.md | L2_基类层/04_物品装备.md |
| 06_UGC系统设计.md | L2_基类层/06_UGC系统.md |
| 07_AI系统设计.md + 07_AI系统设计_v2.md | L2_基类层/07_AI系统.md |
| 05_底层引擎架构.md + 05_底层引擎架构_v2.md | L1_引擎层/底层引擎架构.md |

**合并规则**：
- v2 覆盖 v1 的相同章节
- v1 独有的章节保留
- 决策记录（如有）并入对应章节的注释

### Step 3：新建缺失文档

| 新文档 | 来源 |
|--------|------|
| L1_引擎层/底层引擎架构.md | 合并 05_v1 + 05_v2 |
| L3_玩法层/01_大逃杀规则.md | 从 02_游戏机制.md 拆出大逃杀相关章节 |
| L2_基类层/基类判定标准.md | 从 L0_规范宪法.md 拆出 |

### Step 4：重写入口

- 重写 `docs/README.md` 为新结构的导航文档

### Step 5：归档旧版本

- 将所有 `_v1`、`_v2` 文件移入 `docs/L_归档/`
- 将 `文档概览.md`、`根基审查总结报告.md`、`访谈决策记录.md` 移入 `docs/L_归档/`
