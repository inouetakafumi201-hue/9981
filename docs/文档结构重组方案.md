## 二、执行的关键决策

### 2.1 三层与正交域分离（D-067）

| 决策 | 内容 |
|------|------|
| **D-067** | 三层仅表示对局规则运行链；表现/创作/运营/工程/叙事是正交域，不是 L4 |
| **D-068** | 玩法层只允许玩法包、基类实例组合、1-5 数值、地图数据、稳定叙事 ID |
| **D-069** | 随机选择器是引擎无语义端口；性格和难度是玩法包包装 |
| **D-070** | 世界观独立放叙事设定，玩法包只引用稳定叙事 ID |

## 五、后续维护规则

### 新文档归属判定

对任意新章节依次提问：

1. 它是否定义无游戏语义的运行原语？ → 引擎层
2. 它是否满足可枚举、可组合、不含具体玩法语义？ → 基类层
3. 它是否直接构成一局可装载玩法的规则或数据？ → 玩法层
4. 它是否决定玩家如何感知或输入？ → 表现系统
5. 它是否决定内容如何被制作、校验、发布？ → 创作系统
6. 它是否决定会话外装载、匹配、长期推进？ → 运营系统
7. 它是否约束开发、测试或技术选型？ → 工程治理
8. 它是否是世界观或叙事权威正文？ → 叙事设定

### 禁止行为

- ❌ 把正交域命名为 L4 或"第四层"
- ❌ 在玩法层放入表现、创作、运营、工程或叙事正文
- ❌ 跨域依赖活跃内部形状，必须指向稳定端口
- ❌ 用适配器掩盖职责重复，必须先做所有权裁决
