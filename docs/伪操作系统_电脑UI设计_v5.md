# 伪操作系统：电脑UI 设计（终极定案稿 v5）

> **定位**：玩家在出租屋与世界叙事互动的「梦核多应用台」——**SECDED 终端是不可知的黑市，塑形栏是坚硬的塔兵buff，订购单是弹走的雷**。

> **核心定案**（2026-08-20）：
> - **SECDED** = 「终端无法显示具体外观」的黑市
> - **商品效果永远是宣称态** → 直到实例落地，玩家才「懂它到底多离谱」
> - **订购栏容量 4 格** → 不能囤货，只能「叫车+防抢」的高风险操作
> - **折扣基于「留到多少局」+「玩家历史平均」** → 形成「等崩」的期待心理
> - **塑形栏 ≠ 黑市商品**：塑形栏是「长期buff」的圣坛，订购栏是「一次性药水/卡片」的空投容器

## 一、SECDED 终端：不可知的黑市

### 1.1 终端结构层

```
SECDED终端（电脑里的tab）
├── 顶栏：LOGO + 「活跃/离线」指示灯
├── 主视图区：商品池（7×2网格，动态刷新）
│   ├── 物品封面 = 名字 + 模糊光晕图标
│   ├── 效果行：斜体 + ?号 + 浅灰文本（永远斜着）
│   └── 价格栏：金钱 + 折扣标签（「限时折扣」闪烁）
├── 侧栏：订购栏（4格容器）
│   ├── 01：药水 → 1~3回合倒计时 + 被抢概率
│   ├── 02：Buff卡 → 同上
│   ├── 03：终极药 → 闪红灯「极易被抢」标签
│   └── 04：空位 → 灰显「点击召唤空投」
├── 底栏：促销滚动栏（「商品将下架」「今日新品」）
└── 右上角：「刷新商品池」按钮（消耗记忆碎片）
```

### 1.2 商品设计逻辑

```
终端界面
├── 商品列表（文字颜色区分稀有度）
│   ├── 基础药水：白色文本
│   ├── 高阶药水：石蓝色文本  
│   ├── 终极药水：暗红色文本
│   └── 限时折扣箱：淡紫色文本
└── 每件商品只有「名称 + 机械描述」：
    例：「速效恢复剂」 → 「可以让您的AP瞬间回复3点」
    例：「终极突击剂」 → 「本局所有属性提升至5，突破容量上限」
```

> **核心设计**：**描述是「机制说明」而非「完整指南」**  
> - 会写：**「XX能让XX」**（把握范围写出来）  
> - 不写：**「副作用可能有XX」「服用后1回合有效」「被抢概率XX%」**（这些是实例落地才暴露的「未知数」）

### 1.3 折扣波动算法（玩家可感知的节奏）

```
折扣 = 基础折扣 + 剩余天数惩罚 + 玩家心理期待

- 新上架商品 → 0%
- 留到第2局 → 自动+10%
- 留到第3局 → 自动+30%
- 留到第N局 → up to 50%（但概率递减）

玩家心态：「留着等10%…等到30%…等到50%…」
→ 形成「等崩」的期待 → 被抢时的暴快感
```

### 1.4 订购栏 4 格机制

```
操作流程：
1. 玩家点击商品「召唤」
2. 扣除美元 + 记忆碎片
3. 订购栏新增图标 + 显示「1~3回合投送」
4. 玩家可点击「查看订单状态」
5. 被抢 → 弹窗「订单被劫持！」+ 失去商品 + 触发「抢劫事件」
6. 成功落地 → 播放「黑箱落地」动画 → 玩家服下药水
```

#### 被抢的心机设计

- 订单被抢 → 弹出「警告：该订单近期被多次劫持！」
- 被抢概率 = 商品稀有度 × 玩家近期完成度 × 终端等级

> **设计意图**：玩家永远敬远方的「安全感」——「买完就安全了」是幻觉。

## 二、塑形栏 vs 订购栏：精准定位闭环

### 2.1 职责划分

| 维度 | 塑形栏 | 订购栏 |
|---|---|---|
| **获取方式** | 招式/投点/合成/研究台锻造 | 终端购买 → 叫车空投 |
| **后果** | 长期buff，局间保留（下局仍在） | 一次性消耗，服下即走 |
| **翻盘** | 开局必开 → 爽翻全局 | 叫车+防抢 → 高风险高回报 |
| **管理成本** | 内部决策：选哪些buff | 外部决策：吃啥、不吃、抢谁 |

### 2.2 互不混用的边界

```
局中：
├─ 左手持「塑形栏」 → 长期buff永久化
├─ 右手看「订购栏」 → 一次性药水/卡片
└─ 两者不可互换：
    ├ 塑形栏的buff → 永远显示在人物属性面板
    └ 订购栏的东西 → 服下后→消失+触发副作用
```

```
第1局 → 买药水玩玩 → 服下后发现「这buff太好用」
第2局 → 在终端盯折扣 → 被抢到药水 → 生气又笑
第3局 → 主动埋雷 → 拦截别人的「终极药水」 → 爽直了
第N局 → 学会「翻倍刷新」+「冲动买单」+「挖掘折扣」 → 终于把「黑市交易」玩成「心理战场」
终局 → 玩家懂得「折扣背后的算法」→ 主动「吃亏」买药水 → 期待被抢 → 因被抢获准经验 → 从此「懂黑市」→ 成为「黑市教练」

## 四、V0 投喂要点

### 4.1 必须消除的歧义

1. **「终端商品封面永远模糊」**：玩家点开才显示名字，效果永远带？
2. **「订购栏容量4格」**：买完就排队，不排不到的「背包」
3. **「折扣是留越久越高」**：但概率递减，玩家要盯着等
4. **「塑形栏 ≠ 黑市商品」**：前者是「buff永久化」，后者是「药水一次性」

### 4.2 留给 AI 的设计空间

1. **终端LOGO的动态特效**：字符刷屏 + logo闪烁
2. **商品封面的「模糊滤镜」**：越留越突出的扫描线
3. **折扣弹窗的「闪烁频率」**：越快越紧急
4. **被抢时的「订单劫持」动画**：黑线缩短 + 订单消失的瞬间感

## 六、技术契约（TypeScript 占位）

```ts
interface SecdedTerminalPort {
  // 商品池
  readonly catalog: CatalogItem[];
  readonly refreshCatalog: () => void; // 消耗记忆碎片
  
  // 订购
  readonly orderSlots: OrderSlot[]; // 4格
  readonly placeOrder: (itemId: string) => Result<OrderHandle>;
  readonly cancelOrder: (slotIndex: number) => void;
  
  // 被抢检测（由游戏逻辑驱动）
  readonly onStolen: (handle: OrderHandle) => void;
}

interface CatalogItem {
  id: string;
  name: string;
  description: string; // 永远斜体 + ?号
  price: { dollars: number; memory: number };
  discount: number; // 0.0 - 0.5
}

interface OrderSlot {
  item: CatalogItem | null;
  countdown: number | null; // 1-3回合
  stolenRisk: number; // 0.0 - 1.0
}
```

## 七、结语：SECDED 终端的核心价值

> **「玩家看不见它的样子」** —— 这才是它的灵魂。  
> 你点的不是「商品」，而是 **「一种不确定的承诺」**。  
> 你抢的不是「药水」，而是 **「别人没懂的神器」**。

这是一种 **「用心思当‘收藏夹’，用行动当‘炒股’，用运气当‘翻盘」** 的心态——**SECDED 终端把‘买东西’变成了‘参与一场无时差的博弈赛」**。
