## 🎯 快速理解

### 3句话概括项目
1. 将童年的"起床游戏"数字化为离散策略引擎
2. 用极简约束（数值≤5、五并列）保证深度和稳定性
3. 通过LLM降低UGC门槛，让任何人都能创作内容

### 核心创新点
- ✨ **数值≤5约束**：防止膨胀，逼迫维度拆解
- ✨ **五并列原则**：控制复杂度，保持可推演
- ✨ **自然语言UGC**：零编程门槛创作
- ✨ **通用AI适配**：自动理解所有UGC内容
- ✨ **完全信息对称**：无隐藏属性，纯策略博弈

### 目标用户
1. **策略游戏爱好者**：欣赏深度博弈
2. **UGC创作者**：想表达创意但不会编程
3. **桌游玩家**：喜欢回合制和战术规划
4. **怀旧玩家**：想重温童年游戏

### 商业模式（待定）
- **方案A**：免费游玩 + 可选付费DLC（推荐）
- **方案B**：一次性付费（$15-20）
- **方案C**：免费 + 皮肤商店（不影响平衡）

|------|------|------|
| 生命值 | 1-5 | 标准5点 |

### 概率分布（3人局）
| 获得AP | 概率 | 说明 |
|--------|------|------|
| 3 AP | ~14% | 大胜（罕见爆发） |
| 2 AP | ~28% | 小胜/并列 |
| 1 AP | ~32% | 紧跟（最常见） |
| 0 AP | ~26% | 掉队（体力退回） |

### 槽位系统
- 左手 + 右手（可持单手或双手武器）
- 左口袋 + 右口袋（仅小型物品）
- 背包槽1 + 背包槽2（任意体积）
- **总计6槽**，符合五并列认知

### 场景类型
| 类型 | 最大连接 | 特点 |
|------|----------|------|
| 大场景 | 5 | 可出生，重装+1AP |
| 中场景 | 4 | 标准战场 |
| 微场景 | 3 | 直接交互，无缓冲 |
| 过渡 | 2 | 不可停留，纯连接 |

## 🔖 重要提醒

**设计原则三不变**：
1. ❌ 不能有超过5的玩家可见数值
2. ❌ 不能违反五并列原则
3. ❌ 不能增加不必要的状态

**开发原则三优先**：
1. ✅ 稳定性优先于功能丰富
2. ✅ 可扩展性优先于快速实现
3. ✅ 用户体验优先于技术炫技

**UGC原则三保证**：
1. ✅ 保证创作安全（永远不崩溃）
2. ✅ 保证创作简单（自然语言）
3. ✅ 保证创作有效（AI自动适配）
