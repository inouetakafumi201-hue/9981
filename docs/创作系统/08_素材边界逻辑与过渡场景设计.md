# D-088 素材边界逻辑与过渡场景设计

本规范把地图编辑器中的素材身份、天然场景激活、词条挂载与过渡场景行为固定为可验证契约。展示分类只服务检索与美术表现，不能驱动玩法逻辑。

## 1. 四条边界

### 1.1 素材身份

素材登记期由 `material-adapter.ts` 确定唯一 `logicCategory`。编辑器不能通过卡片名称、展示分类或拖放位置改写素材身份。登记缺少逻辑分类时，只能走确定性的旧六类迁移：装置/交互→机关装置，照明/陈设→装饰，线索→物品，遮挡→容器。

八类逻辑身份为：AI 单位、NPC、载具、容器、物品、机关装置、装饰、过渡场景。

### 1.2 天然场景激活

普通素材落入天然场景框时保存 `activation: native`、宿主节点与 `placementMode: native`，编译为运行时实体。素材移出场景框不删除实例，只保存表现坐标并闭环降级为 `activation: free-decoration`、`placementMode: presentation-only`；它不会生成运行时实体。

装饰不论位置永远是 `free-decoration + presentation-only`。过渡场景不进入普通 `placements`。

### 1.3 词条宿主

词条只写入素材实例的 `tokenIds[]`，不回写素材目录或共享基体。编辑器在写入前调用 accepts 矩阵：

| 宿主 | 可接受词条 |
| --- | --- |
| AI 单位 / NPC | 属性、技能、状态、防御、机动 |
| 载具 | 属性、技能、防御、机动 |
| 容器 | 状态、防御 |
| 物品 | 属性、技能 |
| 机关装置 | 技能、状态 |
| 装饰 / 过渡场景 | 无 |

仅表现素材没有可挂载槽。非法拖放必须在状态写入前拒绝，不能产生实例字段、撤销记录或部分更新。

### 1.4 过渡场景拓扑

过渡场景只能绑定地图连线端点。一条边最多两个实例，`from` 与 `to` 各一个；两侧不是主副关系。边级 `transitionParams` 共享，实例自身的 `effect` 独立。

绑定时先完成拓扑写入：确定边与端点，创建或复用 `d:scene/micro-transition` 子节点，再写入 `TransitionInstance`。实例保存 `edgeId`、端点侧、素材身份、微型场景 id、端点坐标与参数引用。删除连线或宿主节点时同步清理微型场景引用。

## 2. 数据契约

编辑器 `Placement` 保存 `hostSceneId`、`activation`、`hostCapabilities` 与 `tokenIds[]`，同时保留 `sceneId`、`placementMode` 作为旧地图兼容字段。canonical `MapPlacement` 使用相同语义并由 `serializeMapData` 保持 round-trip。

canonical `MapEdge.transitionInstances[]` 是新格式；旧 `transitionWindow` 只允许作为导入迁移输入。无法确定旧窗口最近端点时不能静默伪造实例，应保留诊断。

## 3. 编译与诊断

`compileMap` 过滤 `free-decoration` 与 `presentation-only`，只把 native placement 编译为 `PrefabDef.entities`，并透传 `tokenIds`、激活状态与宿主引用。过渡微型场景作为子节点先进入 prefab 节点拓扑，实例效果和边级共享参数挂入节点 props。

校验器必须报告：

- 过渡场景被错误保存为普通 placement；
- 装饰或 free-decoration 仍声明原生逻辑；
- native placement 没有有效宿主；
- 词条 id 重复/为空或宿主能力快照不一致；
- 一条边超过两个过渡实例或同一端点重复；
- 过渡实例引用不存在的微型场景、错误边或非法坐标。

每条诊断都必须给出可执行的修复建议。保存可以保留半成品，但含 error 的地图不能编译发布。

## 4. 编辑器反馈

素材检查器显示逻辑身份、native/free-decoration、宿主节点、宿主能力、可用词条槽与已挂载数量。拖放到场景外时明确显示仅表现状态；过渡素材靠近连线端点时高亮端点，已占用端点在落点前显示拒绝反馈。

本规范对应 `material-adapter.ts`、`map-types.ts`、`editor-store.ts`、`map-bridge.ts`、`src/play/map/types.ts`、`validate.ts` 与 `compile.ts` 的运行时契约。
