## 一、为什么是这套（一句话）

**脚本能产 MapData，编辑器只是更舒服的输入方式——契约才是主权载体（D-072）。** 数据契约（`src/play/map/**`）自 2026-08-08 已实现并被 73 个测试覆盖；本轮把「产出 → 校验 → 编译 → 进引擎自测 → 可视化」的**开发期工具链**真实搭起来，验证这条数据链畅通，为正式编辑器后置排期与里程碑②（可挂素材对局）铺路。

## 二、三件套命令（npm scripts）

| 命令 | 作用 | 产出 |
|------|------|------|
| `npm run asset:generate` | 生成合法样例地图 `MapData` | `tmp/asset-pipeline/maps/sample-sleeper.json` |
| `npm run asset:pipeline` | 结构校验 → 跨目录引用校验 → `compileMap`→PrefabDef → 引擎真身 spawn 断言落地 | `tmp/asset-pipeline/artifact/pipeline-report.json` |
| `npm run asset:view [json路径]` | 把 MapData 拍平成 mermaid flowchart（编辑器后置下的零成本肉眼检查） | 可粘贴进支持 mermaid 的渲染器 |

脚本本体：`scripts/asset-pipeline/generate-sample-map.mjs`、`validate-and-compile.mjs`、`map-to-mermaid.mjs`。

**跑通判定**：`asset:pipeline` 输出「通过 | 结构错误=0 引用错误=0 spawn=N节点/M边/K实体」且退出码 0。

## 四、两条易踩的校验错（写脚本的人要记住）

1. **曲线首尾必须贴合端点节点坐标**：`SNAP_TOLERANCE = 0.005`，端点距宿主节点超过即报 `MAP_PATH_ENDPOINT_NOT_SNAPPED`。样例里曲线 `path` 的第一/最后一个点就是 `bunk_a`/`carriage` 等的坐标。
2. **场景嵌套尺度逐级合法**：大只能直接含中、中只能直接含小（`ADMITTED_CHILD_SCALES`），否则 `MAP_ILLEGAL_SCENE_NESTING`。且 `MapNode.scale` 必须与跨目录 index 里该 def 声明的尺度一致，否则 `MAP_SCALE_MISMATCH`（`d:scene/room`=medium、`d:scene/closet`=small、`d:scene/yard`=large）。

另：放置覆写键名不得撞 Expr 判别键（`path`/`op`/`call`/`q`/`var`），否则 `MAP_OVERRIDE_KEY_SHADOWS_EXPR`。

## 五、关键实现事实（后续在此拓展时对齐）

- **复用真身、不另起 schema**：校验调 `validateMapStructure` + `validateMapAgainstClasses`（前者无 IO 即时跑、后者需 index），编译调 `compileMap`，spawn 用 `prefab.ops.registerPrefabOps`。全被 `src/play/map/__tests__` 覆盖。
- **占位 def**：基类层 `scene.class.large/medium/small` 与 `transition.class.scene_link` **全体 abstract**、不可直接 spawn（`checkInstantiable` 判 `E_REF_ABSTRACT`）；真实地图装载经玩法层对场景/门户类型具体化。样例地图因此用 `d:scene/*` + `d:transition/*` 占位 def，对应的跨目录 index 与 placeholder defs 在 `validate-and-compile.mjs` 的 `buildIndex`/`spawnAndAssert` 里——**改了样例 def 就要同步这两处**。
- **样例不进产品区**：全部落在 `tmp/asset-pipeline/`（`tmp/` 是开发期临时区）。真实地图属玩法层数据，进 `src/**` 的落地方式（如 `src/play/profiles/maps/`）待正式编辑器/玩法层场景登记后再定。
- **方向 token**：`linkSpecOf` 已保留完整 `directionality` 枚举（bidirectional/unidirectional/one-way-down/up）而非压成布尔 `directed`（L-07 已完成，见 `src/play/map/compile.ts`）。样例四条边覆盖了四值。
