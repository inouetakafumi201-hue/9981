> **性质**：现行目标管线与实现状态交接
> **状态**：目标流程已定；批量生成、登记、实例化、编辑器可选的端到端闭环尚未完成
> **日期**：2026-09-05
> **归属**：创作系统（开发期生产工具，不属于三层运行链）
> **事实源**：`docs/访谈决策记录.md` D-086

## 一、素材的完成定义

素材不是图片集合。可交给地图编辑器使用的素材，至少是以下内容组成的可挂载整体：

- 视觉资源；
- AI、NPC 或物品的稳定实体/定义关联；
- 表现层和渲染层可消费的描述；
- 编辑器目录、检索与预览元数据；
- 稳定 ID、版本与引用完整性信息。

图片生成只完成了视觉资源环节。只有素材能在表现层实例化、渲染层消费，并能在编辑器中检索、选择和放置，才算完成挂载。

---

## 二、现行 V0 原生链路

```text
规划书与资产清单
  → Agent 调用 V0 GenerateImage 等平台工具逐项出图
  → 保存生成结果并登记稳定 ID
  → 组装实体定义、渲染描述与编辑器元数据
  → 校验资源和引用完整性
  → 表现层实例化验证
  → 编辑器索引、检索、选择和放置验证
  → 交给地图编辑步骤使用
```

### 阶段门

| 阶段 | 必须产出 | 不通过条件 |
|---|---|---|
| 资产清单 | 每个 AI/NPC/物品的用途、变体、状态、尺寸和命名 | 只有自然语言愿望，没有可逐项执行清单 |
| V0 出图 | 对应清单项的本地资源文件与生成记录 | 漏项、错配、仅外部 URL |
| 登记与组装 | 稳定 ID、实体关联、渲染描述、编辑器元数据 | 只有图片路径或依赖临时目录名 |
| 实例化 | 表现层能创建并显示实体 | 资源存在但运行路径不可消费 |
| 编辑器可选 | 能检索、预览、选择和放置 | 需人工输入路径或浏览器扫描 `run/` |

## 三、V0 工具与仓库脚本的边界

### V0 Agent 负责

- 读取规划书和资产清单；
- 使用 V0 `GenerateImage` 等平台工具逐项生成图片；
- 把生成结果保存为项目内文件；
- 按报告继续补齐漏项或重生成失败项。

### 仓库脚本负责

- 校验清单结构和完成度；
- 执行确定性的切格、抠图、缩放、格式转换等后处理；
- 登记稳定 ID、实体引用、渲染描述与编辑器元数据；
- 检查悬空引用、重复 ID、漏资源和版本不一致；
- 输出表现层实例化与编辑器索引验收报告。

仓库脚本**不直接调用外部图像模型 API，不持有也不要求模型 API Key**。若有外部 API 适配器或本地 sprite-forge，它们只作为可选历史开发工具，不是 V0 默认入口。

## 四、地图生产中的位置

本管线对应地图包生产的步骤 3 和步骤 5：

1. 步骤 3 生成 AI、NPC、物品实体所需的整套待挂载素材。
2. 用户在步骤 4 导入人工 SVG，并建立地图拓扑和空间意图。
3. 步骤 5 完成素材挂载验收，确保新旧素材都能实际实例化并被编辑器选取。
4. 步骤 6 才由 AI 完成内容、流程、节点与玩法文件绑定。

地图 SVG 不进入本素材生成链。Agent 不负责地图底稿或空间构图。

## 五、当前实现事实

| 能力 | 状态 |
|---|---|
| 单项图片由 V0 平台工具生成并保存 | 平台能力可用 |
| 部分角色资源导入、命名和登记脚本 | 已有实验实现 |
| 确定性 sprite 后处理与本地自测 | 已有可选工具 |
| MapData 结构校验、编译、spawn 自测 | 已实现，但属于地图契约自测 |
| 批量资产清单协议 | 未定稿 |
| V0 多项生成的断点续跑与完成报告 | 未实现 |
| 完整实体/渲染/编辑器元数据组装 | 未闭环 |
| 表现层批量实例化验收 | 未闭环 |
| 编辑器统一索引与可选择验收 | 未闭环 |

因此不得再把“素材工作流已搭通”表述为产品事实。已搭通的是部分工具和地图数据契约实验，不是完整素材生产闭环。

## 六、开发期 MapData 自测附录

以下命令保留，用于证明 `MapData` 数据链可校验、可编译、可进入引擎：

| 命令 | 用途 |
|---|---|
| `npm run asset:generate` | 生成开发期样例 `MapData` |
| `npm run asset:pipeline` | 校验、编译并执行样例 spawn 断言 |
| `npm run asset:view` | 输出样例拓扑的 Mermaid 视图 |

这些命令：

- 不生成正式地图；
- 不生成地图 SVG；
- 不等于素材批量出图；
- 不替代地图编辑器；
- 不证明素材已经挂载到表现层或编辑器。

## 七、后续实现验收

完整闭环必须至少通过以下验收：

1. 给定一份包含多个 AI/NPC/物品及状态变体的清单，Agent 能在 V0 内完成逐项出图并生成可恢复的完成报告。
2. 重跑不会覆盖已确认资产或制造重复 ID，只处理缺失/失败项。
3. 每个视觉资源都能追溯到稳定实体/定义和渲染描述。
4. 验收场景能批量实例化所有素材，并报告无法渲染项。
5. 编辑器资产面板能按稳定 ID 检索、预览、选择和放置所有合格素材。
6. 运行时不扫描 `run/`，不依赖开发期中文目录或临时文件名。
7. 全链路不要求外部模型 API Key。
