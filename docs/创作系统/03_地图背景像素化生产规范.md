# 03 · 地图背景像素化生产规范

> **建筑组补充**：建筑楼层不再作为主地图的平面图层；由场景框创建建筑组，楼层作为该建筑组的独立局部图幅分支。见本文件“建筑组局部楼层管线”。

## 背景

`docs/创作系统/02_地图生产管线.md` 第 19 行明确：**美术侧产出 = 一张 1080P 斜测轴平面图**，
由人工挑选。但实际 `run/v0-assets/scenes/` 目录从未存在，`office-v1.json` 的 `backdrop.image`
引用是虚引用。

**本规范建立这条空缺管线的工具链与工艺纪律。**

## 视角铁律（与全项目统一）

- **唯一允许的视角 = top-down plan view**（PLT-01 §视角与朝向）
- 与 64×64 组件 / 角色同一法则：从正上方俯瞰，靠剪影、地面阴影表达身份与朝向
- 禁止：front face / side face / top face / oblique depth / three-quarter / isometric
- 视角口令：`top-down plan view` / `overhead plan-view sprite`

## 风格铁律（继承自 05_组件生成风格规范）

- 像素艺术（hard-edged color blocks）
- 禁止：抗锯齿、渐变、抖动、模糊、柔边
- 光源：左上恒定
- 调色板：48 色扩展调色板（覆盖场景所有色调）
- 背景：100% solid flat magenta (#FF00FF) — 仅在 Stage 1 AI 出图阶段需要，切格后不再保留

## 管线四段式

```
Stage 1: AI 草图生成         自动化（sprite-forge 出图）
  run/backdrops/{name}/raw.png     AI 直出 1024×1024
  run/backdrops/{name}/raw.json    留档（仅内部）

  工具：map-backdrop-pipeline.py generate --name X --desc "..."
  提示词：内置 MAP_BACKDROP_PROMPT（视角+硬边+调色板+品红底）

      ↓

Stage 2: 作者局部重绘         人工（不可自动化）
  run/backdrops/{name}/author-pass.png
  工具：编辑器内置 paint layer / Photoshop / Aseprite 都可
  关键：这是"AI 不可举证"的法律基础，作者必须介入

      ↓

Stage 3: 硬边化 + 杂色纯化     自动化（hashi-dither-purifier）
  run/backdrops/{name}/final.png   ship 版
  工具：map-backdrop-pipeline.py purify --name X --colors 48

      ↓

Stage 4: ship 资产登记         自动化
  src/devboard/.../public/games/maps/{name}.png
  src/devboard/.../public/games/maps/{name}.manifest.json
  工具：map-backdrop-pipeline.py ship --name X --target <path>
```

## 各阶段参数

### Stage 1 (generate)
- `--name`  地图名（与 MapData JSON id 一致）
- `--desc`  场景描述
- `--provider`  gpt-image-2 / gemini（可选，不传走环境变量）
- 出图尺寸：1024×1024（内部）

### Stage 2 (人工)
- 工具：任意外部编辑器
- 产物：author-pass.png（同尺寸 1024×1024）
- 风格：保持 top-down plan view 视角，统一调色板，不要破坏原图整体构图

### Stage 3 (purify)
- `--colors` 默认 48（地图背景比场景图色数需求高）
- `--passes` 默认 5（比场景图更激进，地图背景需要更硬的边缘）
- 调用 hashi-dither-purifier.py

### Stage 4 (ship)
- `--target` ship 目标目录
  - 推荐：`src/devboard/game-ui-shell-15/public/games/maps/`
  - 或 `src/devboard/game-ui-shell-10/public/games/maps/`
- 同步更新 MapData JSON 的 `backdrop.image` 字段

## 一键模式（跳过 Stage 2）

```
python map-backdrop-pipeline.py auto --name warehouse-v1 \
  --desc "abandoned warehouse, top-down plan view" --colors 48 \
  --target src/devboard/game-ui-shell-15/public/games/maps/
```

⚠ **警告**：auto 模式跳过 Stage 2 人工重绘，ship 出的图依然可举证"AI 生成"（无作者介入痕迹）。
**正式 ship 必须有 Stage 2**——auto 仅供快速预览。

## 大地图迭代（局外出租屋 + 局内 4K 大地图）

### 战略改变

普通 4K 图像生成是"画面质量路线"——AI 优先保证好看、忽略比例尺。
本管线走"大比例尺占位底图"路线——**画面质量让步给细节密度**：
- 出图尺寸 **4K（3840×2160 或更高）**
- 比例尺小（一个人物约 6-10 像素宽）
- 每个平方厘米都有可见细节
- 实际编辑时用 sprite 组件遮盖 AI 出图的位置

### prompt 预设（map-backdrop-pipeline 内置）

| preset | 用途 | 关键约束 |
|--------|------|---------|
| `default` | 通用地图（无 4K 强约束） | 视角铁律 + 硬边色块 + 品红底 |
| `large-map` | 局内 4K 大地图 | **必须 4K + 高细节密度 + 禁止可移动物件** |
| `room` | 局外出租屋等小空间 | **必须 4K + 单房间 + 全部家具可见** |

**关键约束（写在 LARGE_MAP_PRESET 里）**：
- ABSOLUTELY NO MOVING OBJECTS: no vehicles, no people, no animals
- 静态建筑 + 静态道具（墙、地板、门、窗、家具、灯具、井盖、草丛、地面裂缝）
- Components will be placed on top of this in the editor to fill dynamic roles
- NO shadow casting, NO soft shading

**生成命令**：
```bash
# 局外：出租屋（用 room 预设）
python map-backdrop-pipeline.py generate --name dorm-room \
  --preset room \
  --desc "出租屋卧室，含床、书桌、衣柜、窗户、门"

# 局内第一张：大地图-高中校园（用 large-map 预设）
python map-backdrop-pipeline.py generate --name high-school-campus \
  --preset large-map \
  --desc "高中校园：教学楼 3 栋、操场、走廊、花坛、旗杆"

# 局内第一张：大地图-学校门口的街（用 large-map 预设）
python map-backdrop-pipeline.py generate --name street-outside-school \
  --preset large-map \
  --desc "学校门口的街道：商店 4-6 家、人行道、树木、路灯、路标"
```

### 迭代纪律

- **每次迭代打磨 prompt**，不换后处理参数
- 每次出图后**过审视觉**：占位密度、视角正确、无文字、无可移动物件
- 视觉过关后 → Stage 2 局部重绘（仅局内大地图需要，局外出租屋不必）
- Stage 3 硬边化固定 colors=48
- Stage 4 ship

## 建筑组局部楼层管线

一张选定的整图只负责外部空间占位，不同时承担所有建筑内部楼层。编辑时由用户在整图上框选建筑场景框；该框成为建筑组的固定 footprint。建筑组在主地图层级之外形成独立分支：

```text
主地图整图
└── 建筑组（场景框 footprint）
    ├── shell（外部完整建筑）
    ├── floor-1（局部图幅 = 场景框）
    ├── floor-2（局部图幅 = 场景框）
    └── portals（入口/楼梯/电梯锚点）
```

### 设计含义

- 主地图层描述建筑外部、道路和校园连续空间。
- `shell` 是玩家离开建筑时看到的完整建筑，不是全局 layer。
- 每个楼层只覆盖建筑组场景框的局部图幅；上层不会覆盖或遮挡下层的主地图区域。
- 同一建筑内的楼层编号和相对高度只在该建筑组命名空间内有意义；不同建筑可以拥有相同楼层号和高度。
- 楼层图像必须保持与 shell 相同的场景框、入口、楼梯和电梯锚点；生成工具不得擅自改变 footprint。

### 一键生产顺序

```text
选定整图
→ 声明建筑组场景框（regions.json）
→ 一键裁出 shell/reference 与楼层 reference
→ 对指定楼层局部生成或人工重绘 author-pass
→ 校验 mask 外像素不变、尺寸不变、锚点存在
→ 合成每个楼层 final
→ 最终整图/局部统一硬边化与杂色纯化
→ 生成 layer-manifest.json
```

楼层框选必须由人确定，AI 只生成框内候选。局部生成记录 `buildingGroupId`、`floorId`、像素 `bbox`、归一化 frame 和锚点；不得依赖相同的 `height` 自动合并。

### 当前工具边界

- `map-region-extract.py`：区域声明、确定性裁剪、author-pass mask 合成、外部像素不变校验。
- `map-backdrop-pipeline.py`：整图候选、选定图、楼层阶段编排、最终登记。
- `hashi-dither-purifier.py`：最终图像纯化；建筑 frame 和锚点使用保护边界。
- 编辑器和 MapData 的建筑组字段属于后续批次；本阶段不在 Python 工具中伪造运行时层级。

### Prompt 共同硬约束

```text
PURE TOP-DOWN PLAN VIEW. No perspective, no isometric, no three-quarter view,
no front face, no side face, no readable text of any kind, no Chinese characters,
no English letters, no numbers, no shop signs, no road labels, no logos,
no glyphs, no UI, no watermark, no people, no animals, no vehicles,
no bicycles, no scooters, no skateboards, no movable objects.
All signs and storefront fascia are blank geometric color blocks.
```

### 视角铁律

- **唯一允许的视角 = top-down plan view**（PLT-01 §视角与朝向）
- 4K 大图也必须纯俯视；**禁止任何等距投影/斜投影/three-quarter**
- AI 出图后第一件事：核对视角——任何侧脸/斜角出现**立即重生成**

## 与 D-083 全息背景的关系

D-083（2026-08-19）决策：**背景光层由代码生成（Canvas / shader），零贴图**。

本规范与 D-083 不冲突：
- **D-083 全息层** = 梦境的氛围光层（代码生成）
- **本规范底图层** = 地图场景的"实景"（像素化贴图）

两者在渲染时叠加：底图层在下，全息层在上。底图层由本管线产出，全息层由代码层生成。

## 与 02_地图生产管线的衔接

`docs/创作系统/02_地图生产管线.md` 第一节的"两半分工"（美术侧 = 选图，拓扑侧 = 标点），
本规范补全了美术侧的具体工艺：
- 旧："手工挑选的整图"（无具体工具）
- 新：AI 草图 + 作者重绘 + 硬边化 + ship 登记（map-backdrop-pipeline.py 接管）

### 大地图的"两半分工"特化

**美术侧**（本规范）：
- 4K 草图（map-backdrop-pipeline generate --preset large-map）
- 局部重绘（仅局内大地图，局外小图不必）
- 硬边化（map-backdrop-pipeline purify --colors 48）
- ship 登记

**拓扑侧**（沿用 02_地图生产管线）：
- MapData.nodes/edges 在 4K 底图上标点
- 用 sprite 组件遮盖 AI 出图的位置（人/车等）
- 编译为 PrefabDef

## 边界（不自越）

- **不碰权威**：不改视觉定律/视角铁律/调色板铁律/MapData 契约
- **不碰实现**：不进 `src/core/`，只产素材
- **不背美术选型**：作者对 Stage 2 重绘负责，工具只管自动化
- **不绕过 Stage 2**：auto 模式仅供预览，正式 ship 必须有作者重绘
- **大地图不抽密度**：4K 出图密度是硬约束，画面质量让步给细节
