# 03 · 地图背景像素化生产规范（已废止）

> 本文件记录已退役方案，不得再作为地图生产入口或实现依据。现行裁决见 `docs/访谈决策记录.md` D-086，现行流程见 `docs/创作系统/02_地图生产管线.md`。

## 废止结论

下列旧流程整体退役：

```text
AI 生成地图草图
  → 作者局部重绘
  → 硬边化/杂色纯化
  → PNG ship 资产登记
  → 再与 MapData 关联
```

退役原因不是工具质量不足，而是职责已经改变：Agent 不再负责地图图片文件生成；全屏地图统一使用**人工产出的 SVG**，用户在地图编辑器中导入 SVG，并亲自完成拓扑、空间关系和基础设计意图。

因此：

- `map-backdrop-pipeline.py generate/purify/ship` 不属于现行地图管线；
- sprite-forge、Nano Banana、gpt-image 等不得作为地图 SVG 或底稿的默认生成入口；
- `office-v1.json` 等历史 PNG 路径不能据此推导新的地图资产规范；
- 任何尚存历史脚本和图片仅可用于迁移或考古，不得用于宣称地图生产已经跑通。

## 仍然有效的原则

- 地图空间关系必须由创作者明确表达，不由 AI 猜测；
- 地图视觉与拓扑通过稳定坐标和引用关联；
- `MapData` 的结构校验、跨目录校验与编译仍是地图包发布闸门；
- 新旧 AI/NPC/物品实体素材必须经过统一登记、表现层实例化和编辑器可选验收后，才能进入地图编辑。

## 现行入口

现行六步链为：规划书 → 玩法层规则与 API → V0 原生实体素材生成 → 人工 SVG 地图编辑 → 素材挂载 → AI 高逻辑绑定。详细责任、地图包边界和当前实现状态只以 `docs/创作系统/02_地图生产管线.md` 为准。
