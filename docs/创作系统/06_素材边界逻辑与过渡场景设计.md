# WakeUp 素材边界逻辑与过渡场景设计（权威）

> **定位**：本文档是「素材身份、词条宿主、场景框挂载、过渡场景绑定」四条边界的唯一事实源。分类清单见 `docs/v0-dev-material-library-spec.md`；本文档定义的是分类之外的**运行时语义与人机交互边界**。
> **裁决来源**：`docs/访谈决策记录.md` D-088。与本文档冲突的旧口径一律以本文档为准。

---

## 一、素材身份：由运行时适配器决定，且不可切换

1. **身份判据**：一个素材的「真实身份」由它绑定的**运行时适配器**（`runtimeAdapterId`）决定，而不是它的语义用途、图标或摆放位置。八类顶级分类（AI 单位 / NPC / 载具 / 容器 / 物品 / 机关装置 / 装饰 / 过渡场景）只是适配器族的人类可读投影。
2. **适配器即契约**：适配器决定该素材在右侧面板暴露哪些参数 Schema、接受哪些词条宿主、在运行时被编译成什么实体。素材登记（`asset:register-*`）时即固化 `runtimeAdapterId`，写入素材元状态。
3. **不可切换**：编辑器**不提供**在实例上切换身份/适配器的操作。要换身份，必须换素材。这样地图数据里每个 placement 的身份是登记期确定的常量，导入导出、跨版本迁移都不会漂移。
4. **非法即阻止**：任何试图跨适配器改写身份、给素材挂它不接受的能力的操作，编辑器**在操作前阻止并解释原因**（拖放拒绝红闪 + 文案），不落库、不产生半非法数据。

## 二、场景框挂载：锚点归属决定逻辑激活

1. **激活条件**：普通素材（AI 单位 / NPC / 载具 / 容器 / 物品 / 机关装置）**只有挂载在场景框内才加载运行时逻辑**。判据是**锚点归属**——以素材的锚点（不是包围盒、不是任意一角）落在哪个场景框内为准。
2. **两种放置态**：
   - `logic`（逻辑态）：锚点归属于某场景框，运行时按其适配器编译为逻辑实体。
   - `free-decoration`（自由装饰态）：锚点不在任何场景框内，运行时**只保留表现，不加载任何逻辑**。
3. **原生装饰恒无逻辑**：`装饰` 类别的素材是「资产类别」与「放置降级态」的合一——**无论是否在场景框内，都不加载逻辑**，永远等价于 `free-decoration` 的表现语义。
4. **框内外切换必须闭环**：`addPlacement` / `updatePlacement` / 移动场景框 / 场景框缩放重叠 / 重新归属，**任一改变锚点归属的操作都必须重算 `effectiveMode`**。框外拖回框内恢复逻辑态，框内移出立即降级为装饰态。不允许出现「移出后仍是逻辑态」或「拖回后仍是装饰态」的悬空状态。
5. **数据保留**：框外普通素材**仍然保存**（坐标、素材引用、参数草稿都留），只是导出与运行时按 `free-decoration` 处理，不 spawn 逻辑实体。

## 三、词条：挂在素材实例，宿主矩阵约束

1. **挂载层级**：词条挂在**素材实例**上（placement 级），不是挂在素材类型或蓝本上。同一素材的两个实例可以有不同词条集。
2. **词条引用**：实例只存 `TokenId[]` 引用；词条本体、品级、效果都在共享元状态层（`src/meta-state/`）里，编辑器/素材库/研究台读同一份投影，不各存一份 `TokenMeta`。
3. **宿主矩阵（`accepts`）**：每个适配器声明它接受的词条宿主类型。词条只能挂到 `accepts` 命中的素材上。
   - 装饰、过渡场景**不接受任何运行时词条**（它们没有逻辑宿主）。
   - AI 单位 / NPC / 载具 / 容器 / 物品 / 机关装置各自声明可接受的词条族与槽位数。
4. **拖放前阻止**：词条不适配当前素材、或该素材的词条槽位已满时，编辑器**在拖放落点前就阻止**（落点红闪 + 原因文案），不产生非法挂载再回滚。
5. **详情与研究台联动**：
   - 素材详情/检查器**按宿主能力显示槽位**——有几个可用槽就显示几个，装饰与过渡场景不显示词条槽。
   - 点击词条槽跳转研究台并定位到对应词条；「去研究台锻造」按钮**只对能接受词条的素材显示**，装饰与过渡场景不显示。

## 四、过渡场景：连线端点侧实例

过渡场景是极特殊的一类——它不依赖场景框、必须在连线上才生效，且与表现层深度耦合。

### 4.1 绑定方式

1. **只能拖到连线**：过渡场景素材**只能拖到 MapEdge 上**，直接成为该边的过渡场景实例，不创建普通 placement。拖到非连线区域一律拒绝并解释「过渡场景仅可绑定连线」。
2. **线段命中 + 自动吸附**：释放时按**线段命中**判定落在哪条边，并自动吸附到该边，不依赖「当前选中的 edge」。未命中任何边则拒绝，不静默失败。
3. **辅助文案**：过渡场景素材在库/快捷栏的辅助文本必须是「仅可绑定连线」，区别于普通素材的「拖入画布放置」。

### 4.2 端点侧归属与数量

1. **端点侧实例**：一条边连接场景 A 与 B，每个过渡场景实例在数据上**归属于一个端点侧**（`endpoint: A | B`）。它相当于给这条边在该端点侧叠加一层表现层 + 玩法层逻辑。
2. **每条边最多 2 个，两端点各一个**：一条边上允许 1–2 个过渡场景素材；当有 2 个时，**两个端点各挂一个**。拖入第三个一律阻止并解释。
3. **叠加而非主副**：多个过渡场景在图数据上是**叠加**关系，**不存在主/副层之分**。每个过渡场景各自触发自己的表现层动画与过滤逻辑，各自独立生效——微型场景的叠加**不止于跨图层**，因此不套用固定主副合成顺序。
4. **人机交互上的共选**：若一条边只有 1 个过渡场景实例，则该边连接的**两个场景框都可以在交互上选中它**；数据上它仍记为其所属端点侧的实例。

### 4.3 调参共享边界

1. **边级参数共享**：属于「这条边怎么过渡」的参数（边级 transition 参数）由该边上的过渡场景实例**共享**。
2. **素材效果独立**：每个过渡场景素材自己的表现效果、触发的动画配方、过滤逻辑**各自独立**，互不覆盖。

### 4.4 微型场景与空间归属

1. **自动创建微型场景**：过渡场景落到边上后**自动创建**其微型场景，无需额外手动步骤。
2. **实体实际所在处**：
   - 若过渡场景**在某场景框侧**（端点侧对应的场景框内），微型场景以该实体在场景框内的位置为实际所在处，可据此创建框内微型场景。
   - 若**不在任何场景框内**，实体实际所在处取**连线与场景框的交点**。
   - 若该边只连接**一个**场景（另一端无场景框），则该实例作为**两个场景框侧的共同实例引用**处理。
3. **垂直/平行判定顺序**：过渡场景沿用既定的垂直/平行几何逻辑，但**先判拓扑关系，再判空间关系**——先确定端点侧归属与连接拓扑，再据几何做垂直/平行细化。

### 4.5 拓扑迁移与校验

连线、场景或过渡场景被删除、拆分、反向或复制时，过渡场景**跟随拓扑迁移并重新校验**：

| 拓扑操作 | 过渡场景处理 |
|---|---|
| 删除边 | 边上过渡场景一并删除 |
| 删除端点场景框 | 该端点侧实例降级/迁移，按 4.4 重算实体所在处并校验 |
| 拆分边 | 过渡场景跟随其端点侧所在的新子边，重算数量约束（仍 ≤2、两端各一） |
| 反向边 | 端点侧归属随方向翻转，重新判定拓扑再判空间 |
| 复制边/场景 | 过渡场景随之复制，复制后立即校验数量与端点侧唯一性 |

迁移后若违反「≤2 且两端点各一」或宿主约束，编辑器阻止该拓扑操作并解释，不留下非法叠加。

## 五、运行时契约对齐（实现要求）

以下字段必须进入正式 MapData 契约（`src/play/map/types.ts`），编辑器桥接（`map-bridge.ts`）导入导出不得丢弃：

- placement 级：`runtimeAdapterId`、`logicCategory`、`effectiveMode`（`logic | free-decoration`）、`tokens: TokenId[]`。
- 过渡场景：以端点侧实例结构表达（`edgeId` + `endpoint` + 边级共享参数 + 各实例独立效果），过渡窗口几何对齐玩法层要求的 `TransitionWindowPoints { control: Vec2[] }`，不再用单点坐标。
- 编译（`compile.ts`）：`effectiveMode === 'free-decoration'` 与原生装饰**不编译为逻辑实体**；过渡场景按端点侧实例编译，边级参数共享、实例效果独立。

旧分类适配器（装置/照明/陈设/交互/线索/遮挡作为分类键）与旧 `TokenSlot`（attr/skill/state/defense/mobility）一律退役为标签或迁移到 `TokenId` 引用，不得再作为身份或宿主判据。
