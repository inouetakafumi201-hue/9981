# 主线关卡设计

> **归属**：叙事设计 / 主线关卡结构
> **状态**：设计中，整合全部已定案叙事流的统筹方案
> **创建日期**：2026-08-27
> **依赖**：`叙事设定/00`（世界观）、`叙事设定/01`（主角与三边关系）、`叙事设定/02`（四幕与爆点）、`叙事设定/03`（时间线）、`叙事设定/04`（组织）、`叙事设定/05`（物理与塑形）、`叙事设定/06`（风格）、`运营系统/03`（驻地）、`运营系统/04`（门缝纸条）
> **设计核心**：每关不是"一关讲一件事"，而是"一个叙事流密集时刻"——同时承载明线推进、暗线变化、世界观释放、玩法解锁、冷面幽默、关系或情感变化、势力介入。

### 1.2 关卡设计原则

- **每关同时承载至少 6 条叙事流**，并标注优先级；
- **暗线 D 从第 1 章开始就有微变化**，不能只靠第 4 章死亡才揭示；
- **冷面幽默 H 每关必有至少一个锚点**，且不暂停剧情；
- **隔空关系语法 O 渗透到每一关的细节**，不集中爆发；
- **现实活动 Q 可发生在任务地图内**，不强制返回局外地图；
- **每关从驻地床 P 开始**，不使用独立过场。

## 二、三个阶段的关卡特征

| 阶段 | 章节 | 核心动作 | 主导叙事流 | 情感基调 | 时长估算 |
|---|---|---|---|---|---|
| **第一阶段** | 1–4 | 追回梦 | A + D（萌芽） + E + F + G（基础） + H + I（神秘档案） + M + N（特长期） | 主角是"超忆症天才"，偶有不对劲 | 20–40 分钟/关 |
| **第二阶段** | 5–10 | 夺回梦 | B + D（显形→协作→冲突） + E + F + G（双线/编辑器） + H + I（深梦收编→黑客掩体） + J（萌芽） + K + L + N（传奇期） | 关系建立、信任与冲突 | 25–45 分钟/关 |
| **第三阶段** | 11 | 找回人 | C + D（生死未卜） + E + F（百目全力） + G（双屏） + H + I（黑客掩体） + J（完成） + L（收网） + O（隔空追寻） | 追寻、隔空、开放 | 35–50 分钟 |
| **尾声** | — | 关系余波 | D + H + I + J + N | 未决、隔空守护 | 15–25 分钟 |

**总时长估算**：主线 11 章 + 尾声约 **6–8 小时**；竞技模式单局 5–10 分钟独立存在。

## 三、关卡总表（11 章 + 尾声）

> 每关都标注：明线（哪个句子）、暗线（哪个变化）、势力（谁出现）、玩法（学什么）、幽默（哪个锚点）、传闻（哪个分期）、关系（哪个场景变化）、缺陷（哪个萌芽）。

### 第一阶段：追回梦（1–4 章）

#### 第 1 章：入侵与反杀

| 维度 | 内容 |
|---|---|
| **入口** | 主角在驻地床上睡下，醒时发现自己在高中梦境（玩家自己的巢，童年记忆 2027–2030） |
| **明线 A** | 主角的高中梦境被入侵，他需要保护自己的梦 |
| **关卡事件** | 催收员带着认领令来抢夺无主梦境；主角反杀 |
| **暗线 D（萌芽）** | 玩家注意到入侵者临死前说"你不该醒来"——催收员以为目标是锚定者，不该能清醒反抗。超忆症第一次显形，但被解释为"主角自己记得" |
| **势力 F** | 首次出现：入侵者（行业催收员，无名组织） |
| **玩法 G** | 基础战斗（正弦弹跳移动、SP/体力、武器切换、入侵者识别） |
| **幽默 H** | 入侵者放完狠话后一弹一弹地倒下；系统提示"目标已移出场域" |
| **传闻 N** | 特长期：主角有超忆症，记得所有梦 |
| **关系 I** | 第一次感受到"被盯着"——这是主角巢的第一次被破 |
| **梦境被夺的关键物品** | 入侵者留下的"梦境资产认领申报单"——P1 暗线发动机，纸面流转开始 |
| **碎片 / 证据** | 提交"黑制服"素材可触发隐藏对话 |
| **时长** | 25–35 分钟 |

#### 第 2 章：证据与公安

| 维度 | 内容 |
|---|---|
| **入口** | 床 → 任务，调查上一章入侵者来源 |

| **关卡事件** | 战斗中梦境公安突然出现，封锁现场，盘问主角；主角的梦境管理违反"标准流程"，公安要求提交证据 |
| **暗线 D（萌芽）** | 公安说"这段梦境应该不存在"——这句话让主角和玩家都感到奇怪 |
| **势力 F** | 首次出现 PSYCHO-5 / CPD（梦境公安）；上一章认领单的痕迹出现 |
| **玩法 G** | 证据提交机制教学（VR 头显面谈、素材槽位、警官反馈三种） |
| **幽默 H** | 公安要求填写"被盗梦境损失申报表"，最后一栏"您是否确认自己曾经拥有该梦境？" |

| **传闻 N** | 特长期持续：玩家"记得所有梦"是天赋 |
| **隔空 O** | 第一次出现"被改动的小东西"：主角的装备被某人不经意间摆正 |
| **碎片 / 证据** | 刷熟悉度解锁"童年医院走廊"素材 |
| **时长** | 20–30 分钟 |

#### 第 3 章：据点守卫与天然权限

| 维度 | 内容 |
|---|---|
| **入口** | 床 → 任务：保护一个据点（深梦网络委托，佣兵工作） |
| **明线 A** | 主角追查认领单下落，开始接深梦的活作为掩护 |

| **暗线 D（增强）** | 队友说"你上次不是说要留活口吗"——主角不记得；东西被动过，时间错位加强 |
| **势力 F** | 黑客地下组织（首次出现，但身份未明）；深梦网络（首次以雇主身份） |
| **玩法 G** | 据点攻防 + 团队协作 + 潜行（DESIGNER.ai 入侵任务） |

| **隔空 O** | 装备被动过 + 路线被标记（很轻，第一次明确被玩家感知） |
| **事件 M** | 天然权限事件（`narrative:designer-ai-innate-access`）——门是给他修的 |
| **碎片 / 证据** | 提交"据点守卫尸体"触发时间矛盾线索 |
| **时长** | 30–40 分钟 |

#### 第 4 章：第一次死亡（转折 1）

| 维度 | 内容 |
|---|---|
| **入口** | 床 → 任务：主角继续追查认领单，进入一个可疑梦境 |
| **明线 A** | 任务失败，认领单下落中断 |
| **关卡事件** | 主角在任务中被刺杀，几十分钟的死亡空间 |
| **死亡空间** | 白光 → 抽象空间（扭曲的走廊或纯白）→ 玩家可以走动，几个自言自语的对话框（"就在刚刚……人死后会到图书馆吗？"）→ 一行小字"你醒了？"（字体不同，像是别人留下的）→ 强制切回现实，主角在病床上醒来 |
| **暗线 D（明确）** | "你醒了？"——这不是问主角，是问原生人。玩家第一次看到"裂缝" |
| **演出要点** | 死亡空间使用迷幻视觉，不解释它是什么；"你醒了？"不配音、不高亮，玩家可能注意到也可能错过 |
| **机制变化** | 此后主角开始在梦境中发现留言和被动过的痕迹；超忆症的医学解释开始出现裂缝 |
| **幽默 H** | 死亡空间里的系统提示"连接异常。正在重新建立。" |
| **情感爆点 1** | 第一次死亡（迷幻处理）——裂缝起点 |
| **时长** | 20–30 分钟（短，但分量重） |

| **关系 I** | 主角与原生人公开争吵，但任务仍在推进 |
| **传闻 N** | 传奇顶峰前夕 |
| **百目压力 L** | 收网倒计时：百目确认原生人显形，紧急预案启动 |
| **时长** | 25–35 分钟 |

#### 第 10 章：主动停搏（转折 3）

| 维度 | 内容 |
|---|---|
| **入口** | 床 → 任务：主角被追杀 |
| **明线 B** | 任务目标"逃出梦境"——所有出口被封锁 |
| **关卡事件** | 梦境出口封锁 → 画面切到现实（同一张地图的现实层，主角站在医院门口）→ 玩家可移动 → 主角掏枪，对准心脏 → 选择开枪/放弃 |
| **死亡空间** | 白光 → 抽象空间 → 看到原生人背影（第一次"看到"对方），他在走远，头也不回 → 主角想喊，发不出声音 → 原生人消失 → 强制切回现实病床 |
| **暗线 D（分离）** | 连接彻底断裂；超忆症消失；主角不记得原生人 |
| **机制变化** | 主角失去超忆症，但可以通过其他方式（留言、证据、痕迹）追踪；开启双屏玩法 |
| **幽默 H** | 急救画面配严肃的"生命体征异常"提示，主角在地上以不体面姿势慢慢弹起来 |
| **关系 I** | 主角被黑客地下组织救出医院（他们曾经因为天然权限事件注意到他） |
| **情感爆点 3** | 主动停搏（信任的证明）——赌原生人会救他 |
| **时长** | 30–40 分钟（短关，但分量重） |

### 第三阶段：找回人（11 章）

#### 第 11 章：双屏追逐

| 维度 | 内容 |
|---|---|
| **入口** | 床 → 双屏：现实侧（主角在黑客掩体）+ 梦境侧（追踪原生人） |
| **明线 C** | 主角要在百目抓到原生人之前找到他 |
| **关卡事件（双线同时）** | 现实侧：与公安、黑客组织、科学家突入百目设施，破坏捕获档案/切断定位节点/保护证人；梦境侧：追踪原生人痕迹，清理百目猎手，开辟逃跑路线 |
| **两边互相影响** | 现实破坏节点 → 梦境侧逃跑路线多出出口；梦境改写节点 → 现实百目设备失去目标 |
| **暗线 D（生死未卜）** | 原生人也在逃主角；留言接力；最后原生人留下一个出口，消失 |
| **势力 F** | 百目全力捕获；公安 + 黑客 + 科学家作为盟友；深梦可能临时协防 |
| **玩法 G** | 双屏协作（现实 + 梦境）；追逃；破坏；护送 |
| **幽默 H** | 百目报告写"目标已完成空间转移"，实际是原生人从墙里蠕动出去了；公安要求"请提交证人消失证明" |
| **隔空 O** | 留言接力高潮：主角"我不是来抓你的"；原生人"你以前也这么说"；主角"这次不一样"；原生人"我看看" |
| **关系 I** | 主角站在世界视线下（缺陷救赎的第一次完成） |
| **传闻 N** | 圈内：传奇过气 |
| **百目压力 L** | 收网进行中 |
| **情感爆点 4** | 生死未卜（无法确认原生人是否还活着） |
| **时长** | 35–50 分钟（最长关） |

## 五、设计验收

每关完成后必须检查：

1. **明线推进**：主角在追回/夺回/找回梦的路上走了一步
2. **暗线变化**：原生人显形有微变化（哪怕只是一个"被摆正的装备"）
3. **势力介入**：至少有一个势力事件推进
4. **玩法解锁**：玩家学到或使用一个机制
5. **冷面幽默**：至少一个锚点自然发生
6. **隔空关系**：至少有 O 的一种形式出现
7. **现实与梦境同地图**：现实活动可在任务地图内发生
8. **睡下入口**：从驻地床开始，无独立过场
9. **传闻双读**：玩家和百目读同一份传闻（如果适用）
10. **缺陷萌芽**：主角不信任他人评价的缺陷有表现
11. **关系弧光**：四类局外场景关系有推进
12. **百目压力曲线**：按曲线推进
13. **情感密度**：玩家离开关卡时情感有所变化
