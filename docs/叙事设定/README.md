## 核心设计原则

### 轻叙事

- **不是"不叙事"，而是"可以很深，但表面要轻"**
- 不强制播片，不长对话，不复杂反转
- 玩家可以"不深究"也能学会所有机制，但"愿意深究"会发现完整的情感内核

### 三层体验结构

| 层次 | 玩家类型 | 体验内容 |
|---|---|---|
| 表层 | 所有玩家 | 扁平的"金手指佣兵探索真相"故事 |
| 中层 | 愿意观察的玩家 | "不对劲"的细节与惊喜/惊吓 |
| 深层 | 深挖证据/素材的玩家 | 完整的"主体性裂缝"情感内核 |

### 无厘头 + Z世代黑色幽默

- **无厘头体现在机制本身**：入梦按传票收费、清理=删除、运营商标榜"你的睡眠值得更好的版本"
- **黑色幽默体现在张力**：主角知道自己在重复资本的行为，但他需要钱活下去

### 碎片化叙事的载体

- **门缝纸条**：主线任务节拍的解锁闸（告知书/信/传票/水电费）
- **梦境留言**：原生人的存在证明（墙上的字/地上的标记）
- **证据提交**：深层真相的拼图（特定组合触发隐藏对话）
- **素材描述**：世界观的侧面呈现（某些素材藏着"童年实验"的线索）
- **自言自语**：主角的内心独白（简短、自嘲、带点黑色幽默）

## 核心叙事线

### 主角的身份弧光

**从**：麻木的工具人（"我是超忆症患者，用这个能力换钱"）  
**到**：主体性裂缝（"我不是唯一的我？原生人醒了？"）  
**到**：对立与协作（"谁主谁从？我们能共存吗？"）  
**到**：信任的跨越（"我把命交给你"）  
**到**：融合与遗忘（"我们本来就是一个人"）

### 主线的四个核心爆点

1. **死亡的几十秒**（第三/四章）：迷幻处理，主体性裂缝的起点
2. **"他在哪？我在哪？"**（第六/七章）：存在论焦虑的爆发，认知颠覆
3. **开枪自杀**（第九/十章）：主动的、信任的、绝望的赌注
4. **宿命的回归**（结局）：融合与遗忘，开放式的情感闭环

## 与其他设计文档的关系

- **表现系统**：颜色语义（纯白=梦境边界与过载）、驻地演出（纯白显形传送）
- **创作系统**：素材库承载主角的收藏、UGC是主角行为的玩家镜像
- **运营系统**：驻地HCI（门缝纸条）、证据提交玩法、局外养成
- **工程治理**：稳定叙事ID体系（`role:` / `condition:` / `technology:` / `rule:` / `narrative:`）
