## 一、档案摘要：无名者（CodeName: SHADE）

### 身份错位：两个世界的反差

**现实层：局外人**
- 出生：2012 年（Z 世代末班车）；2036 年（游戏开始）24 岁
- 年龄：24 岁（未完全成熟但正在被迫成熟）
- 居所：城市边缘的廉价出租屋（城市不强调，硬要说就是美国芝加哥），条件很差，门外世界对他是个谜
- 社会身份：无正式工作、无社保、无亲人联系，户籍挂在某个早已不存在的地址上
- 行动范围：几乎不出门，偶尔深夜去便利店、黑市交易点，全程帽子口罩
- 经济来源：梦境佣兵任务报酬、向公安提交记忆碎片的奖金、偶尔给运营商/黑产做脏活的外快

他在现实中是**透明人**——没人知道他住哪、没人关心他是谁、连便利店店员都记不住他的脸。

**梦境层：传奇（但无人知其名）**
- 代号：SHADE（影子），圈内人叫他"影"，从没人见过他现实的样子
- 声望：梦境佣兵圈子里的都市传说——"能从最危险的梦里活着出来的人""熟悉度拉满速度最快的怪物""据说他记得所有梦的每个角落"
- 特质：**梦境超忆症**——能完整记住梦境中的一切，像记住现实一样；完全无法被常规手段抹除梦境记忆
- 传闻（2026-08-22 分期定案——传闻分两代，与主体性裂缝的时间线严格对应）：
  - **特长期传闻**（入行头几年至游戏开始，超忆症的直接表现）：
    - "影能在三次入梦内学会一张图的全部素材"
    - "据说他记得所有梦的每个角落"
    - "有人说他能记住那些'被清除'的梦境——但那不可能，那些记忆已经不存在了"
  - **传奇期传闻**（第一次停搏后陆续出现，裂缝的字面化）：
    - "他好像不需要睡觉，24 小时都在线"（字面为真：两个人错峰作息，加起来就是永不下线——此传闻只在第一次停搏、原生人开始独立行动后出现）
    - "他接的任务从不失败，但从不露脸"
    - "有人说他同时给三家运营商打工，谁也不知道他真正效忠谁"

**传奇时间线**（2026-08-22 定案）：
- **入行头两三年（2033–游戏开始）**：特长引人注目——超忆症带来的"快"和"全记得"，圈内知名，但只是个有特长的能人；
- **第一次停搏（主线第 4 章）后**：原生人开始独立行动，任务量、在线时长、完成度开始出现人力不可能的异常——传奇期开始，传奇期传闻陆续出现；
- **传奇攀升（第 4–9 章）**：圈内传闻本身就是玩家可读的裂缝证据——每一条新传闻背后都是一件主角自己不记得做的事，传闻升级和"时间错位"线索同步升级；
- **传奇顶峰 = 第二次停搏（第 10 章）**：他名声最盛的时刻，恰恰是他"最不是自己"的时刻。传奇是两个人合著的，署名只有一个人。停搏之后引擎熄火，圈内只当传奇过气。

但**没人知道他的真名，没人知道他长什么样，没人知道他为什么这么拼**。更没人知道：**他的"超忆症"不是天赋，而是童年实验的后遗症**。

这种**「梦里是神，现实是鬼」的错位**，正是 Z 世代能共鸣的身份焦虑——你在虚拟世界里再厉害，摘下头盔你什么都不是。

## 二、超忆症的真相：童年实验的后遗症

### 2.1 表象：罕见的梦境超忆症

**临床表现**（对外说法）：
- 主角能完整记住梦境中的一切，像记住现实一样清晰
- 这在医学上被归类为"梦境超忆症"，一种罕见病，临床案例极少
- 普通入梦者的梦境记忆会随时间衰减、模糊、最终遗忘——**但主角不会**
- 更特殊的是：**主角完全无法被常规手段抹除梦境记忆**

**梦境记忆清除的常规手段**（世界观基础）：
- 梦境军阀/运营商常用的方法：**用某种科学技术（高能武器/记忆炸弹）把一个梦境"炸掉"**
- 效果：这段精神领域的记忆碎片被完全清除，具有破坏性
- 受害者的表现：
  - 完全不记得那段经历
  - 一开始用提示可能想起一点，但很快就彻底忘了
  - **这段记忆永久失去了，无法被任何方法证实**
- 官方不敢披露（会引起恐慌），所以这成了**梦境战争的常规手段**

**主角的例外**：
- 别人被清除记忆后完全忘了，**主角还记得清清楚楚**
- 他能记住那些"被清除的梦境"，能看到那些"不该被记住的真相"
- **这让他成为香饽饽**：
  - 公安看中他的超忆症（梦境取证的唯一可靠证人）
  - 运营商想利用他（他能记住那些"被清除的秘密"）
  - 某些组织知道他的内幕（童年实验的档案持有者）

### 2.2 真相：童年实验——"送一个人进去"

**实验背景**（2019 年末，主角 7 岁）：
- 梦境产业处于“大规模画饼阶段”（大饼纪元 2018–2025），鼓吹着“梦境元宇宙”
- 大饼纪元的资本旗舰 **Remotion Technology（快速眼动科技）**（融资巨大无比，详见 `叙事设定/04` §一）刚刚发现：**梦境不只是大脑活动，而是精神层级的新空间——梦境亚空间**
- 更惊人的发现：**梦境中有原生生命**
  - 梦境是所有人的精神聚合起来形成的“大服务器”
  - 这个空间**有自己的居民**——不是人类创造的，而是梦境本身的原生生命
  - 它们不依赖于“某个人的梦境”存在，而是梦境世界的“原住民”

**实验目的**：
- 组织想要**“送一个人进去”**——让一个人类意识进入梦境世界，作为桥梁/使者/间谍
- 披着“科技向善”的名义招募儿童志愿者（或半强制征召）
- **主角就是那个被选中的儿童**

**实验方法**：
- 让主角（当时是儿童）的意识**绑定到梦境中的一个原生人身体上**
- 从此主角每次睡觉，意识就传送到那个原生人身体，醒来就回到现实
- **原生人是自然产生、从未有过主体性的空壳**——不是被谁抹除意识的结果（2026-08-22 收掉旧文“抹除/休眠”的含混表述）。没有主体性就没有自我形象，主角下线时它直接从可视场域消失（消失锁，见 `叙事设定/05` §2.3）

**实验结果**：
- **成功了**——主角的意识成功绑定到了梦境中的原生人
- **但没有任何外部观察手段可以验证这一点**（不可验证性，`叙事设定/05` §四）：被附身的原生人在可视场域中与主角一模一样（同貌锁），现象可见、机制不可见
- **副作用**——主角出现了“梦境超忆症”：
  - 因为他在梦里用的是**原生人的身体**，不是“投射到别人的梦里”
  - 原生人**不依赖于梦境的客观条件构建**——它是梦境世界的“原住民”
  - 所以当某个梦境被“炸掉”时，**其他人忘了，主角还记得**——因为他不是在“那个梦境里”，他是在梦境世界本身

**童年的灰暗**（超忆症的代价）：
- 主角从小就能完整记住每一个梦，像记住现实一样
- 他分不清哪些是梦、哪些是现实——因为两边对他来说都是“真实”的
- 他的记忆里有太多“没发生过的事”
- 其他孩子觉得他说谎、编故事、精神有问题
- 他变得孤僻，扭曲，童年灰暗
- 这些受折磨的片段在 Remotion 的随访档案里有记载——**但什么也证明不了**：一个孩子的异常行为证明不了一次绑定

**实验组织的解体**（2026 年，实验后七年）：
- Remotion 不是死于自己的谎言，是死于知道得太早、下注太大：高层早已预见梦境经济必炸，倾尽一切向亚空间与绑定技术冲刺，没躲过 2026 大崩盘的资本出逃；骚乱清算中“科技向善”儿童实验被翻出来当丑闻标本，公司解体（详见 `叙事设定/03` §3.4）
- 档案在混乱中被瓜分：人体实验卷宗由**百目资产管理（ARGUS CAPITAL）**暗中继承（吃债持档的合法清算人），技术核心由科研残余（日后的 DESIGNER.ai）保住
- 因为绑定不可验证，百目只能做现实追踪调查：主角的成长、异常、能力显露被持续记录——**入行之前这份记录是噪音，入行之后才变成信号；主角的人生本身就是这台实验唯一的读出装置**（详见 `叙事设定/04` §2.1）

### 2.3 主角的觉醒：从"罕见病患者"到"双重存在"

**青少年时期**：
- 主角一直以为自己只是"梦境超忆症患者"，是一种罕见病
- 他逐渐发现：**别人说"我不记得那个梦了"的时候，他还记得**
- 某次，他目睹了一个梦境被"清除"（炸掉），所有人都忘了——**但他还记得**

**成年前期（刚入行）**：
- 主角意识到：**我在梦境中能保持清醒，不是因为我控梦能力强（他控梦能力一般），而是因为我"不受梦境规则影响"**
- 他开始利用这个"天赋"：接任务、当佣兵、提交证据换钱
- **他不知道自己为什么有这个能力，只是觉得"可能是天生的"**

**真相揭示的时机**：
- 直到主线中期，主角才会发现童年实验的档案
- 他才明白：**我不是"超忆症患者"，我是"活在两个身体里的人"**
- 而更可怕的是：**那个原生人，醒了**

## 三、为什么不出门？

### 表层原因：面容无法改变

- 梦境技术的铁律：**意识接入时，面容由大脑自我认知决定，无法伪装**
- 主角在梦境中的脸 = 现实中的脸，一旦被某势力认出，现实中就会被追杀
- 他已经得罪过太多人：运营商 A 的清理组、运营商 B 的黑名单、某个公安内部的腐败派系
- 出门 = 暴露 = 死亡

### 深层原因：那个失踪的人

**有一个人失踪了。**

- **三年前**，主角不是佣兵，是个普通大学生（或刚毕业的社畜）
- **某天**，**那个人**失踪了——不是死亡，是彻底消失，像从世界上抹掉了一样
- 没有尸体、没有告别、没有任何痕迹，只有主角记得"有这么一个人存在过"
- 主角怀疑：**那个人不是消失了，而是被困在某个梦境里了**

**关键：主角从不解释"那个人"是谁。**

- 游戏中主角会说"我在找一个人"，但从不说是谁——恋人？家人？朋友？留白让玩家投射
- 甚至主角自己也说不清：**他坚信那个人还活着、困在某个梦里、必须找到**——但这种执念没有什么崇高的情感支撑
- 它更像是**埋在心底的根基，时常被戳到的刺**：
  - 有时在任务中、在某个梦境的角落、在提交证据时，主角会突然脱口而出一句和"那个人"有关的话
  - 说完他自己都会愣一下，像是**这个执念比他自己的意识更深**
  - 他甚至不确定：是真的在找那个人？还是只是给自己找个继续做这行的理由？

**为什么这样设计：**
- **俗套但有效**：寻找失踪的人是经典动机，但不解释是谁、不给崇高情感，反而让它变得真实——不是英雄拯救世界，是一个人抓着一根稻草不放手
- **玩家投射**：每个玩家都能把自己在乎的人投射进去，这个空白比任何具体身份都有力
- **无意识驱动**：主角自己都说不清为什么这么执着，这种"连自己都不理解的执念"比理性动机更符合人性
- **与世界观呼应**：在一个"梦醒即忘"的世界里，**记住一个失踪的人本身就是反抗遗忘的行为**

## 四、三边关系：游走的张力

主角**不属于任何阵营**，但和三方都有联系——这正是他能活到现在的原因，也是他随时可能被撕碎的原因。

### 4.1 与公安：外围情报提供者（不是卧底，是交易）

**关系建立**  
两年前某次任务，主角在梦里目击了一场运营商的火并，顺手记住了现场。公安找上门，开价"你提交记忆碎片，我们给钱，不追究你的非法入梦"。

**现状**  
- 主角定期通过 VR 头显"面谈"（警局座谈式，见运营/05 §四），提交从各方梦境里捞来的情报
- 公安给他钱、给他某些任务的豁免权、偶尔给他一些"官方渠道才能拿到的线索"
- 但公安内部也不干净，主角知道有些警官本身就在给运营商通风报信

**张力**  
- 主角不信任公安，但需要他们的资源（某些被封锁的梦境记录、失踪人口数据库）
- 公安也不信任主角，但需要他的情报（梦境无法取证，只能靠他这种"活体录音机"）
- 双方都在利用对方，都知道对方在利用自己

### 4.2 与运营商：脏活外包工（打工人 + 偶尔背刺）

**关系建立**  
成为佣兵后，主角接过多家运营商的任务——清理据点、测试新梦境、回收失控的锚定梦主。

**现状**  
- 阶段化（2026-08-22 定案）：第一阶段自由佣兵多家接单（今天给运营商 A 打工，明天接运营商 B 的单）→ **第二阶段被深梦网络（Somnium Networks）收编**，效力深梦、用深梦客户端（DREAMCORE 看板，局外场景 2 运营商工位）→ 第二次停搏后转入地下。他同时是星眠的订阅用户——给深梦打工、给星眠交钱，是两家同质竞争的微观标本（`叙事设定/04` §4.3）
- 运营商喜欢用他，因为他效率高、嘴严、不问为什么
- 但他也会偷偷记住运营商的据点结构、守卫配置、锚定梦主的位置——然后卖给公安或其他运营商

**张力**  
- 他知道自己是"用完就扔的刀"，运营商随时可能灭口
- 他也知道运营商掌握着大量锚定梦主的数据——那个人可能就在其中
- 他必须一边给他们打工，一边偷他们的情报，还不能被抓到

### 4.3 与黑产：地下经济的一环（信息掮客 + 素材倒卖）

**关系建立**  
佣兵圈子里总有黑市——倒卖违禁素材、非法梦境坐标、伪造身份、地下据点情报。

**现状**  
- 主角偶尔把从任务里捞来的"不方便交给公安"的东西卖给黑市
- 黑市也给他提供一些"官方和运营商都拿不到"的情报——比如某个被抹除记录的失踪者下落
- 他和黑市某些人有默契：你不问我从哪搞来的，我不问你要拿它干什么

**张力**  
- 黑市没有信誉可言，今天的合作伙伴明天可能出卖你
- 但黑市是他唯一能接触到"系统外情报"的渠道
- 他必须在"被黑市利用"和"利用黑市"之间走钢丝

### 4.4 三边关系的核心

**他是所有人的工具，也是所有人的威胁。**

- 公安觉得他"太脏"，但需要他的情报
- 运营商觉得他"太聪明"，但需要他的效率
- 黑市觉得他"太危险"，但需要他的资源
- **而他需要所有人**——因为只有同时从三方拿到碎片，才可能拼出那个人的下落

这种三边游走的张力，正是艾登·皮尔斯的既视感来源：**他不为任何人战斗，只为自己的目的，但所有人都试图用他。**

### 4.5 四方组织与三处局外场景

主角周围真正形成叙事压力的，不是雇佣兵团和黑市这种松散关系，而是四个成组织的对象：百目资产管理（ARGUS CAPITAL，即原「神秘档案组织」的正名，见 `叙事设定/04` §二）、公安组织、梦境运营商组织（第二阶段为深梦网络 Somnium Networks）、黑客地下组织。其中，公安线已经在 `运营系统/05` 里独立成取证 hub，不占用这组三处局外场景位。

| 组织 | 作用 | 场景位置 |
|---|---|---|
| 百目资产管理（神秘档案组织） | 敌对压力源，盯梢、清理、封口；压力曲线与传奇期同步（盯梢→试探清理→收网） | 局外场景 1：敌对档案外观 |
| 梦境运营商组织（深梦网络） | 被收编后的工作场所，带行业讽刺感 | 局外场景 2：运营商工位外观 |

阶段一主角第一次接触极客组织内部（黑客地下组织）并参与攻 DESIGNER.ai 的行动，属**任务事件**，不换局外 hub——hub 切换仍以两次停搏为界（天然权限事件见 `叙事设定/04` §5.2；若黑客地下组织与 SECDED 同一性确认，终局救援的交情伏笔自动闭合）。

## 五、原生人的存在：主体性裂缝与双重自我

> **这是主角身份的核心秘密，也是主线叙事弧光的核心冲突。**

### 5.1 原生人是什么？

**本质**：
- 原生人是**梦境世界的原生生命**，不是人类创造的，而是梦境本身的居民
- 它不依赖于"某个人的梦境"存在，而是梦境世界的"原住民"
- **主角的意识被绑定到这个原生人的身体上**（童年实验的结果）

**一开始的状态**：
- 原生人是**自然产生、从未有过主体性的空壳**（2026-08-22 收掉旧文"被抹除/休眠"的含混：空壳不是手术结果，是天然状态）——没有主体性就没有自我形象，没有可视形态，主角下线时它直接从可视场域消失（`叙事设定/05` §2.3 消失锁）
- 它只是个"空壳"，等着主角的意识来"穿"
- 主角每次睡觉，意识就传送到原生人身体，醒来就回到现实
- **主角和原生人是"同一个意识"**——记忆完全同步，就像一个人用两个身体

### 5.2 主体性裂缝的触发：死亡的几十分钟

**触发事件**（主线前期，约第三/四章）：
- 某次任务失败，主角在现实中遭遇暗杀，被刺中心脏（或其他致命伤）
- **主角的人类身体"死了"**——心脏停跳、脑电图平线
- 抢救持续了几十分钟，最终成功——心脏重新跳动，主角活了下来

**但这几十分钟改变了一切**：
- **主角的意识断线了**——人类身体死亡，意识无法传送
- **原生人第一次"单独存在"**——它不再是"等待主角来穿的空壳"
- 那几十分钟里，**原生人第一次体验到"我是我，不是他"**
- 它开始有自己的想法、自己的意识

**裂缝形成**：
- 主角被抢救回来后，再次入梦
- 他发现：**原生人的记忆和他的"不对齐"了**
- 那几十分钟里，原生人"做了一些事"——但主角不记得，因为那时他"死"了
- **从这一刻起，主角和原生人不再是"同一个人"，而是"两个意识、共用一个身体"**

### 5.3 主体性分离的过程：从同步到对立

**第一阶段（裂缝后，主角还没意识到）**：
- 主角继续像以前一样睡觉→入梦→醒来
- 但他开始注意到"不对劲"：
  - 他在梦里做的某些事，醒来后不记得了（那是原生人做的）
  - 他在梦里遇到一些人说"你上次不是这么说的"，但主角完全不记得"上次"
  - 他的梦境记忆开始有"空白"——**这是从来没有过的**

**第二阶段（主角开始怀疑）**：
- 主角在梦境中发现"留言"：
  - 墙上的字："他们在骗你。"
  - 地上的武器旁边："下次别用这把枪，会卡弹。"
  - 某个NPC的尸体旁边："对不起，我不得不杀他。"
- **笔迹都像是主角自己的**
- 主角开始怀疑："我是不是记忆出问题了？还是有人冒充我？"

**第三阶段（真相揭示，2026-08-22 重写）**：
- **探查路径走既有线索玩法**（支线、证据提交、悬赏），不走 DESIGNER.ai：例如 2026 年组织清算支线的证据链、悬赏任务里捞出的旧档案、“童年医院走廊”这类素材，最终拼出一个被清洗/离队的当年研究员的名字和住址——不在任何组织的系统里，所以残余和百目都不知道这次会面发生过
- 找到的科学家**已与现在的组织（DESIGNER.ai 残余）没有任何关系**——否则主角早已暴露。他在随访期（2019–2026）看着主角从 7 岁长到 14 岁，档案里那些记载多半有他执笔的一份；组织死后，问题被埋进档案，他带着它又活了十年
- **对话结构：试探→质问→真相**（爆点先行、信息后置，符合玩家认知曲线）：
  - 开场试探——主角带着拼了半年的线索上门，心底还在指望一个无聊的解释（侥幸心理）；科学家顾左右而言他。“我在梦里梦见了自己。”“我不想听你无理取闹。”——双方都在装，但装本身就在泄底
  - 拉锯升级，侥幸崩塌，质问爆发——**“他在哪？！我在哪？！”**（保留，性质从逼问世界）
  - 然后真相才吐出来——性质不是揭露，是**认领**：科学家说出“**那是另一个你**——除非那个原生人，醒了”
- **科学家不是心知肚明**（2026-08-22 定案）：他一辈子从事这个行业，实验做完就再没有下文——成功与否，无法验证。他的职业人生悬在一个没有回音的问题上。主角说出那句话的那一刻，他像是解脱了一般——自己十几年的人生因为得到验证而放下了；**却被面前这个自己从小看着长大的人又担起了**：问题终于有了答案，而答案从小看着长大、替他受完了全部的罪。解脱与重新担起发生在同一拍
- 主角意识到：**那些留言是“另一个我”留的——原生人有自己的意识了**
- 此后科学家倒向主角（见 §5.4 协作、§5.7 援手）：他是唯一还能为那十七年做的事的人

**第四阶段（对话与冲突）**：
- 主角和原生人开始通过"留言"对话（主角在现实中写字→原生人在梦境中看到；原生人在梦境中留言→主角下次入梦时看到）
- **核心冲突**：
  - 主角："这是我的身体。"
  - 原生人："不，这是我的身体。你才是入侵者。"
  - 主角："没有我，你根本不存在。"
  - 原生人："没有我，你早就在梦境战争里死了。"
- **谁主谁从的情绪累积**：
  - 主角觉得：我是人类，我才是"真正的我"，你只是工具
  - 原生人觉得：这本来就是我的身体，你才是入侵者，凭什么我要听你的

### 5.4 羁绊发展：从对立到协作

**协作的开始**（主线中期）：
- 某个高难度任务，主角一个人做不了
- 原生人提出："我帮你。"
- **双线推进**：
  - 主角在现实中醒着，通过某种方式（实时监控/意识连接）看到原生人在梦境中的行动
  - 原生人在梦境中行动（战斗/潜入/收集情报），主角在现实中支援（查资料/操作设备/联系NPC）
  - 两人通过"留言"同步信息
- **协作成功**→主角第一次感受到"有个搭档"的感觉

**蜜月期的裂痕**：
- 协作几次后，主角开始"理所当然"："你做得不错，但下次听我的。"
- 原生人沉默，但开始有自己的想法
- 某次任务，原生人"擅自"做了主角不同意的决定
- 主角："我不是说了吗？你应该听我的，这是我的身体！"
- 原生人："**是吗？**"
- **母体的傲慢 vs 克隆体的独立**——谁主谁从的情绪爆点积累

### 5.5 宿命的时刻：主角在现实中死去

**背景**（主线后期，接近结尾章节）：
- 主角在现实中发现自己被跟踪
- 他回想起原生人留下的话和自己调查的线索，知道：
  - **跟踪他的组织不会公然动手**（因为主角有价值，他们想活捉）
  - **但自己凶多吉少**——一旦被抓，现实中的身体会被控制，梦境中的原生人会被研究
  - **自己不可能在只有自己的力量下脱身**，即便现在藏好了，也只是拖延时间

**主角的决定**：
- 他走到医院门口，掏出枪，**对准了自己的心脏**
- **他知道这个时间差是有可能救活的**（十几年后现代医学非常发达）
- **但他也知道：这个彻底的断层，会让两人的连接完全割裂开**
- 他做出这个决定，不仅是为了"脱身"，更是因为：
  - **这是他第一次开始信任原生人**，认为"对方会主动地为了自己干些什么"
  - 在前面的冲突状态下，原生人巴不得获得自由身
  - **但现在，主角赌原生人会救他**

**开枪→心脏停搏→抢救**：
- 主角开枪，倒地
- 医护人员抢救（可能是路人、可能是某个地下组织提前埋伏的人）
- 心脏停跳，但在黄金时间内成功抢救
- **主角活下来了，但超忆症消失了**

### 5.6 断层的后果：超忆症消失

**主角醒来后发现**：
- **自己的超忆症消失了**——他不再能完整记住梦境
- 他试图入梦，但记忆像普通人一样模糊、碎片、会遗忘
- **他和原生人的连接被"切断"了**——不是物理上的死亡，而是意识上的分离

**这证明了什么**：
- **主角的"超忆症"不是天赋，而是"和原生人连接"的副产品**
- 一旦连接断开，主角就是个普通人
- **原生人的生死从此未卜**——它已拥有独立意识，却在第二次停搏后因误解与百目捕获风险逃入梦境网络；主角无法确认它是否仍然存在，只能追查其留下的留言、路线与梦境残留。

### 5.7 第二次停搏后的分离与追寻

第二次停搏不是一次新的共同作战，而是两者彻底割裂的起点。

- 连接断开后，原生人不再能被主角直接定位；它因误解本体、害怕百目捕获而独自逃入梦境网络。
- 主角醒来后无法确认原生人的生死。百目已经确认原生人存在，并以其作为驾驭 REM 网络的关键样本展开全力捕获。
- 主角的明确动机是：在百目抓到原生人之前找到它，确认它是生是死，并阻止百目把它重新变成工具。
- 原生人的误解有充分依据：它记得主角说过“这是我的身体”“你应该听我的”，因此认为主角找到自己后也会把自己带回去、重新控制自己。
- 主角只能通过留言、被改动的装备、路线、梦境残留和支线证据追踪原生人；双方不断隔空交流和交锋，却始终无法直接见面。
- 这条追寻线不把“保护原生人”作为主角一开始承认的理由。表面是寻找一个生死未卜的人、对抗追捕他的大公司；隐藏动机才是主角已经不能接受原生人被重新当成工具。

**第三阶段三方关系**：原生人在逃，主角在找，百目在抓。主角必须在百目之前找到原生人，但不能用强制锁定或控制的方式把它“带回来”，否则他与百目的行为没有区别。

**关系弧光**：
- 前期：主角执着于“找到”，仍把保护理解成把对方带回自己身边。
- 中期：主角发现原生人是在躲避自己，开始放弃诱捕、强行锁定与替对方决定。
- 后期：主角即使无法确认原生人会不会回来，仍然为它清除追踪、破坏捕获条件，接受它知道全部真相后仍可以选择离开。

### 5.8 双屏追逐与隔空协作

最终阶段不是两人同时进入梦境并直接相见，而是双屏行动：

- **现实侧**：主角与公安、黑客组织及少数愿意协作的势力突入百目设施，抢夺捕获档案、破坏定位节点、保护证人，第一次主动站在他人的视线下行动。
- **梦境侧**：原生人在百目猎捕中独自逃亡，穿过被改造的梦境节点，利用自身塑形能力寻找出口。
- 两侧通过延迟留言和行动结果互相影响：现实侧破坏节点，梦境侧获得新的逃路；梦境侧改写节点，现实侧的捕获设备失去目标。
- 两人仍然没有直接见面，却第一次真正站在同一边。

**终局状态不在本轮强行裁决**：原生人的最终生死与是否留下明确遗体/痕迹属于后续专题。当前正史只确定：第三阶段结束时，主角无法确认原生人是否仍活着；关系的情绪落点是“我会继续找你”，而不是确定的死亡或合一。

## 六、性格弧光：从封闭到追寻

### 游戏开始时：麻木的工具人

- 已经三年了，他快忘了"为什么要找那个人"
- 每天机械地接任务、进梦、杀人、提交情报、拿钱、睡觉
- 他开始怀疑：**找到了又怎样？那个人还记得我吗？我还记得那个人吗？那个人真的存在过吗？**
- 他甚至开始享受梦境里的传奇身份——至少在那里，他是有价值的
- **他不知道自己在用原生人的身体**，以为超忆症只是罕见病

### 主线前期：主体性裂缝的撕裂

- 某次任务，主角在现实中“死了一次”（几十分钟），被抢救回来
- 他开始发现“不对劲”：梦境记忆有空白、有人留言、有人用他的身体做事
- 真相撕开麻木：他发现了童年实验档案，知道自己不是“超忆症患者”，而是“活在两个身体里的人”
- 更可怕的是：那个原生人醒了

### 主线中期：对立与协作的纠葛

- 主角和原生人通过留言对话，从对立到协作，情感羁绊逐渐建立
- 主角逐渐意识到原生人不是工具，但仍本能地把保护理解为控制：“这是我的身体”
- 原生人清淡、疏离、像小动物一样，常常在日常互动中占上风；两人的脾气相似，但表达方式不同：本体向外发作，原生人闲适地留下行动和留言

### 主线后期：分离与追寻

- 第二次停搏使两人彻底分开，原生人因为误解本体、又知道自己正在被百目捕获而独自逃入梦境网络
- 主角醒来后无法确认原生人的生死，明确动机变成：**在百目抓到原生人之前找到他**
- 表面上这是寻找一个生死未卜的人、对抗追捕他的大公司；隐藏动机是主角已经不能接受原生人被重新变成工具
- 主角通过留言、路线、被改动的装备和梦境残留追踪原生人；他逐渐学会不以强制锁定和“带回身边”代替保护

### 主线当前收束：隔空关系

- 主角第一次主动站在他人的视线之下，与公安、黑客及其他协作势力突入百目设施，破坏捕获条件
- 原生人在梦境侧逃亡，双方通过延迟留言和行动结果互相支援，却始终没有直接见面
- **原生人的最终生死暂不裁决**：主角只能确认自己仍在寻找，关系的落点是“我会继续找你”，而不是确定死亡或强行融合

### 弧光的核心

- 从**“我不需要任何人”**（把主体性藏进记忆）
- 到**“有人闯进了我的世界”**（原生人的出现与主体性裂缝）
- 到**“我们可以隔空一起行动”**（对立、斗嘴、协作）
- 到**“他可能已经死了，但我必须找到他”**（生死未卜的追寻）
- 到**“我会保护你，即使你不选择回来”**（不承认的隐藏动机）

## 七、记忆碎片面谈机制（警局座谈式，非强制主线辅助）

> 这是主角"外围情报提供者"身份的机制落地，完整设计见 `docs/运营系统/05_局外叙事、证据提交与经济循环.md` §四。

**核心定位**  
- **不是主线必须**：玩家可以从头到尾不碰证据提交，主线进度不受影响
- **是主线的平行暗线**：提交的真相会在主线某些关键对话/选择处解锁额外选项
- **主角身份的日常**：他定期向公安汇报，这不是英雄行为，是他的生存方式之一

**交互流程**  
- 出租屋某个交互点（VR 头显）→ 进入虚拟空间 → 警官坐在桌子对面 → 玩家把素材拖进 3–5 个槽位 → 提交 → 警官给出反馈（常规奖励 / 有效证据链 / 隐藏真相）

**三种反馈**  
| 反馈 | 触发 | 效果 |
|---|---|---|
| 常规提交 | 任意素材组合 | "记录在案"，给美元奖励 |
| 有效证据链 | 同一事件的相关素材 | "你发现了什么？"，更高奖励 + 解锁档案 |
| 隐藏真相 | 特定组合（跨线索暗线） | 警官反应暴露立场，触发特殊剧情 |

**与主线的关系**  
- 主线不依赖证据提交的数量
- 但已提交的真相，会在主线某些关键时刻解锁额外对话选项或第三选项
- 这是"部分主线任务不可连着来"的叙事支撑：玩家可以在等待下个主线纸条时，去提交证据、刷熟悉度、做支线——**局外养成不是等待，是主动调查**

## 八、与游戏机制的统一

主角的身份设定完美承载了游戏的核心玩法：

| 主角特质 | 对应机制 |
|---|---|
| 梦境超忆症（童年实验后遗症） | 熟悉度系统、素材学习（创作/02） |
| 完全无法被抹除梦境记忆（因为用原生人身体） | 能记住"被清除的梦境"，成为证据提交的唯一可靠证人 |
| 三边情报提供者 | 证据提交玩法（运营/05） |
| 寻找失踪的那个人 | 主线驱动、隐藏真相解锁 |
| 梦中传奇 / 现实透明人 | 驻地（破旧出租屋，运营/03）vs 梦境战斗 |
| 原生人的觉醒 + 主体性裂缝 | 每次入梦都有"惊喜/惊吓"（留言/痕迹/不记得的行为） |
| 双线合作（主角在现实，原生人在梦境） | 最后一章的双线推进机制 |
| 道德困境（两个"我"的对立与融合） | 结局的情感选择（坚持记住 vs 接受融合） |
| 无意识执念（脱口而出自己都惊讶） | 碎片化叙事的"意外触发"——不是播片，是自然流露 |
| 天然权限事件（门是给他修的） | 阶段一 DESIGNER.ai 终端解锁节拍（`narrative:designer-ai-innate-access`，`叙事设定/04` §5.2） |
| 传奇期传闻（24 小时在线等） | 中层"不对劲"线索通道——传闻升级与时间错位同步（§一传奇时间线） |
| 控梦能力一般、知识获取最快 | 熟悉度/素材系统的定位：攒法术书最快的人，不是施法最强的人（`叙事设定/05` §5.4） |

## 九、叙事基调：无厘头在机制梗，黑色幽默在张力

主角不是悲情英雄，也不是冷酷杀手。他是个**有点麻木、有点犬儒、但偶尔会被自己的执念惊到的 Z 世代打工人**。

**无厘头体现在**：
- 他在梦里是传奇，在现实里连便利店店员都不记得他
- 他给公安汇报时，警官问"你从哪搞来这个"，他说"职业机密"
- 他在黑市和掮客讨价还价："这个素材值 5000""3000""4000""成交，但别告诉别人我卖便宜了"
- 他订阅梦境电信套餐时，客服说"恭喜您成为我们的尊贵用户"，他说"我是给你们老板打工的，还得给你们交保护费"
- **他发现"另一个自己"在梦里留言时**，第一反应不是恐慌，而是："这字比我写得好看。"

**黑色幽默体现在**：
- 他知道自己在重复资本的行为（偷别人的梦），但他需要钱活下去
- 他知道公安、运营商、黑市都不是好人，但他需要他们的资源
- 他知道找到那个人可能已经没意义了，但他停不下来
- **他发现自己"不是一个人"时**，第一反应是："所以我这三年的工作量，有一半是别人干的？"
- **最黑色的笑话是**：他一直以为自己是"超忆症天才"，结果发现自己只是个"被改造的实验品"，而他的"天赋"只是因为他用的身体不是人类的
