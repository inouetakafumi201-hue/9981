## 一、设计原则：轻叙事的三层体验结构

### 什么是"轻叙事"

**轻叙事 ≠ 不叙事**，而是：

- **表面要轻**：对话少、情节简单、不玩复杂反转，玩家可以"不深究"也能学会所有机制。
- **可以很深**：愿意观察的玩家能从细节、碎片、证据提交中拼出完整真相。
- **玩法驱动**：每一段主线都对应一个核心玩法解锁，叙事是教学梯子的外衣。

### 三层体验结构（设计目标）

| 层次 | 玩家类型 | 体验到的故事 | 获得的游戏内容 |
|---|---|---|---|
| **表层**（不深究） | 所有玩家 | 主角有金手指（超忆症），接任务、探索真相、完成任务 | 学会所有玩法机制，能玩全部内容 |
| **中层**（愿意观察） | 观察型玩家 | 发现"不对劲"的细节（留言、惊喜/惊吓、时间错位），意识到"有另一个我" | 感受到紧张感、好奇心、世界的异样 |
| **深层**（深挖证据） | 探索型玩家 | 拼出完整真相：主角是实验品、原生人的存在、主体性冲突、生死未卜的追逃与百目捕获逻辑 | 体验情感冲击、理解主角不承认却开始保护原生人的关系弧 |

**核心承诺**：表层玩家不会因为"不懂剧情"而卡关；深层玩家不会因为"剧情太浅"而失望。

## 二、主线的定位与功能

### 定位

> **一条职业成长线。玩家从一个刚入行的梦境佣兵，逐渐成为能构建自己梦境的"筑梦师"，同时一步步发现这个世界的真相。**

这条线足够直白（表层），但每个阶段都在释放新玩法、新区域、新势力、新的世界真相（中层 + 深层）。

### 功能（主线必须完成的任务）

1. **引导玩法**：每章对应一个核心机制解锁（战斗 / 熟悉度 / 素材 / 据点 / 建梦 / 证据提交 / 双线协作）。
2. **建立世界观**：通过碎片化线索（门缝纸条 / 证据提交 / 梦境残留 / NPC 闲聊）让玩家感受到"世界的运作方式"。
3. **推进情感弧光**：主角从“孤独的透明人”到“发现并协作的另一个意识”，再到第二次停搏后的生死未卜追寻；情感通过隔空留言、错身与追逃逐步升高。
4. **设置叙事节拍**：通过门缝纸条（任务简报 + 节拍闸）控制主线节奏，避免"无限连打"，留出局外养成的呼吸空间。

## 三、情感曲线与起承转合

### 情感曲线设计

主线的情感节奏遵循**四幕剧结构**（起 / 承 / 转 / 合），每一幕对应一个情感阶段，每个阶段有一个**情感爆点**。

| 幕 | 情感阶段 | 主角状态 | 玩家体验 | 情感爆点 |
|---|---|---|---|---|
| **起**（1-3 章） | 孤独的透明人 | 主角不知道原生人存在，认为自己是"超忆症天才" | 学习基础玩法，感受"世界的异样" | **爆点 1：第一次死亡**（几十秒的迷幻空间） |
| **承**（4-6 章） | 困惑与对立 | 主角发现"有人在留言"，开始调查，触发科学家对话 | 发现留言、触发真相、理解原生人存在 | **爆点 2：科学家对话**（"他在哪？！我在哪？！"） |
| **转**（7-9 章） | 信任的建立 | 主角和原生人从对立到协作，情感羁绊逐渐建立 | 双线合作、感受默契、体验"谁主谁从"的冲突 | **爆点 3：主动停搏**（信任的证明） |
| **合**（10-11 章 + 尾声） | 生死未卜与追寻 | 第二次停搏造成彻底分离；原生人逃亡，主角追查并对抗百目 | 追、逃、留言交锋、双屏协作；主角不承认却开始保护原生人 | **爆点 4：生死未卜**（主角找不到原生人，只能在百目之前追上他） |

### 四个情感爆点（核心设计）

**爆点 1：第一次死亡（迷幻处理）**
- **时机**：第一章或第二章，主角在任务中被刺杀
- **呈现**：一道白光 → 几十秒的"死亡空间"（可能是纯白、可能是抽象场景）→ 主角可以走动，但只有几个自言自语的对话框（"就在刚刚……人死后会到图书馆吗？"）→ 强制切回现实，在病床上醒来
- **表层**：主角命大，活下来了
- **深层**：玩家第一次看到"裂缝" — 死亡和梦境之间有某种连接

**爆点 2：科学家对话（"他在哪？！我在哪？！"，2026-08-22 重写：试探→质问→真相）**
- **时机**：第六章左右。主角的探查走既有线索玩法（2026 组织清算支线的证据链、悬赏任务捞出的旧档案、"童年医院走廊"类素材、证据提交），拼出一个被清洗/离队的当年研究员的名字和住址——**不走 DESIGNER.ai**，且会面不在任何组织的系统里，残余与百目都不知道
- **科学家设定**：已与现在的组织（DESIGNER.ai 残余）没有任何关系，否则主角早已暴露。他不是心知肚明——他一辈子从事这个行业，实验做完就再没有下文，成功与否无法验证（不可验证性，`叙事设定/05` §四）。他在随访期看着主角从 7 岁长到 14 岁，组织死后带着那个没有回音的问题又活了十年
- **呈现（试探→质问→真相，爆点先行、信息后置，符合玩家认知曲线）**：
  - 试探——主角带着拼了半年的线索上门，心底还在指望一个无聊的解释（侥幸心理）；科学家顾左右而言他。**"我在梦里梦见了自己。""我不想听你无理取闹。"**——双方都在装，但装本身就在泄底：如果真没什么，为什么不直接把人笑出门
  - 质问——拉锯升级，侥幸崩塌，爆发：主角抓住科学家的衣领，崩溃地喊：**"他在哪？！我在哪？！"**
  - 真相——性质不是揭露，是**认领**：科学家说出"**那是另一个你**——除非那个原生人，醒了"。主角说出那句话的那一刻，科学家像是解脱了一般——自己十几年的人生因为得到验证而放下了；**却被面前这个自己从小看着长大的人又担起了**：解脱与重新担起发生在同一拍
- **表层**：主角知道了"自己是实验品"
- **深层**：主角第一次直面"我不是一个人"的事实，情感崩溃；两个悬了十七年的问题（主角的"我是什么"、科学家的"实验成了吗"）在同一场对话里相撞，答案是同一句话

**爆点 3：主动停搏（信任的证明）**
- **时机**：第九章，主角被某组织盯上，无路可逃
- **呈现**：主角回想起原生人的留言和线索，判断"他们不会公然动手，但我凶多吉少"→ 主角做出决定：走到医院门口，掏出枪，**对准自己的心脏，开枪**→ 倒地、急救、心脏停跳几分钟→ 在"死亡空间"里，主角看到原生人的身影（第一次"看到"对方），但**原生人背对着他，在走远**→ 主角想喊，发不出声音→ 原生人头也不回，消失在白光里→ 主角在病床上醒来，发现**超忆症消失了**，**不记得原生人了**
- **表层**：主角用"假死"脱身，但超忆症消失了
- **深层**：主角第一次**主动选择信任**原生人（"我相信你会帮我"），而不是被动依赖；但代价是**连接断裂**，两人分离

**爆点 4：生死未卜（第二次停搏后的追寻）**
- **时机**：第二次停搏之后，第三阶段开启。
- **呈现**：连接彻底断裂，主角醒来后无法确认原生人的位置，也无法确认他是否还活着。原生人因为误解本体、害怕百目捕获，独自逃入梦境网络。百目同时展开全力捕获：他们已经从主角在现实中清醒状态下改写梦境的事件确认原生人存在，并把他视为驾驭 REM 网络的关键样本。
- **明线动机**：主角要在百目抓到原生人之前找到他，确认他是生是死，并阻止百目把他重新变成工具。玩家不需要先理解更深的原生人权利，只需要理解“一个和主角一起生活过的人生死未卜，正在被大公司追捕”。
- **关系张力**：原生人也在逃避主角，因为此前“这是我的身体”“你应该听我的”等冲突让他误以为主角找到自己后也会把自己带回去、重新控制自己。主角只能通过留言、被改动的装备、路线和梦境残留追踪他；双方始终无法直接见面，只能隔空交流和交锋。
- **百目的合理动机**：现有 REM、锚定梦主和运营商基础设施只会制造无法管制的梦境战争；人类没有梦境人权、知情权与可靠记忆。百目认为只有绑定原生人，才能真正驾驭 REM 网络并找到出路。他们不把原生人当人，而把它当成必要的研究材料和技术接口。主角的公开改写证明原生人不仅存在，还拥有强大塑形能力，因此百目认为必须加快捕获。
- **表层**：主角追查失踪的原生人，对抗百目资产管理。
- **中层**：主角一边追踪原生人，一边逐渐发现他是在躲避自己；百目在追捕，主角在寻找，原生人在逃亡。
- **深层**：主角嘴上仍然说自己只是在找回“自己的另一部分”，行动却已经变成保护一个他不愿承认其独立性的人。第三阶段的隐藏动机不是拯救世界，而是不接受原生人被重新变回工具。

## 四、章节结构与玩法映射（11 章 + 尾声）

### 4.1 局外场景拓扑

主线之外的局外体验不是一套单独的菜单树，而是三处等价场景的切换：神秘档案组织外观、梦境运营商工作场所、黑客地下组织掩体。公安组织的证据提交已经独立成 `运营系统/05` 的取证 hub，所以不计入这组三场景。

这三处场景共用同一套菜单功能、同一份逻辑层状态和服务器通讯契约，客户端只负责本地渲染换皮，不拆成三套菜单系统。神秘档案组织是敌对压力源，梦境运营商工作场所是主角被收编后暴露行业讽刺的中段，黑客地下组织掩体是最终藏身与协作的收束点。两次心脏停搏只是把主线外的局外体验切成三段的边界，不改变它们在拓扑上的对等关系。

| 章 | 玩法支柱 | 情感节点 | 表层叙事 | 中层细节（不对劲） | 深层线索（证据/素材） |
|---|---|---|---|---|---|
| **1** | 基础操作 / 入梦概念 | 主角被入侵，展示超忆症 | 主角在梦中被刺杀，反杀入侵者 | 入侵者临死前说"你不该醒来" | 提交"黑制服"素材触发隐藏对话 |
| **2** | 证据提交 / 公安关系 | 建立"提交证据换钱"机制 | 公安找上门，主角开始接任务 | 主角在"被清除"的梦境里，看到涂鸦"他们在撒谎" | 刷熟悉度解锁隐藏素材"童年医院走廊" |
| **3** | 据点攻防 / 团队协作 | 第一次"惊吓"（烂摊子） | 主角保护据点，但发现"有人动过我的东西" | 队友说"你上次不是说要留活口吗" | 提交"据点守卫尸体"触发时间矛盾 |
| **4** | 迷幻处理 / 裂缝起点 | **爆点 1：第一次死亡** | 主角在任务中被刺杀，几十秒的死亡空间 | 主角在死亡空间里看到一行小字"你醒了？" | 如果仔细探索死亡空间会触发隐藏独白 |

| **6** | 编辑器入口 / 真相浮现 | **爆点 2：科学家对话** | 主角经线索玩法（2026 清算支线/悬赏/证据提交）找到离队科学家；试探→质问→真相 | 科学家说"如果原生人醒了，你们会冲突" | 提交"童年实验档案"触发军事项目真相 |
| **7** | 双线意识 / 第一次对话 | 协作的起点（羁绊建立） | 主角和原生人通过"留言"第一次对话 | 原生人说"你是我的另一半，或者我是你的" | 无 |
| **8** | 双线推进 / 协作玩法 | 协作的蜜月期 | 主角和原生人合作完成高难度任务 | 主角说"下次听我的"，原生人说"……好" | 无 |
| **9** | 谁主谁从 / 情感裂痕 | 信任的累积 + 冲突 | 原生人擅自做决定，主角质疑"谁是主体" | 主角说"这是我的身体"，原生人说"是吗？" | 无 |
| **10** | 顶级智斗 / 信任证明 | **爆点 3：主动停搏** | 主角被追杀，走到医院门口，对准自己心脏开枪 | 在死亡空间看到原生人背影，走远，消失；连接即将彻底断裂 | 无 |

| **尾声** | 未决的寻找 / 隔空关系 | 关系余波 | 主角无法确认原生人最终下落；保留笔记、留言和被改动的物品，继续追查 | 他不再强迫对方回来，但仍为其留下可以回来的路 | 结局表达“记住他”或“承认他曾是另一个人”，不把生死未卜强行解释为确定死亡 |

**阶段一新增节拍（2026-08-22）：天然权限事件**（约第 2~3 章，第一次停搏前）：黑客地下组织长期攻不进 DESIGNER.ai，组织联合行动，主角作为合作佣兵第一次进入极客组织内部参与攻击。全员被拦截、被反追踪、被打出来，唯独主角摸到终端——门开了，天然权限，等级还不低。极客组织不知道这件事，主角自己也以为是一次侥幸的黑入。表层玩家看到一场漂亮的潜入；中层玩家隐约觉得"这也太顺了"；深层玩家此刻什么都看不出来——线索还不存在，这个异常要到爆点 2 之后才会被重新读懂：**门不是他撬开的，门是给他修的**（残余系统权限表上躺着十七年前的实验体编号）。本事件是任务事件，不换局外 hub。（`narrative:designer-ai-innate-access`，详见 `叙事设定/04` §5.2）

## 五、原生人机制与主体性裂缝（深层叙事核心）

### 原生人的存在逻辑

**设定**（引用 `叙事/01` §七）：
- 主角小时候参加了一个"梦境认知实验"，目的是**把人类意识送进梦境世界**。
- 实验成功了 — **主角的意识绑定到了一个梦境世界的原生生命身体上**。
- 科学家以为"人类意识会完全占据原生人身体"，但实际上**原生人的意识也醒了**。
- **两个意识共享一个身体**：主角醒着时，原生人"旁观"；主角睡着（进入梦境）时，原生人"行动"。

### 主体性裂缝的呈现方式

**表层**（主角视角）：
- 主角以为自己有"超忆症"（能完整记住梦境）。
- 主角不知道"原生人"的存在，认为自己是唯一的意识。

**中层**（玩家观察到的"不对劲"）：
- **时间错位**：某个任务明明没做，但完成了；某个 NPC 说"你上次不是这么说的"。
- **留言**：梦境中出现"不记得留下"的痕迹（武器、尸体、涂鸦、文字），笔迹像主角自己。
- **惊喜/惊吓**：每次进入梦境都有"有人动过我的东西"的感觉。

**深层**（真相）：
- 主角醒着时，原生人在"旁观"，无法行动。
- 主角睡着（进入梦境）时，原生人"接管身体"，在梦境中单独行动。
- **主角的"超忆症"其实是"原生人帮他做了事"的结果** — 原生人在梦境中行动，主角醒来后"记得"那些事（因为他们共享记忆），但主角以为"是自己做的"。
- **主动停搏后，连接断裂** — 主角的人类身体死了，意识完全转移到原生人身体，但"关于原生人存在的记忆"被超忆症机制屏蔽了。

### 谁主谁从的情感冲突

**核心矛盾**：
- 主角认为：**我是人类，我才是"真正的我"，你只是工具。**
- 原生人认为：**这本来就是我的身体，你才是入侵者。**

**情感弧光**：
- **第 7-8 章**：协作的蜜月期，主角开始信任原生人。
- **第 9 章**：裂痕，主角说“这是我的身体”，原生人说“是吗？”。
- **第 10 章**：第二次停搏，连接彻底断开，原生人生死未卜并逃入梦境网络。
- **第 11 章及尾声**：主角追查原生人、对抗百目；双方只能隔空留言和错身，主角不承认却开始保护原生人。

### 传奇时间线与传闻双读（2026-08-22 补充定案）

主角的圈内声望与主体性裂缝严格同步（传闻分期详见 `叙事设定/01` §一）：

- **入行头两三年（游戏开始前）**：特长引人注目——超忆症的"快"与"全记得"，只是个有特长的能人；
- **第一次停搏（第 4 章）后**：原生人开始独立行动，"24 小时在线"等传奇期传闻出现（字面为真），传奇期开始；
- **第 4–9 章**：传奇攀升——**圈内传闻本身就是玩家可读的裂缝证据**，每一条新传闻背后都是一件主角自己不记得做的事，传闻升级与时间错位线索同步升级，中层玩家不用看日记，读 gossip 就能感觉到"不对劲"；
- **传奇顶峰 = 第二次停搏（第 10 章）**：他名声最盛的时刻恰恰是他"最不是自己"的时刻——传奇是两个人合著的，署名只有一个人；停搏后引擎熄火，圈内只当传奇过气。

**传闻双读（推断待验，方向已定）**：玩家和百目读同一份传闻——玩家越读越不安，百目越读越确定裂缝已发生。传奇期同时是百目的信号期，敌方压力曲线（盯梢→试探清理→收网）与传奇攀升同步，第 9–10 章"走投无路"由此有了情报结构的必然（详见 `叙事设定/04` §2.3）。

## 六、轻叙事的实现方式（碎片化 + 不强制播片）

### 现实地图 = 主界面（引用 `运营/03`）

玩家在现实公寓（驻地）里：
- **走到床边** → 选择"入梦" → 进入任务或联机
- **走到电脑前** → 打开"素材库" → 进入编辑器
- **走到门边** → 看门缝下的纸条 → **获取任务简报**（主线节拍闸）
- **走到研究台** → 编辑节点 → 调整素材/词条
- **走到保险箱** → 查看收藏 → 回顾里程碑

现实公寓会随着章节推进而变化：
- 一开始破旧但正常。
- 后来开始出现纸条、奇怪的涂鸦、不属于自己的物品。
- 最后玩家可能发现，自己现实公寓里的某些东西，是从梦里带出来的。

### 门缝纸条 = 主线任务节拍闸（引用 `运营/04` §三·五）

**功能**：
- 部分主线结束后，**过一段时间**会在门边出现纸条。
- 纸条内容 = **任务简报**（中间人/地下组织的加密讯息，告知"有活了""新任务开了"）。
- **纸条出现 = 主线任务解锁**，但入梦仍走床 A（纸条不是入口，是告知）。

**节奏设计**：
- 部分主线任务**不可连着来**，至少间隔（如 ≥1 分钟，或等下一张纸条出现）。
- 这个间隔是**节奏呼吸** — 让玩家在"刚打完一段主线"和"下一段主线"之间，有时间做局外的事（整理书架、开保险箱、回研究台）。
- 具体间隔时长、纸条掉落表与文本属于后续迭代。

**纸条类型**（引用 `运营/04`）：
- **任务简报 / 接取提示**：主线节拍闸功能，告知任务可接。
- **告知书 / 通知**：官方口吻、荒谬内容（"梦境信号欠费"）。
- **信 / 便条**：来自某个人，一句话的情绪。
- **传票 / 公文**：不知道谁寄的，措辞正规但指向不明。
- **水电费单**：最"无厘头但真实"的生活气。

### 碎片化叙事的承载物

**不强制播片** — 叙事通过以下方式嵌入：
- **门缝纸条**：任务简报 + 世界气味（引用 `运营/04`）
- **证据提交**：VR 头显 / 警局座谈，非强制，主线辅助（引用 `叙事/01` §六）
- **梦境残留**：墙上的字、NPC 的尸体、留言、涂鸦
- **NPC 闲聊**：队友的只言片语（"老王上个月在梦里被杀了七次，醒来就疯了"）
- **素材描述**：素材库里的元素描述，藏着线索
- **主角独白**：简短的自言自语，带点自嘲（"这字比我写得好看"）

### 主线短 + 对话少

**设计约束**：
- 每章只有 3-5 个任务，每个任务 5-10 分钟。
- 对话不超过 5 句。
- 用场景讲故事，不用大段文本。

## 七、尾声的情感选择（不是机制选择）

### 设计原则

**不弹出"选 A 还是 B"的对话框** — 而是让玩家**通过主角的行为**，自己决定"我要记住他，还是接受合二为一"。

### 两种结局的触发方式

**结局 A：坚持记住**
- **触发方式**：玩家在尾声中，反复点击"那些留言"（笔记、录像、任务报告）。
- **独白**：
  - "我知道我忘了一个很重要的人。"
  - "我不知道他是谁，但我知道他救了我。"
  - "我会一直记着：**曾经有人和我并肩作战。**"
  - "也许有一天，我会再次想起他。"
- **最后一幕**：主角在出租屋里，看着镜子，喃喃自语："**你还在吗？**"
- **黑屏，一行字**："我一直都在。"

**结局 B：真正接受合二为一**
- **触发方式**：玩家在尾声中，不点击留言，直接走向床，睡下。
- **独白**：
  - "也许我本来就是一个人。"
  - "也许那些留言，都是我自己留的。"
  - "也许我从来没有忘记什么 — **因为他本来就是我。**"
- **最后一幕**：主角在出租屋里，睡下，进入梦境；他在梦里走着，突然停下，笑了："**我回来了。**"
- **黑屏，一行字**："我们回来了。"

### 两个结局都不是"好"或"坏"

**设计意图**：
- 结局 A 是"记住他" — 主角承认"有另一个我"，保留分离感。
- 结局 B 是"合二为一" — 主角接受"我们是一个人"，保留整体感。
- **两者都是合理的情感选择**，没有道德评判。
