## 〇、最重要的一条全局修正

**你之前把「场景框」当成了地图节点本身（点击场景框 = 选中场景 = 编辑）。这是错的。**

真实模型是**双层**的（D-074 双分层坐标：编辑时是人性化涂鸦，储存时翻译为拓扑层严格声明）：
- **场景框（Scene Box）** = 玩家涂鸦拖出的 **矩形边界**，只是「这个天然/微型场景画多大」的视觉容器，**不代表场景本身**。
- **地图节点（MapNode / 高光点 Highlight Point）** = 一个带 `at` 坐标的 **点**，才是场景的**逻辑锚点**，用来拉连线、承载名称/尺度/楼层/上级属性。

所以**一个场景 = 若干场景框（聚合边界）+ 一个高光点（逻辑锚点）**。点击场景框要落到「选中该场景（含其高光点）」，编辑属性打开的是这个场景的节点详情，不是框的宽高。

**连线永远从锚点（高光点）出发，不从框边缘出发。** 锚点 = 该场景全部成员框的「最大距离矩形中心」（系统自动计算，不允许手动创建）。

**人机分工铁律**（D-072）：碰撞、视觉遮挡/物理遮挡由**人**用有限图元裁定并编码入库；**AI 读编码不看图**。编辑器只是把「拖框 / 划线 → 逻辑语义」翻译得足够紧凑。

## 一、场景框与高光点（核心修正，必须加）

### 1.1 场景框（Scene Box）——真实渲染

- 淡青虚线矩形，`rx=6` 圆角，半透淡底
- **内部显示**：居中尺度字母（L/M/S，取 `scale[0]`）+ 框下方显示场景名
- **不显示** 框的四角控制点（涂鸦式，无 PS 4 角拖拽；框的形状只在造的时候定，之后整体拖动/旋转）
- 每个节点默认只有一个场景框，但**支持多个框聚合成一个场景**

### 1.2 高光点（Highlight Point / 锚点）——必须新增的图元

- **显示**：每个场景中心一个青色发光小圆点（半径约 6px，带柔和光晕），比场景框小但视觉权重高
- **位置**：该场景所有成员框外接矩形的中心（自动跟随场景移动/聚合重算）
- **交互**：
  - **悬停** = 强青色发光（比场景框更亮），提示「这是合法拖线起点」（拉边流程第 2 步的"蓝色合法起点"）
  - **左键拖拽（在 E 拉边模式下）** = 从这一锚点开始描线（拉边流程第 3 步），到目标锚点松手建边
  - **左键单击** = 选中整个场景（等同点击场景框）
  - **悬停 1 秒** = 弹出该场景的详细属性浮层（名称/尺度/楼层/Def）
- **生成方式**：不可手动创建，系统根据场景聚合自动算出一个

### 1.3 场景框聚合 = 场景（涂鸦式合并）

- 多个同类型场景框**重叠 = 自动合并为一个场景**，边界消失，高光点重算到新外接矩形中心
- 点击任一成员框 = 选中整个聚合（阴影高亮覆盖所有成员框）
- Delete = 删除全部成员框 + 该场景的连线/素材
- 滚轮 = 绕聚合外接矩形中心整体旋转 10°/格
- 移动 = 整个聚合一起移动，高光点跟随

### 1.4 空洞全填（仅场景框，必须实现）

- **触发**：场景框围成内部封闭空洞（如 4 矩形围出矩形洞）
- **视觉**：空洞被半透明青色「油漆桶」填充，看起来是连续场景
- **逻辑**：空洞区域视为场景一部分，**不可在其中放置新场景节点**（防止把另一场景塞进空洞导致嵌套崩坏）
- **存储**：仍是多个独立矩形，**不用虚假矩形补洞**
- **只对场景框生效**：视觉遮挡框/物理遮挡框/高地/洼地等方框图元没有「封闭区域归属」语义，不参与填充判定

### 1.5 粘连判定（必须实现）

- **触发**：一次场景框拖拽/创建**同时碰到两个不同场景**
- **行为**：整个操作被拒绝，松手 = 框消失 + 淡出提示「不能跨场景连接」（违反任一涂鸦原则的操作都被拒绝并给出违反原则的提示）

## 二、连线图元（修正起点）

### 2.0 拉边流程（Select 之外最常用的创造性动作，必须完整）

```
1. 按 E 进入拉边模式
2. 悬停节点 → 蓝色（合法起点，即高光点发光）
3. 节点上按下 → 开始描线（起点 = 高光点）
4. 自由拖动 → 实时预览折线，原始点全收
5. 进入其他节点吸附半径 → 那个节点亮蓝（只有松手点吸附，中间点永不吸附）
6. 在节点上松手 → 端点精确吸附节点中心 → RDP 简化 → 建边
7. 在别处松手 → 整条丢弃 + 红色一闪
8. 保持 E 模式可连画，Esc 退出
```

### 2.1 连线的锚点是高光点，不是框

- 连线 `path[0]` = 起点场景的高光点，`path[last]` = 终点场景的高光点
- 移动场景框时连线端点跟随（移动节点时同步更新 `path` 首/尾）

### 2.2 Catmull-Rom 样条（已正确，保留）

- 曲线绝对穿过所有必经点（非贝塞尔控制点在外；全程只叫"样条线"，不叫贝塞尔）
- 拉弯即追加隐藏样条点（`pushKnot`，Fire-and-Forget，无上限；隐藏点不可见、不可选中、不可二次编辑）
- 只有松手点吸附节点中心，中间点永不吸附
- 直线段 `path` 为空数组时按线性插值渲染；非空即切换 Catmull-Rom 逐段穿过样本点

### 2.3 折点（已正确，保留）

- 中间折点 = 白色小圆点 + 橙色描边，可拖拽（[B] 折点调整，左右连线跟随）
- 首末折点恒吸附锚点（不可直接改）
- 拖某折点距邻折点 <10px → 目标折点高亮 → 松手融合删除 + 拍直两侧（[D]）
- 双击已拉弯线段 = 清空该线段内全部隐藏样条点，瞬间绷直（唯一重塑入口）
- 单击线段只高亮，不选中任何控制点、不弹菜单（高亮是镀层，不参与逻辑）

## 三、图层切换与透明度（上次完全漏掉，必须完整补充）

### 3.1 图层是什么

- 图层是「楼层/高度」的容器，一个图层一个 `height`
- **参与透视**的图层：`height` 填一个数值（可为 0，如地面层 height=0）；不同参与透视图层的 height **不能重复**
- **独立**的图层：`height` 留空（可多个互相独立、无透视关系），恒不透明

### 3.2 左栏图层行交互（必须完整）

每行图层：
- 左：图层名 + 青色亮点
- 右：**高度数字输入框**（可清空 = 独立层）
- 点击图层行 = **切换当前图层**
- 图层高度输入：填数字则参与透视；清空则独立
- 高度冲突时提示「参与透视的图层高度不可重复」并拒绝

### 3.3 图层注记（必须显示）

- 「当前：{当前图层名}」
- 「可见 {当前层及以下（含独立层）}/{总层数} 层」
- 「相邻透明度 {overlayOpacity 结果}」

### 3.4 图层透明度公式（必须实现，权威）

两层都填 `height` 时，透明度：

```
opacity = clamp(1 − |Δheight| × 0.1, 0, 1)
```

- 差满 10 或更大 → 全隐（opacity 0）
- 任一侧 height 留空（独立层）→ 不参与叠加、恒不透明，注记显示「独立」

### 3.5 画布裁剪（必须实现）

- **当前图层**：完整详情显示（可编辑）
- **低于当前图层**：半透明显示（像从高层看下层建筑）
- **高于当前图层**：淡显（不参与编辑）
- 快捷键 `1/2/3` = 快速切换到第 1/2/3 个图层（超出按最后一个）

### 3.6 背板（backdrop，可选）

- 每个图层可带一张底图背景（简笔画），作为该层的画面底
- 主视图显示当前层底图，其他层底图半透明

## 四、检查器（修正字段，与双层模型对齐）

**选中场景（节点+高光点）时**：

## 十、补充的真实数据模型（用这个替换你推测的）

真实导出是 **canonical v2**（`schemaVersion: '2.0'`，`layers[]` + 节点 `layerId`，**不写 legacy `floors`/`floor`**；legacy v1 只在导入边界经 `normalizeMapDocument` 规范化）。所有坐标是 `[0,1]` 归一化：

```typescript
interface MapData {                       // CanonicalMapData
  schemaVersion: '2.0';
  id: string;                             // 玩家命名 + 随机 key
  name: string;
  backdrop: { image: string; pixelWidth: number; pixelHeight: number; tileRows: number; tileCols: number };
  layers: Array<{                         // 图层（权威）
    id: string;                           // 稳定命名
    name?: string;
    height?: number;                      // 可空；填数值=参与透视（去重），留空=独立层
    backdrop?: { image: string; pixelWidth: number; pixelHeight: number };
    transform?: { scaleX: number; scaleY: number; tx: number; ty: number };
  }>;

  nodes: Array<{                          // 场景节点（点，高光点锚点）
    id: string;
    def: string;                          // 如 'd:scene/yard'
    scale: 'large' | 'medium' | 'small';
    at: { x: number; y: number };         // 归一化坐标 = 高光点位置
    layerId: string;                      // 引用 layers[].id（编辑内部以 floor 为轴，导出时按图层就近归类）
    parent?: string;                      // 上级场景 id；留空=顶层。已定义+已校验（3 条码），运行期未接通
    name?: string;                        // '月台' 等
  }>;

  edges: Array<{                          // 连线（Catmull-Rom 样条点）
    id: string;
    def: string;                          // 'd:transition/door'
    a: string;                            // 起点节点 id
    b: string;                            // 终点节点 id
    directionality: 'bidirectional' | 'unidirectional' | 'one-way-up' | 'one-way-down';
    path: Array<{ x: number; y: number }>;// 折线，首=起点锚点尾=终点锚点；空数组=直线
    transitionWindow?: { control: Array<{ x: number; y: number }> };  // 仅双向连接有意义
    visualObstruction?: { shape: 'box' | 'circle' | 'polygon'; bounds?: Array<Vec2>; height?: number };
    physicalObstruction?: { shape: 'box' | 'circle' | 'polygon'; bounds?: Array<Vec2>; height?: number };
    semanticAnchor?: 'high' | 'low' | 'neutral';
  }>;

  placements: Array<{                     // 实例放置（快照内联，不引用外部实例库）
    id: string;
    at: string;                           // 宿主节点 id
    def: string;
    overrides?: Record<string, unknown>;  // 键名不得撞 Expr 判别键（path/op/call/q/var）
    temporaryFree?: boolean;              // 地图自带临时免费实例，随复制传染
  }>;
}
```

**节点 at = 高光点。** 所有连线锚点、透视定位都以 `nodes[].at` 为准，不是场景框的几何中心（场景框只是显示边界）。

**编译边界**：编辑器产出 MapData；`compileMap` 丢弃全部几何（at/path/backdrop）得到 `PrefabDef`（"删掉几何，一局游戏照样跑"）。遮挡/锚点/过渡窗口由表现层与寻路段1 单独消费 MapData，不进入 PrefabDef。编辑器内不做碰撞/透视预计算（预运算发生在运行期启动时）。

## 十一、给 v0.dev 的实施顺序建议

1. **先修数据模型**：节点是点（at）+ 场景框是显示边界，把「场景框=节点」的错误认知改掉
2. **加高光点**：每个节点中心渲染青色锚点，作为连线起点/终点
3. **加场景框聚合/合并/空洞/粘连**：涂鸦式几何（如果工程量过大，至少把「点击场景框选中整个场景 + 高光点自动算中心」做对）
4. **补图层切换与透明度公式**：图层行点击切换 + overlayOpacity 透明度 + 裁剪（当前层全彩、下层半透明、更高层淡显）
5. **补诊断列表点击定位 + correction 悬浮 + 红/黄脉冲**
6. **补遮挡框点击选中 + 语义锚点 + 过渡窗口独立拖拽**

请按以上逐条核查你的生成，缺失就补、不一致就改。布局骨架（三栏/顶栏/底栏/工具栏）保持不动。
