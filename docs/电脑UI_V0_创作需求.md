# 电脑UI - V0 创作需求总览（质感锚点 + 反差设计 + 核心体验）

> **文档性质**：这是给 V0 的**创作需求**，不是实现规范。重点在「告诉 AI 这个应用的灵魂是什么」，而不是「告诉 AI 怎么写代码」。
> **使用方式**：直接把以下内容复制给 V0，它会理解「我要的是这种感觉」。

---

## 🔥 核心设计哲学（全局适用）

### 1. 电脑UI的本质
- 不是工具，是**组织身份的表演舞台**
- 玩家不是在「用软件」，而是在**扮演不同组织的角色**
- 每个应用都有**独特的质感锚点**和**反差设计**

### 2. 统一的反馈语言（所有应用共享）
- **提现动画**：充电灯从左→右扫描 + 数字滚动 + "滴!" 的金属声
- **成功反馈**：青色光晕 + 数据流粒子 + 微震动
- **失败反馈**：红色闪烁 + 错误音 + 文字抖动
- **加载状态**：蓝色加载球 + 模糊背景

## 💻 SECDED 终端：终端式悬赏商城

### 质感锚点
- **极客硬核 + 商业感**
- 深绿 = 字符终端 × 金属按钮（高档感）
- 不是黑客风，是**高端科技的冷酷感**

### 界面元素
- **Logo**：左上角「8位渲染骷髅logo」+ 右侧「商城积分按钮」
- **背景**：深绿色终端背景 + 扫描线纹理 + 细小的数据流粒子
- **按钮**：金属质感，点击时有「机械按压」的微动画

### 悬赏区
- 每个悬赏都写着：**"价值：$XXX" + 经验值条（刷完可获得信用点）**
- 经验值条：灰色底 + 绿色填充，完成后弹出"信用点+1"的气泡
- 倒计时：黄色数字，接近截止时变红 + 闪烁

### 商城区
- **货币显示**："信用点"打头，"记忆碎片"底部
- **购买动画**：刷卡 + 充电灯（从左到右扫描）
- **商品列表**：文字描述 + 价格，无图标（保持神秘感）

### 核心体验（30秒玩家体验）
```
玩家流程：
1. 打开终端 → 看到骷髅logo闪烁 + 字符刷屏动画
2. 浏览悬赏 → 发现"当今头目 价值$1200"，经验值条已填充80%
3. 点击交付 → 弹出"获得信用点+1 + $1200"
4. 进入商城 → 用信用点购买"记忆增强剂"
5. 购买成功 → 刷卡动画 + 充电灯扫描
6. 返回悬赏 → 发现新的悬赏已刷新
```

### 反差设计
- **高端科技 vs 黑市交易**：界面很高级，但交易内容很地下
- **神秘感 vs 透明价格**：商品没有图标，但价格清清楚楚

## 📊 运营商A：佣兵数据看板

### 质感锚点
- **高级SaaS仪表盘**
- 全蓝底毛玻璃 × 透明卡片（V0爆款SaaS风）
- 不是花哨，是**专业的冷静感**

### 界面元素
- **顶栏**：佣金数字（大号等宽字体）+ "提现按钮"
- **卡片**：透明背景 + 微阴影，叠加效果
- **表格**：任务列表 + 完成状态 + 评分

### 核心交互
- **提现按钮**：点一下弹窗"已提现 $XXX，24h到账" + 充电灯扫描
- **数字滚动**：佣金变化时，数字从右向左滚动
- **加载动画**：快速刷新时出现「加载球」

### 核心体验（30秒玩家体验）
```
玩家流程：
1. 打开看板 → 看到"佣金 $3,420"的大号数字
2. 查看任务表 → "本周 4/5 完成 80%"
3. 点击提现 → 弹出"已提现 $200 → 24h到账"
4. 充电灯从左→右扫描，数字滚动 + "滴!"声音
5. 新余额：$3,220
6. 看见升级徽章光晕框飘出（从灰到彩）
```

### 反差设计
- **专业仪表盘 vs 讽刺文案**：界面很专业，但组织评语很讽刺
- **冷静数据 vs 激动提现**：数字很冷静，但提现时很激动

## 💰 运营商B：营销App

### 质感锚点
- **亮片塑料感 × 促销文案**
- 圆角矩形塑料感 × 卡通式按钮（V0最爱的「弹窗式营销」）
- 不是高级，是**商业的浮夸感**

### 界面元素
- **顶栏**：套餐卡片（当前套餐高亮）+ "立即续费"按钮
- **账单**：弹窗"账单到底了 → 点开是莫名其妙的高额支出"
- **升级**：点「升级」时弹"优惠到底了" → 界面切成「会员金光」效果

### 核心交互
- **续费动画**：秒达充值 + 金光闪烁
- **自动扣款**：账单直接扣除，无需确认
- **优惠弹窗**：右上角闪烁，点击后出现优惠码

### 核心体验（30秒玩家体验）
```
玩家流程：
1. 打开营销App → 看到"标准企业版 剩余20天"
2. 点击续费 → "秒达充值"动画，金光闪烁
3. 弹出"优惠到底了！本月8折" → 界面切成金色
4. 点击账单 → 发现"2024/8/15 莫名加收 $400"
5. 账单自动扣款 → 余额减少
6. 看见"会员特权"徽章亮起
```

### 反差设计
- **浮夸营销 vs 隐藏扣款**：界面很浮夸，但扣款很隐蔽
- **金光闪烁 vs 莫名其妙**：升级很爽，但账单很迷惑

## 🏛️ CPD取证室：老爸官网风

### 质感锚点
- **极端土到不行**
- 不是现代，是**90年代政府网站的复古感**

### 界面元素
- **Logo**：居中鹰头 + 灰底 + "CPD梦境取证数据系统"
- **页面**：拖拉机拟物渐变 + 右下角"© 2024 CPD"
- **按钮**：阴皮蓝 —— hover 才露底板

### 核心交互
- **VR入口**：点击按钮 → VR加载动画 → 素材槽位界面
- **证据提交**：拖拽素材到槽位 + 警官立绘反馈
- **结果回溯**：提交后显示"记录在案" + 奖励数字

### 核心体验（30秒玩家体验）
```
玩家流程：
1. 打开CPD → 看到鹰头logo + 灰色背景
2. 点击"进入取证室" → VR加载动画
3. 拖拽素材到槽位 → 警官立绘微动
4. 提交证据 → 弹出"记录在案 + $500"
5. 返回界面 → 看见"今日已提交 2/5"
6. 看见"© 2024 CPD"的版权信息
```

### 反差设计
- **复古官网 vs VR科技**：界面很土，但功能很先进
- **严肃取证 vs 简陋界面**：任务很严肃，但界面很简陋

## 👥 社区：占位灰

### 质感锚点
- **占位灰 → 待联机时转成「游戏内UI」**
- 不是功能，是**未来的承诺**

### 界面元素
- **占位**：灰掉的所有按钮
- **提示**：右下角"敬请期待，XX月更新"
- **新机制**：佣兵奖励「一键提现」

### 核心体验（30秒玩家体验）
```
玩家流程：
1. 打开社区 → 看到所有按钮灰显
2. 点击任意按钮 → 弹出"敬请期待联机版"
3. 看见右下角"2026年12月更新"
4. 返回其他应用 → 继续游戏
```

## 🎯 统一语言：提现动画

### 动画细节
1. **充电灯扫描**：从左到右，速度均匀，持续0.8秒
2. **数字滚动**：等宽字体，数字从右向左补齐，持续0.5秒
3. **声音**："滴!"的金属声，在动画结束时播放
4. **弹窗**：白底 + 青色边框 + "已提现 $XXX → 24h到账"

### 适用场景
- 运营商A：佣金提现
- 运营商B：套餐续费成功
- SECDED：信用点兑换

## 🎨 8位骷髅Logo（SECDED）

### 设计需求
- **风格**：8位像素风
- **元素**：骷髅头 + 绿色调色盘
- **动画**：开机时字符刷屏 + logo闪烁
- **尺寸**：64×64px（顶栏） / 128×128px（主界面）

### 参考描述
```
骷髅头由方块组成：
- 头部：8×8的方块矩阵
- 眼睛：2×2的空心方块
- 嘴巴：3×1的空心方块
- 颜色：深绿色 (#006600) + 亮绿色 (#00FF00) 高光
```

## 📌 V0 创作提示

1. **SECDED**：重点在**终端感**和**商业感**的结合，logo要帅，字符刷屏要酷
2. **运营商A**：重点在**提现的爽感**，数字滚动和充电灯扫描要流畅
3. **运营商B**：重点在**营销的浮夸感**，金光闪烁和优惠弹窗要吸引眼球
4. **CPD**：重点在**复古的土感**，界面要简陋，但功能要先进
5. **社区**：重点在**占位的灰感**，所有按钮都要灰显
