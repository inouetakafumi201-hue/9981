### 2. DiagnosticSink 去重机制验证

**去重键构成**（`diagnosticDedupKey` 函数）：
```typescript
[
  code,
  severity,
  scope,
  sourceId,
  start,
  end,
  at.def,
  path,
  phase,
  messageKey
].join('::')
```

**关键保证**：
- ✅ 不同 `definition` 的错误不会被折叠（at.def 不同）
- ✅ 不同 `path` 的错误不会被折叠（path 不同）
- ✅ 不同 `source` 的错误不会被折叠（sourceId/start/end 不同）
- ✅ 相同消息但不同位置的错误都会被记录

**测试证据**：
```typescript

              sourceSpan: { file: 'a.json', start: point(1), end: point(2) } });
  sink.emit({ code: 'E_REF_MISSING', severity: 'error', message: 'same', 
              sourceSpan: { file: 'a.json', start: point(3), end: point(4) } });

});
```

### 3. Fatal E_INV_* 不可被覆盖验证

**实现机制**：
```typescript
function isHaltingDiagnostic(diag: Diagnostic): boolean {
  return diag.severity === 'fatal' ||
    diag.haltClass === 'infrastructure' ||
    isFatalCode(diag.code) ||
    isInfrastructureFatalCode(diag.code);
}

// E_INV_* 无论声明什么 severity，都强制 fatal
function isFatalCode(code: string): boolean {
  return code.startsWith('E_INV_');
}
```

**测试证据**：
```typescript
it('Property 20: E_INV_* 前缀无论声明严重度如何都强制 fatal', () => {
  const invCodes = ERR_CODES.E_INV.map(suffix => `E_INV_${suffix}`);
  for (const code of invCodes) {
    const sink = new DiagnosticSink({ onFatal: () => { triggered = true; } });
    // 即使声明为 'error'，仍会触发 fatal
    expect(() => sink.emit({ code, severity: 'error', message: 'test', phase: 0 }))
      .toThrow(code);
    expect(triggered).toBe(true);
  }
});
```
