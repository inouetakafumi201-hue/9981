# AI系统设计

## 设计哲学

### 核心原则
> "只要AI表现出一个明确意图，它就被认为是智能的。"

### 目标定位
- **不追求完美决策**：AI不是为了不可战胜
- **追求可读意图**：玩家能看懂AI在"图谋"什么
- **保持棋类纯洁性**：AI和玩家使用相同的心智模型

## AI架构：分层设计

### 两层架构

```
高层：意图规划（Goal-Oriented Selector）
  ↓
底层：战术执行（Tactical Executor）
```

### 高层：意图机（Utility Theory）【我，对意图机取保留意见。我认知中最好使用纯粹的分数αβ剪枝搜索+随机选择器，像棋类那样，好处是可怕的通用，除非不可行】

#### 意图评估
```typescript
interface Intent {
  goal: string;          // "seek_weapon" | "hunt_player" | "survive" | "control_area"
  priority: number;      // 0-100
  duration: number;      // 维持几个回合
  target?: EntityId;     // 目标对象（如果有）
}

function evaluateIntents(ai: AIEntity, state: GameState): Intent[] {
  const intents: Intent[] = [];
  
  // 生存意图
  if (ai.health <= 2 && hasNearbyHealthPack(ai)) {
    intents.push({
      goal: "survive",
      priority: 90,
      duration: 3
    });
  }
  
  // 狩猎意图
  if (ai.hasWeapon && canSeeEnemy(ai)) {
    intents.push({
      goal: "hunt_player",
      priority: 80,
      duration: 5,
      target: getNearestEnemy(ai)
    });
  }
  
  // 装备意图
  if (!ai.hasWeapon && knowsWeaponLocation(ai)) {
    intents.push({
      goal: "seek_weapon",
      priority: 70,
      duration: 4
    });
  }
  
  // 选择优先级最高的意图
  return intents.sort((a, b) => b.priority - a.priority);
}
```

### 底层：战术执行器

#### 主观确定论AI
**核心思想**：假装世界是确定的，每人每回合1 AP

```typescript
function planActions(ai: AIEntity, intent: Intent): Action[] {
  // 假设世界确定性：每人每回合恒定1 AP
  const state = createDeterministicView(gameState);
  
  // 根据意图计算目标
  const goal = getGoalPosition(intent);
  
  // 使用简单的搜索算法（Alpha-Beta或Dijkstra）
  const path = searchBestPath(ai.position, goal, state);
  
  return path;
}
```

**为什么这样设计？**
- 人类玩家也是这样思考的："我离车3步，他离车4步"
- 不去算复杂的概率分布
- 只在投点出现意外时即时调整

#### 应对随机性

```typescript
function executeWithAdaptation(ai: AIEntity, plan: Action[]): void {
  // 投点获得实际AP
  const actualAP = rollDice(ai);
  
  if (actualAP > plan.expectedAP) {
    // AP暴涨：抓住机会完成更多动作
    const bonus = actualAP - plan.expectedAP;
    extendPlan(ai, plan, bonus);
  } else if (actualAP < plan.expectedAP) {
    // AP不足：执行计划的前N步
    truncatePlan(plan, actualAP);
  }
  
  // 执行调整后的计划
  executePlan(ai, plan);
}
```

```typescript
function selectActionWithTemperature(
  options: Action[], 
  temperature: number
): Action {
  // 计算每个动作的评估分
  const scores = options.map(action => evaluate(action));
```

## 估值函数（Heuristics）

### 简单静态评分

```typescript
function evaluatePosition(ai: AIEntity, state: GameState): number {
  let score = 0;
  
  // 生命值
  score += ai.health * 20;
  
  // 武器
  if (ai.hasWeapon) {
    score += ai.weapon.damage * 15;
  }
  
  // 距离目标
  if (ai.target) {
    const distance = getDistance(ai.position, ai.target.position);
    score -= distance * 5;
  }
  
  // 掩体
  if (isInCover(ai.position)) {
    score += 10;
  }
  
  // 处于危险状态
  if (ai.hasStatus('burning') || ai.hasStatus('poisoned')) {
    score -= 30;
  }
  
  return score;
}
```

### 物品价值评估

```typescript
function evaluateItem(item: Item, context: AIContext): number {
  let value = 0;
  
  // 基础价值
  if (item.type === 'weapon') {
    value = item.damage * 10;
  } else if (item.type === 'health_pack') {
    // 动态价值：血量低时价值高
    value = context.ai.health <= 2 ? 40 : 10;
  } else if (item.type === 'key') {
    // 动态价值：附近有锁时价值高
    value = hasNearbyLock(context.ai.position) ? 30 : 5;
  }
  
  // 负重惩罚
  if (item.tags.includes('heavy')) {
    value -= 5;
  }
  
  return value;
}
```

## 搜索算法

### 基础搜索：Dijkstra/A*

```typescript
function findBestPath(
  from: NodeId, 
  to: NodeId, 
  state: GameState
): Path {
  const openSet = new PriorityQueue<Node>();
  const cameFrom = new Map<NodeId, NodeId>();
  const costSoFar = new Map<NodeId, number>();
  
  openSet.push(from, 0);
  costSoFar.set(from, 0);
  
  while (!openSet.isEmpty()) {
    const current = openSet.pop();
    
    if (current === to) {
      return reconstructPath(cameFrom, current);
    }
    
    for (const next of getNeighbors(current, state)) {
      const cost = costSoFar.get(current)! + getMoveCost(current, next, state);
      
      if (!costSoFar.has(next) || cost < costSoFar.get(next)!) {
        costSoFar.set(next, cost);
        const priority = cost + heuristic(next, to);
        openSet.push(next, priority);
        cameFrom.set(next, current);
      }
    }
  }
  
  return null;  // 无路径
}

function heuristic(from: NodeId, to: NodeId): number {
  // 曼哈顿距离【？是节点又不是网格哪来的曼哈顿。不存在任何逻辑上的坐标系】
  return Math.abs(from.x - to.x) + Math.abs(from.y - to.y);
}
```

```typescript
function getMoveCost(
  from: NodeId, 
  to: NodeId, 
  state: GameState,
  ai: AIEntity
): number {
  let cost = 1;  // 基础1 AP
  
  // 考虑场景类型
  if (to.type === 'large' && ai.hasTag('heavy')) {
    cost += 1;  // 重装在大场景+1 AP
  }
  
  // 考虑危险
  if (isHostileNearby(to, state)) {
    cost += 2;  // 危险位置权重增加
  }
  
  // 考虑门户效果
  const portal = getPortal(from, to);
  if (portal) {
    cost += portal.cost;
    if (portal.effects.includes('fall_damage')) {
      cost += 1;  // 受伤也算入成本
    }
  }
  
  return cost;
}
```

```typescript
function selectActionMCTS(ai: AIEntity, iterations: number): Action {
  const root = new MCTSNode(getCurrentState());
  
  for (let i = 0; i < iterations; i++) {
    // 1. 选择
    let node = root;

}
```

```typescript
  private planValidUntil: number = 0;
  
  getNextAction(currentTurn: number): Action {
    // 如果计划还有效，直接使用
    if (currentTurn < this.planValidUntil && this.cachedPlan.length > 0) {
```

## AI设计最佳实践

### DO
- ✅ 让AI表现出明确的意图
- ✅ 使用玩家相同的心智模型
- ✅ 保持决策过程可解释
- ✅ 用温度调节制造个性
- ✅ 让AI能自动适配新内容

### DON'T
- ❌ 让AI有隐藏的特权信息
- ❌ 让AI使用玩家无法使用的操作
- ❌ 创建不可预测的随机行为
- ❌ 让AI决策过程不可调试
- ❌ 为每个新机制重写AI代码
