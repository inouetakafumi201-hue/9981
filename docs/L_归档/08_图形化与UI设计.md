## 视觉风格定位

### Among Us启发的2D扁平风格

**核心理念**：
- 本质上就是一张2D图片
- 极简的贴纸叠加系统
- 手绘/草稿纸美术风格

**为什么选择2D？**
1. **UGC友好**：任何人都能画图或用AI生成
2. **数据轻量**：一张地图<1MB
3. **性能优异**：无3D计算开销
4. **风格统一**：所有UGC内容视觉一致
5. **暗示离散性**：画风本身就暗示了规则的离散性

### 可选美术风格

#### 风格A：手绘草稿纸
```
特点：
- 圆珠笔线条
- 简笔画图标
- 草稿纸纹理背景
- 元游戏表现力（手从屏幕伸下来画东西）

情感：童年、怀旧、创意
```

#### 风格B：像素艺术
```
特点：
- 16x16或32x32像素
- 复古游戏风格
- 清晰的网格对齐

情感：经典、极客、精确
```

#### 风格C：扁平卡通（Among Us风格）
```
特点：
- 简洁的矢量图形
- 明亮的配色
- 可爱的角色设计

情感：轻松、友好、现代
```

## 核心UI架构

### 三层渲染系统

```
Layer 1: 背景图层（Background）
  └─ 地图背景图片（2D PNG/JPG）
  └─ 静态装饰元素

Layer 2: 实体贴纸层（Entity Sprites）
  └─ 玩家棋子
  └─ 物品图标
  └─ 载具
  └─ NPC
  └─ 装备叠加（纸娃娃系统）

Layer 3: 交互覆盖层（Interactive Overlay）
  └─ 高亮区域
  └─ 连接线（动态显示）
  └─ 动作提示
  └─ 效果动画
```

### 屏幕布局

```

│                                             │
```

## 过渡门户可视化

### 门户图标系统

```
统一图标语言：【没完全确定，只是表达思维】
🪜 楼梯 = 阶梯图标
🪜 梯子 = 竖梯图标
🪟 窗户 = 窗框图标
🚪 门 = 门框图标
⬇️ 跳台 = 向下箭头
```

### 成本与后果筹码

```
图标徽章系统：
┌─────┐
│ 🪟  │ ← 门户图标
│ ⬇️2 │ ← 方向箭头
│ D2  │ ← 坠落伤害2
│ Chk │ ← 需要检定
└─────┘

颜色编码：
- 蓝色数字：AP成本
- 绿色：Free（0 AP）
- 红色D#：伤害
- 黄色Chk：检定
- 紫色Sl#R：迟缓#回合
```

### 动态显示原则

**默认状态**：清爽无连线
```
只显示：
- 背景图
- 实体位置
- 门户图标（小）
```

**移动模式**：显示可达范围
```
激活时：
- 高亮可达节点（绿色）
- 显示门户连接（虚线）
- 标注AP成本
- 不可达节点变灰
```

**攻击模式**：显示射程
```
激活时：
- 显示视线通道（红色扇形）
- 高亮可攻击目标
- 窗户等los_bridge亮起
- 障碍物变暗
```

## 节点交互设计

### 点击目标优先级

```【点击目标可以视为另一种直观选择方式，后期如果实现困难先完成选项栏登记】
1. 实体（玩家、敌人、物品）
2. 门户锚点
3. 节点区域
4. 空白区域（取消选择）

避免重叠时：
- 显示快捷菜单让玩家选择
```

### 拖拽操作

```
拖拽玩家棋子：
1. 拾起棋子
2. 沿途显示路径预览
3. 经过门户时显示效果提示
4. 松手确认移动

拖拽物品：
1. 从槽位拾起
2. 拖到目标槽位
3. 自动验证合法性
4. 不合法则弹回原位
```

## UI/UX最佳实践

### DO
- ✅ 默认清爽无连线
- ✅ 按需动态显示信息
- ✅ 用图标+颜色+文字多重表示
- ✅ 提供悬停详细信息
- ✅ 所有操作可撤销预览
- ✅ 关键决策有确认步骤

### DON'T
- ❌ 同时显示所有连线
- ❌ 使用过小的点击目标
- ❌ 隐藏关键信息

```typescript
    // 加载背景图
    const background = await this.loadImage(
      `/maps/${mapId}/background.png`
    );
    
    // 加载JSON配置
    const config = await this.loadJSON(
      `/maps/${mapId}/config.json`
    );
    
    // 加载精灵图集
    const sprites = await this.loadSpriteSheet(
      `/maps/${mapId}/sprites.png`
    );
    
    return { background, config, sprites };
  }
}
```

### 动画系统
```typescript
class AnimationSystem {
  // 补间动画
  tween(from: number, to: number, duration: number): Animation {
    return new Tween({
      from,
      to,
      duration,
      easing: Easing.easeInOutCubic
    });
  }
  
  // 移动动画
  moveEntity(entity: Entity, to: Position): Promise<void> {
    return this.tween(entity.position, to, 500)
      .onUpdate(pos => entity.setPosition(pos))
      .play();
  }
  
  // 效果动画
  showDamage(target: Entity, amount: number): void {
    const text = new FloatingText(`-${amount}`, {
      color: 'red',
      fontSize: 24,
      duration: 1000,
      trajectory: 'float-up'
    });
    text.spawn(target.position);
  }
}
```

这个UI系统的设计核心是：**简洁、清晰、响应式，让复杂的规则通过直观的视觉呈现变得容易理解。**
