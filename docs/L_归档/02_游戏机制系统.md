# 游戏机制系统

## 行动点（AP）系统

### 基础概念
- **AP（Action Point）是游戏的唯一时间货币**
- 1 AP = 1 个离散行动
- 玩家通过投点获得每回合的AP

### 投点机制设计

#### 核心规则：最高点差距结算法
所有人同时投掷1颗6面骰（可加体力修正），根据与最高点的差距获得AP：

- **差距为0（并列或唯一最高）**
  - 大胜（领先第二名2点或以上）：获得 **3 AP** *(罕见爆发)*
  - 小胜/并列（领先1点或并列第一）：获得 **2 AP** *(中等优势)*
  
- **差距为1（比最高点少1点）**
  - 紧跟（虽败犹荣）：获得 **1 AP** *(最常见的常态)*
  
- **差距≥2（比最高点少2点及以上）**
  - 掉队：获得 **0 AP** *(本回合无法行动)*

#### 概率分布（3人局，无体力修正）
- 获得 1 AP 的概率 ≈ 32.4%（接近 1/3）
- 获得 2 AP 的概率 ≈ 28.2%（接近 2/9）
- 获得 3 AP 的概率 ≈ 13.9%（接近 1/9）
- 获得 0 AP 的概率 ≈ 25.5%（约 1/4）

**设计意图**：这个简单的"看差距"规则，天然跑出了童年时最舒服的数学曲线

### 体力系统（可选模块）

#### 体力槽
- 初始上限：4点
- 每回合结束自动回复1点体力（上限4）

#### 强力骰
投骰前可以选择消耗体力：
- 消耗1体力 = 骰子结果 +1 修正
- 消耗2体力 = 骰子结果 +2 修正

#### 零挫败退还机制
- 如果结算后获得的AP为0（掉队了）
- **本回合消耗的体力全额退回**
- 设计妙处：玩家永远不会觉得"白花了资源"

### 特殊变体（可选）

#### 自然6奖励
- 投出自然6（未修正）：无论是否最高，额外+1 AP
- 如果是最高者且投出6：2+1=3 AP
- 概率：约17%

## AP经济学原则

### 统一价值货币
在游戏系统中，**时间（AP）= 空间（节点数）= 资源（武器/状态）**

### 路径设计原则
**从出生到拿到武器需要多少AP，是否配得上武器强度**

示例：
- 常规路径：出生点 → (3 AP) → 普通武器库 → 获得2伤手枪
- 风险路径：出生点 → (2 AP) → 危险微型场景 → (1 AP) → 获得3伤重武器（但回程需要多花AP）

### AP消耗类型

#### 付费动作（1 AP）
- 移动到相邻节点
- 拾取一个物品
- 使用武器攻击
- 整理背包（一揽子重排）
- 上车/下车
- 举盾格挡
- 进入对峙状态

#### 零费动作（0 AP）
必须依附于付费动作触发，不能独立执行：
- 丢弃物品（依附于移动等动作）
- 使用背包中的消耗品
- 某些被动触发效果

#### 成本修正
- 重型武器/负重：大场景移动 +1 AP
- 载具加速：大中场景移动可能 -1 AP（两节点算1 AP）

## 回合与时序系统

### 回合结构
1. **投点阶段**：所有玩家同时投骰并消耗体力（如果使用）
2. **结算阶段**：根据差距分配AP，体力退还判定
3. **行动阶段**：按获得AP从高到低依次行动（或同时规划）
4. **回合结束**：恢复1点体力，触发持续效果

### 行动顺序
- 获得AP多的玩家优先行动
- 相同AP时按投骰点数决定（或随机）【时序系统还未设计完备，记录。目前想法是按照修正后投点确定顺序，但相等时还要考虑】
- 每个玩家花完自己的AP后轮到下一位

### 时序纯洁性原则
- **禁止回合外选择**：不在自己回合的玩家不能做主动抉择
- **被动必须自动结算**：所有触发效果都是确定性的
- **零费动作不产生搜索分支**：AI和玩家不需要为零费动作单独决策

## 持续效果系统

### 状态表示
所有持续效果用标准格式表示：
```
[状态名称]
- 效果：具体影响
- 持续：X回合
- 打断条件：特定事件或状态
```

### 常见状态示例

#### 负面状态【这些未定，作为大逃杀的重要原型模式必须精选，如无必要不增机制】
- **[中毒]**：每回合开始扣1点生命，持续3回合
- **[燃烧]**：持续1回合，结束时对同微型场景造成3伤害
- **[冰冻]**：限制移动动作，持续2回合，受到火焰伤害解除
- **[迟缓]**：特定动作额外消耗1 AP，持续X回合
- **[虚弱]**：伤害输出-1，持续2回合
- **[倒地]**：不能移动，可以爬行。1ap站起。

#### 正面状态
- **[格挡]**：免疫下一次伤害，持续到下回合开始
- **[加速]**：移动消耗-1 AP（最低0），持续2回合
- **[隐蔽]**：在中型场景不需要被"找到"，持续到移动

#### 环境状态
- **[淋湿]**：重型buff移动惩罚加倍，持续3回合，被火焰效果打断
- **[辐射]**：每回合扣1点生命，无持续限制（区域效果）

### 状态交互规则
- 同名状态不叠加，取最长持续时间
- 特定状态之间有克制关系（如火焰解除冰冻）
- 某些状态会阻止其他状态生效

## 生命值系统

### 基础设定
- 标准生命值上限：**5点**
- 所有伤害和治疗数值：1-5之间
- 生命值归零即淘汰（具体规则由玩法包定义）

### 伤害类型（可选扩展）【深入点2】
- 直接伤害：普通攻击
- 持续伤害：中毒、燃烧
- 坠落伤害：跳窗、翻越
- 环境伤害：陷阱、爆炸

### 治疗机制
- 使用医疗物品：恢复1-2点生命
- 特定地点休息：每回合恢复1点
- 不会自然恢复（除非规则指定）

## 特殊机制模块

### 校园广播（赛季内容示例）
- **触发**：每3回合
- **效果**：随机大场景，暴露该区域所有玩家位置
- **实现**：监听OnTurnStart事件，condition: current_turn % 3 == 0

### 教导主任（NPC示例）
- **类型**：移动的动态障碍/动态微型场景
- **行为**：每回合朝最近的玩家移动1节点
- **交互**：遇到教导主任触发惩罚（如没收武器标签的物品）

### 为什么"替身使者"拓展失败
- 引入了第二状态源（替身的血量、距离、朝向、技能）
- 玩家的心智负荷直接翻倍（超出了5并列原则）
- 需要管理两套平行的状态机

## 机制设计验证清单

添加新机制前检查：
1. ✅ 是否符合"五并列原则"？
2. ✅ 是否能用现有系统复用实现？
3. ✅ 是否增加了新的状态类型？
4. ✅ 玩家能否在3秒内理解？
5. ✅ 是否破坏了回合纯洁性？
6. ✅ AI能否自动适配？
