## 归档原因

`.kiro/steering/` 下的文件是早期并行作战阶段的**活体执行状态**（Wave 波次计划、紧急修复流水账、并行锁定），在 Wave 0 完成、阶段推进后它们已从「仍需持续读取的行动指南」降级为「已落地、仅供追溯的历史记录」。继续在 steering 目录承载这些内容会让新会话误以为它们仍是当前约束。
