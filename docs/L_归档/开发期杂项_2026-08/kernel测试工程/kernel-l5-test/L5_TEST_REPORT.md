## 修复的缺陷

1. **查询过滤变量不能解析**：过滤表达式内的普通字段和 `$.field` 原先无法一致地指向当前元素。现在查询上下文会绑定当前元素为 `$`，且其对象字段优先于外层同名变量。
2. **非有限数校验未接入求值路径**：`checkFinite` 原先未用于表达式结果。现在拒绝 `Infinity`、`NaN`、算术溢出及非有限变量，并维持错误码 `E_EXPR_TYPE`。
3. **短路表达式结果不稳定**：`&&` / `||` 现在不求值被短路的右操作数，并始终返回布尔值。
4. **聚合字段访问不完整**：`sum` 现在支持 `$`（元素自身）和点路径字段（如 `stats.attack`），并拒绝非数值与非有限聚合值。
5. **fast-check v4 参数兼容性**：属性测试改用约束对象形式，例如 `fc.integer({ min, max })`，避免范围参数被忽略。
