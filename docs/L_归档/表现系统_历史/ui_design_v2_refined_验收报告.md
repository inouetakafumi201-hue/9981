## 一、精修目标

对 V2-B 进行**局部精修**，保持布局完全不变，仅改进以下两点：

1. **轮次栏背景改为半透明**：左侧轮次栏从纯黑背景改为半透明深色遮罩，浮动在地图之上，不挤压地图展示区域
2. **移除状态图标**：角色头顶的 ✖️ 和 ◆ 标记移除（后期容易加，先保持画面干净）

## 三、技术实现记录

### 精修方法

- **工具**：gpt-image-2 图生图 (image-to-image editing)
- **API 端点**：`https://apiclaude.cc/v1/images/edits`
- **输入图像**：`run/ui-mockup/v2/ui_v2_B.png` (1536×1024, 2.0MB)
- **输出图像**：`run/ui-mockup/v2-refined/ui_v2_refined_20260815_175907.png` (1536×1024, 2.4MB)
- **提示词长度**：1629 字符

### 提示词策略

强调 **MINIMAL CHANGES**（最小化改动）：
1. 明确指出只改两处（轮次栏透明度 + 移除状态图标）
2. 列出"Keep everything else EXACTLY the same"清单（布局/动作栏/骰子/角色/地图）
3. 标注"This is an IMAGE REFINEMENT task, not a complete redesign"
4. 具体给出透明度目标值：`rgba(10, 15, 25, 0.85)`

### 生成参数

```json
{
  "provider": "gpt-image-2",
  "api_endpoint": "https://apiclaude.cc/v1/images/edits",
  "method": "image-to-image",
  "input_format": "multipart/form-data",
  "fields": {
    "image": "source.png (binary)",
    "prompt": "MODIFY THIS UI DESIGN IMAGE WITH MINIMAL CHANGES...",
    "model": "gpt-image-2",
    "size": "1792x1024",
    "n": 1
  },
  "response_format": "b64_json"
}
```
