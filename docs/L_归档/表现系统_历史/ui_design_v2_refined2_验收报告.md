## 三、微小瑕疵（不影响设计意图传达）

项目所有者确认以下瑕疵**不需要继续精修**，因为已经足够指导 AI，后期实现时可以轻松微调：

### 📝 瑕疵1：投点数值超出规则范围
- **现状**：显示11点（超出D6的1-6范围）
- **实际规则**：强力骰投点范围应为1-6
- **不影响原因**：视觉上完美展示了"长度∝投点大小"的核心设计意图
- **后期微调**：实现时使用真实投点范围1-6

### 📝 瑕疵2：横条为平滑渐变，未保持格子状分段
- **现状**：横条是平滑的彩色渐变条
- **理想状态**：横条应为格子状分段（类似左侧轮次栏的HP/SP格子条）
- **不影响原因**：颜色和长度的对比关系已经非常清晰，设计意图完整传达
- **后期微调**：实现时改为格子状分段横条
