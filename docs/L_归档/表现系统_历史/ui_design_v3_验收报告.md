## 三、视觉风格评估

### 像素风 + 简笔画叠加（核心定位）

- **前景**：角色/武器/道具使用 32×32 或 64×64 高饱和像素艺术
- **背景**：地图场景使用低饱和简笔画风格（清爽线条 + 浅色填充）
- **叠加效果**：前后景对比鲜明，交互元素一目了然，符合 UGC 友好/数据轻量原则

### 颜色语义映射（严格执行）

- **红色**：HP（生命值条）
- **蓝色**：SP（体力/清醒度条）+ 💧 体力消耗图标
- **橙色**：AP（行动点）+ ◆ AP 消耗图标
- **紫色**：逆转状态（顶部逆转横条）
- **绿色**：可用/选中动作（右下绿色边框技能）
- **灰色**：不可用/待命（左侧 5-8 号灰化玩家）
