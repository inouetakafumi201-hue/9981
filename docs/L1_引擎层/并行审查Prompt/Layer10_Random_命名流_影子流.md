## 目标
按照**哲学宪法**原则，对内核Spec第10章（随机数系统）进行原则性彻查。

## 宪法铁律

### 核心约束
- 随机流必须有**名字**，保证可复现
- AI搜索使用**影子流**，与主世界解耦
- 确定性是内核的**铁律**，随机也不例外

### 完备性判据
Random能力必须满足：
| 判据 | 含义 |
|------|------|
| 不可绕过 | 缺了它无法表达"不确定性" |
| 三处复用 | 战斗骰/技能效果/事件触发都需要 |
| 不含语义 | 它不知道骰子代表什么 |

## 第10层审查清单

### 10.1 命名流机制

#### 流管理
```typescript
interface RandomStream {
  name: string                    // 流名称，全局唯一
  seed: number                    // 初始种子
  state: Uint32Array              // 当前内部状态
  consumed: number                // 已消耗随机数数量
}
```
- [ ] 每个命名流是否独立seed？
- [ ] 流是否在Playpack加载时创建？
- [ ] 流是否可以嵌套（子流）？
- [ ] `consumed`是否用于诊断/重放？

#### 随机操作
- [ ] `roll(sides, stream?)`是否走命名流？
- [ ] `pick(array, stream?)`是否走命名流？
- [ ] `shuffle(array, stream?)`是否走命名流？
- [ ] 同一seed是否产生同一序列？

### 10.2 影子流（AI搜索）

#### 隔离机制
```typescript
interface ShadowContext {
  streams: Map<string, RandomStream>  // 影子随机流
  snapshots: Map<string, WorldSnapshot> // 影子状态快照
}
```
- [ ] AI搜索是否使用独立的影子流？
- [ ] 影子流的seed是否确定？（与主流同seed派生？）
- [ ] 搜索回退时流状态是否恢复？
- [ ] 影子流是否完全隔离（不污染主流）？

#### 同步机制
- [ ] AI决策采纳后影子流是否合并？
- [ ] 合并策略是否明确？（取第一个可行解？）
- [ ] 合并失败是否回滚？

### 10.3 与其他层的关系

#### 与Flow的关系
- [ ] step预算是否包含随机操作？
- [ ] 影子流搜索是否消耗step预算？

#### 与Transaction的关系
- [ ] 事务回滚时随机流状态是否恢复？
- [ ] 嵌套事务是否正确处理流状态？

#### 与Persistence的关系
- [ ] save/load是否保存流状态？
- [ ] 回放是否使用相同的流状态序列？

### 10.4 常见随机模式

#### 战斗骰
- [ ] `roll(20)`是否走命名流？
- [ ] 暴击/大失败是否有Hook介入？

#### 技能效果
- [ ] "50%几率眩晕"如何实现？
- [ ] 多次独立roll是否使用同一流？

#### 事件触发
- [ ] 随机事件是否走全局流？
- [ ] 事件与战斗流是否分离？

## 决策记录检查

| 决策 | 理由 | 风险 |
|------|------|------|
| 命名流 | 可复现/可诊断 | 低 |
| 影子流隔离 | AI搜索需要可回退 | 中 |
| 流状态可序列化 | 支持存档/回放 | 低 |
| 种子派生影子流 | 保证搜索与执行一致性 | 低 |

## 思维实验清单

### 边界情况
1. "固定种子"游戏如何实现？（固定所有命名流的seed）
2. AI在影子流中roll出20，是否一定在主世界roll出20？
3. 两个玩家同时roll，如何保证确定性？（使用相同的流）

### 反模式检测
1. 能否通过猜测seed预测未来随机数？
2. 能否通过重置流状态实现"读档重roll"？
3. 能否通过影子流漏洞获取主世界随机信息？

### 扩展性测试
1. 能否支持"加权随机"（不等概率pick）？
2. 能否支持"高斯分布"（非均匀roll）？
3. 能否支持"实时随机"（不通过命名流）？

## 注意事项
- 随机是确定性的伪装，不是真正的"不确定性"
- 命名流是实现可复现性的机制
- 影子流是实现AI搜索安全性的机制
