## 目标
按照**哲学宪法**原则，对内核Spec第12章（持久化与回放）进行原则性彻查。

## 宪法铁律

### 核心约束
- snapshot是**状态的完整序列化**，不是差异存储
- replay是**Op序列的精确重放**，不是状态回放
- rewind是**snapshot之间的跳转**，需要状态插值

### 完备性判据
Persistence能力必须满足：
| 判据 | 含义 |
|------|------|
| 不可绕过 | 缺了它无法存档/回放/AI搜索 |
| 三处复用 | 存档/回放/调试都需要 |
| 不含语义 | 它不知道存的是什么游戏 |

## 第12层审查清单

### 12.1 快照机制

#### 序列化
```typescript
interface WorldSnapshot {
  version: string                  // 格式版本
  timestamp: number                // 快照时间
  phase: PhaseId                   // 当前相位
  step: number                     // 当前step
  entities: Map<EntityId, Entity>  // 所有实体
  attachments: Attachment[]        // 所有附件
  transactions: Transaction[]      // 未完成事务
  randomStreams: Map<string, RandomStreamState>
  knowledge: Map<AgentId, KnowledgeState>
}
```
- [ ] 所有结构区字段是否可序列化？
- [ ] Ref在序列化后是否有效？（ID引用 vs 指针）
- [ ] 循环引用如何处理？（Entity A引用B，B引用A）
- [ ] `version`是否用于迁移？

#### 增量快照
- [ ] 是否支持增量checkpoint？（节省空间）
- [ ] 增量与全量快照的边界？（何时强制全量）
- [ ] 快照大小是否有上限？（防止磁盘撑爆）

### 12.2 回放机制

#### 精确性
- [ ] 回放是否产生**完全相同**的状态？
- [ ] 随机操作是否使用**相同seed**？
- [ ] 时间戳是否精确记录？（毫秒级）
- [ ] 浮点数精度是否一致？（避免NaN/Inf问题）

#### 性能
- [ ] 大型对局（10000+回合）回放是否可行？
- [ ] 是否支持快进/快退？（跳跃到指定快照）
- [ ] 回放中是否可以切换视角？（不同Agent的Knowledge）

#### Op序列
- [ ] Op序列是否完整记录？（无遗漏）
- [ ] 嵌套Op是否扁平化或嵌套记录？
- [ ] Op序列与快照是否对齐？

### 12.3 重演（AI搜索）

- [ ] 重演是否使用影子流？（与主世界隔离）
- [ ] 重演是否修改主世界状态？（不应该）
- [ ] 重演回溯是否恢复**所有**副作用？
- [ ] 重演是否记录评估函数的调用？

### 12.4 迁移机制

#### 版本升级
```typescript
interface Migration {
  fromVersion: string
  toVersion: string
  transform: (snapshot: WorldSnapshot) => WorldSnapshot
}
```
- [ ] 版本升级时如何迁移数据？
- [ ] 迁移是否可逆？（一般不可逆）
- [ ] 迁移失败是否有回退？（保留原快照）
- [ ] 旧版本快照是否长期支持？

#### 向后兼容
- [ ] 新增字段是否有默认值？
- [ ] 删除字段是否被忽略？
- [ ] 类型变更是否安全？

## 决策记录检查

| 决策 | 理由 | 风险 |
|------|------|------|
| 快照包含所有状态 | 完整性与一致性 | 低 |
| Op序列独立存储 | 精确回放 | 低 |
| 版本字段 | 迁移支持 | 低 |
| 增量快照支持 | 空间优化 | 中 |

## 思维实验清单

### 边界情况
1. "从第10回合开始重放"如何实现？（快照+Op序列拼接）
2. 快照中是否包含AI的思考过程？（不包含，只含决策结果）
3. 存档损坏如何检测和报告？（checksum校验）

### 反模式检测
1. 能否通过修改Op序列实现作弊？
2. 能否通过回放漏洞获取AI决策信息？
3. 能否通过快照注入恶意代码？

### 扩展性测试
1. 能否支持"云存档"（远程存储快照）？
2. 能否支持"增量Op序列"��只记录差异）？
3. 能否支持"压缩快照"（节省空间）？
