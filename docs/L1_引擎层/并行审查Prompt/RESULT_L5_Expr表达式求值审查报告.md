**Spec空白**：

| 比较场景 | Spec状态 |
|----------|----------|
| null == null | ✅ 明确为 true |
| null != null | ❌ 未定义 |
| null == 0 | ❌ 未定义 |

**选项分析**：

| 方案 | 行为 | 优点 |
|------|------|------|

```
- null == 任何非 null 值 → false
- 这与 SQL 三值逻辑的 UNKNOWN 不同，采用确定性语义
```
