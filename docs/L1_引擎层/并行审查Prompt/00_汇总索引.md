## 执行流程

1. **创建审查会话**：为每个批次创建独立的Claude会话
2. **分发Prompt**：复制对应批次的Prompt到各会话
3. **并行执行**：各会话同时执行审查
4. **收集报告**：汇总所有审查报告
5. **生成汇总**：按模板生成最终汇总报告

## 注意事项

1. **依赖关系**：批次内可并行，批次间必须按顺序
2. **已知修复**：需验证第十轮、第十一轮的修复是否完整 —— 已验证通过，见
   `ENGINE_KERNEL_13LAYER_REVIEW_SUMMARY.md` §2.3
3. **输出标准**：每个Prompt的输出必须包含宪法合规性矩阵、决策记录、风险项、思维实验结论
4. **质量标准**：通过标准为高风险项=0，中风险项≤3
   - **高风险项 = 0：✅ 达成**（H-1/H-2/H-3 规范文本已合并入 Spec）
   - **中风险项 ≤ 3：❌ 未达成** —— 实际 13 项（M-1 ~ M-13）全部开放，
     见 [`00_开放事项跟踪.md`](00_开放事项跟踪.md) §1.1。
     此外低风险 18 项（L-1 ~ L-18）亦全部开放。
     该门禁未达成不影响已完成的 13 层属性实测结论（两者判定对象不同：门禁看设计风险清单，
     实测看运行时不变量），但**不应把本目录当作"已全部通过"来引用**。
