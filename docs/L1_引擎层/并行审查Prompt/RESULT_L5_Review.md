## 审查摘要

本次审查对内核Spec第3章（Expr）的47条边界测试用例进行了逐一推演。审查发现：

- **PASS**：21条（规则明确且正确）⚠️ 与文末统计表的 19 条矛盾
- **UNDEF**：26条（Spec未明确定义）⚠️ 与文末统计表的 28 条矛盾
- **FAIL**：0条（无错误）

**关键发现**：
1. Spec §3.1对算术运算的类型规则、错误处理机制描述不完整
2. 缺少浮点数精度、溢出行为、运算符优先级的明确定义
3. 缺少null与其他类型的比较规则
4. 缺少表达式副作用、递归、复杂度限制的明确边界

### L5-EXPR-003：除零错误

**判定**：UNDEF

**原因**：
§3.1第538行明确写道："`/` 除零返回 `null`，不抛。"

这与测试用例的期望不一致。测试用例期望：
- ✅ 求值失败
- ✅ 错误码 == E_EXPR_DIV_ZERO

但Spec规定除零返回null，不是错误。

**建议**：
明确除零行为。选项：
- 选项A：返回null（当前Spec）
- 选项B：返回错误E_EXPR_DIV_ZERO（测试期望）

**Spec引用**：§3.1第538行
