## 修复建议

### P0 - 立即补充

1. **补充null传播规则**（§3.1）
   ```
   规则：null参与算术运算时返回null
   规则：null参与逻辑运算时视为false（或报错）
   规则：null比较：null == null为true，null == 其他为false
   ```

2. **明确类型系统**（§3.1）
   ```
   规则：算术运算仅接受number类型
   规则：逻辑运算仅接受boolean类型
   规则：类型不匹配时返回E_EXPR_TYPE
   ```

3. **定义未绑定变量**（§3.1或§5）
   ```
   规则：访问未绑定变量返回E_EXPR_UNBOUND_VAR
   规则：Linter在加载期检查所有变量引用
   ```

### P1 - 本周补充

4. **明确浮点数行为**（§1.1）
   ```
   规则：采用IEEE 754双精度浮点数
   规则：精度损失是预期行为，不报错
   ```

5. **明确查询纯度**（§3.2）
   ```
   规则：查询是纯读操作，禁止副作用
   规则：where/orderBy表达式不允许emit/Op调用
   ```

6. **明确变量类型系统**（§5）
   ```
   规则：动态类型，变量可改变类型
   规则：每次赋值时检查右值的类型有效性
   ```

### P2 - 后续补充

7. 补充运算符表（幂运算、位运算）
8. 定义溢出行为
9. 定义查询性能约束
